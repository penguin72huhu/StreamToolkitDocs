# กระดานการสนับสนุน

แสดงรายการการสนับสนุนล่าสุดบนสตรีม: ไอคอนแพลตฟอร์ม ชื่อผู้สนับสนุน จำนวนเงิน และข้อความ

## URL ซอร์ส OBS

```
http://127.0.0.1:7272/sponsors
```

คัดลอก URL จากด้านบนของหน้า **ตั้งค่ากระดานการสนับสนุน** แล้วเพิ่มลงใน OBS เป็นซอร์สเบราว์เซอร์ ดู [วิธีเพิ่มซอร์สใน OBS](../getting-started/obs-source)

ใช้สวิตช์ข้าง **กระดานการสนับสนุน** ในแถบด้านซ้ายเพื่อแสดงหรือซ่อนกระดานใน OBS เมื่อปิดอยู่ กระดานจะค่อย ๆ จางหายไป การสนับสนุนยังคงถูกบันทึกแม้ปิดอยู่

## แท็บตั้งค่า

### แพลตฟอร์มที่เชื่อมต่อ

ติ๊กเลือกแพลตฟอร์มที่จะบันทึกการสนับสนุน: **Twitch**, **YouTube**, **PayPal**, **Stripe**, **O'Pay**, **ECPay** จุดสีเขียวหมายถึงแพลตฟอร์มนั้นเชื่อมต่อแล้ว มิฉะนั้นแถวนั้นจะแสดง **(ยังไม่ได้เชื่อมต่อ)** ช่องติ๊กเหล่านี้มีผลเฉพาะกับกระดานเท่านั้น ไม่มีผลกับแถบเป้าหมายการสนับสนุนหรือการแจ้งเตือนการสนับสนุน

**Twitch ⚙️** (แสดงเมื่อเชื่อมต่อ Twitch และติ๊กเลือกไว้):

1. เลือก **นับ Bits และการสมัครสมาชิก**, **นับเฉพาะ Bits** หรือ **นับเฉพาะการสมัครสมาชิก**
2. **นับการต่ออายุสมาชิก**: จะบันทึกการต่ออายุสมาชิกหรือไม่ (แสดงเมื่อนับการสมัครสมาชิก)
3. **ต่ำกว่า [N] Bits จะไม่ถูกนำมานับ**: ติ๊กเลือกแล้วใส่จำนวนขั้นต่ำ เพื่อไม่ให้บันทึก Cheer จำนวนน้อย (แสดงเมื่อนับ Bits)
4. คลิก **บันทึก**

**YouTube ⚙️**:

- **แสดงชื่อผู้ชมแทน @แฮนเดิล**: ใช้ได้หลังจากลงชื่อเข้าใช้ด้วย Google เท่านั้น
- **รายการที่นับ**: **Super Chat**, **Super Sticker**, **สมาชิกใหม่**, **ต่ออายุสมาชิก**, **สมาชิกที่มอบให้**, **อัญมณี** โดย **อัญมณี** ต้องลงชื่อเข้าใช้ Google ของขวัญอัญมณีจะแสดงเป็นไอคอนอัญมณีพร้อมจำนวนอัญมณีแทนจำนวนเงิน

หากแชทสดของ YouTube ยังไม่ได้เชื่อมโยง แถวนั้นจะแสดง **ยังไม่ได้เชื่อมต่อ URL ห้องแชท** พร้อมปุ่ม **เชื่อมต่ออัตโนมัติ** (ต้องลงชื่อเข้าใช้ Google) และ **กรอกเอง** (พาไปที่ช่อง URL แชทในหน้าตั้งค่า) หากติ๊กเลือกรายการสมาชิกไว้แต่ยังไม่ได้ตั้งราคาสมาชิก ให้คลิก **⚠ ยังไม่ได้ตั้งราคาสมาชิก** เพื่อไปตั้งค่า ดู [การตั้งค่า YouTube](../platforms/youtube-settings)

หากต้องการเชื่อมต่อ PayPal, Stripe, O'Pay หรือ ECPay ดู [PayPal](../payments/paypal), [Stripe](../payments/stripe), [O'Pay](../payments/opay) และ [ECPay](../payments/ecpay)

### ตั้งค่า

| ฟิลด์ | คำอธิบาย |
|-------|-------------|
| **แปลงเป็นสกุลเงินของตนเองอัตโนมัติ** | เปิดเป็นค่าเริ่มต้น แสดงจำนวนเงินที่แปลงเป็น **สกุลเงินสำหรับการสนับสนุน** ที่ตั้งไว้ในหน้าตั้งค่า |
| **แสดงสูงสุด** | จำนวนรายการที่เก็บไว้ (1–100) ค่าเริ่มต้น: 20 เมื่อมีการสนับสนุนใหม่เข้ามาเกินขีดจำกัดนี้ รายการที่เก่าที่สุดจะถูกลบออก |

## แท็บรูปลักษณ์

### ตัวอย่าง

ใช้ตัวเลือกสีข้าง **ตัวอย่าง** เพื่อเปลี่ยนพื้นหลังของตัวอย่าง คลิก **ทดสอบแอนิเมชันการเพิ่ม** เพื่อเล่นแอนิเมชันการปรากฏด้วยรายการตัวอย่าง รายการตัวอย่างจะไม่ถูกบันทึกลงในประวัติ

คลิก **คืนค่าเริ่มต้น** เพื่อคืนรูปลักษณ์เริ่มต้น

### การตั้งค่าการแสดงผล

- **แสดง icon แพลตฟอร์ม**: แสดงไอคอนของแพลตฟอร์มบนแต่ละรายการ
- **ทิศทางการปรากฏ**: **บนลงล่าง** (ค่าเริ่มต้น), **ล่างขึ้นบน**, **ซ้ายไปขวา** หรือ **ขวาไปซ้าย**

### ฟอนต์

ตั้งค่าฟอนต์ สี และขนาด (8–72 px) สำหรับ **ชื่อเรื่อง** (ชื่อผู้สนับสนุน), **เนื้อหา** (ข้อความ) และ **จำนวนเงิน**

### สีพื้นหลัง

- **ค่าเริ่มต้น**: สีพื้นหลังสำหรับทุกรายการ
- **+ เพิ่มช่วง**: เพิ่มสีพร้อมช่วง **จำนวนเงิน** (**ต่ำสุด** ~ **สูงสุด**) รายการที่จำนวนเงินอยู่ในช่วงนั้นจะใช้สีนั้นแทน เว้นต่ำสุดหรือสูงสุดว่างไว้หากไม่ต้องการจำกัดด้านนั้น คลิก **✕** เพื่อลบช่วง

เมื่อเปิด **แปลงเป็นสกุลเงินของตนเองอัตโนมัติ** อยู่ ช่วงจะถูกเปรียบเทียบกับจำนวนเงินที่แปลงแล้ว

### CSS กำหนดเอง

ขยาย **CSS กำหนดเอง** เพื่อแก้ไข CSS ของกระดาน **คืนค่าเริ่มต้น** จะคืนค่า CSS เริ่มต้น และ **จัดการวัสดุ** จะเปิดตัวจัดการวัสดุ ยังสามารถใช้ธีมจาก Steam Workshop ได้ที่นี่ ระหว่างที่ใช้ธีมอยู่ CSS จะเป็นแบบอ่านอย่างเดียว ดู [ธีม](./themes)

## แท็บประวัติ

### เพิ่มด้วยตนเอง (สำหรับทดสอบ)

เลือกแพลตฟอร์ม ใส่ **ชื่อ**, **จำนวนเงิน** และ **ข้อความ (ไม่บังคับ)** แล้วคลิก **เพิ่ม** รายการจะถูกเพิ่มเฉพาะเมื่อแพลตฟอร์มนั้นถูกติ๊กเลือกไว้ใน **แพลตฟอร์มที่เชื่อมต่อ** เท่านั้น จำนวนเงินจะถือเป็นสกุลเงินสำหรับการสนับสนุนของคุณ

### ประวัติ

แสดงรายการที่บันทึกไว้พร้อมจำนวนรายการ

- คลิก **🗑** แล้วคลิก **ยืนยันการลบ** เพื่อลบหนึ่งรายการ
- คลิก **ล้าง** เพื่อลบรายการทั้งหมด จะมีการยืนยันก่อน และไม่สามารถย้อนกลับได้

:::info เวอร์ชันทดลองใช้งาน
CSS กำหนดเองใช้ได้เฉพาะในเวอร์ชันเต็มเท่านั้น ระบบชำระเงินจริง (PayPal / Stripe / O'Pay / ECPay) รวมถึงรายการสมาชิกและอัญมณีของ YouTube ใช้ไม่ได้ในเวอร์ชันทดลองใช้งาน และกระดานจะมีลายน้ำใน OBS ดู [การเปรียบเทียบเวอร์ชันทดลอง / เวอร์ชันเต็ม](../getting-started/trial-comparison)
:::

## คำถามที่พบบ่อย

**Q: การแจ้งเตือนทดสอบไปปรากฏบนกระดาน**
**ทดสอบการแจ้งเตือน** ในหน้าตั้งค่าจะถูกจัดการเหมือนการสนับสนุนจริง จึงถูกบันทึกที่นี่ด้วยหากติ๊กเลือกแพลตฟอร์มนั้นไว้ ลบได้ในแท็บ **ประวัติ**
