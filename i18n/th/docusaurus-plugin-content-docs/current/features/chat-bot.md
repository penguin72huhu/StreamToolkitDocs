# แชทบอท

โพสต์ข้อความในแชทของคุณโดยอัตโนมัติ: ข้อความตั้งเวลาตามช่วงเวลาที่กำหนด และการตอบกลับตามคีย์เวิร์ดเมื่อผู้ชมพิมพ์คำสั่ง บอทจะโพสต์ด้วยบัญชีของคุณเอง

แชทบอทไม่มีโอเวอร์เลย์สำหรับ OBS จึงไม่มี URL ที่ต้องเพิ่ม

:::tip
เปิดสวิตช์ข้าง **แชทบอท** ในเมนูด้านซ้าย ระหว่างที่ปิดอยู่ บอทจะไม่ส่งอะไรเลย
:::

หน้านี้มีสามแท็บ: **ตั้งค่า**, **ข้อความตั้งเวลา** และ **ตอบกลับตามคีย์เวิร์ด**

## แท็บตั้งค่า

ในส่วน **แพลตฟอร์ม** คลิก **Twitch** เพื่อเปิดใช้งาน (คลิกอีกครั้งเพื่อปิด) จุดข้าง ๆ จะสว่างขึ้นเมื่อเชื่อมต่อ Twitch แล้ว มิฉะนั้นจะแสดง **(ยังไม่ได้เชื่อมต่อ)** ให้เชื่อมต่อ Twitch ก่อน: [การตั้งค่า Twitch](../platforms/twitch)

**YouTube** แสดงเป็น **เร็วๆ นี้** และยังเปิดใช้งานไม่ได้

หากยังไม่ได้เชื่อมต่อแพลตฟอร์มใด อีกสองแท็บจะแสดง "ยังไม่ได้เชื่อมต่อแพลตฟอร์มใด บอทจะไม่ส่งข้อความ" พร้อมปุ่ม **ไปที่การตั้งค่า**

## ข้อความตั้งเวลา

โพสต์ข้อความเป็นระยะระหว่างที่คุณไลฟ์

1. คลิก **+ เพิ่ม**
2. กรอก:
   - **ข้อความ**: ข้อความที่จะโพสต์ (สูงสุด 500 ตัวอักษรบน Twitch) ข้อความจะเป็นบรรทัดเดียวเสมอ: กด Enter จะไม่มีผล และการขึ้นบรรทัดใหม่ที่วางมาจะกลายเป็นช่องว่าง
   - **ช่วงเวลา**: จำนวนนาทีระหว่างการโพสต์แต่ละครั้ง (5–240 ค่าเริ่มต้น 15)
   - **แชทขั้นต่ำ**: จำนวนแชทใหม่ที่ต้องมีหลังการโพสต์ครั้งก่อนจึงจะโพสต์อีกครั้ง (0–100 ค่าเริ่มต้น 2) เพื่อไม่ให้โพสต์ซ้ำ ๆ ตอนที่แชทเงียบ
   - **แพลตฟอร์ม**: แพลตฟอร์มที่จะโพสต์
3. คลิก **บันทึก**

วิธีการโพสต์:

- โพสต์เฉพาะตอนที่สตรีมของคุณกำลังไลฟ์อยู่เท่านั้น การโพสต์ครั้งแรกจะเกิดขึ้นหลังจากเริ่มไลฟ์ไปครบหนึ่งช่วงเวลา ไม่ใช่ทันทีที่เริ่มสตรีม
- หากมีข้อความตั้งเวลาหลายข้อความถึงกำหนดพร้อมกัน จะทยอยโพสต์แทนการโพสต์พร้อมกันทั้งหมด

## ตอบกลับตามคีย์เวิร์ด

ตอบกลับเมื่อข้อความของผู้ชมขึ้นต้นด้วยคำสั่ง

1. คลิก **+ เพิ่ม**
2. กรอก:
   - **คำสั่ง**: เลือกเครื่องหมายนำหน้า (`! @ # $ % & ~`) แล้วพิมพ์คำเดียวโดยไม่มีช่องว่าง เช่น `!dc` ระบบจะจับคู่กับคำแรกของข้อความแชท โดยไม่สนตัวพิมพ์เล็ก/ใหญ่
   - **ข้อความตอบกลับ**: ข้อความที่จะโพสต์ `{user}` จะถูกแทนที่ด้วยชื่อผู้ชมที่ใช้คำสั่ง
   - **คูลดาวน์**: จำนวนวินาทีก่อนที่คำสั่งเดียวกันจะตอบกลับได้อีกครั้ง (0–3600 ค่าเริ่มต้น 5)
   - **แพลตฟอร์ม**: แพลตฟอร์มที่จะตอบกลับ
3. คลิก **บันทึก**

การตอบกลับตามคีย์เวิร์ดทำงานได้ตลอดเวลา ไม่ว่าจะไลฟ์อยู่หรือไม่

คำสั่งต้องไม่ซ้ำกับการตอบกลับตามคีย์เวิร์ดอื่น หรือคำสั่งที่ใช้อยู่แล้วใน [ขอเพลง](./song-request) หรือคีย์เวิร์ดของ [การจับรางวัล](./lottery)

## การจัดการรายการ

ในทั้งสองแท็บ แต่ละรายการจะมี:

- ช่องติ๊กทางซ้ายสำหรับเปิดหรือปิดรายการโดยไม่ต้องลบ
- แท็กแพลตฟอร์ม แท็กที่จางลงหมายถึงแพลตฟอร์มนั้นถูกปิดอยู่ในแท็บตั้งค่า
- **แก้ไข** และ **ลบ**
