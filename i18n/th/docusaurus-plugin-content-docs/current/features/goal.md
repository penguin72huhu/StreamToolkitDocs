# แถบเป้าหมาย Twitch

แสดงแถบความคืบหน้าบนสตรีมสำหรับเป้าหมายผู้ติดตาม สมาชิก และ Bits บน Twitch ของคุณ เป้าหมายแต่ละประเภทมีแถบ การตั้งค่า และ URL สำหรับ OBS ของตัวเอง

:::note ก่อนเริ่มต้น
แถบเป้าหมายนับเหตุการณ์จาก Twitch จึงต้องเชื่อมต่อบัญชี Twitch ก่อน ดู [การตั้งค่า Twitch](../platforms/twitch)
:::

## ขั้นตอนที่ 1: เลือกประเภทเป้าหมายและเพิ่มซอร์ส OBS

ที่ด้านบนของหน้า ให้เลือกประเภทเป้าหมาย: **ติดตาม**, **สมาชิก** หรือ **Bits** **URL สำหรับ OBS** ใต้ปุ่มจะเปลี่ยนตามที่เลือก คลิก **คัดลอก** เพื่อคัดลอก

| ประเภทเป้าหมาย | URL ซอร์ส OBS |
|-----------|----------------|
| **ติดตาม** | `http://127.0.0.1:7272/goal/follow` |
| **สมาชิก** | `http://127.0.0.1:7272/goal/sub` |
| **Bits** | `http://127.0.0.1:7272/goal/bits` |

เพิ่มแต่ละแถบที่ต้องการแสดงลงใน OBS เป็นซอร์สเบราว์เซอร์แยกกัน ดู [วิธีเพิ่มซอร์สใน OBS](../getting-started/obs-source) แถบเป้าหมายไม่มีเสียง จึงไม่จำเป็นต้องเปิด "ควบคุมเสียงผ่าน OBS"

:::tip
เปิดสวิตช์ข้าง **แถบเป้าหมาย Twitch** ในแถบด้านซ้ายด้วย (**เปิดการแสดงใน OBS**) ระหว่างที่ปิดอยู่ แถบจะถูกซ่อนใน OBS
:::

## ขั้นตอนที่ 2: ตั้งเป้าหมาย

การตั้งค่าทั้งหมดด้านล่างใช้กับประเภทเป้าหมายที่คุณเลือกไว้ด้านบน

- **ชื่อเรื่อง**: ข้อความชื่อเรื่องที่แสดงบนแถบ
- **เป้าหมาย**: ตัวเลขเป้าหมาย (จำนวนเต็ม ตั้งแต่ 0 ขึ้นไป)
- **ความคืบหน้า**: แสดงจำนวนปัจจุบัน เป้าหมาย และเปอร์เซ็นต์

### วิธีนับความคืบหน้า

| ประเภทเป้าหมาย | สิ่งที่เพิ่มความคืบหน้า |
|-----------|----------------------|
| **ติดตาม** | การติดตามใหม่แต่ละครั้งเพิ่ม 1 ระหว่างที่เชื่อมต่อ Twitch อยู่ จำนวนจะถูกซิงค์กับยอดผู้ติดตามทั้งหมดของช่องคุณจาก Twitch ทุก 30 วินาทีด้วย คลิก **ซิงค์** เพื่อซิงค์ทันที |
| **สมาชิก** | การสมัครสมาชิกใหม่และสมาชิกที่มอบให้ (การมอบสมาชิกหลายรายการจะเพิ่มตามจำนวนที่มอบ) การต่ออายุสมาชิกจะนับเฉพาะเมื่อเปิด **นับการต่ออายุสมาชิก** |
| **Bits** | Cheer แต่ละครั้งเพิ่มตามจำนวน Bits ที่ Cheer |

### ตัวเลือกสมาชิก

แสดงเฉพาะสำหรับ **สมาชิก**:

- **ถ่วงน้ำหนักตาม Tier (T1=+1, T2=+2, T3=+6)**: เมื่อเปิด สมาชิก Tier สูงกว่าจะเพิ่มความคืบหน้ามากกว่า เมื่อปิด สมาชิกทุกรายการเพิ่ม 1
- **นับการต่ออายุสมาชิก**: เมื่อเปิด ข้อความต่ออายุสมาชิกจะเพิ่มความคืบหน้าด้วย

### รีเซ็ตความคืบหน้า

**สมาชิก** และ **Bits** มีปุ่ม **รีเซ็ตความคืบหน้า** คลิกแล้วคลิก **ยืนยันรีเซ็ต** เพื่อตั้งจำนวนปัจจุบันกลับเป็น 0 โดยตัวเลขเป้าหมายจะยังคงอยู่

**ติดตาม** ไม่มีปุ่มรีเซ็ต เพราะจำนวนจะเป็นไปตามยอดผู้ติดตามบน Twitch ของคุณ

## ขั้นตอนที่ 3: ปรับรูปลักษณ์

### ตัวอย่าง

**ตัวอย่าง** ที่ด้านบนแสดงแถบของประเภทเป้าหมายที่เลือก ใช้กล่องสีข้าง ๆ เพื่อเปลี่ยนพื้นหลังของตัวอย่าง ติ๊กเลือก **ตัวอย่างเมื่อบรรลุ** เพื่อดูหน้าตาของแถบเมื่อบรรลุเป้าหมายแล้ว

### การตั้งค่ารูปลักษณ์

| การตั้งค่า | คำอธิบาย |
|---------|-------------|
| **สีพื้นหลัง** | พื้นหลังของแถบ |
| **สีแถบความคืบหน้า** | สีของส่วนที่เติมแล้ว |
| **สีเมื่อบรรลุเป้าหมาย** | สีเติมเมื่อบรรลุเป้าหมายแล้ว |
| **ตัวอักษรชื่อเรื่อง** | ฟอนต์ สี และขนาด (8–72 px) ของชื่อเรื่อง |
| **ตัวอักษรเป้าหมาย** | ฟอนต์ สี และขนาด (8–72 px) ของตัวเลข |
| **เปอร์เซ็นต์** | ฟอนต์ สี และขนาด (8–72 px) ของเปอร์เซ็นต์ |

คลิก **คืนค่าเริ่มต้น** เพื่อคืนรูปลักษณ์ของประเภทเป้าหมายที่เลือก

### CSS กำหนดเอง

คลิก **CSS กำหนดเอง** เพื่อขยายตัวแก้ไข เป้าหมายแต่ละประเภทมี CSS ของตัวเอง ใช้สำหรับเลย์เอาต์และโครงสร้าง ส่วนสี ฟอนต์ และขนาด ให้ตั้งค่าในการตั้งค่ารูปลักษณ์ด้านบน

- **คืนค่าเริ่มต้น**: คืนค่า CSS เริ่มต้น
- **จัดการวัสดุ**: เปิดตัวจัดการวัสดุสำหรับรูปภาพที่ใช้ใน CSS ของคุณ

หาก CSS ของคุณเขียนทับคุณสมบัติด้วย `!important` ตัวควบคุมรูปลักษณ์ที่ตรงกันจะถูกล็อก เพราะ CSS จะมีผลเหนือกว่าอยู่ดี

:::info ข้อจำกัดของเวอร์ชันทดลองใช้งาน
- **CSS กำหนดเอง** ใช้ได้เฉพาะในเวอร์ชันเต็มเท่านั้น
- โอเวอร์เลย์ OBS จะแสดงลายน้ำ

:::
