# ขอเพลง

ผู้ชมขอเพลงจาก YouTube ด้วยคำสั่งในแชท และเพลงจะเล่นใน OBS ทีละเพลง คุณยังสามารถเพิ่มเพลงเองและตั้งเพลย์ลิสต์เริ่มต้นที่จะเล่นเมื่อไม่มีคนขอเพลงได้ด้วย

## URL ซอร์ส OBS

```
http://127.0.0.1:7272/song-request
```

คลิก **คัดลอก** ข้าง **URL แหล่งที่มาสำหรับ OBS** ที่ด้านบนของหน้า แล้วเพิ่มลงใน OBS เป็นซอร์สเบราว์เซอร์ ดู [วิธีเพิ่มซอร์สใน OBS](../getting-started/obs-source)

:::warning
การขอเพลงจะมีเสียง ในคุณสมบัติของซอร์สเบราว์เซอร์ ต้องติ๊กเลือก **ควบคุมเสียงผ่าน OBS** มิฉะนั้นเพลงจะไม่ถูกส่งไปยังสตรีมของคุณ
:::

:::tip
เปิดสวิตช์ข้าง **ขอเพลง** ในเมนูด้านซ้ายด้วย คำสั่งในแชทจะถูกประมวลผลเฉพาะตอนที่สวิตช์เปิดอยู่เท่านั้น
:::

หน้านี้มีสองแท็บ: **ตั้งค่า** และ **รายการเพลง**

## แท็บตั้งค่า

### แพลตฟอร์ม

แต่ละแพลตฟอร์มมีการ์ดของตัวเอง:

- **เปิดให้ขอเพลงจากแพลตฟอร์มนี้**: ให้ผู้ชมในแชทนั้นขอเพลงได้
- **เปิดใช้งานบอทตอบในแชท** (เฉพาะ Twitch เปิดเป็นค่าเริ่มต้น): ตอบผลลัพธ์ของแต่ละคำสั่งในแชท Twitch โดยใช้บัญชี Twitch ที่คุณเชื่อมต่อไว้ แสดงเฉพาะเมื่อเปิดใช้งานและเชื่อมต่อ Twitch แล้ว

แพลตฟอร์มที่ยังไม่ได้เชื่อมต่อจะแสดง **(ยังไม่ได้เชื่อมต่อ)** (Twitch) หรือ **ยังไม่ได้เชื่อมต่อ URL ห้องแชท** (YouTube) ให้เชื่อมต่อก่อน:

- [การตั้งค่า Twitch](../platforms/twitch)
- [การตั้งค่า YouTube](../platforms/youtube-settings)

### คำสั่งในห้องแชท

| ฟิลด์ | ค่าเริ่มต้น |
|------|--------|
| **คำนำหน้าคำสั่ง** | `!` (เลือกจาก `! @ # $ % & ~`) |
| **คำสั่งขอเพลง** | `sr` |
| **ลบเพลงที่ขอ** | `remove` |
| **ดูรายการเพลงที่ขอ** | `queue` |
| **สอบถามเพลงที่เล่นอยู่** | `song` |
| **เวลาคูลดาวน์การขอเพลง** | 3000 ms |

คูลดาวน์นับแยกตามผู้ชม: หลังจากขอเพลงสำเร็จ ผู้ชมคนเดิมต้องรอตามเวลานี้ก่อนจะขอเพลงได้อีก

### ตั้งค่า

- **แสดงวิดีโอบนหน้าจอ** (เปิดเป็นค่าเริ่มต้น): เมื่อปิด วิดีโอจะถูกซ่อนใน OBS แต่เสียงยังคงเล่นอยู่
- **จำนวนสูงสุดในรายการ** (1–100 ค่าเริ่มต้น 20): จำนวนเพลงที่ขอได้สูงสุดในรายการ เพลงจากเพลย์ลิสต์เริ่มต้นไม่นับรวม
- **แสดงการแจ้งเตือนขอเพลง** (เปิดเป็นค่าเริ่มต้น): แสดงการ์ดแจ้งเตือนใน OBS เมื่อผู้ชมขอเพลง ลบเพลง หรือขอเพลงไม่สำเร็จ เมื่อเปิดอยู่ คุณสามารถตั้งค่า:
  - **X** / **Y**: ตำแหน่งของการแจ้งเตือนจากมุมซ้ายบน (px ค่าเริ่มต้น 16 / 16)
  - **ขนาดการแจ้งเตือน**: ตัวคูณขนาด (ค่าเริ่มต้น 1.0)
  - **ทดสอบรูปลักษณ์การแจ้งเตือน**: ส่งการแจ้งเตือนทดสอบไปยัง OBS

การแจ้งเตือนแต่ละรายการจะแสดงอยู่ 5 วินาที และแสดงพร้อมกันได้สูงสุด 3 รายการ

## วิธีที่ผู้ชมใช้งาน

เมื่อใช้การตั้งค่าเริ่มต้น:

| คำสั่ง | หน้าที่ |
|------|------|
| `!sr <ลิงก์ YouTube>` | ขอวิดีโอนั้น |
| `!sr <คำค้นหา>` | ค้นหาใน YouTube และขอผลลัพธ์แรก |
| `!remove` | ลบเพลงที่ผู้ชมขอล่าสุด (ไม่ใช่เพลงที่กำลังเล่นอยู่) |
| `!queue` | ตอบกลับด้วยเพลงที่ขอ 3 เพลงถัดไป |
| `!song` | ตอบกลับด้วยเพลงที่กำลังเล่นอยู่ |

- ลิงก์ที่รับได้: `youtube.com/watch?v=…`, `youtu.be/…`, `youtube.com/live/…`, `youtube.com/shorts/…` หรือ ID วิดีโอ 11 ตัวอักษร
- ไม่รับลิงก์เพลย์ลิสต์
- การขอเพลงจะล้มเหลวเมื่อรายการถึง **จำนวนสูงสุดในรายการ** แล้ว
- เพลงที่ขอใหม่จะต่อคิวหลังเพลงที่ผู้ชมคนอื่นขอ และอยู่ก่อนเพลงจากเพลย์ลิสต์เริ่มต้น
- `!queue` และ `!song` ใช้ได้เฉพาะในแชท Twitch เมื่อเปิด **เปิดใช้งานบอทตอบในแชท** อยู่เท่านั้น

## แท็บรายการเพลง

### การควบคุมการเล่น

บรรทัดบนสุดแสดงผู้ขอเพลงปัจจุบันและชื่อเพลง ปุ่ม:

- **เล่น** / **หยุดชั่วคราว**: หากไม่มีอะไรเล่นอยู่ จะเริ่มจากเพลงแรกในรายการ
- **หยุด**: หยุดการเล่น
- **เพลงถัดไป**: ข้ามไปยังเพลงถัดไป

ระหว่างที่เพลงเล่นอยู่ จะมีแถบความคืบหน้าปรากฏขึ้น ลากเพื่อข้ามไปยังตำแหน่งที่ต้องการ เมื่อเพลงจบ เพลงถัดไปจะเริ่มโดยอัตโนมัติ

:::note
จะไม่มีอะไรเล่นอัตโนมัติเมื่อเปิดโปรแกรม กด **เล่น** เพื่อเริ่ม
:::

### เพลย์ลิสต์เริ่มต้น

วาง URL เพลย์ลิสต์ YouTube แล้วเลือก **เล่นวนซ้ำ** หรือ **เล่นแบบสุ่ม** เมื่อรายการหมด เพลงจากเพลย์ลิสต์นี้จะถูกเพิ่มและเล่นโดยอัตโนมัติ เพลงเหล่านี้จะแสดงเป็น **รายการเริ่มต้น** ในรายการ

เพลย์ลิสต์เริ่มต้นจะอ่านผ่านบัญชี YouTube ของคุณ จึงต้องลงชื่อเข้าใช้ด้วย Google ใน [การตั้งค่า YouTube](../platforms/youtube-settings) ก่อน

### ขอเพลงด้วยตนเอง

วาง URL วิดีโอ YouTube แล้วคลิก **เพิ่มเข้ารายการ** (หรือกด Enter) การขอเพลงด้วยตนเองไม่รองรับคำค้นหา

### รายการ

**รายการ (n)** แสดงเพลงทั้งหมด: แพลตฟอร์ม ผู้ขอ ชื่อเพลง และ ID วิดีโอ (คลิกเพื่อเปิดบน YouTube) คลิก **ลบ** เพื่อนำเพลงออก การลบเพลงที่กำลังเล่นอยู่จะข้ามไปยังเพลงถัดไป **ล้าง** จะล้างรายการทั้งหมด

## คำถามที่พบบ่อย

**Q: ผู้ชมพิมพ์คำสั่งแล้วแต่ไม่มีอะไรเกิดขึ้น?**
ตรวจสอบว่า:
- สวิตช์ **ขอเพลง** ในเมนูด้านซ้ายเปิดอยู่
- ติ๊กเลือก **เปิดให้ขอเพลงจากแพลตฟอร์มนี้** สำหรับแพลตฟอร์มนั้นแล้ว
- สำหรับ Twitch: แชท Twitch จะถูกอ่านผ่านฟีเจอร์ [ห้องแชท](./chat) หากคุณปิด Twitch ในหน้าห้องแชท (และ [แชทบอท](./chat-bot) ไม่ได้ใช้ Twitch อยู่) จะไม่ได้รับคำสั่งจาก Twitch

**Q: เพลย์ลิสต์เริ่มต้นไม่เล่น?**
ตรวจสอบว่าคุณลงชื่อเข้าใช้ด้วย Google ในหน้าตั้งค่าแล้ว และ URL เป็นลิงก์เพลย์ลิสต์ (มี `list=` อยู่)

:::info ข้อจำกัดของเวอร์ชันทดลองใช้งาน
- การขอเพลงจากแชทของผู้ชมใช้ได้เฉพาะในเวอร์ชันเต็มเท่านั้น ในเวอร์ชันทดลองใช้งาน การขอเพลงจากแชทจะล้มเหลวพร้อมข้อความ "รุ่นทดลองไม่รองรับการขอเพลง" ส่วน **ขอเพลงด้วยตนเอง** และเพลย์ลิสต์เริ่มต้นยังใช้งานได้
- โอเวอร์เลย์ OBS จะแสดงลายน้ำ

ดู [การเปรียบเทียบเวอร์ชันทดลอง / เวอร์ชันเต็ม](../getting-started/trial-comparison)
:::
