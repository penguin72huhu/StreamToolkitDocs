# แจ้งเตือนผู้ติดตามใหม่

แสดงการแจ้งเตือนบนสตรีมเมื่อมีคนติดตามคุณบน Twitch หรือติดตามช่อง YouTube ของคุณ

## URL ซอร์ส OBS

```
http://127.0.0.1:7272/fan-alert
```

คัดลอก URL จากด้านบนของหน้า **ตั้งค่าแจ้งเตือนผู้ติดตามใหม่** แล้วเพิ่มลงใน OBS เป็นซอร์สเบราว์เซอร์ ดู [วิธีเพิ่มซอร์สใน OBS](../getting-started/obs-source)

:::warning
การแจ้งเตือนจะมีเสียง ต้องติ๊กเลือก **ควบคุมเสียงผ่าน OBS** ในคุณสมบัติของซอร์สเบราว์เซอร์ มิฉะนั้นจะไม่ได้ยินเสียงในสตรีม
:::

ใช้สวิตช์ข้าง **แจ้งเตือนผู้ติดตามใหม่** ในแถบด้านซ้ายเพื่อเปิดหรือปิดการแจ้งเตือน ระหว่างที่ปิดอยู่ ผู้ติดตามใหม่จะไม่ถูกแสดงและไม่ถูกบันทึก และปุ่มทดสอบก็จะใช้งานไม่ได้ด้วย

เมื่อมีผู้ติดตามหลายคนเข้ามาในเวลาใกล้กัน การแจ้งเตือนจะถูกเข้าคิวและแสดงทีละรายการ โอเวอร์เลย์นี้มีคิวของตัวเอง จึงไม่ต้องรอคิวต่อจาก [การแจ้งเตือนการสนับสนุน](./donate-alert)

## แท็บตั้งค่า

### แพลตฟอร์มที่เชื่อมต่อ

ติ๊กเลือกแพลตฟอร์มที่จะให้แสดงการแจ้งเตือน: **Twitch** และ **YouTube** (ติ๊กเลือกทั้งคู่เป็นค่าเริ่มต้น) จุดสีเขียวหมายถึงแพลตฟอร์มนั้นเชื่อมต่อแล้ว มิฉะนั้นแถวนั้นจะแสดง **ยังไม่ได้อนุญาต**

- **Twitch**: การติดตามใหม่ทุกครั้งจะแสดงการแจ้งเตือนทันที ให้เชื่อมต่อ Twitch ก่อน: [การตั้งค่า Twitch](../platforms/twitch)
- **YouTube**: ผู้ติดตามช่องใหม่ ให้ลงชื่อเข้าใช้ด้วย Google ก่อน: [การตั้งค่า YouTube](../platforms/youtube-settings)

วิธีค้นหาผู้ติดตามใหม่บน YouTube:

- YouTube ไม่มีเหตุการณ์ "ผู้ติดตามใหม่" แบบเรียลไทม์ โปรแกรมจึงสอบถาม YouTube ถึงผู้ติดตามล่าสุดของคุณทุก 1.5 นาที
- จะตรวจสอบเฉพาะตอนที่คุณกำลังไลฟ์และแชทสด YouTube เชื่อมต่อกับไลฟ์นั้นอยู่เท่านั้น จะไม่ตรวจสอบในห้องรอหรือหลังจากไลฟ์จบแล้ว
- คนที่ติดตามก่อนเริ่มสตรีม (เกินประมาณ 5 นาทีก่อนเริ่มตรวจสอบ) จะไม่ถูกแจ้งเตือน
- ตามที่คำแนะนำในหน้านี้ระบุไว้ **YouTube จะแจ้งเตือนเฉพาะผู้ชมที่เปิดการติดตามเป็นสาธารณะ และอาจล่าช้าหลายนาทีถึงหลายชั่วโมง**

### ตั้งค่า

| ฟิลด์ | คำอธิบาย |
|-------|-------------|
| **ระยะเวลาแสดง** | ระยะเวลาที่การแจ้งเตือนแต่ละครั้งแสดงบนหน้าจอ หน่วยเป็นวินาที (1–60) ค่าเริ่มต้น: 5 |
| **ผู้ชมคนเดิมแจ้งเตือนได้ไม่เกินวันละครั้ง (24 ชม.)** | ปิดเป็นค่าเริ่มต้น เมื่อเปิด ผู้ชมคนเดิมที่ติดตามอีกครั้งภายใน 24 ชั่วโมง (เช่น เลิกติดตามแล้วติดตามใหม่) จะไม่ถูกแสดงและไม่ถูกบันทึก |

### ทดสอบการแจ้งเตือน

คลิก **ทดสอบแจ้งเตือน (Twitch)** หรือ **ทดสอบแจ้งเตือน (YouTube)** เพื่อส่งการแจ้งเตือนตัวอย่างไปยัง OBS การแจ้งเตือนทดสอบจะไม่ถูกเพิ่มลงในประวัติ

หากปิดแจ้งเตือนผู้ติดตามใหม่อยู่ การทดสอบจะไม่เล่น และหน้านี้จะแสดง **เปิดแจ้งเตือนผู้ติดตามใหม่ในสวิตช์ด่วนก่อน**

## แท็บรูปลักษณ์

### ตัวอย่าง

ตัวอย่างใช้หน้าเดียวกับซอร์ส OBS ใช้ตัวเลือกสีข้าง **ตัวอย่าง** เพื่อเปลี่ยนพื้นหลังของตัวอย่าง และคลิก **▶ เล่นแอนิเมชันซ้ำ** เพื่อเล่นแอนิเมชันการแจ้งเตือนอีกครั้ง

### รูปแบบเดียวกัน / แยกตามแต่ละแพลตฟอร์ม

- **รูปแบบเดียวกัน**: Twitch และ YouTube ใช้รูปแบบการแจ้งเตือนเดียวกัน
- **แยกตามแต่ละแพลตฟอร์ม**: แต่ละแพลตฟอร์มมีรูปแบบของตัวเอง เลือก **Twitch** หรือ **YouTube** ด้วยปุ่มด้านล่างแล้วแก้ไขการตั้งค่า เมื่อสลับครั้งแรก แพลตฟอร์มที่คุณยังไม่ได้ปรับแต่งจะคัดลอกรูปแบบเดียวกันปัจจุบัน โดยแต่ละแพลตฟอร์มมีสีแถบนับถอยหลังของตัวเอง

**คืนค่าเริ่มต้น** จะคืนรูปแบบเริ่มต้นให้กับรูปแบบที่คุณกำลังแก้ไข

### รูปภาพ

- **เลือกรูปภาพ**: เลือกรูปภาพจากตัวจัดการวัสดุ หากไม่เลือก จะแสดงอีโมจิรูปหัวใจ **ล้าง** จะนำรูปภาพออก
- **ขนาดรูปภาพ**: 1–400 px
- **ตำแหน่งรูปภาพ**: **ชิดซ้าย**, **ชิดขวา**, **ด้านบน** หรือ **ด้านล่าง**

### เสียง

เลือกเสียงในตัว: **ไม่มี**, **เสียงกระดิ่ง** (ค่าเริ่มต้น), **เหรียญ**, **เสียงระฆัง**, **ป๊อป**, **แตรวง** คลิก **▶** เพื่อฟัง คลิก **เลือกเสียง** เพื่อใช้ไฟล์เสียงของคุณเองจากตัวจัดการวัสดุ

### ข้อความกำหนดเอง

เขียนข้อความที่จะแสดงบนการแจ้งเตือน ใช้ `{name}` แทนชื่อผู้ติดตาม และ `{platform}` แทนชื่อแพลตฟอร์ม เว้นว่างไว้เพื่อใช้ข้อความเริ่มต้น: `ยินดีต้อนรับ {name} ขอบคุณที่ติดตาม!`

### ข้อความและสี

- **ข้อความ**: ตั้งค่าฟอนต์ ขนาด และสีสำหรับ **ข้อความกำหนดเอง** และ **ชื่อผู้ติดตาม**
- **สี**: **พื้นหลัง**, **เงา** และ **แถบนับถอยหลัง**

### CSS กำหนดเอง

ขยาย **CSS กำหนดเอง** เพื่อแก้ไข CSS ของรูปแบบที่คุณกำลังแก้ไข (รูปแบบเดียวกันหรือแพลตฟอร์มที่เลือก) **คืนค่าเริ่มต้น** จะคืน CSS ของเทมเพลต และ **จัดการวัสดุ** จะเปิดตัวจัดการวัสดุ ยังสามารถใช้ธีมจาก Steam Workshop ได้ที่นี่ ระหว่างที่ใช้ธีมอยู่ CSS จะเป็นแบบอ่านอย่างเดียว ดู [ธีม](./themes)

## แท็บประวัติ

แสดงรายการผู้ติดตามใหม่ล่าสุดจากทั้งสองแพลตฟอร์ม เรียงจากใหม่ไปเก่า: แพลตฟอร์ม ชื่อ และเวลา ประวัติจะแสดงเฉพาะในโปรแกรมเท่านั้น ไม่แสดงบนโอเวอร์เลย์

- เก็บผู้ติดตามไว้สูงสุด 100 คน และรายการที่เก่ากว่า 30 วันจะถูกลบโดยอัตโนมัติ
- คลิก **ล้าง** เพื่อล้างรายการ

:::info เวอร์ชันทดลองใช้งาน
CSS กำหนดเองใช้ได้เฉพาะในเวอร์ชันเต็มเท่านั้น และการแจ้งเตือนจะมีลายน้ำใน OBS ดู [การเปรียบเทียบเวอร์ชันทดลอง / เวอร์ชันเต็ม](../getting-started/trial-comparison)
:::

## คำถามที่พบบ่อย

**Q: ไม่มีเสียงในสตรีม?**
ตรวจสอบว่าได้ติ๊กเลือก **ควบคุมเสียงผ่าน OBS** ในคุณสมบัติของซอร์สเบราว์เซอร์ และซอร์สไม่ได้ถูกปิดเสียงในมิกเซอร์ของ OBS รวมทั้งตรวจสอบว่า **เสียง** ไม่ได้ตั้งเป็น **ไม่มี**

**Q: ผู้ติดตามช่อง YouTube ไม่ได้รับการแจ้งเตือน**
YouTube จะรายงานเฉพาะการติดตามที่เป็นสาธารณะเท่านั้น และอาจใช้เวลาหลายนาทีถึงหลายชั่วโมงกว่าจะรายงาน นอกจากนี้โปรแกรมจะตรวจสอบเฉพาะตอนที่คุณกำลังไลฟ์และเชื่อมต่อแชทสด YouTube อยู่เท่านั้น

**Q: ฉันเพิ่มซอร์ส OBS ทีหลัง จะเล่นการแจ้งเตือนก่อนหน้าซ้ำไหม?**
ไม่ ซอร์สที่เพิ่งเปิดจะแสดงเฉพาะการแจ้งเตือนที่มาหลังจากเชื่อมต่อแล้วเท่านั้น ผู้ติดตามก่อนหน้ายังคงอยู่ในแท็บ **ประวัติ**
