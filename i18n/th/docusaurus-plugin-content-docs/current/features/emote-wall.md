# กำแพงอิโมจิ

เมื่อผู้ชมใช้อิโมจิในแชท อิโมจิจะลอยผ่านหน้าจอสตรีมของคุณ

:::note ก่อนเริ่มต้น
กำแพงอิโมจิอ่านอิโมจิจากแชท จึงต้องเชื่อมต่อแพลตฟอร์มที่คุณใช้ก่อน ดู [การตั้งค่า Twitch](../platforms/twitch) และ [การตั้งค่า YouTube](../platforms/youtube-settings)
:::

## ขั้นตอนที่ 1: เพิ่มซอร์ส OBS

คัดลอก **URL แหล่งที่มาสำหรับ OBS** ที่ด้านบนของหน้า:

```
http://127.0.0.1:7272/emote-wall
```

เพิ่มลงใน OBS เป็นซอร์สเบราว์เซอร์ ดู [วิธีเพิ่มซอร์สใน OBS](../getting-started/obs-source) กำแพงอิโมจิไม่มีเสียง จึงไม่จำเป็นต้องเปิด "ควบคุมเสียงผ่าน OBS"

:::tip
เปิดสวิตช์ข้าง **กำแพงอิโมจิ** ในแถบด้านซ้ายด้วย (**เปิดการแสดงใน OBS**) ระหว่างที่ปิดอยู่ อิโมจิจากแชทจะไม่ถูกส่งไปยังโอเวอร์เลย์
:::

## ขั้นตอนที่ 2: เลือกแหล่งที่มา

ในส่วน **แหล่งที่มา** จะมีการ์ดสำหรับ **Twitch** และ **YouTube** อย่างละหนึ่งใบ แต่ละการ์ดแสดงสถานะการเชื่อมต่อ:

- Twitch จะแสดง **(ยังไม่ได้เชื่อมต่อ)** เมื่อยังไม่ได้เชื่อมต่อบัญชี Twitch
- YouTube จะแสดง **ยังไม่ได้เชื่อมต่อ URL ห้องแชท** เมื่อยังไม่ได้เชื่อมต่อแชท YouTube

ติ๊กเลือก **เปิดใช้งานกำแพงอิโมจิ** บนการ์ดเพื่อแสดงอิโมจิจากแชทของแพลตฟอร์มนั้น ยกเลิกการติ๊กเพื่อไม่สนใจแพลตฟอร์มนั้น

## ขั้นตอนที่ 3: ตั้งค่าแอนิเมชัน

| การตั้งค่า | คำอธิบาย |
|---------|-------------|
| **ขนาดสติกเกอร์** | ขนาดของอิโมจิแต่ละตัว 16–256 px |
| **จำนวน emote สูงสุดต่อข้อความ** | จำนวนอิโมจิสูงสุดที่จะดึงจากข้อความแชทหนึ่งข้อความ (1–20) |
| **ระยะเวลาที่ลอย** | ระยะเวลาที่อิโมจิแต่ละตัวลอยอยู่ 1–30 วินาที |
| **ความเร็วการลอย** | 50–500 px/s |

คลิก **คืนค่าเริ่มต้น** ข้างชื่อส่วนเพื่อคืนค่าทั้งสี่ค่า

## ขั้นตอนที่ 4: ทดสอบ

คลิก **ทดสอบ (แสดงใน OBS)** เพื่อส่งอิโมจิ Twitch ตัวอย่างไปยังโอเวอร์เลย์ตามการตั้งค่าปัจจุบัน จำนวนอิโมจิทดสอบจะเป็นไปตาม **จำนวน emote สูงสุดต่อข้อความ**
