# แถบเป้าหมายการสนับสนุน

แสดงแถบความคืบหน้าสู่เป้าหมายการสนับสนุนบนสตรีม การสนับสนุนจากแพลตฟอร์มที่คุณเลือกจะถูกเพิ่มเข้ายอดรวมโดยอัตโนมัติ

## URL ซอร์ส OBS

```
http://127.0.0.1:7272/donate
```

คัดลอก URL จากด้านบนของหน้า **ตั้งค่าแถบเป้าหมายการสนับสนุน** แล้วเพิ่มลงใน OBS เป็นซอร์สเบราว์เซอร์ ดู [วิธีเพิ่มซอร์สใน OBS](../getting-started/obs-source)

ใช้สวิตช์ข้าง **แถบเป้าหมายการสนับสนุน** ในแถบด้านซ้ายเพื่อแสดงหรือซ่อนแถบใน OBS เมื่อปิดอยู่ แถบจะถูกซ่อน

## สกุลเงิน

แถบนี้ใช้ **สกุลเงินสำหรับการสนับสนุน** ที่ตั้งไว้ในหน้า **ตั้งค่า** การสนับสนุนในสกุลเงินอื่นจะถูกแปลงเป็นสกุลเงินนี้ก่อนเพิ่มเข้ายอด หากแปลงสกุลเงินของการสนับสนุนไม่ได้ จะไม่ถูกเพิ่มลงในแถบ (การแจ้งเตือนการสนับสนุนและกระดานการสนับสนุนยังคงแสดงในสกุลเงินเดิม)

## แท็บตั้งค่า

### แพลตฟอร์มที่เชื่อมต่อ

ติ๊กเลือกแพลตฟอร์มที่จะนับการสนับสนุนเข้าแถบ:

- **Twitch** — Bits และการสมัครสมาชิก
- **YouTube**
- **PayPal**
- **Stripe**
- **O'Pay**
- **ECPay**

จุดสีเขียวหมายถึงแพลตฟอร์มนั้นเชื่อมต่อแล้ว มิฉะนั้นแถวนั้นจะแสดง **(ยังไม่ได้เชื่อมต่อ)** ช่องติ๊กเหล่านี้กำหนดเฉพาะสิ่งที่แถบนับเท่านั้น ไม่มีผลกับการแจ้งเตือนการสนับสนุนหรือกระดานการสนับสนุน ซึ่งมีรายการแพลตฟอร์มของตัวเอง

- **YouTube**: หากแชทสดยังไม่ได้เชื่อมโยง แถวนั้นจะแสดง **ยังไม่ได้เชื่อมต่อ URL ห้องแชท** พร้อมสองปุ่ม: **เชื่อมต่ออัตโนมัติ** (ต้องลงชื่อเข้าใช้ Google) และ **กรอกเอง** (พาไปที่ช่อง URL แชทในหน้าตั้งค่า) ดู [การตั้งค่า YouTube](../platforms/youtube-settings)
- **YouTube ⚙️**: เลือก **รายการที่นับ** ที่จะเพิ่มเข้าแถบ: **Super Chat**, **Super Sticker**, **สมาชิกใหม่**, **ต่ออายุสมาชิก**, **สมาชิกที่มอบให้**, **อัญมณี** โดย **อัญมณี** ต้องลงชื่อเข้าใช้ Google
- หากติ๊กเลือกรายการสมาชิกใดไว้แต่ยังไม่ได้ตั้งราคาสมาชิก จะปรากฏ **⚠ ยังไม่ได้ตั้งราคาสมาชิก** คลิกเพื่อไปที่หน้าตั้งค่าและใส่ราคาแต่ละระดับใน **ตั้งค่าการแปลงค่า** ของ YouTube
- มูลค่าของ Twitch Bits และการสมัครสมาชิกตั้งได้ใน ตั้งค่า → Twitch → **ตั้งค่าการแปลงค่า** ดู [การตั้งค่า Twitch](../platforms/twitch)
- หากต้องการเชื่อมต่อ PayPal, Stripe, O'Pay หรือ ECPay ดู [PayPal](../payments/paypal), [Stripe](../payments/stripe), [O'Pay](../payments/opay) และ [ECPay](../payments/ecpay)

### ความคืบหน้าปัจจุบัน

แสดงยอดรวมปัจจุบัน เป้าหมาย และเปอร์เซ็นต์

| ฟิลด์ | คำอธิบาย |
|-------|-------------|
| **ชื่อเรื่อง** | ไม่บังคับ แสดงเหนือแถบ |
| **จำนวนเป้าหมาย** | จำนวนเงินเป้าหมาย ในสกุลเงินสำหรับการสนับสนุนของคุณ |
| **เพิ่มด้วยตนเอง** | ใส่จำนวนเงินแล้วคลิก **เพิ่ม** (หรือกด Enter) เพื่อเพิ่มเข้ายอดรวม |
| **รีเซ็ตเป็นศูนย์** | ตั้งยอดรวมปัจจุบันกลับเป็นศูนย์ จะมีการยืนยันก่อน และไม่สามารถย้อนกลับได้ |

## แท็บรูปลักษณ์

### ตัวอย่าง

ตัวอย่างแสดงแถบพร้อมจำนวนเงินตัวอย่าง ใช้ตัวเลือกสีข้าง **ตัวอย่าง** เพื่อเปลี่ยนพื้นหลังของตัวอย่าง ติ๊กเลือก **ตัวอย่างเมื่อบรรลุ** เพื่อดูแถบในสถานะที่บรรลุเป้าหมายแล้ว

### ฟอนต์และสี

คลิก **คืนค่าเริ่มต้น** เพื่อคืนรูปลักษณ์เริ่มต้น

- **ฟอนต์**: ตั้งค่าฟอนต์ สี และขนาด (8–72 px) สำหรับ **ชื่อเรื่อง**, **จำนวนเงิน** และ **เปอร์เซ็นต์**
- **สี**: ตั้งค่า **พื้นหลัง**, **แถบเป้าหมาย** (สีเติม) และ **แถบเป้าหมายเมื่อบรรลุ** (สีเติมเมื่อบรรลุเป้าหมายแล้ว)

### CSS กำหนดเอง

ขยาย **CSS กำหนดเอง** เพื่อแก้ไข CSS ของแถบ **คืนค่าเริ่มต้น** จะคืนค่า CSS เริ่มต้น และ **จัดการวัสดุ** จะเปิดตัวจัดการวัสดุสำหรับรูปภาพที่คุณต้องการใช้ใน CSS ยังสามารถใช้ธีมจาก Steam Workshop ได้ที่นี่ ระหว่างที่ใช้ธีมอยู่ CSS จะเป็นแบบอ่านอย่างเดียวจนกว่าคุณจะคืนค่า ดู [ธีม](./themes)

:::info เวอร์ชันทดลองใช้งาน
CSS กำหนดเองใช้ได้เฉพาะในเวอร์ชันเต็มเท่านั้น ระบบชำระเงินจริง (PayPal / Stripe / O'Pay / ECPay) รวมถึงรายการสมาชิกและอัญมณีของ YouTube ใช้ไม่ได้ในเวอร์ชันทดลองใช้งาน และโอเวอร์เลย์จะมีลายน้ำ ดู [การเปรียบเทียบเวอร์ชันทดลอง / เวอร์ชันเต็ม](../getting-started/trial-comparison)
:::

## คำถามที่พบบ่อย

**Q: ยอดรวมเพิ่มขึ้นหลังจากที่ฉันส่งการแจ้งเตือนทดสอบ**
**ทดสอบการแจ้งเตือน** ในหน้าตั้งค่านับเป็นการสนับสนุนจริง จึงถูกเพิ่มเข้าแถบ (หากติ๊กเลือกแพลตฟอร์มนั้นไว้) หลังทดสอบเสร็จ ให้คลิก **รีเซ็ตเป็นศูนย์** เพื่อตั้งยอดรวมกลับเป็นศูนย์
