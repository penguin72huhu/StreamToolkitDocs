# การแจ้งเตือนการสนับสนุน

แสดงการแจ้งเตือนพร้อมรูปภาพ เสียง ชื่อผู้สนับสนุน จำนวนเงิน และข้อความ เมื่อมีคนสนับสนุน

## URL ซอร์ส OBS

```
http://127.0.0.1:7272/donate-alert
```

คัดลอก URL จากด้านบนของหน้า **ตั้งค่าการแจ้งเตือนการสนับสนุน** แล้วเพิ่มลงใน OBS เป็นซอร์สเบราว์เซอร์ ดู [วิธีเพิ่มซอร์สใน OBS](../getting-started/obs-source)

:::warning
การแจ้งเตือนจะมีเสียง ต้องติ๊กเลือก **ควบคุมเสียงผ่าน OBS** ในคุณสมบัติของซอร์สเบราว์เซอร์ มิฉะนั้นจะไม่ได้ยินเสียงในสตรีม
:::

ใช้สวิตช์ข้าง **การแจ้งเตือนการสนับสนุน** ในแถบด้านซ้ายเพื่อเปิดหรือปิดการแจ้งเตือน ระหว่างที่ปิดอยู่ จะไม่มีการแจ้งเตือนแสดง (รวมถึงการแจ้งเตือนทดสอบ) แต่การสนับสนุนยังคงถูกบันทึกลงใน [กระดานการสนับสนุน](./sponsors)

เมื่อมีการสนับสนุนหลายรายการเข้ามาในเวลาใกล้กัน การแจ้งเตือนจะถูกเข้าคิวและแสดงทีละรายการ

## แท็บตั้งค่า

### แพลตฟอร์มที่เชื่อมต่อ

ติ๊กเลือกแพลตฟอร์มที่จะให้แสดงการแจ้งเตือน: **Twitch**, **YouTube**, **PayPal**, **Stripe**, **O'Pay**, **ECPay** จุดสีเขียวหมายถึงแพลตฟอร์มนั้นเชื่อมต่อแล้ว มิฉะนั้นแถวนั้นจะแสดง **(ยังไม่ได้เชื่อมต่อ)** ช่องติ๊กเหล่านี้มีผลเฉพาะกับการแจ้งเตือนเท่านั้น ไม่มีผลกับแถบเป้าหมายการสนับสนุนหรือกระดานการสนับสนุน

**Twitch ⚙️** (แสดงเมื่อเชื่อมต่อ Twitch และติ๊กเลือกไว้):

1. เลือก **นับ Bits และการสมัครสมาชิก**, **นับเฉพาะ Bits** หรือ **นับเฉพาะการสมัครสมาชิก**
2. **นับการต่ออายุสมาชิก**: ให้การต่ออายุสมาชิกแสดงการแจ้งเตือนหรือไม่ (แสดงเมื่อนับการสมัครสมาชิก)
3. **ต่ำกว่า [N] Bits จะไม่ถูกนำมานับ**: ติ๊กเลือกแล้วใส่จำนวนขั้นต่ำ เพื่อไม่ให้ Cheer จำนวนน้อยแสดงการแจ้งเตือน (แสดงเมื่อนับ Bits)
4. คลิก **บันทึก**

**YouTube ⚙️**:

- **แสดงชื่อผู้ชมแทน @แฮนเดิล**: ใช้ได้หลังจากลงชื่อเข้าใช้ด้วย Google เท่านั้น
- **รายการที่นับ**: **Super Chat**, **Super Sticker**, **สมาชิกใหม่**, **ต่ออายุสมาชิก**, **สมาชิกที่มอบให้**, **อัญมณี** โดย **อัญมณี** ต้องลงชื่อเข้าใช้ Google

หากแชทสดของ YouTube ยังไม่ได้เชื่อมโยง แถวนั้นจะแสดง **ยังไม่ได้เชื่อมต่อ URL ห้องแชท** พร้อมปุ่ม **เชื่อมต่ออัตโนมัติ** (ต้องลงชื่อเข้าใช้ Google) และ **กรอกเอง** (พาไปที่ช่อง URL แชทในหน้าตั้งค่า) หากติ๊กเลือกรายการสมาชิกไว้แต่ยังไม่ได้ตั้งราคาสมาชิก ให้คลิก **⚠ ยังไม่ได้ตั้งราคาสมาชิก** เพื่อไปตั้งค่า ดู [การตั้งค่า YouTube](../platforms/youtube-settings)

หากต้องการเชื่อมต่อ PayPal, Stripe, O'Pay หรือ ECPay ดู [PayPal](../payments/paypal), [Stripe](../payments/stripe), [O'Pay](../payments/opay) และ [ECPay](../payments/ecpay)

## แท็บรูปลักษณ์

### ตัวอย่าง

ตัวอย่างใช้หน้าเดียวกับซอร์ส OBS ใช้ตัวเลือกสีข้าง **ตัวอย่าง** เพื่อเปลี่ยนพื้นหลังของตัวอย่าง และคลิก **▶ เล่นแอนิเมชันซ้ำ** เพื่อเล่นแอนิเมชันการแจ้งเตือนอีกครั้ง

### รูปแบบเดียวกัน / แยกตามแต่ละแพลตฟอร์ม

- **รูปแบบเดียวกัน**: ทุกแพลตฟอร์มใช้รูปแบบการแจ้งเตือนเดียวกัน
- **แยกตามแต่ละแพลตฟอร์ม**: แต่ละแพลตฟอร์มมีรูปแบบของตัวเอง เลือกแพลตฟอร์มด้วยปุ่มด้านล่าง (**Twitch**, **YouTube**, **O'Pay**, **ECPay**, **PayPal**, **Stripe**) แล้วแก้ไขการตั้งค่า เมื่อสลับครั้งแรก แพลตฟอร์มที่คุณยังไม่ได้ปรับแต่งจะคัดลอกรูปแบบเดียวกันปัจจุบัน โดยแต่ละแพลตฟอร์มมีสีแถบนับถอยหลังของตัวเอง

**คืนค่าเริ่มต้น** จะคืนรูปแบบเริ่มต้นให้กับรูปแบบที่คุณกำลังแก้ไข

### รูปภาพ

- **เลือกรูปภาพ**: เลือกรูปภาพจากตัวจัดการวัสดุ หากไม่เลือก จะแสดงอีโมจิรูปหัวใจ **ล้าง** จะนำรูปภาพออก
- **ขนาดรูปภาพ**: 1–400 px
- **ตำแหน่งรูปภาพ**: **ชิดซ้าย**, **ชิดขวา**, **ด้านบน** หรือ **ด้านล่าง**

### เสียง

เลือกเสียงในตัว: **ไม่มี**, **เสียงกระดิ่ง** (ค่าเริ่มต้น), **เหรียญ**, **เสียงระฆัง**, **ป๊อป**, **แตรวง** คลิก **▶** เพื่อฟัง คลิก **เลือกเสียง** เพื่อใช้ไฟล์เสียงของคุณเองจากตัวจัดการวัสดุ

### การแสดงข้อความ

- **ค่าเริ่มต้น**: แสดงจำนวนเงิน ชื่อผู้สนับสนุน และข้อความแยกบรรทัดกัน
- **ข้อความกำหนดเอง**: เขียนข้อความของคุณเอง ใช้ `{name}` แทนชื่อผู้สนับสนุน และ `{amount}` แทนจำนวนเงิน เช่น `ขอบคุณ {name} ที่สนับสนุน {amount}!`

### ข้อความและสี

- **ข้อความ**: ตั้งค่าฟอนต์ ขนาด และสีสำหรับ **จำนวนเงิน**, **ชื่อผู้สนับสนุน** และ **ข้อความ** (รวมถึง **ข้อความกำหนดเอง** ในโหมดข้อความกำหนดเอง)
- **สี**: **พื้นหลัง**, **เงา** และ **แถบนับถอยหลัง**

### CSS กำหนดเอง

ขยาย **CSS กำหนดเอง** เพื่อแก้ไข CSS ของรูปแบบที่คุณกำลังแก้ไข (รูปแบบเดียวกันหรือแพลตฟอร์มที่เลือก) **คืนค่าเริ่มต้น** จะคืน CSS ของเทมเพลต และ **จัดการวัสดุ** จะเปิดตัวจัดการวัสดุ ยังสามารถใช้ธีมจาก Steam Workshop ได้ที่นี่ ระหว่างที่ใช้ธีมอยู่ CSS จะเป็นแบบอ่านอย่างเดียว ดู [ธีม](./themes)

## ทดสอบการแจ้งเตือน

ในหน้า **ตั้งค่า** คลิก **ทดสอบการแจ้งเตือน** ข้าง **การเชื่อมต่อแพลตฟอร์มสนับสนุน**:

1. กรอก **ชื่อทดสอบ**, **ข้อความทดสอบ** และ **จำนวนเงินทดสอบ** แล้วเลือก **แพลตฟอร์มทดสอบ**
2. คลิก **ส่งการแจ้งเตือนทดสอบ**

ส่วน **ทดสอบ YouTube Super Chat** ให้คุณใส่ **สตริงจำนวนเงิน** แบบดิบ (เช่น `$5.00`, `¥500`, `NT$150`) แล้วคลิก **ส่งทดสอบ Super Chat** เพื่อทดสอบการอ่านจำนวนเงินและการแปลงสกุลเงิน

:::note
การแจ้งเตือนทดสอบจะถูกจัดการเหมือนการสนับสนุนจริง: จะถูกเพิ่มลงใน [แถบเป้าหมายการสนับสนุน](./donate) และ [กระดานการสนับสนุน](./sponsors) ด้วย หากติ๊กเลือกแพลตฟอร์มนั้นไว้ในฟีเจอร์ดังกล่าว
:::

:::info เวอร์ชันทดลองใช้งาน
CSS กำหนดเองใช้ได้เฉพาะในเวอร์ชันเต็มเท่านั้น ระบบชำระเงินจริง (PayPal / Stripe / O'Pay / ECPay) รวมถึงรายการสมาชิกและอัญมณีของ YouTube ใช้ไม่ได้ในเวอร์ชันทดลองใช้งาน และการแจ้งเตือนจะมีลายน้ำใน OBS ดู [การเปรียบเทียบเวอร์ชันทดลอง / เวอร์ชันเต็ม](../getting-started/trial-comparison)
:::

## คำถามที่พบบ่อย

**Q: ไม่มีเสียงในสตรีม?**
ตรวจสอบว่าได้ติ๊กเลือก **ควบคุมเสียงผ่าน OBS** ในคุณสมบัติของซอร์สเบราว์เซอร์ และซอร์สไม่ได้ถูกปิดเสียงในมิกเซอร์ของ OBS รวมทั้งตรวจสอบว่า **เสียง** ไม่ได้ตั้งเป็น **ไม่มี**

**Q: ฉันเพิ่มซอร์ส OBS ทีหลัง จะเล่นการแจ้งเตือนก่อนหน้าซ้ำไหม?**
ไม่ ซอร์สที่เพิ่งเปิดจะแสดงเฉพาะการแจ้งเตือนที่มาหลังจากเชื่อมต่อแล้วเท่านั้น
