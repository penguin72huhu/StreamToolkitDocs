# นาฬิกา

แสดงเวลาปัจจุบันบนสตรีม พร้อมวันที่และวันในสัปดาห์ได้ตามต้องการ

## ขั้นตอนที่ 1: เพิ่มซอร์ส OBS

คัดลอก **URL แหล่งที่มาสำหรับ OBS** ที่ด้านบนของหน้า:

```
http://127.0.0.1:7272/clock
```

เพิ่มลงใน OBS เป็นซอร์สเบราว์เซอร์ ดู [วิธีเพิ่มซอร์สใน OBS](../getting-started/obs-source) นาฬิกาไม่มีเสียง จึงไม่จำเป็นต้องเปิด "ควบคุมเสียงผ่าน OBS"

:::tip
เปิดสวิตช์ข้าง **นาฬิกา** ในแถบด้านซ้ายด้วย (**เปิดการแสดงใน OBS**) ระหว่างที่ปิดอยู่ นาฬิกาจะถูกซ่อนใน OBS
:::

## ตัวอย่าง

**ตัวอย่าง** ที่ด้านบนแสดงโอเวอร์เลย์ OBS จริง และอัปเดตตามที่คุณเปลี่ยนการตั้งค่า ใช้กล่องสีข้าง ๆ เพื่อเปลี่ยนพื้นหลังของตัวอย่าง

ใต้ตัวอย่างมีสามแท็บ: **รูปลักษณ์**, **รูปแบบนาฬิกา** และ **การตั้งค่าการแสดงผล**

## รูปลักษณ์

| การตั้งค่า | คำอธิบาย |
|---------|-------------|
| **ฟอนต์** | ฟอนต์สำหรับข้อความทั้งหมดของนาฬิกา |
| **รูปแบบ** | วิธีจัดเรียงเวลา วันที่ และวัน: **Stack**, **Horizontal**, **One-Top-Two-Bottom** หรือ **Two-Top-One-Bottom** โดย **ระยะห่างบรรทัด** ใช้ได้ในทุกรูปแบบยกเว้น **Horizontal** และ **ระยะห่าง** ใช้ได้ในทุกรูปแบบยกเว้น **Stack** (ทั้งคู่ −200 ถึง 200 px) |
| **ลำดับ** | ลากบล็อก **เวลา**, **วันที่** และ **วัน** เพื่อเปลี่ยนลำดับ |
| **ข้อความ** | ตั้งค่า **เวลา**, **วันที่** และ **วัน** แยกกัน: **ขนาดตัวอักษร**, สี (**สีทึบ** หรือ **ไล่ระดับสี** สองสีพร้อม **มุม**) และสี **ขอบ**, **ความโปร่งใส** และ **ความหนา** (0–7 px) |
| **เงา** | สีเงา **ความโปร่งใส**, **เบลอ** และระยะเลื่อน **X** / **Y** ใช้ร่วมกันกับข้อความทั้งหมด |

ปุ่ม **คืนค่าเริ่มต้น** อยู่ที่ด้านบนของแท็บ

### CSS กำหนดเอง

คลิก **CSS กำหนดเอง** เพื่อขยายตัวแก้ไข CSS เริ่มต้นจะแสดงรายการตัวเลือก (selector) ของแต่ละส่วนของนาฬิกา (เวลา วันที่ วัน และคอนเทนเนอร์ของแต่ละส่วน) พร้อมคำอธิบาย ใช้สำหรับเลย์เอาต์และโครงสร้าง ส่วนสี ฟอนต์ และขนาด ให้ตั้งค่าในการตั้งค่ารูปลักษณ์ด้านบน

- **คืนค่าเริ่มต้น**: คืนค่า CSS เริ่มต้น
- **จัดการวัสดุ**: เปิดตัวจัดการวัสดุสำหรับรูปภาพที่ใช้ใน CSS ของคุณ

หาก CSS ของคุณเขียนทับคุณสมบัติด้วย `!important` ตัวควบคุมรูปลักษณ์ที่ตรงกันจะถูกล็อก เพราะ CSS จะมีผลเหนือกว่าอยู่ดี

## รูปแบบนาฬิกา

- **ระบบเวลา**: **24 ชั่วโมง** หรือแบบ 12 ชั่วโมงหนึ่งในสองตัวเลือก: **12 ชั่วโมง (AM/PM)** แสดง AM/PM ส่วน **12 ชั่วโมง (ก่อนเที่ยง/หลังเที่ยง)** แสดงเครื่องหมายภาษาจีน 上午 / 下午
- **เขตเวลา**: UTC−12 ถึง UTC+14 ค่าเริ่มต้นจะตรงกับเขตเวลาของคอมพิวเตอร์ของคุณ

## การตั้งค่าการแสดงผล

- **แสดงวินาที**
- **แสดงวันที่**: เมื่อเปิด ให้เลือกรูปแบบวันที่จากเมนูดรอปดาวน์ รูปแบบที่มีเครื่องหมาย **ไม่แสดงปี** จะไม่แสดงปี
  - **เติมศูนย์หน้าวันที่**: แสดงเดือนและวันที่เป็นเลขหลักเดียวโดยมีศูนย์นำหน้า (เช่น 2026/05/20)
  - **รูปแบบปี**: แสดงสำหรับรูปแบบที่ขึ้นต้นด้วยปี **เต็ม (2026)** หรือ **ย่อ (26)**

  สองตัวเลือกนี้ใช้กับรูปแบบตัวเลข (ที่มี `/` หรือ `-`) ส่วนรูปแบบที่เขียนเป็นคำ (เช่น "20 พฤษภาคม 2569") จะเป็นไปตามภาษาของอินเทอร์เฟซโปรแกรมแทน
- **แสดงวันในสัปดาห์**: เมื่อเปิด ให้เลือกวิธีเขียนวันในสัปดาห์ (เช่น **วันพุธ**, **Wednesday**, **WED** หรือ **Wed**)
