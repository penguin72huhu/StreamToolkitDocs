# ห้องแชท

**ห้องแชท** แสดงแชท Twitch และ YouTube รวมกันในโอเวอร์เลย์เดียว พร้อมการแปลอัตโนมัติ (เลือกเปิดได้) และยังแสดงแชทในหน้าต่างเดสก์ท็อปแบบโปร่งใสที่มีแค่คุณเท่านั้นที่มองเห็นได้ด้วย

## URL ซอร์ส OBS

```
http://127.0.0.1:7272/chat
```

เพิ่มเป็นซอร์สเบราว์เซอร์: [วิธีเพิ่มซอร์สใน OBS](../getting-started/obs-source) โอเวอร์เลย์นี้ไม่มีเสียง

:::info
ข้อความจะถูกส่งไปยังโอเวอร์เลย์เฉพาะตอนที่สวิตช์ **ห้องแชท** ในแถบด้านข้างเปิดอยู่เท่านั้น แต่ระหว่างที่ปิดอยู่ โปรแกรมยังคงรับแชท ดังนั้นฟีเจอร์ที่อ่านแชท (โพล การจับรางวัล ขอเพลง ฯลฯ) ยังทำงานได้ตามปกติ
:::

## ก่อนเริ่มต้น

เชื่อมต่อแพลตฟอร์มที่คุณต้องการแสดง:

- [การตั้งค่า Twitch](../platforms/twitch)
- [การตั้งค่า YouTube](../platforms/youtube-settings)

หน้าตั้งค่ามีสองแท็บ: **ตั้งค่า** และ **รูปลักษณ์**

## แท็บตั้งค่า

### แพลตฟอร์ม

- **แสดง icon แพลตฟอร์ม (Twitch / YouTube)** — แสดงไอคอน <img src={require('@site/static/img/twitch-icon.png').default} alt="Twitch" className="inline-icon" /> / <img src={require('@site/static/img/youtube-icon.png').default} alt="YouTube" className="inline-icon" /> หน้าข้อความแต่ละข้อความ

แต่ละแพลตฟอร์มมีการ์ดของตัวเอง จุดข้างชื่อแพลตฟอร์มจะเป็นสีเขียวเมื่อเชื่อมต่อและเปิดใช้งานแล้ว หาก Twitch ยังไม่ได้เชื่อมต่อจะแสดง **(ยังไม่ได้เชื่อมต่อ)** และหากแชท YouTube ยังไม่ได้เชื่อมโยงจะแสดง **ยังไม่ได้เชื่อมต่อ URL ห้องแชท**

| ตัวเลือก | คำอธิบาย |
|--------|-------------|
| **เปิดใช้งานห้องแชท** | แสดงข้อความของแพลตฟอร์มนี้ |
| **แสดงรูปโปรไฟล์** | แสดงรูปโปรไฟล์ของผู้ชม |
| **แสดงตราสัญลักษณ์** (Twitch) / **แสดงตราสัญลักษณ์ (ไอคอนสมาชิก)** (YouTube) | แสดงตราสัญลักษณ์ |
| **แสดงชื่อผู้ชมแทน @แฮนเดิล** | เฉพาะ YouTube ใช้งานไม่ได้จนกว่าคุณจะลงชื่อเข้าใช้ด้วย Google |

เมื่อเปิดใช้งานแชท YouTube แต่ยังไม่ได้เชื่อมโยง การ์ดจะมีปุ่มสองปุ่ม:

- **เชื่อมต่ออัตโนมัติ** — ค้นหาการถ่ายทอดสดปัจจุบันของคุณโดยอัตโนมัติ (ต้องลงชื่อเข้าใช้ Google)
- **กรอกเอง** — พาไปที่หน้าตั้งค่าเพื่อวาง URL แชท

**จำนวนข้อความสูงสุด**: จำนวนข้อความที่เก็บไว้บนหน้าจอ (5–200 ค่าเริ่มต้น 50)

### แปลอัตโนมัติ

1. ติ๊กเลือก **เปิดใช้งานการแปล**
2. **ภาษาเป้าหมาย**: ภาษาที่จะแปลข้อความไป ค่าเริ่มต้น **ตามภาษาของอินเทอร์เฟซ** จะใช้ภาษาอินเทอร์เฟซของโปรแกรม
3. **ภาษาที่ไม่ต้องแปล** (ไม่บังคับ): ข้อความในภาษาที่ติ๊กเลือกไว้จะไม่ถูกแปล ภาษาโปรตุเกส PT-BR และ PT-PT แยกจากกันไม่ได้ ดังนั้นการติ๊กอันใดอันหนึ่งจะข้ามทั้งสองภาษา

**บริการแปล** คือ **MyMemory** ซึ่งไม่ต้องใช้ API Key

- **Email (ไม่บังคับ)**: หากไม่ใส่อีเมล โควตารายวันคือ 5,000 ตัวอักษร ใส่อีเมลแล้วคลิก **บันทึก** เพื่อเพิ่มเป็น 50,000 ตัวอักษร (ฟรี ไม่ต้องลงทะเบียน MyMemory)
- แถบด้านล่างแสดงปริมาณที่ใช้ไปโดยประมาณของวันนี้ รีเซ็ตทุกวันเวลา 08:00 UTC

### ทดสอบ

- **ส่งข้อความทดสอบ** — ส่งข้อความตัวอย่างแบบสุ่มไปยังโอเวอร์เลย์
- **ล้าง** — ล้างข้อความทั้งหมดออกจากโอเวอร์เลย์

หากปรากฏ **เชื่อมต่อไม่สำเร็จ — เซิร์ฟเวอร์อาจไม่ได้ทำงาน** แสดงว่าเซิร์ฟเวอร์ภายในเครื่องของ Stream Toolkit ไม่ตอบสนอง

### หน้าต่างห้องแชทบนเดสก์ท็อป

แสดงแชทในหน้าต่างเล็กแบบโปร่งใสที่อยู่บนสุดเสมอทับเกมของคุณ มีแค่คุณเท่านั้นที่มองเห็น — สะดวกสำหรับการสตรีมด้วยจอเดียว

1. คลิก **เปิดหน้าต่าง** (หรือคลิกขวาที่ไอคอนในถาดระบบแล้วเลือก **เปิดห้องแชทบนเดสก์ท็อป**)
2. ระหว่างที่ปลดล็อกอยู่ ลากแถบด้านบนเพื่อย้ายหน้าต่าง และลากขอบเพื่อปรับขนาด
3. คลิก **🔒 ล็อก** เมื่อวางตำแหน่งเรียบร้อยแล้ว จากนั้นการคลิกจะทะลุหน้าต่างไปยังเกมของคุณ หากต้องการปลดล็อก ให้เลื่อนเมาส์ไปบนหน้าต่างแล้วคลิก 🔓 ที่ปรากฏที่มุมขวาบน หรือคลิก **🔓 ปลดล็อก** ในหน้าตั้งค่า

**รีเซ็ตตำแหน่ง** จะย้ายหน้าต่างกลับไปยังตำแหน่งเริ่มต้น

| การตั้งค่า | คำอธิบาย |
|---------|-------------|
| **รูปแบบ** | **เฉพาะชื่อและข้อความ** (ค่าเริ่มต้น) หรือ **เหมือนห้องแชทใน OBS** |
| **ขนาดตัวอักษร** | 12–32 px ค่าเริ่มต้น 16 ใช้ได้เฉพาะ **เฉพาะชื่อและข้อความ** |
| **ความทึบของข้อความ** | 10–100% ค่าเริ่มต้น 100% |
| **ความทึบของพื้นหลัง** | 0–100% ค่าเริ่มต้น 40% |
| **ข้อความค่อย ๆ หายไป** | 0–120 วินาที ค่าเริ่มต้น 0 แต่ละข้อความจะค่อย ๆ หายไปหลังจากจำนวนวินาทีนี้ และเลื่อนกลับไปดูข้อความที่หายไปแล้วไม่ได้ หากตั้งเป็น 0 จะไม่มีข้อความหายไป และเลื่อนขึ้นไปดูข้อความก่อนหน้าได้ระหว่างที่ปลดล็อกอยู่ (สูงสุดตามจำนวนข้อความสูงสุด) |
| **ซ่อนจากภาพที่สตรีม** | เปิดเป็นค่าเริ่มต้น การจับภาพหน้าจอ (Display Capture) ของ OBS จะไม่จับหน้าต่างนี้ ผู้ชมจึงไม่เห็นแชทซ้ำสองครั้ง และหน้าต่างนี้จะไม่ปรากฏในภาพหน้าจอหรือการแชร์หน้าจอบน Discord ด้วย |

:::tip
หากมองไม่เห็นหน้าต่างขณะเล่นเกมแบบเต็มจอ ให้เปลี่ยนเกมเป็นโหมด Borderless Window หรือ Windowed ใช้ **ส่งข้อความทดสอบ** เพื่อตรวจสอบตำแหน่งและขนาดของหน้าต่าง
:::

## แท็บรูปลักษณ์

### ตัวอย่าง

ด้านบนของแท็บแสดงตัวอย่างแบบสด ตัวเลือกสีข้าง **ตัวอย่าง** จะเปลี่ยนเฉพาะพื้นหลังของตัวอย่าง ช่องติ๊ก **รูปโปรไฟล์**, **ตราสัญลักษณ์** และ **icon แพลตฟอร์ม** จะเปลี่ยนเฉพาะสิ่งที่แสดงในตัวอย่างเท่านั้น

### การตั้งค่ารูปลักษณ์

**คืนค่าเริ่มต้น** จะคืนรูปลักษณ์เริ่มต้น (หรือรูปลักษณ์ของธีมที่ใช้อยู่ หากใช้ธีมอยู่)

- **ทิศทางการปรากฏ**: **จากบนลงล่าง**, **จากล่างขึ้นบน** (ค่าเริ่มต้น), **จากซ้ายไปขวา**, **จากขวาไปซ้าย**
- **ข้อความ** — ตั้งค่าแยกกันสำหรับ **ชื่อเล่น** และ **ข้อความ**:
  - ฟอนต์ ขนาด (px) และสี สำหรับชื่อผู้ใช้ คุณเลือกได้ระหว่าง **สีดั้งเดิม** (สีของผู้ชมบนแพลตฟอร์ม) หรือ **สีกำหนดเอง**
  - **ขอบ**: สี **ความโปร่งใส** **ความหนา**
  - **เงา**: สี **ความโปร่งใส** **เบลอ** ระยะเลื่อน X / Y
- **ขนาดไอคอน**: สเกลของ **icon แพลตฟอร์ม**, **รูปโปรไฟล์** และ **ตราสัญลักษณ์** (0.1–5x)
- **สี**: **สีพื้นหลัง** ของแต่ละข้อความ

### CSS กำหนดเอง

ขยาย **CSS กำหนดเอง** เพื่อแก้ไข CSS ของโอเวอร์เลย์โดยตรง ใช้ **จัดการวัสดุ** เพื่ออัปโหลดรูปภาพสำหรับอ้างอิงใน CSS **คืนค่าเริ่มต้น** จะคืนค่า CSS เริ่มต้น ดูเพิ่มเติมที่ [ธีม](./themes)

:::tip
หาก CSS กำหนดเองของคุณตั้งค่าฟิลด์รูปลักษณ์ใดด้วย `!important` ฟิลด์นั้นจะเป็นสีเทาในการตั้งค่ารูปลักษณ์ ("การตั้งค่านี้ถูกควบคุมโดย CSS ที่กำหนดเอง") เมื่อใช้ธีมอยู่ CSS จะเป็นแบบอ่านอย่างเดียว — ต้องคืนค่าก่อนจึงจะแก้ไขได้
:::

- **CSS กำหนดเอง** ใช้ได้เฉพาะในเวอร์ชันเต็มเท่านั้น
- **หน้าต่างห้องแชทบนเดสก์ท็อป** ใช้ได้เฉพาะในเวอร์ชันเต็มเท่านั้น
