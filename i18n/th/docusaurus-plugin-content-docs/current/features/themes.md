# ธีม

แชร์และดาวน์โหลดหน้าตาของโอเวอร์เลย์ผ่าน Steam Workshop ธีมหนึ่งธีมสามารถรวมรูปลักษณ์ของฟีเจอร์ต่อไปนี้ได้:

- [ห้องแชท](./chat)
- [แถบเป้าหมายการสนับสนุน](./donate)
- [การแจ้งเตือนการสนับสนุน](./donate-alert)
- [แจ้งเตือนผู้ติดตามใหม่](./fan-alert)
- [แจ้งเตือนวันเกิดผู้ชม](./birthday-alert)
- [กระดานการสนับสนุน](./sponsors)
- [โพลสด](./vote)
- [นาฬิกา](./clock)
- [แถบเป้าหมาย Twitch](./goal): **เป้าหมายผู้ติดตาม**, **เป้าหมายสมาชิก**, **เป้าหมาย Bits**

เปิดได้จาก **🎨 ธีม** ที่ด้านล่างของเมนูด้านซ้าย หน้านี้มีสองแท็บ: **ธีมของฉัน** และ **ธีมที่ดาวน์โหลด** ต้องเปิด Steam ไว้

## ค้นหาและใช้ธีมในหน้าฟีเจอร์

ในแต่ละฟีเจอร์ข้างต้น ให้เปิดส่วน **CSS กำหนดเอง** แล้วคลิก **เรียกดูธีมใน Workshop**:

1. **สำรวจธีม** แสดงรายการธีมใน Workshop สำหรับฟีเจอร์นี้ พิมพ์ใน **ค้นหาชื่อธีม** แล้วคลิก **ค้นหา** หรือใช้ **หน้าก่อนหน้า** / **หน้าถัดไป** เพื่อเลื่อนดู
2. คลิกภาพขนาดย่อเพื่อดูรูปภาพตัวอย่าง
3. คลิก **ใช้งาน** ธีมจะถูกสมัครสมาชิก ดาวน์โหลด และนำไปใช้กับฟีเจอร์นี้
4. **สมัครสมาชิกแล้ว** แสดงรายการธีมที่คุณสมัครสมาชิกไว้แล้วสำหรับฟีเจอร์นี้

ระหว่างที่ใช้ธีมอยู่ หน้านี้จะแสดง **ธีมที่ใช้อยู่: (ชื่อ)** และปุ่ม **คืนค่า** และ CSS กำหนดเองจะเป็นแบบอ่านอย่างเดียว คลิก **คืนค่า** เพื่อกลับไปใช้การตั้งค่าของคุณเอง

## ธีมที่ดาวน์โหลด

แสดงรายการธีมทั้งหมดที่คุณสมัครสมาชิกไว้บน Steam ธีมที่สมัครสมาชิกจะไม่ถูกนำไปใช้โดยอัตโนมัติ — ให้ใช้ปุ่มบนการ์ด OBS จะอัปเดตทันที

แต่ละการ์ดแสดงภาพตัวอย่าง ชื่อ **ใช้อยู่** หากมีฟีเจอร์ใดใช้ธีมนี้ และ **ประกอบด้วย:** ฟีเจอร์ที่ธีมครอบคลุม (✓ หมายถึงฟีเจอร์ที่กำลังใช้ธีมนี้อยู่)

| ปุ่ม | หน้าที่ |
|------|------|
| **ใช้ทั้งหมด** | ใช้ธีมกับทุกฟีเจอร์ที่ธีมมี หากฟีเจอร์ใดกำลังใช้ธีมอื่นอยู่ จะมีการขอให้ยืนยันการแทนที่ |
| **เลือกใช้** | เลือกฟีเจอร์ที่จะใช้ธีม |
| **คืนค่าทั้งหมด** | คืนทุกฟีเจอร์ที่ใช้ธีมนี้กลับไปเป็นการตั้งค่าของคุณเองก่อนใช้ธีม |
| **เลือกคืนค่า** | เลือกฟีเจอร์ที่จะคืนค่า |
| **ยกเลิกการสมัครสมาชิก** | ยกเลิกการสมัครสมาชิก หากธีมกำลังใช้อยู่ ฟีเจอร์เหล่านั้นจะถูกคืนค่าก่อน |

หลังจากใช้ธีม ข้อความที่ด้านล่างจะแสดงสิ่งที่เปลี่ยนแปลงเป็นเวลา 30 วินาที พร้อมปุ่ม **คืนค่า** เพื่อเลิกทำ

:::note
- การคืนค่าจะกลับไปเป็นการตั้งค่าของคุณเอง ไม่ใช่ธีมที่ถูกแทนที่
- การเปลี่ยนรูปลักษณ์ที่ทำระหว่างใช้ธีมจะไม่ถูกเก็บไว้หลังคืนค่า
:::

- **กำลังดาวน์โหลด…**: เปิด Steam ไว้ คุณสามารถใช้ธีมได้เมื่อดาวน์โหลดเสร็จ
- **ธีมที่ถูกนำออก (#id)**: ธีมไม่อยู่ในการสมัครสมาชิก Steam ของคุณแล้ว แต่บางฟีเจอร์ยังใช้อยู่ รูปภาพอาจไม่แสดง จึงแนะนำให้คืนค่า
- หาก Steam ไม่ได้เปิดอยู่ ให้เปิด Steam แล้วคลิก **รีเฟรช**

## ธีมของฉัน: อัปโหลดธีม

1. ตั้งค่ารูปลักษณ์ของฟีเจอร์ที่คุณต้องการแชร์ในหน้าของแต่ละฟีเจอร์
2. ใน **ธีมของฉัน** คลิก **อัปโหลดธีมใหม่**
3. กรอก:
   - **ชื่อธีม** (จำเป็น)
   - **คำอธิบายธีม**
   - **ฟีเจอร์ที่ประกอบด้วย** (อย่างน้อยหนึ่งรายการ)
   - **รูปภาพตัวอย่าง** (จำเป็น ไม่เกิน 1MB): คลิก **เลือกภาพตัวอย่าง**
4. ติ๊กช่องยืนยันว่าคุณมีสิทธิ์เผยแพร่รูปภาพ ฟอนต์ และเสียงทั้งหมดในธีม ไม่อนุญาตให้อัปโหลดทรัพยากรที่มีสิทธิ์ใช้งานเฉพาะส่วนตัวหรือไม่ใช่เชิงพาณิชย์
5. คลิก **อัปโหลดธีม**

หากเห็นข้อความ "โปรดยอมรับข้อกำหนดของ Steam Workshop ในเบราว์เซอร์ก่อน" ให้ยอมรับข้อกำหนดเพื่อให้ธีมเผยแพร่ต่อสาธารณะได้

### การจัดการธีมที่คุณอัปโหลด

แต่ละธีมที่อัปโหลดจะมี:

- **ดาวน์โหลดและใช้**: ใช้ธีมที่เผยแพร่แล้วกับฟีเจอร์ของคุณ การตั้งค่ารูปลักษณ์ปัจจุบันของคุณจะถูกเขียนทับ
- **แก้ไข**: อัปโหลดการตั้งค่ารูปลักษณ์ปัจจุบันของคุณซ้ำไปยังธีมเดิม หากคุณยังไม่ได้ดาวน์โหลดธีมนั้น รูปภาพตัวอย่างเดิมจะไม่ถูกนำมาด้วย และคุณต้องเลือกรูปใหม่
- **จัดการใน Steam**: เปิดธีมใน Steam
