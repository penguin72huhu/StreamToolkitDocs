# แปลเสียง

กดปุ่มลัดค้างไว้แล้วพูด Stream Toolkit จะแปลงคำพูดของคุณเป็นข้อความ แปล แล้วแสดงทั้งสองบรรทัดเป็นคำบรรยายใน OBS

การรู้จำเสียงทำงานบนคอมพิวเตอร์ของคุณเองด้วยโมเดล Whisper จากนั้นข้อความจะถูกแปลด้วย MyMemory

หน้านี้มีสองแท็บ: **ตั้งค่า** และ **รูปลักษณ์**

## ขั้นตอนที่ 1: เพิ่มซอร์ส OBS

URL ซอร์ส OBS แสดงอยู่ที่ด้านบนของหน้า:

```
http://127.0.0.1:7272/voice-translate
```

คลิก **คัดลอก** แล้วเพิ่มลงใน OBS เป็นซอร์สเบราว์เซอร์ ดู [วิธีเพิ่มซอร์สใน OBS](../getting-started/obs-source) แปลเสียงไม่มีเสียง จึงไม่จำเป็นต้องเปิด "ควบคุมเสียงผ่าน OBS"

คำบรรยายจะปรากฏที่ด้านล่างของซอร์ส: ข้อความต้นฉบับอยู่ด้านบนและคำแปลอยู่ด้านล่าง และจะค่อย ๆ หายไปหลังจาก **ระยะเวลาแสดงคำบรรยาย**

:::tip
เปิดสวิตช์ข้าง **แปลเสียง** ในแถบด้านซ้าย (**เปิดการแสดงใน OBS**) ปุ่มลัดจะทำงานเฉพาะตอนที่สวิตช์เปิดอยู่เท่านั้น
:::

## ขั้นตอนที่ 2: ตั้งค่าปุ่มลัด

ใน **ปุ่มลัด (กดค้างเพื่ออัด ปล่อยเพื่อถอดเสียง)**:

1. คลิก **คลิกเพื่อตั้งปุ่มลัด**
2. กดชุดปุ่มที่ต้องการ แล้วปล่อย กด **Esc** เพื่อยกเลิก
3. หากต้องการลบปุ่มลัด ให้คลิก **ล้าง**

หากชุดปุ่มนั้นถูกใช้โดยฟีเจอร์อื่นอยู่แล้ว ปุ่มจะแสดง **ปุ่มลัดขัดแย้ง** และปุ่มลัดจะไม่ถูกบันทึก

ปุ่มลัดทำงานได้แม้ Stream Toolkit จะไม่ใช่หน้าต่างที่ใช้งานอยู่ **กดค้าง** ไว้ระหว่างที่พูด แล้ว **ปล่อย** เพื่อถอดเสียงและแปล การบันทึกจะหยุดอัตโนมัติหลังจาก 15 วินาที

คุณยังสามารถใช้เมาส์กดปุ่ม **REC** ใต้ปุ่มลัดค้างไว้ได้ ซึ่งทำงานแบบเดียวกัน: กดเพื่อบันทึก ปล่อยเพื่อแปล หน้าต่าง [เครื่องมือด่วน](./quick-tools) ก็มีปุ่ม **REC** แบบเดียวกัน

## ขั้นตอนที่ 3: ตั้งค่าการถอดเสียง

| ฟิลด์ | คำอธิบาย |
|-------|-------------|
| **สถานะโมเดล** | แสดง **กำลังโหลด xx%**, **พร้อมแล้ว** หรือ **โหลดโมเดลไม่สำเร็จ** บันทึกเสียงได้เมื่อแสดง **พร้อมแล้ว** |
| **โมเดล Whisper** | **Tiny (เร็วที่สุด ประมาณ 40MB)**, **Base (แนะนำ ประมาณ 75MB)** (ค่าเริ่มต้น) หรือ **Small (แม่นยำที่สุด ประมาณ 245MB)** โมเดลจะถูกดาวน์โหลดเมื่อใช้งานครั้งแรก การเปลี่ยนโมเดลจะโหลดโมเดลใหม่ |
| **ภาษาของเสียงพูด** | ภาษาที่คุณพูด ค่าเริ่มต้นคือภาษาจีนตัวเต็ม |
| **ไมโครโฟน** | ไมโครโฟนที่ใช้บันทึก **ค่าเริ่มต้นของระบบ** จะใช้อุปกรณ์อินพุตเริ่มต้นของ Windows |

## ขั้นตอนที่ 4: ตั้งค่าการแปล

| ฟิลด์ | คำอธิบาย |
|-------|-------------|
| **ระยะเวลาแสดงคำบรรยาย** | ระยะเวลาที่คำบรรยายแสดงบนหน้าจอ 1–30 วินาที ค่าเริ่มต้นคือ 5 |
| **ภาษาเป้าหมาย** | ภาษาที่จะแปลไป ค่าเริ่มต้นคือภาษาอังกฤษ |
| **ใช้ Whisper แปลเมื่อภาษาเป้าหมายเป็น English** | เมื่อภาษาเป้าหมายเป็นภาษาอังกฤษ Whisper จะแปลแทน MyMemory (ฟรีและไม่มีโควตา แต่มีความหน่วงสูงกว่า) ไม่มีผลกับภาษาเป้าหมายอื่น |
| **บริการแปล** | MyMemory |

### Email (ไม่บังคับ)

MyMemory ใช้งานฟรี โควตารายวันขึ้นอยู่กับว่าคุณใส่อีเมลหรือไม่:

- ไม่ใส่อีเมล: 5,000 ตัวอักษร/วัน
- ใส่อีเมล: 50,000 ตัวอักษร/วัน (ฟรี ไม่ต้องลงทะเบียน MyMemory)

ใส่อีเมลของคุณแล้วคลิก **บันทึก** อีเมลนี้ **ใช้ร่วมกับการแปลห้องแชท**

แถบด้านล่างแสดง **ใช้ไปวันนี้ (ประมาณการ รีเซ็ตเวลา UTC 08:00 ทุกวัน)** เมื่อใช้โควตาหมดแล้ว จะแสดง **ใช้เต็มแล้ว**

## ขั้นตอนที่ 5: รูปลักษณ์

ในแท็บ **รูปลักษณ์** คุณสามารถเปลี่ยนหน้าตาของคำบรรยายได้ การเปลี่ยนแปลงจะถูกบันทึกทันที

- **ตัวอย่าง**: แสดงคำบรรยายตัวอย่าง กล่องสีข้าง ๆ จะเปลี่ยนเฉพาะพื้นหลังของตัวอย่าง
- **การจัดเรียง**: **ชิดซ้าย** (ค่าเริ่มต้น), **กึ่งกลาง** หรือ **ชิดขวา**
- **ฟอนต์**: หนึ่งแถวสำหรับ **ภาษาต้นฉบับ** (ข้อความต้นฉบับ) และหนึ่งแถวสำหรับ **ภาษาเป้าหมาย** (คำแปล) แต่ละแถวมีฟอนต์ สี และขนาด (8–120 px) ค่าเริ่มต้นคือ 14 px สำหรับต้นฉบับ และ 22 px สำหรับคำแปล
- **เงา**: สีเงาของข้อความ
- **คืนค่าเริ่มต้น**: คืนรูปลักษณ์เริ่มต้น

## คำถามที่พบบ่อย

**Q: กดปุ่มลัดค้างไว้แล้วแต่ไม่มีอะไรเกิดขึ้น**
ตรวจสอบว่าสวิตช์ข้าง **แปลเสียง** ในแถบด้านซ้ายเปิดอยู่ และ **สถานะโมเดล** แสดง **พร้อมแล้ว**

**Q: บันทึกเสียงได้ แต่ไม่มีคำบรรยายปรากฏใน OBS**
หาก MyMemory แปลไม่ได้ (เช่น ใช้โควตารายวันหมดแล้ว) จะไม่มีคำบรรยายแสดง ตรวจสอบแถบ **ใช้ไปวันนี้** การใส่อีเมลจะเพิ่มโควตา หากภาษาเป้าหมายของคุณเป็นภาษาอังกฤษ คุณยังสามารถเปิด **ใช้ Whisper แปลเมื่อภาษาเป้าหมายเป็น English** ซึ่งไม่มีโควตาได้ด้วย
