# ปุ่มลัด

**⌨️ ปุ่มลัด** ที่ด้านล่างของเมนูด้านซ้ายแสดงรายการปุ่มลัดทั้งหมดที่คุณตั้งค่าไว้ในที่เดียว

## ภาพรวมปุ่มลัด

แต่ละแถวแสดงชุดปุ่มและสิ่งที่ปุ่มนั้นสั่งให้ทำงาน เช่น `ตัวจับเวลา › (ชื่อตัวจับเวลา) › เริ่ม / หยุดชั่วคราว` คลิกที่แถวเพื่อเปิดหน้าตั้งค่าของฟีเจอร์นั้นและแก้ไขที่นั่น ไม่สามารถแก้ไขปุ่มลัดในหน้านี้ได้

หากยังไม่ได้ตั้งค่าอะไรเลย จะแสดง "ยังไม่ได้ตั้งค่าปุ่มลัด"

## ฟีเจอร์ที่มีปุ่มลัด

| ฟีเจอร์ | ปุ่มลัดทำอะไร |
|------|------|
| [ตัวทำเครื่องหมายไฮไลต์สตรีม](./highlight) | เพิ่มเครื่องหมาย |
| [Media Board](./multimedia) | เล่นเสียง / แสดงรูปภาพ / เล่นวิดีโอ (หนึ่งปุ่มลัดต่อหนึ่งรายการ) |

| [ควบคุมฉาก OBS](./obs-scene) | **สลับฉาก** / **สลับแหล่ง** |
| [ตัวจับเวลา](./timer) | **เริ่ม / หยุดชั่วคราว**, **รอบ**, **รีเซ็ต** (แยกตามตัวจับเวลา) |

## การตั้งค่าปุ่มลัด

[ตัวทำเครื่องหมายไฮไลต์สตรีม](./highlight), [ควบคุมฉาก OBS](./obs-scene) และ [ตัวจับเวลา](./timer) ใช้ช่องปุ่มลัดแบบเดียวกัน สำหรับ Media Board และแปลเสียง ดูที่หน้าของแต่ละฟีเจอร์

1. คลิกปุ่มปุ่มลัด
2. กดชุดปุ่มที่ต้องการ เช่น `Ctrl+Shift+F1`
3. ปล่อยปุ่มทั้งหมดเพื่อบันทึก

- กด **Esc** ระหว่างบันทึกเพื่อยกเลิก
- หากชุดปุ่มนั้นถูกใช้โดยปุ่มลัดอื่นอยู่แล้ว จะมีข้อความแจ้งว่าขัดแย้งกันและจะไม่ถูกบันทึก ให้เลือกชุดปุ่มอื่น
- คลิก **✕** (หรือปุ่มล้าง) ข้าง ๆ เพื่อลบปุ่มลัด
- ปุ่มบนแป้นตัวเลข (Numpad) แยกจากปุ่มตัวเลขในแถวหลัก: `Num1` และ `1` เป็นปุ่มลัดคนละปุ่มกัน

ปุ่มลัดทำงานได้แม้ Stream Toolkit จะทำงานอยู่เบื้องหลัง เช่น ขณะที่คุณกำลังเล่นเกม
