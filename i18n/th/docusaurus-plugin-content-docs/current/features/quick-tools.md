# เครื่องมือด่วน

**เครื่องมือด่วน** คือหน้าต่างควบคุมขนาดเล็กที่คุณเปิดค้างไว้ข้างเกมหรือ OBS ได้ ช่วยให้คุณเปิด/ปิดฟีเจอร์และใช้ตัวควบคุมที่ใช้บ่อยที่สุดได้โดยไม่ต้องสลับกลับไปที่หน้าต่างหลัก

## การเปิดเครื่องมือด่วน

ใช้วิธีใดวิธีหนึ่งต่อไปนี้:

- คลิก **⚡ เครื่องมือด่วน** ที่ด้านบนของแถบด้านซ้ายในหน้าต่างหลัก
- คลิกขวาที่ไอคอน Stream Toolkit ในถาดระบบแล้วเลือก **เปิดเครื่องมือด่วน**

หากหน้าต่างเปิดอยู่แล้ว หน้าต่างนั้นจะขึ้นมาด้านหน้าแทนการเปิดหน้าต่างที่สอง

## หน้าต่าง

- **ย้ายหน้าต่าง**: ลากแถบชื่อเรื่อง
- **📌 ปักหมุด / เลิกปักหมุด**: ให้หน้าต่างอยู่บนสุดเหนือหน้าต่างอื่นเสมอ การปักหมุดจะเปิดอยู่เมื่อเปิดหน้าต่าง
- **✕**: ปิดหน้าต่าง

หน้าต่างจะใช้ธีมและภาษาอินเทอร์เฟซตามโปรแกรม

## แผงสลับด่วน

คลิกลูกศร **›** ที่ขอบซ้ายเพื่อเลื่อนแผง **สลับด่วน** ออกมา แผงนี้แสดงรายการฟีเจอร์ทั้งหมด:

- สวิตช์ใช้เปิดหรือปิดฟีเจอร์ (เหมือนกับสวิตช์ข้างแต่ละฟีเจอร์ในแถบด้านข้างของหน้าต่างหลัก)
- **⚙** (**เปิดการตั้งค่า**) จะเปิดหน้าต่างหลักไปที่หน้าตั้งค่าของฟีเจอร์นั้น

คลิกนอกแผงหรือคลิกลูกศรอีกครั้งเพื่อปิด

ฟีเจอร์จะเรียงตามลำดับเดียวกับแถบด้านข้างของหน้าต่างหลัก หากต้องการเปลี่ยนลำดับ ให้ลากที่จับ **⠿** ข้างฟีเจอร์ในแถบด้านข้างของหน้าต่างหลัก

## การ์ดฟีเจอร์

ฟีเจอร์ที่เปิดอยู่และมีตัวควบคุมจะแสดงเป็นการ์ด การ์ดจะเริ่มต้นแบบยุบไว้ — คลิกชื่อการ์ดเพื่อขยายหรือยุบ หากไม่มีฟีเจอร์เหล่านี้เปิดอยู่เลย หน้าต่างจะแสดง **ยังไม่ได้เปิดใช้งานฟีเจอร์ใดๆ**

| ฟีเจอร์ | สิ่งที่การ์ดมีให้ |
|---------|---------------------|
| [ควบคุมฉาก OBS](./obs-scene) | สถานะการเชื่อมต่อ พร้อมปุ่มสำหรับการสลับฉากหรือการสลับแหล่งแต่ละรายการที่ตั้งค่าไว้ (ฉากปัจจุบันจะถูกไฮไลต์) ปุ่มจะใช้งานไม่ได้ระหว่างที่ไม่ได้เชื่อมต่อ การ์ดจะแสดงเมื่อมีรายการปุ่มลัดอย่างน้อยหนึ่งรายการเท่านั้น |
| [แปลเสียง](./voice-translate) | ปุ่ม **REC** — กดค้างไว้เพื่อบันทึก ปล่อยเพื่อแปล |
| [ตัวทำเครื่องหมายไฮไลต์สตรีม](./highlight) | ปุ่ม **MARK** หลังทำเครื่องหมาย จะแสดงไอคอนแพลตฟอร์มและเวลาเป็นเวลา 5 วินาที |
| [แถบเป้าหมายการสนับสนุน](./donate) | จำนวนปัจจุบัน / เป้าหมายพร้อมแถบความคืบหน้า ช่อง **เพิ่มจำนวนด้วยตนเอง** พร้อมปุ่ม **เพิ่ม** และ **รีเซ็ตเป็นศูนย์** |
| [ตัวจับเวลา](./timer) | สำหรับตัวจับเวลาแต่ละตัวที่แสดง: ชื่อ เวลา **เริ่ม** / **หยุดชั่วคราว**, **รีเซ็ต** และปุ่มเพิ่มเวลาที่คุณตั้งค่าไว้ นาฬิกาจับเวลาจะแสดง **หยุด** และ **รอบเดียว** แทน |
| [วงล้อสุ่ม](./turntable) | สำหรับวงล้อแต่ละอันที่แสดง: **เริ่มหมุน** และ **รีเซ็ต** |
| [Media Board](./multimedia) | ปุ่มสำหรับรูปภาพที่ปักหมุด (แสดง / ซ่อน) วิดีโอที่ปักหมุด (เล่น) และเสียงที่ปักหมุด (เล่น) |
| [ขอเพลง](./song-request) | **เล่น** / **หยุดชั่วคราว**, **หยุด**, **เพลงถัดไป** |

หากตัวควบคุมมีปุ่มลัดกำหนดไว้ ปุ่มลัดจะแสดงบนปุ่มนั้น

ฟีเจอร์ที่ไม่มีอะไรให้ควบคุมที่นี่ (ห้องแชท แถบเป้าหมาย Twitch การแจ้งเตือนการสนับสนุน กระดานการสนับสนุน นาฬิกา กำแพงอิโมจิ โพลสด การจับรางวัล แชทบอท) จะมีเพียงสวิตช์เปิด/ปิดในแผงสลับด่วนเท่านั้น

:::tip
**รีเซ็ตเป็นศูนย์** บนการ์ดแถบเป้าหมายการสนับสนุนต้องคลิกสองครั้ง: คลิกแรกจะเปลี่ยนปุ่มเป็น **ยืนยันรีเซ็ตเป็นศูนย์** และคลิกครั้งที่สองภายใน 10 วินาทีจะตั้งจำนวนเป็นศูนย์
:::

:::info
ตัวจับเวลาและวงล้อจะเป็นไปตาม **โหมดการแสดงผล** ของแต่ละฟีเจอร์: เมื่อเป็น **ตัวจับเวลาเดียว** / **วงล้อเดียว** จะแสดงเฉพาะอันที่เลือกอยู่ เมื่อเป็น **หลายตัวจับเวลา** / **หลายวงล้อ** จะแสดงเฉพาะอันที่คุณเพิ่มไว้ หากไม่มีเลย การ์ดจะแสดง **ยังไม่มีตัวจับเวลา** / **ยังไม่มีวงล้อ**
:::
