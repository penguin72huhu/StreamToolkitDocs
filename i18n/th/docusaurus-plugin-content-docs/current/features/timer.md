# ตัวจับเวลา

แสดงตัวจับเวลานับถอยหลังหรือนาฬิกาจับเวลาบนสตรีม ตัวนับถอยหลังสามารถเพิ่มหรือลดเวลาได้จากปุ่มที่คุณคลิก หรือโดยอัตโนมัติจากการติดตาม สมาชิก Bits และการสนับสนุนบน Twitch

หน้านี้มีสองแท็บ: **ตั้งค่า** และ **สร้างตัวจับเวลา** ให้สร้างตัวจับเวลาก่อน แล้วควบคุมจาก **ตั้งค่า**

## ขั้นตอนที่ 1: สร้างตัวจับเวลา

1. เปิด **ตัวจับเวลา** ในแถบด้านซ้ายแล้วสลับไปที่แท็บ **สร้างตัวจับเวลา**
2. ใน **ตัวจับเวลาของฉัน** คลิก **เพิ่ม** ตัวจับเวลานับถอยหลังใหม่จะถูกสร้างขึ้นโดยมีเวลาเริ่มต้น 10 นาทีและตัวเลือกเวลาสามรายการ (+30 วินาที, +1 นาที, +5 นาที)
3. คลิกการ์ดตัวจับเวลาเพื่อแก้ไข คลิก **✕** บนการ์ดเพื่อลบตัวจับเวลานั้น

**ตัวอย่าง** แสดงหน้าตาของตัวจับเวลาที่เลือก ใช้กล่องสีข้าง ๆ เพื่อเปลี่ยนพื้นหลังของตัวอย่าง

ใต้ตัวอย่าง สลับระหว่าง **ตั้งค่าตัวจับเวลา** และ **รูปลักษณ์**

## ขั้นตอนที่ 2: ตั้งค่าตัวจับเวลา

### โหมดจับเวลา

- **นับถอยหลัง**: นับถอยหลังจากเวลาเริ่มต้น
- **นาฬิกาจับเวลา**: นับขึ้นจาก 0 และบันทึกรอบได้ โหมดนาฬิกาจับเวลาไม่มีเวลาเริ่มต้น เวลาเตือน เสียงเมื่อจบ หรือตัวเลือกเวลา

### ชื่อ

ชื่อที่แสดงในรายการตัวจับเวลา เมนูดรอปดาวน์ และเครื่องมือด่วน

### เวลาเริ่มต้น

เวลาเริ่มต้นของการนับถอยหลัง เป็นชั่วโมง นาที และวินาที ผลรวมเป็นวินาทีจะแสดงอยู่ข้าง ๆ

### เวลาเตือน

เมื่อเวลาที่เหลือถึงค่านี้ ข้อความตัวจับเวลาจะเปลี่ยนเป็นสี **เตือน** ที่ตั้งไว้ใน **รูปลักษณ์** ตั้งเป็น 0 หากไม่ต้องการเตือน

### เสียงเมื่อนับถอยหลังจบ

เสียงที่เล่นเมื่อการนับถอยหลังถึง 0 เลือก **ไม่มี** หรือเสียงในตัว (**เสียงกระดิ่ง**, **เหรียญ**, **เสียงระฆัง**, **ป๊อป**, **แตรวง**) คลิก **▶** เพื่อทดสอบ หากต้องการใช้ไฟล์ของคุณเอง ให้คลิก **เลือกเสียง** แล้วเลือกจากตัวจัดการวัสดุ

เสียงจะเล่นโดยซอร์สเบราว์เซอร์ของ OBS จึงต้องเปิด **ควบคุมเสียงผ่าน OBS** สำหรับซอร์สตัวจับเวลา ดู [วิธีเพิ่มซอร์สใน OBS](../getting-started/obs-source)

### ตัวเลือกเวลา

ตัวเลือกเวลาคือปุ่มเพิ่ม/ลดเวลาสำหรับการนับถอยหลัง ตัวจับเวลาแต่ละตัวมีได้สูงสุด 20 รายการ

หากต้องการเพิ่ม ให้กรอกฟอร์ม **เพิ่มตัวเลือกเวลา**:

1. **แหล่งทริกเกอร์**: เลือกสิ่งที่จะทำให้ตัวเลือกนี้ทำงานโดยอัตโนมัติ
   - **ด้วยตนเอง**: ทำงานเฉพาะเมื่อคุณคลิกปุ่ม
   - **ติดตาม**: ทำงานทุกครั้งที่มีการติดตามใหม่บน Twitch
   - **Twitch Bits**: ทำงานเมื่อมีการ Cheer Bits
   - **สมาชิกใหม่ Twitch**: ทำงานเมื่อมีการสมัครสมาชิก Twitch
   - **การสนับสนุน**: ทำงานเมื่อมีการสนับสนุน ใช้ **แพลตฟอร์มสนับสนุน** เพื่อเลือกว่าจะนับ **YouTube**, **O'Pay**, **ECPay** และ **PayPal** รายการใด
2. สำหรับ **Twitch Bits** และ **การสนับสนุน** ให้ตั้งค่าเพิ่มเติม:
   - **เกณฑ์ทริกเกอร์**: จำนวน Bits หรือจำนวนเงินสนับสนุนต่อหนึ่งขั้น
   - **วิธีแปลงค่า**: **ทริกเกอร์เป็นจำนวนเต็มเท่า** หรือ **แปลงค่าตามสัดส่วน** (ดูตัวอย่างด้านล่าง)
3. **เพิ่มเวลา**: เลือก **＋** หรือ **－** แล้วตั้งชั่วโมง นาที และวินาที
4. คลิก **เพิ่ม**

หากต้องการเปลี่ยนตัวเลือก ให้คลิก **แก้ไข** ของตัวเลือกนั้น แก้ไขฟอร์ม แล้วคลิก **บันทึก** (หรือ **ยกเลิก**) คลิก **✕** เพื่อลบ ตัวเลือกที่มีทริกเกอร์อัตโนมัติจะมีเครื่องหมาย 🔗 และชื่อทริกเกอร์

**ตัวอย่างการแปลงค่า**: เกณฑ์ทริกเกอร์ 100 bits เพิ่มเวลา +1 นาที และผู้ชม Cheer 250 bits:

- **ทริกเกอร์เป็นจำนวนเต็มเท่า**: นับเฉพาะผลคูณเต็มของเกณฑ์เท่านั้น → 2 × 1 นาที = **+2 นาที**
- **แปลงค่าตามสัดส่วน**: 250 ÷ 100 × 1 นาที → **+2 นาที 30 วินาที**

สำหรับการสนับสนุน จำนวนเงินจะถูกแปลงเป็นสกุลเงินที่เลือกไว้ในหน้าตั้งค่าของโปรแกรมก่อนนำไปเปรียบเทียบกับเกณฑ์

:::note
- ทริกเกอร์อัตโนมัติมีผลเฉพาะกับตัวจับเวลานับถอยหลังเท่านั้น
- ตัวเลือกเวลาที่มีทริกเกอร์อัตโนมัติยังคงแสดงเป็นปุ่มในแผงควบคุม คุณจึงคลิกเองได้ด้วย
- **สมาชิกใหม่ Twitch** ทำงานหนึ่งครั้งต่อเหตุการณ์สมัครสมาชิกหนึ่งครั้ง: การมอบสมาชิกหลายรายการจะทำงานเพียงครั้งเดียว การต่ออายุสมาชิกจะทำงานเฉพาะเมื่อเปิด **นับการต่ออายุสมาชิก** ใน [แถบเป้าหมาย Twitch](./goal)
:::

### ปุ่มลัดควบคุม

ตั้งปุ่มลัดแป้นพิมพ์สำหรับตัวจับเวลานี้:

- **เริ่ม／หยุดชั่วคราว**
- **ปุ่มลัดจับรอบ** (เฉพาะนาฬิกาจับเวลา)
- **ปุ่มลัดรีเซ็ต**

ดูเพิ่มเติมที่ [ปุ่มลัด](./hotkeys)

## ขั้นตอนที่ 3: รูปลักษณ์

| การตั้งค่า | คำอธิบาย |
|---------|-------------|
| **ฟอนต์** | ฟอนต์ของข้อความเวลา |
| **ขนาดตัวอักษร** | 12–300 px |
| **สีตัวอักษร** | **ปกติ**: **สีทึบ** หรือ **ไล่ระดับสี** (สองสีพร้อม **มุม**) **เตือน** (เฉพาะนับถอยหลัง): สีที่ใช้เมื่อถึงเวลาเตือน |
| **สีพื้นหลัง** | พื้นหลังด้านหลังเวลา |
| **ขอบ** | สีขอบ **ความโปร่งใส** และ **ความหนา** (0–20 px) |
| **เงา** | สีเงา **ความโปร่งใส**, **เบลอ** และระยะเลื่อน **X** / **Y** |

## ขั้นตอนที่ 4: เลือกโหมดการแสดงผลและเพิ่มซอร์ส OBS

สลับไปที่แท็บ **ตั้งค่า** ใน **แผงควบคุม** ให้เลือก **โหมดการแสดงผล**:

| โหมด | คำอธิบาย | URL ซอร์ส OBS |
|------|-------------|----------------|
| **ตัวจับเวลาเดียว** | OBS แสดงเฉพาะตัวจับเวลาที่เลือก สลับตัวจับเวลาได้ด้วยเมนูดรอปดาวน์ **ตัวจับเวลาปัจจุบัน** | `http://127.0.0.1:7272/timer` |
| **หลายตัวจับเวลา** | ตัวจับเวลาแต่ละตัวมี URL ของตัวเอง และเพิ่มลงใน OBS แยกกันได้ | `http://127.0.0.1:7272/timer/<timer ID>` |

ในโหมด **หลายตัวจับเวลา** ให้เลือกตัวจับเวลาจาก **เพิ่มเข้าการแสดงผล** ตัวจับเวลาแต่ละตัวที่เพิ่มจะมีการ์ดของตัวเองพร้อม **URL แหล่งที่มาสำหรับ OBS** คลิก **คัดลอก** เพื่อคัดลอก คลิก **✕** บนการ์ดเพื่อนำออกจากการแสดงผล

เพิ่ม URL ที่คัดลอกลงใน OBS เป็นซอร์สเบราว์เซอร์ ดู [วิธีเพิ่มซอร์สใน OBS](../getting-started/obs-source)

:::tip
เปิดสวิตช์ข้าง **ตัวจับเวลา** ในแถบด้านซ้ายด้วย (**เปิดการแสดงใน OBS**) ระหว่างที่ปิดอยู่ ตัวจับเวลาจะถูกซ่อนใน OBS
:::

## ขั้นตอนที่ 5: ควบคุมตัวจับเวลา

การ์ดตัวจับเวลาแต่ละใบในแท็บ **ตั้งค่า** มี:

- **เริ่ม** / **หยุดชั่วคราว**: สำหรับนาฬิกาจับเวลา ปุ่มหยุดชั่วคราวจะเป็น **หยุด** ตัวนับถอยหลังที่ถึง 0 แล้วจะเริ่มไม่ได้จนกว่าคุณจะรีเซ็ตหรือเพิ่มเวลา
- **จับรอบ** (เฉพาะนาฬิกาจับเวลา): บันทึกรอบระหว่างที่กำลังทำงาน รอบจะแสดงใต้การ์ดพร้อมเวลาและผลต่างจากรอบก่อนหน้า
- **รีเซ็ต**: หยุดตัวจับเวลาและกลับไปที่เวลาเริ่มต้น (0 สำหรับนาฬิกาจับเวลา) พร้อมล้างรอบ
- **เพิ่มเวลา** (เฉพาะนับถอยหลัง): ปุ่มหนึ่งปุ่มต่อตัวเลือกเวลาหนึ่งรายการ

เวลาที่กำลังเดินจะแสดงเฉพาะในโอเวอร์เลย์ OBS ไม่แสดงในหน้าตั้งค่า คุณยังสามารถควบคุมตัวจับเวลาจากหน้าต่าง [เครื่องมือด่วน](./quick-tools) ซึ่งแสดงเวลาปัจจุบันด้วย
