# ควบคุมฉาก OBS

**ควบคุมฉาก OBS** ช่วยให้คุณสลับฉากและแสดง/ซ่อนแหล่งในซอฟต์แวร์สตรีมของคุณได้ด้วยปุ่มลัดแบบ global หรือจาก [เครื่องมือด่วน](./quick-tools) รองรับ **OBS Studio**, **Streamlabs** และ **Meld Studio**

ฟีเจอร์นี้ไม่มีโอเวอร์เลย์ จึงไม่ต้องเพิ่มอะไรใน OBS เป็นซอร์สเบราว์เซอร์

:::info
ปุ่มลัดจะทำงานเฉพาะตอนที่สวิตช์ **ควบคุมฉาก OBS** ในแถบด้านข้างเปิดอยู่เท่านั้น และทำงานได้แม้หน้าต่าง Stream Toolkit จะถูกย่อไว้ในถาดระบบ
:::

หน้าตั้งค่ามีสองแท็บ: **การเชื่อมต่อ** และ **ปุ่มลัด**

## แท็บการเชื่อมต่อ

### ขั้นตอนที่ 1: เลือกซอฟต์แวร์ของคุณ

ในส่วน **ซอฟต์แวร์** ให้เลือก **OBS Studio**, **Streamlabs** หรือ **Meld Studio** เปลี่ยนได้เฉพาะตอนที่ไม่ได้เชื่อมต่ออยู่เท่านั้น

ซอฟต์แวร์แต่ละตัวเก็บปุ่มลัดและรายการฉากของตัวเอง ดังนั้นเมื่อสลับซอฟต์แวร์ จะแสดงการตั้งค่าของซอฟต์แวร์นั้น

### ขั้นตอนที่ 2: เตรียมซอฟต์แวร์

#### OBS Studio

1. ใน OBS ให้เปิด **Tools → WebSocket Server Settings**
2. ติ๊กเลือก **Enable WebSocket server**
3. คลิก **Show Connect Info** เพื่อดูรหัสผ่าน
4. ใน Stream Toolkit ให้กรอก **โฮสต์** (ค่าเริ่มต้น `localhost`), **พอร์ต** (ค่าเริ่มต้น `4455`) และ **รหัสผ่าน**

#### Streamlabs / Meld Studio

ไม่ต้องตั้งค่าอะไร — แค่เปิดโปรแกรมไว้

### ขั้นตอนที่ 3: เชื่อมต่อ

คลิก **เชื่อมต่อ** **สถานะ** จะเปลี่ยนเป็น **เชื่อมต่อแล้ว** (สำหรับ OBS และ Meld จะแสดงหมายเลขเวอร์ชันด้วย) คลิก **ตัดการเชื่อมต่อ** เพื่อยกเลิกการเชื่อมต่อ

**เชื่อมต่อเมื่อเปิดโปรแกรม** (เปิดเป็นค่าเริ่มต้น): เชื่อมต่ออัตโนมัติเมื่อ Stream Toolkit เริ่มทำงาน และเมื่อคุณเปิดสวิตช์ฟีเจอร์ การปิดสวิตช์ฟีเจอร์จะตัดการเชื่อมต่อ

### ฉาก

ส่วน **ฉาก** แสดงรายการฉากของคุณและจำนวนแหล่งในแต่ละฉาก ฉากปัจจุบันจะถูกไฮไลต์ คลิก **รีเฟรช** เพื่อดึงรายการล่าสุดหลังจากเปลี่ยนฉากในซอฟต์แวร์ของคุณ

เมื่อไม่ได้เชื่อมต่อ จะยังแสดงรายการที่ดึงมาครั้งล่าสุด

## แท็บปุ่มลัด

หากต้องการตั้งปุ่มลัด ให้คลิก **คลิกเพื่อตั้งปุ่มลัด** แล้วกดชุดปุ่ม กด `Esc` เพื่อยกเลิก หากชุดปุ่มนั้นถูกใช้โดยฟีเจอร์อื่นอยู่แล้ว จะแสดง **ปุ่มลัดขัดแย้ง** และจะไม่ถูกบันทึก คลิก **✕** ข้างปุ่มลัดเพื่อล้าง

### สลับฉาก

1. คลิก **เพิ่ม**
2. ตั้งปุ่มลัด
3. เลือกฉากที่จะสลับไป

คลิก **✕** ที่ท้ายแถวเพื่อลบ

### สลับแหล่ง

ปุ่มลัดเดียวควบคุมหลายแหล่งในฉากเดียวกันได้พร้อมกัน

1. คลิก **เพิ่ม**
2. ตั้งปุ่มลัด
3. ใส่ **ชื่อ** (ไม่บังคับ — ใช้เป็นป้ายปุ่มในเครื่องมือด่วน หากเว้นว่างจะใช้ชื่อฉาก)
4. เลือกฉากที่แหล่งเหล่านั้นอยู่
5. คลิก **เพิ่มแหล่ง** เลือกแหล่ง แล้วเลือก **แสดง**, **ซ่อน** หรือ **สลับ** (ค่าเริ่มต้น **สลับ**)
6. ทำขั้นตอนที่ 5 ซ้ำสำหรับแหล่งอื่น ๆ

การเปลี่ยนฉากของรายการจะล้างรายการแหล่งของรายการนั้น

:::tip
ฉากหรือแหล่งที่ไม่มีอยู่ในซอฟต์แวร์ของคุณแล้วจะถูกทำเครื่องหมายเป็นสีแดง ให้เลือกใหม่จากเมนูดรอปดาวน์
:::

## การใช้งานจากเครื่องมือด่วน

เมื่อเปิดฟีเจอร์อยู่และมีรายการปุ่มลัดอย่างน้อยหนึ่งรายการ [เครื่องมือด่วน](./quick-tools) จะแสดงการ์ด **ควบคุมฉาก OBS** พร้อมปุ่มสำหรับแต่ละรายการ การคลิกปุ่มจะทำงานเหมือนกับการกดปุ่มลัดของรายการนั้น

## ข้อความแสดงข้อผิดพลาด

เมื่อใช้ปุ่มลัดหรือปุ่ม อาจมีข้อความเหล่านี้เด้งขึ้นมา:

| ข้อความ | ความหมาย |
|---------|---------|
| **ยังไม่ได้เชื่อมต่อกับ OBS** | ยังไม่ได้เชื่อมต่อ — ไปที่แท็บ **การเชื่อมต่อ** แล้วคลิก **เชื่อมต่อ** |
| **ไม่พบฉาก “…”** | ฉากถูกเปลี่ยนชื่อหรือถูกลบในซอฟต์แวร์ของคุณ |
| **ไม่พบแหล่ง: …** | แหล่งเหล่านั้นไม่มีอยู่ในฉากแล้ว |

## ข้อจำกัดของเวอร์ชันทดลองใช้งาน

:::info
เวอร์ชันทดลองใช้งานมีรายการปุ่มลัดได้ทั้งหมด **1** รายการ (รวมสลับฉากและสลับแหล่ง) ดู [การเปรียบเทียบเวอร์ชันทดลอง / เวอร์ชันเต็ม](../getting-started/trial-comparison)
:::

## คำถามที่พบบ่อย

**Q: แจ้งว่าเชื่อมต่อ OBS ไม่ได้ และไม่ลองใหม่หลังจากที่ฉันเปิด OBS แล้ว**
หากการเชื่อมต่อครั้งแรกสุดล้มเหลว (เช่น OBS ยังไม่ได้เปิด) Stream Toolkit จะไม่พยายามเชื่อมต่อซ้ำ ให้เปิดซอฟต์แวร์สตรีมของคุณ แล้วคลิก **เชื่อมต่อ** เมื่อเชื่อมต่อสำเร็จแล้วครั้งหนึ่ง หากการเชื่อมต่อหลุด ระบบจะเชื่อมต่อใหม่โดยอัตโนมัติ
