# YouTube 設定（新版）

Stream Toolkit は Google アカウントでのログインで YouTube チャンネルを連携します。API キーの作成や入力は不要です。

## ステップ 1：YouTube アカウントを連携

1. Stream Toolkit を起動します
2. 左下のメニューの **設定** をクリックします
3. プラットフォーム連携から **YouTube** を見つけ、**アカウントを連携** をクリックします
4. 確認画面が表示されます。YouTube 利用規約とプライバシーポリシーを確認し、**同意してログイン** をクリックします
5. ブラウザで Google のログインページが開きます。YouTube チャンネルを所有する Google アカウントを選びます（複数のチャンネルがある場合は配信用のチャンネルを選択）
6. 要求される権限を確認し、**続行**／**許可** をクリックします

完了すると、設定の YouTube に **接続済み：チャンネル名** と表示されます。

## 接続を解除

YouTube の横にある **接続を解除** をクリックします。Google アカウントからも Stream Toolkit のアクセス権が削除されます。

## よくある質問

**Q：YouTube API キーはまだ必要ですか？**
不要です。Google アカウントでログインするだけです。

**Q：間違ったチャンネルでログインしてしまった**
**接続を解除** をクリックし、もう一度連携して正しいアカウントまたはチャンネルを選んでください。

**Q：ブラウザでログインしてもアプリが反応しない**
ログイン中は Stream Toolkit を開いたままにしてください。ブラウザが結果をアプリに返します。それでも更新されない場合は、もう一度アカウントを連携してください。
