# エモートウォール

視聴者がチャットでエモートを使うと、そのエモートが配信画面上を漂います。

:::note 始める前に
エモートウォールはチャットからエモートを読み取るため、先に使用するプラットフォームを接続してください。[Twitch 設定](../platforms/twitch) と [YouTube 設定](../platforms/youtube-settings) を参照してください。
:::

## ステップ 1：OBS ソースを追加する

ページ上部の **OBS ソース URL** をコピーします：

```
http://127.0.0.1:7272/emote-wall
```

OBS にブラウザソースとして追加します。[OBS でソースを追加する方法](../getting-started/obs-source) を参照してください。エモートウォールは音を再生しないため、「OBS を介して音声を制御する」をオンにする必要はありません。

:::tip
左サイドバーの **エモートウォール** の横にあるスイッチ（**OBS 表示をオンにする**）もオンにしてください。オフの間は、チャットのエモートはオーバーレイに送信されません。
:::

## ステップ 2：ソースを選ぶ

**ソース** の下には **Twitch** と **YouTube** のカードがあり、それぞれ接続状態が表示されます：

- Twitch アカウントが接続されていない場合、Twitch には **（未接続）** と表示されます
- YouTube チャットが接続されていない場合、YouTube には **チャット URL が未接続です** と表示されます

カードの **絵文字ウォールを有効化** にチェックを入れると、そのプラットフォームのチャットのエモートが表示されます。チェックを外すとそのプラットフォームは無視されます。

## ステップ 3：アニメーション設定

| 設定 | 説明 |
|---------|-------------|
| **スタンプサイズ** | 各エモートのサイズ、16–256 px |
| **1 メッセージあたりの最大 emote 数** | 1 つのチャットメッセージから取り出すエモートの最大数（1–20） |
| **漂う持続時間** | 各エモートが漂う時間、1–30 秒 |
| **漂う速度** | 50–500 px/s |

セクションタイトルの横にある **初期設定に戻す** をクリックすると、4 つの値がすべて元に戻ります。

## ステップ 4：テスト

**テスト（OBS に表示）** をクリックすると、現在の設定でサンプルの Twitch エモートがオーバーレイに送信されます。テストのエモート数は **1 メッセージあたりの最大 emote 数** に従います。
