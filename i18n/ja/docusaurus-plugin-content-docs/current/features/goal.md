# Twitch 目標バー

Twitch のフォロワー、サブスク、Bits の目標をプログレスバーで配信画面に表示します。目標の種類ごとに、専用のバー、設定、OBS URL があります。

:::note 始める前に
目標バーは Twitch のイベントを数えるため、先に Twitch アカウントを接続してください。[Twitch 設定](../platforms/twitch) を参照してください。
:::

## ステップ 1：目標の種類を選んで OBS ソースを追加する

ページ上部で目標の種類を選びます：**フォロー**、**サブスク**、**Bits**。ボタンの下にある **OBS URL** が選択に合わせて変わります。**コピー** をクリックしてコピーします。

| 目標の種類 | OBS ソース URL |
|-----------|----------------|
| **フォロー** | `http://127.0.0.1:7272/goal/follow` |
| **サブスク** | `http://127.0.0.1:7272/goal/sub` |
| **Bits** | `http://127.0.0.1:7272/goal/bits` |

表示したいバーをそれぞれ別のブラウザソースとして OBS に追加します。[OBS でソースを追加する方法](../getting-started/obs-source) を参照してください。目標バーは音を再生しないため、「OBS を介して音声を制御する」をオンにする必要はありません。

:::tip
左サイドバーの **Twitch 目標バー** の横にあるスイッチ（**OBS 表示をオンにする**）もオンにしてください。オフの間、OBS ではバーが非表示になります。
:::

## ステップ 2：目標を設定する

以下の設定はすべて、上部で選んだ目標の種類に適用されます。

- **タイトル**：バーに表示するタイトル
- **目標**：目標の数値（0 以上の整数）
- **進捗**：現在の数、目標、パーセントを表示します

### 進捗の数え方

| 目標の種類 | 進捗に加算されるもの |
|-----------|----------------------|
| **フォロー** | 新規フォローごとに 1 加算。Twitch 接続中は、30 秒ごとに Twitch のチャンネル総フォロワー数とも同期されます。**同期** をクリックするとすぐに同期します |
| **サブスク** | 新規サブスクとギフトサブスク（複数のギフトはギフトされた数だけ加算）。再サブスクは **再サブスクを含める** がオンのときだけ数えます |
| **Bits** | 応援（Cheer）ごとに、その Bits 数を加算します |

### サブスクのオプション

**サブスク** のときだけ表示されます：

- **Tier で加重（T1=+1、T2=+2、T3=+6）**：オンにすると、上位 Tier のサブスクほど進捗に多く加算されます。オフにすると、どのサブスクも 1 加算です
- **再サブスクを含める**：オンにすると、再サブスクのメッセージも進捗に加算されます

### 進捗のリセット

**サブスク** と **Bits** には **進捗をリセット** ボタンがあります。クリックしてから **リセットを実行** をクリックすると、現在の数が 0 に戻ります。目標の数値はそのまま残ります。

**フォロー** の数は Twitch のフォロワー総数に従うため、リセットボタンはありません。

## ステップ 3：外観を調整する

### プレビュー

上部の **プレビュー** には、選んだ目標の種類のバーが表示されます。横のカラーボックスでプレビューの背景色を変更できます。**達成プレビュー** にチェックを入れると、目標達成時のバーの見た目を確認できます。

### 外観設定

| 設定 | 説明 |
|---------|-------------|
| **背景色** | バーの背景 |
| **プログレスバーの色** | 進捗部分の色 |
| **達成時の色** | 目標達成後の進捗部分の色 |
| **タイトル文字** | タイトルのフォント、色、サイズ（8–72 px） |
| **目標文字** | 数値のフォント、色、サイズ（8–72 px） |
| **パーセント** | パーセントのフォント、色、サイズ（8–72 px） |

**初期設定に戻す** をクリックすると、選んだ目標の種類の外観が元に戻ります。

### カスタム CSS

**カスタム CSS** をクリックするとエディタが展開されます。目標の種類ごとに専用の CSS があります。レイアウトや構造の調整に使ってください。色・フォント・サイズは上の外観設定で設定します。

- **初期設定に戻す**：初期 CSS に戻します
- **素材を管理**：CSS で使う画像の素材管理を開きます

CSS で `!important` を使ってプロパティを上書きすると、対応する外観設定の項目はロックされます。どのみち CSS が優先されるためです。

:::info 試用版の制限
- **カスタム CSS** は製品版でのみ使用できます
- OBS オーバーレイに透かしが表示されます

詳しくは [試用版 / 製品版の比較](../getting-started/trial-comparison) を参照してください。
:::
