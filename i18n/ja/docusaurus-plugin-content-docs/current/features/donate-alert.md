# 支援通知

支援があったときに、画像、サウンド、支援者名、金額、メッセージ付きの通知をポップアップ表示します。

## OBS ソース URL

```
http://127.0.0.1:7272/donate-alert
```

**支援通知 の設定** ページ上部の URL をコピーし、OBS にブラウザソースとして追加します。[OBS でソースを追加する方法](../getting-started/obs-source) を参照してください。

:::warning
通知ではサウンドが再生されます。ブラウザソースのプロパティで **OBS を介して音声を制御する** にチェックを入れないと、配信で音が聞こえません。
:::

左サイドバーの **支援通知** の横にあるスイッチで通知のオン/オフを切り替えます。オフの間は通知（テスト通知を含む）は表示されませんが、支援は [支援履歴ボード](./sponsors) に記録され続けます。

複数の支援が続けて届いた場合、通知は順番待ちになり、1 つずつ表示されます。

## 設定タブ

### 連携プラットフォーム

通知を表示するプラットフォームにチェックを入れます：**Twitch**、**YouTube**、**PayPal**、**Stripe**、**O'Pay**、**ECPay**。緑のドットは接続済みを意味します。接続されていない場合は **（未接続）** と表示されます。これらのチェックボックスは通知にのみ影響し、支援目標バーや支援履歴ボードには影響しません。

**Twitch ⚙️**（Twitch が接続済みでチェックが入っているときに表示）：

1. **Bits とサブスクを計算**、**Bits のみ計算**、**サブスクのみ計算** から選びます
2. **再サブスクを含める**：再サブスクで通知を表示するかどうか（サブスクを数える場合に表示）
3. **未満 [N] Bits は計算に含めない**：チェックを入れて最小値を入力すると、それより少ない応援では通知が表示されません（Bits を数える場合に表示）
4. **保存** をクリックします

**YouTube ⚙️**：

- **視聴者名を @ハンドルの代わりに表示**：Google でログインした後にのみ使用できます。
- **カウント対象**：**スーパーチャット**、**スーパーステッカー**、**メンバー加入**、**メンバー継続**、**ギフト メンバーシップ**、**ジュエル**。**ジュエル** には Google ログインが必要です。

YouTube のライブチャットが連携されていない場合、**チャット URL が未接続です** と、**自動接続**（Google ログインが必要）、**手動で入力**（設定のチャット URL 欄に移動）が表示されます。メンバーシップのイベントにチェックを入れているのにメンバー価格が設定されていない場合は、**⚠ メンバー価格が未設定** をクリックして設定してください。[YouTube 設定](../platforms/youtube-settings) を参照してください。

PayPal、Stripe、O'Pay、ECPay の接続方法は [PayPal](../payments/paypal)、[Stripe](../payments/stripe)、[O'Pay](../payments/opay)、[ECPay](../payments/ecpay) を参照してください。

### 設定

| 項目 | 説明 |
|-------|-------------|
| **自国の通貨に自動換算** | 初期設定でオン。設定ページで設定した **サポート通貨** に換算した金額を表示します。 |
| **表示時間** | 各通知が画面に表示される秒数。初期値：6。 |

## 外観タブ

### プレビュー

プレビューには OBS ソースと同じページが使われます。**プレビュー** の横のカラーピッカーでプレビューの背景を変更し、**▶ アニメーションを再生** をクリックすると通知アニメーションをもう一度再生します。

### 共通スタイル / プラットフォームごとに個別

- **共通スタイル**：すべてのプラットフォームで同じ通知スタイルを使います。
- **プラットフォームごとに個別**：プラットフォームごとに専用のスタイルを使います。下のボタン（**Twitch**、**YouTube**、**O'Pay**、**ECPay**、**PayPal**、**Stripe**）でプラットフォームを選び、その設定を編集します。初めて切り替えたとき、まだカスタマイズしていないプラットフォームには現在の共通スタイルがコピーされ、それぞれ専用のカウントダウンバーの色が付きます。

**初期設定に戻す** で、編集中のスタイルを初期スタイルに戻します。

### 画像

- **画像を選択**：素材管理から画像を選びます。画像がない場合はハートの絵文字が表示されます。**クリア** で画像を削除します。
- **画像サイズ**：1–400 px。
- **画像位置**：**左寄せ**、**右寄せ**、**上**、**下**。

### サウンド

内蔵サウンドを選びます：**なし**、**チャイム**（初期設定）、**コイン**、**ベル**、**ポップ**、**ファンファーレ**。**▶** をクリックすると試聴できます。**サウンドを選択** をクリックすると、素材管理から自分のサウンドファイルを使えます。

### テキスト表示

- **デフォルト**：金額、支援者名、メッセージを別々の行に表示します。
- **カスタムテキスト**：自分で 1 行の文を書きます。`{name}` で支援者名、`{amount}` で金額を表示します（例：`Thanks {name} for donating {amount}!`）

### テキストと色

- **テキスト**：**金額**、**サポーター名**、**メッセージ**（カスタムテキストモードでは **カスタムテキスト** も）のフォント、サイズ、色を設定します。
- **色**：**背景**、**影**、**カウントダウンバー**。

### カスタム CSS

**カスタム CSS** を展開すると、編集中のスタイル（共通スタイルまたは選択中のプラットフォーム）の CSS を編集できます。**初期設定に戻す** でテンプレート CSS に戻し、**素材を管理** で素材管理を開きます。ここでは Steam Workshop のテーマも適用できます。テーマを適用している間、CSS は読み取り専用です。[テーマ](./themes) を参照してください。

## 通知のテスト

**設定** ページで、**サポートプラットフォーム連携** の横にある **テスト通知** をクリックします：

1. **テスト名**、**テストメッセージ**、**テスト金額** を入力し、**テストプラットフォーム** を選びます
2. **テスト通知を送信** をクリックします

**YouTube Super Chat テスト** セクションでは、生の **金額文字列**（例：`$5.00`、`¥500`、`NT$150`）を入力して **テスト Super Chat を送信** をクリックすると、金額の解析と通貨換算をテストできます。

:::note
テスト通知は実際の支援と同じように扱われます：[支援目標バー](./donate) と [支援履歴ボード](./sponsors) でそのプラットフォームにチェックが入っていれば、そちらにも加算・記録されます。
:::

:::info 試用版
カスタム CSS は製品版でのみ使用できます。実際の決済サービス（PayPal / Stripe / O'Pay / ECPay）と YouTube のメンバーシップイベント・ジュエルは試用版では使用できず、OBS の通知に透かしが表示されます。[試用版 / 製品版の比較](../getting-started/trial-comparison) を参照してください。
:::

## よくある質問

**Q：配信で音が出ません。**
ブラウザソースのプロパティで **OBS を介して音声を制御する** にチェックが入っているか、OBS の音声ミキサーでソースがミュートになっていないかを確認してください。また、**サウンド** が **なし** になっていないかも確認してください。

**Q：OBS ソースを後から追加しました。それ以前の通知は再生されますか？**
いいえ。新しく開いたソースには、接続後に届いた通知だけが表示されます。
