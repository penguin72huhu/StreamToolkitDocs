# 配信ハイライトマーカー

配信中にショートカットを押すと、ハイライトが「配信開始から何分何秒の時点」で起きたかを記録します。後でその時刻の一覧を使って、編集時にアーカイブからハイライトを探せます。

マーカーは Stream Toolkit に保存されます。この機能には OBS オーバーレイがないため、OBS ソースを追加する必要はありません。

ページには **設定** と **ハイライト記録** の 2 つのタブがあります。

:::tip
左サイドバーの **配信ハイライトマーカー** の横にあるスイッチをオンにしてください。オフの間は、ショートカットでも **MARK** ボタンでもマーカーは追加されません。
:::

## ステップ 1：ソースを選ぶ

**ソース** で配信時間の算出方法を決めます：

| ソース | 時間の算出方法 | 必要なもの |
|--------|----------------------------|-------------|
| **Twitch** | 現在の Twitch 配信の開始からの経過時間 | Twitch の接続。[Twitch 設定](../platforms/twitch) を参照 |
| **YouTube** | 現在の YouTube ライブ配信の開始からの経過時間 | Google ログイン。[YouTube 設定](../platforms/youtube-settings) を参照 |
| **手動で合わせる**（初期設定） | このページの手動タイマーの値 | なし |

**Twitch** と **YouTube** の横のドットは接続状態を示します。接続されていない場合、選択肢には **（未接続）** または **（Google に未ログイン）** と表示されます。

配信していないとき（**手動で合わせる** の場合はタイマー停止中）にマークすると、時間は **配信していません** として記録されます。**Twitch** ソースでは、開始直後の配信を Twitch がまだ認識していない場合に備えて何度か再試行するため、結果が表示されるまで約 20 秒かかることがあります。

### 手動タイマー

**手動で合わせる** を選ぶと **手動タイマー** が表示されます：

1. 現在の配信時間を `HH:MM:SS` で入力します（例：配信開始直後なら `00:00:00`）
2. **同期タイマーを開始** をクリックします。その値からタイマーがカウントアップを始めます
3. すべてのマーカーにタイマーの現在値が使われます
4. **停止** をクリックするとタイマーが止まります

### マーク時に Twitch クリップを作成

ソースが **Twitch** のときだけ表示されるオプションです。オンにすると、マーカーごとに Twitch クリップも作成します。

- 配信中である必要があります。クリップの長さは約 30 秒です
- クリップはクリエイターダッシュボード → コンテンツ → クリップに保存されます
- マーク後、ページには **Twitch クリップを作成しました**、または失敗の理由（**配信中ではありません**、**権限不足です。Twitch を再接続してください**、**Twitch に接続していません**、**作成に失敗しました**）が表示されます

## ステップ 2：ショートカットを設定する

初期のショートカットは `Ctrl+Shift+M` です。変更するには：

1. ショートカットのボタンをクリックします
2. 使いたいキーの組み合わせを押してから離します。**Esc** でキャンセルします
3. 削除するには **クリア** をクリックします

その組み合わせが別の機能ですでに使われている場合、ボタンに **このショートカットは使用済みです** と表示され、ショートカットは保存されません。ショートカットは Stream Toolkit がアクティブウィンドウでなくても動作します。

ショートカットの下にある **MARK** ボタンをクリックしても、ショートカットと同じ動作をします。[クイックツール](./quick-tools) ウィンドウにも **MARK** ボタンがあります。

## ステップ 3：配信中にマークする

1. （任意）マークする前に **マーカー名** に名前を入力します。空欄の場合、マーカーには自動で番号が付きます（`精華標記_1`、`精華標記_2`、…）
2. ショートカットを押すか、**MARK** をクリックします

入力した名前は次のマーカーにだけ使われ、その後入力欄はクリアされます。

## ハイライト記録

**ハイライト記録** タブには、すべてのマーカーが新しい順に一覧表示されます。各行には配信時間、名前、ソース、マークした日時が表示されます。

- **コピー**：マーカーを `[日付] 名前 🎬 配信時間 (ソース)` の形式でテキストとしてコピーします
- **🗑️**：クリックしてから **削除の確認** をクリックすると、マーカーを削除します
- **Twitch クリップを開く**：このマーカーで Twitch クリップが作成された場合に表示されます。Twitch でクリップを開きます
