# チャットボット

チャットに自動でメッセージを投稿します：一定間隔で送る定期メッセージと、視聴者がコマンドを入力したときのキーワード返信です。ボットはあなた自身のアカウントから投稿します。

チャットボットには OBS オーバーレイがないため、追加する URL はありません。

:::tip
左メニューの **チャットボット** の横にあるスイッチをオンにしてください。オフの間、ボットは何も送信しません。
:::

ページには **設定**、**定期メッセージ**、**キーワード返信** の 3 つのタブがあります。

## 設定タブ

**プラットフォーム** の下で **Twitch** をクリックするとオンになります（もう一度クリックするとオフ）。Twitch が接続されていると横のドットが点灯し、そうでない場合は **（未接続）** と表示されます。先に Twitch を接続してください：[Twitch 設定](../platforms/twitch)。

**YouTube** は **近日公開** と表示されており、まだオンにできません。

どのプラットフォームも接続されていない場合、他の 2 つのタブには「プラットフォームが接続されていないため、ボットは何も送信しません。」と **設定へ** ボタンが表示されます。

## 定期メッセージ

配信中、一定間隔ごとにメッセージを投稿します。

1. **+ 追加** をクリックします
2. 以下を入力します：
   - **内容**：投稿するテキスト（Twitch では最大 500 文字）。常に 1 行で、Enter は無効、貼り付けた改行はスペースになります
   - **間隔**：投稿の間隔（分）（5–240、初期値 15）
   - **最少チャット数**：前回の投稿以降、再度投稿するまでに必要な新着チャット数（0–100、初期値 2）。誰も話していないチャットに投稿し続けないためです
   - **プラットフォーム**：投稿先
3. **保存** をクリックします

投稿のしくみ：

- 配信中のみ投稿します。最初の投稿は配信開始の瞬間ではなく、配信開始から 1 間隔分経過した後です
- 複数の定期メッセージが同時に送信時刻を迎えた場合は、まとめて投稿せずに間隔を空けて投稿します

## キーワード返信

視聴者のメッセージがコマンドで始まると返信します。

1. **+ 追加** をクリックします
2. 以下を入力します：
   - **コマンド**：接頭辞（`! @ # $ % & ~`）を選び、スペースなしの 1 単語を入力します（例：`!dc`）。チャットメッセージの最初の単語と照合され、大文字・小文字は区別しません
   - **返信**：投稿するテキスト。`{user}` はコマンドを使った視聴者の名前に置き換わります
   - **クールダウン**：同じコマンドが再び返信できるまでの秒数（0–3600、初期値 5）
   - **プラットフォーム**：返信先
3. **保存** をクリックします

キーワード返信は配信中かどうかに関係なく、いつでも動作します。

コマンドは他のキーワード返信、または [リクエスト曲](./song-request) や [抽選](./lottery) のキーワードですでに使われているコマンドと同じにはできません。

## リストの管理

どちらのタブでも、各項目には次のものがあります：

- 左側のチェックボックス：削除せずに項目をオン/オフできます
- プラットフォームタグ：タグが薄く表示されている場合、そのプラットフォームは設定タブでオフになっています
