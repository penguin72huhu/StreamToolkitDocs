# メディアボード

クリックやショートカットで、配信画面に画像を表示したり、動画や効果音を再生したりできます。

ページには **画像**、**動画**、**サウンド** の 3 つのタブがあります。タブごとに専用の OBS ソース URL があります。

| タブ | OBS ソース URL | OBS を介して音声を制御する |
|-----|----------------|-----------------------|
| **画像** | `http://127.0.0.1:7272/imageboard` | 不要 |
| **動画** | `http://127.0.0.1:7272/videoboard` | 必要 |
| **サウンド** | `http://127.0.0.1:7272/soundboard` | 必要 |

各 URL の横にある **コピー** をクリックし、OBS にブラウザソースとして追加します。[OBS でソースを追加する方法](../getting-started/obs-source) を参照してください。動画とサウンドは Stream Toolkit 内ではなく OBS ソースで再生されるため、この 2 つのソースでは **OBS を介して音声を制御する** をオンにする必要があります。オンにしないと視聴者には聞こえません。

:::tip
左サイドバーの **メディアボード** の横にあるスイッチ（**OBS 表示をオンにする**）をオンにしてください。オフの間は、ボタンでもショートカットでも、画像の表示や動画・サウンドの再生はできません。
:::

## 共通の操作

画像、動画、サウンドはすべてカードとして一覧表示されます：

- カードをクリックすると設定を展開/折りたたみます
- カード右側のチェックボックス：チェックすると、その項目が [クイックツール](./quick-tools) の起動ツールに表示されます。新しい項目は初期設定でチェックされています
- **✕** で項目を削除します
- ローカルファイルが移動または削除された場合、カードに **ファイルが見つかりません** と表示されます

### ショートカット

項目ごとに専用のショートカットを設定できます：

1. カードを展開し、ショートカットのボタンをクリックします
2. 使いたいキーの組み合わせを押してから離します。**Esc** でキャンセルします
3. ショートカットを削除するには **クリア** をクリックします

その組み合わせが別の機能ですでに使われている場合は保存されず、ボタンに競合メッセージが表示されます。ショートカットは Stream Toolkit がアクティブウィンドウでなくても動作します。すべてのショートカットは [ショートカット](./hotkeys) ページにも一覧表示されます。

### 画像を追加する

1. **画像を追加** をクリックします
2. ファイル（jpg、jpeg、png、gif）を選びます。ファイル名が画像名になります

カードを展開すると、サムネイルと次の設定が表示されます：

- **名前**：画像の名前
- **ファイルパス**：**選び直す** をクリックすると別のファイルを選べます
- **ショートカットキー**：1 回押すと画像を表示し、もう一度押すと非表示にします
- **位置とサイズを設定**：下記を参照
- **画像を削除**：画像を削除します

### 表示と非表示

カードの **○** ボタンをクリックすると、OBS に画像が表示され、ボタンが **◉** に変わります。もう一度クリックすると画像を非表示にします。

### 表示設定

**複数の画像を同時に表示することを許可** は初期設定でオフです。オフの間は、画像を表示すると現在表示中の画像が非表示になります。オンにすると複数の画像を同時に表示できます。

### 位置とサイズを設定

- **X 位置** / **Y 位置**：px 単位。0/0 がソースの中央です。正の値で右/下へ、負の値で左/上へ移動します
- **幅** / **高さ**：元のサイズに対する %。100 = 元のサイズ。🔗 ボタンで縦横比を固定します（初期設定でオン）。クリックすると自由に拡大縮小できます
- 画像を表示している間は、変更が OBS にリアルタイムでプレビューされます
- **保存** で変更を保存し、**リセット** でウィンドウを開いたときの値に戻し、**キャンセル** で保存せずに閉じます

## 動画

{/* TODO: 截圖 — 影片分頁 */}

**動画を追加** をクリックしてカードを追加し、展開します：

- **動画名**：カードに表示される名前
- **ソース**：**YouTube** または **ローカル**
  - **YouTube**：**YouTube URL** に動画のリンクを貼り付けます。**解析をテスト** をクリックすると確認できます。成功すると「解析済み。再生時に自動適用されます」と表示されます
  - **ローカル**：**ファイルを選択** をクリックして mp4、webm、ogg ファイルを選びます。サイズの上限は 200MB で、ファイルが大きいほど遅延が大きくなります。背景を透明にするには WebM（VP9 Alpha）動画を使ってください
- **順番に再生**：動画をループ再生します
- **再生時間**：**開始** と **終了**（時・分・秒・ミリ秒）を設定します。**終了** を 00:00 のままにすると最後まで再生します
- **音量**：0–100%
- **ショートカットキー**：押すと動画を再生します。再生中にもう一度押すと停止します
- **位置とサイズを設定**：画像と同じ位置・サイズの項目です。**プレビューをループ** をクリックすると、調整中に OBS で動画をループ再生し、**プレビューを停止** で止めます。終わったら **保存** または **キャンセル** をクリックします

カードの **▶** をクリックすると OBS で動画を再生します。**■** をクリックすると停止します。

## サウンド

{/* TODO: 截圖 — 音效分頁 */}

**サウンドを追加** をクリックしてカードを追加し、展開します：

- **サウンド名**：カードに表示される名前
- **ソース**：**YouTube URL** または **ローカルファイル**
  - **YouTube URL**：リンクを貼り付けて **解析をテスト** をクリックすると確認できます
  - **ローカルファイル**：**ファイルを選択** をクリックして mp3、wav、ogg、flac、m4a、aac、opus ファイルを選びます
- **再生時間**：**開始** と **終了** を設定します。**終了** を 00:00 のままにすると最後まで再生します
- **音量**：0–100%
- **ショートカットキー**：押すとサウンドを再生します

カードの **▶** をクリックすると OBS でサウンドを再生します。**■** をクリックすると停止します。一度に再生できるサウンドは 1 つだけです。別のサウンドを再生すると、現在のサウンドは停止します。

:::info 試用版の制限
- 追加できるのは画像 **1** 件、動画 **1** 件、サウンド **1** 件だけです
- 画像と動画のオーバーレイに透かしが表示されます

詳しくは [試用版 / 製品版の比較](../getting-started/trial-comparison) を参照してください。
:::

## よくある質問

**Q：動画やサウンドは再生されますが、配信で音が出ません。**
`/videoboard` と `/soundboard` のソースで **OBS を介して音声を制御する** にチェックが入っているか、OBS の音声ミキサーでソースがミュートになっていないかを確認してください。

**Q：動画ファイルを選べません。**
選べるのは mp4、webm、ogg ファイルで、最大 200MB です。ファイルが大きすぎる場合は上限を示すメッセージが表示され、ファイルは追加されません。
