# リアルタイム投票

配信中に投票を行います。視聴者が Twitch または YouTube のチャットに選択肢の番号を入力して投票し、結果は OBS オーバーレイにリアルタイムで反映されます。

## OBS ソース URL

```
http://127.0.0.1:7272/vote
```

ページ上部の **OBS ソース URL** の横にある **コピー** をクリックし、OBS にブラウザソースとして追加します。[OBS でソースを追加する方法](../getting-started/obs-source) を参照してください。リアルタイム投票は音を再生しないため、「OBS を介して音声を制御する」をオンにする必要はありません。

:::tip
左サイドバーの **リアルタイム投票** の横にあるスイッチ（**OBS 表示をオンにする**）もオンにしてください。オフの間、オーバーレイは非表示のままです。
:::

ページには **設定**、**外観**、**履歴** の 3 つのタブがあります。

## 投票を始める（設定タブ）

### 投票プラットフォーム

**Twitch** または **YouTube** をクリックして、どのプラットフォームのチャットから投票できるかを選びます。両方選ぶこともできます。接続されていないプラットフォームには、Twitch は **（未接続）**、YouTube は **チャット URL が未接続です** と表示されます。先に接続してください：

- [Twitch 設定](../platforms/twitch)
- [YouTube 設定](../platforms/youtube-settings)

### 投票タイトル

任意。例：「今夜はどのゲーム？」

### 投票の選択肢（2〜10 項目）

- 選択肢を 2 つ以上入力します。最大 10 個まで設定できます
- **+ 選択肢を追加** で行を追加し、**×** で削除します
- **履歴を適用** で最近の投票 15 件から 1 つを選び、そのタイトルと選択肢を入力できます

編集中は、OBS オーバーレイにタイトルと選択肢がプレビュー表示されます。

### 投票時間

投票の長さ（秒）。初期値は 60、最小値は 10 です。

### 開始 / 停止

- **投票を開始**：入力済みの選択肢が 2 つ以上あり、接続済みのプラットフォームが 1 つ以上選ばれている必要があります
- **投票を停止**：投票を途中で終了します。停止しない場合は時間切れで終了します

投票中は、プラットフォーム、タイトル、選択肢、投票時間を変更できません。

## 視聴者の投票方法

投票中、オーバーレイには「チャットに選択肢の番号を入力すると投票できます（例：1）」と表示されます。

- メッセージ全体が選択肢の番号である必要があります（例：`1` や `1.`）。スペースは無視されます。他の文字が含まれるメッセージは数えられません
- 視聴者 1 人につき 1 票です。別の番号を送ると票が新しい選択肢に移り、時間切れ前の最後の票が有効になります

## リアルタイム結果

投票中は、設定の下に **リアルタイム結果** が表示され、残り時間、各選択肢の得票数と割合、総投票数を確認できます。投票終了後は **最終結果** に変わります。**詳細** をクリックすると、各選択肢に誰が投票したかを Twitch と YouTube に分けて確認できます。

## 外観

**外観** タブの上部には **プレビュー** があります。横のカラーピッカーはプレビューの背景だけを変更し、OBS オーバーレイには影響しません。

- **フォント**：**タイトル**、**ヒント**、**選択肢**、**カウントダウン秒数**、**得票数** のフォント、色、**サイズ**（px）を設定します
- **プログレスバーの色**：最大 5 色で、選択肢のバーに順番に使われます。それぞれ **単色** または **グラデーション** を選べます。グラデーションには **角度** もあります
- **背景色**：投票カードの背景
- **初期設定に戻す**：初期の外観に戻します。テーマを適用している場合は、そのテーマの外観に戻します

**カスタム CSS** で独自のスタイルを書けます。デザインの共有やダウンロードについては [テーマ](./themes) を参照してください。

## 履歴

**履歴** タブには、各投票のタイトル、時刻、選択肢の数、総投票数が一覧表示されます。投票を展開すると、結果、プラットフォームごとの得票数、**詳細** を確認できます。投票履歴は直近 30 日分のみ保存されます。記録を削除するには 🗑 をクリックしてから **削除の確認** をクリックします。

:::info 試用版の制限
- **カスタム CSS** は製品版でのみ使用できます
- OBS オーバーレイに透かしが表示されます

詳しくは [試用版 / 製品版の比較](../getting-started/trial-comparison) を参照してください。
:::
