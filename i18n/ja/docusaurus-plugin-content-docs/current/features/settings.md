# 設定

左メニューの一番下にある **⚙️ 設定** をクリックします。このページには、アプリ全体のオプション、プラットフォーム連携、支援用の決済サービスがまとめられています。

## 一般

| オプション | 機能 | 初期値 |
|------|------|------|
| **テーマ** | 画面の表示モード：**グレー** または **ライト** | グレー |
| **言語** | 画面の表示言語。すぐに切り替わります | — |
| **X ボタンでタスクトレイに最小化** | ウィンドウを閉じると、終了せずにタスクトレイへ最小化します | オン |
| **サポート通貨** | 全体の通貨単位。支援目標バー、通知など、すべての金額表示に使われます | 初回起動時にシステム言語から設定（例：繁体字中国語（台湾）→ TWD、日本語 → JPY、その他 → USD） |

## プラットフォーム連携

### Twitch

**アカウントを連携** をクリックし、ブラウザで認可します。接続すると **接続済み @あなたの名前** と **接続を解除** ボタンが表示されます。詳しい手順：[Twitch 設定](../platforms/twitch)。

接続後、**▸ 換算設定** で Bits とサブスクをサポート通貨でいくらとして扱うかを設定します：

- **収益分配の仕組み**：**50 / 50** または **70 / 30**
- **100 Bits あたり**、**Tier 1 サブスク**、**Tier 2 サブスク**、**Tier 3 サブスク**
- **保存** で現在の通貨の値を保存します。**初期設定に戻す** でその通貨の内蔵値を入力します

### YouTube

1. **アカウントを連携** をクリックし、Google でログインします。手順の詳細：[YouTube 設定](../platforms/youtube-settings)
2. 接続すると **接続済み：チャンネル名** と表示されます。**接続を解除** でアカウントの連携を解除します
3. ライブチャットの見つけ方を選びます：
   - **現在の配信を自動検出**：Google ログインが必要です。**接続** をクリックすると、チャンネルの現在の配信または予定されている配信を検索します。複数ある場合はリストから選びます
   - **手動で URL を指定**：**チャット URL** を貼り付けます
4. **プログラム起動時にチャット URL の入力を求める**：任意

YouTube の **▸ 換算設定** では、メンバーシップの金額を設定します（YouTube はメンバーシップの金額を送ってこないため）：

- **メンバーシップレベル設定**：各等級の名前と金額を追加します。等級名は YouTube チャンネルの設定と完全に一致させる必要があります
- **未登録の等級**：表にない等級に使う金額
- **ギフト メンバーシップの等級**：ギフトされたメンバーシップをどの等級として数えるか
- イベントで検出されたものの表にない等級は、**表に追加** / **無視** とともに一覧表示されます

## サポートプラットフォーム連携

決済サービスをクリックすると展開されます。それぞれに設定ガイドへの **チュートリアルはこちら** リンクがあります：

- [PayPal](../payments/paypal)
- [Stripe](../payments/stripe)
- [O'Pay](../payments/opay)
- [ECPay](../payments/ecpay)

### テスト通知

見出しの横にある **テスト通知** ボタンでテスト用ウィンドウが開きます：

- **テスト名**、**テストメッセージ**、**テスト金額** を入力し、**テストプラットフォーム** を選んで **テスト通知を送信** をクリックします
- **YouTube Super Chat テスト**：`$5.00` や `NT$150` などの **金額文字列** を入力し、**テスト Super Chat を送信** をクリックすると、金額の解析と通貨換算をテストできます

## 情報

左メニュー上部の「Stream Toolkit」の横にある **i** ボタンをクリックすると、バージョン、作者、公式ドキュメントへのリンクが表示されます。

- YouTube メンバーシップの **換算設定** は製品版でのみ使用できます

[試用版 / 製品版の比較](../getting-started/trial-comparison) を参照してください。
