# 時計

現在時刻を配信画面に表示します。日付や曜日も表示できます。

## ステップ 1：OBS ソースを追加する

ページ上部の **OBS ソース URL** をコピーします：

```
http://127.0.0.1:7272/clock
```

OBS にブラウザソースとして追加します。[OBS でソースを追加する方法](../getting-started/obs-source) を参照してください。時計は音を再生しないため、「OBS を介して音声を制御する」をオンにする必要はありません。

:::tip
左サイドバーの **時計** の横にあるスイッチ（**OBS 表示をオンにする**）もオンにしてください。オフの間、OBS では時計が非表示になります。
:::

## プレビュー

上部の **プレビュー** には実際の OBS オーバーレイが表示され、設定を変更するとすぐに反映されます。横のカラーボックスでプレビューの背景色を変更できます。

## 外観

| 設定 | 説明 |
|---------|-------------|
| **フォント** | 時計のすべてのテキストに使うフォント |
| **レイアウト** | 時刻・日付・曜日の配置：**Stack**、**Horizontal**、**One-Top-Two-Bottom**、**Two-Top-One-Bottom**。**行間** は **Horizontal** 以外のすべてのレイアウトで、**間隔** は **Stack** 以外のすべてのレイアウトで使用できます（どちらも −200〜200 px） |
| **順序** | **時刻**、**日付**、**曜日** のブロックをドラッグして順番を変更します |
| **テキスト** | **時刻**、**日付**、**曜日** を個別に設定：**文字サイズ**、色（**単色**、または 2 色と **角度** を指定する **グラデーション**）、**枠線** の色・**不透明度**・**太さ**（0–7 px） |
| **影** | 影の色、**不透明度**、**ぼかし**、**X** / **Y** オフセット。すべてのテキスト共通 |

**初期設定に戻す** ボタンはタブの上部にあります。

### カスタム CSS

**カスタム CSS** をクリックするとエディタが展開されます。初期 CSS には、時計の各部分（時刻・日付・曜日とそれぞれのコンテナ）のセレクタがコメント付きで記載されています。レイアウトや構造の調整に使ってください。色・フォント・サイズは上の外観設定で設定します。

- **初期設定に戻す**：初期 CSS に戻します
- **素材を管理**：CSS で使う画像の素材管理を開きます

CSS で `!important` を使ってプロパティを上書きすると、対応する外観設定の項目はロックされます。どのみち CSS が優先されるためです。

## 時計フォーマット

- **時刻表記**：**24 時間**、または 2 種類の 12 時間表記。**12 時間（午前/午後）** は中国語の 上午 / 下午 を表示し、**12 時間（AM/PM）** は AM/PM を表示します
- **タイムゾーン**：UTC−12〜UTC+14。初期設定ではパソコンのタイムゾーンに合わせます

## 表示設定

- **秒を表示**
- **日付を表示**：オンにすると、ドロップダウンから日付の形式を選べます。**年なし** と付いた形式は年を表示しません
  - **日付をゼロ埋め**：1 桁の月と日の先頭に 0 を付けて表示します（例：2026/05/20）
  - **年の形式**：年から始まる形式で表示されます。**完全（2026）** または **短縮（26）**

  この 2 つのオプションは数字の形式（`/` または `-` を使うもの）に適用されます。文字で書く形式（例："May 20, 2026"）はアプリの表示言語に従います
- **曜日を表示**：オンにすると、曜日の表記を選べます（例：**水曜日**、**Wednesday**、**WED**、**Wed**）

:::info 試用版の制限
**カスタム CSS** は製品版でのみ使用できます。詳しくは [試用版 / 製品版の比較](../getting-started/trial-comparison) を参照してください。
:::
