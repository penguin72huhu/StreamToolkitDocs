# リクエスト曲

視聴者がチャットコマンドで YouTube の曲をリクエストし、曲は OBS で順番に再生されます。自分で曲を追加したり、リクエストがないときに流すデフォルトのプレイリストを設定したりすることもできます。

## OBS ソース URL

```
http://127.0.0.1:7272/song-request
```

ページ上部の **OBS ソース URL** の横にある **コピー** をクリックし、OBS にブラウザソースとして追加します。[OBS でソースを追加する方法](../getting-started/obs-source) を参照してください。

:::warning
リクエスト曲では音声が再生されます。ブラウザソースのプロパティで **OBS を介して音声を制御する** にチェックを入れないと、音楽が配信に流れません。
:::

:::tip
左メニューの **リクエスト曲** の横にあるスイッチもオンにしてください。チャットコマンドはスイッチがオンの間だけ処理されます。
:::

ページには **設定** と **プレイリスト** の 2 つのタブがあります。

## 設定タブ

### プラットフォーム

プラットフォームごとにカードがあります：

- **このプラットフォームからのリクエストを許可**：そのチャットの視聴者が曲をリクエストできるようにします
- **チャットボットの返信を有効化**（Twitch のみ、初期設定でオン）：接続中の Twitch アカウントを使って、各コマンドの結果を Twitch チャットに返信します。Twitch が有効かつ接続済みのときだけ表示されます

接続されていないプラットフォームには **（未接続）**（Twitch）または **チャット URL が未接続です**（YouTube）と表示されます。先に接続してください：

- [Twitch 設定](../platforms/twitch)
- [YouTube 設定](../platforms/youtube-settings)

### チャットコマンド

| 項目 | 初期値 |
|------|--------|
| **コマンド接頭辞** | `!`（`! @ # $ % & ~` から選択） |
| **リクエストコマンド** | `sr` |
| **リクエストを削除** | `remove` |
| **リクエストリストを表示** | `queue` |
| **現在の曲を確認** | `song` |
| **リクエストのクールダウン時間** | 3000 ms |

クールダウンは視聴者ごとに数えられます：リクエストが成功した後、同じ視聴者はこの時間が経つまで再度リクエストできません。

### 設定

- **画面に動画を表示**（初期設定でオン）：オフにすると OBS では動画が非表示になりますが、音声は再生されます
- **リスト上限**（1–100、初期値 20）：リスト内のリクエスト曲の最大数。デフォルトのプレイリストの曲は数えません
- **リクエスト通知を表示**（初期設定でオン）：視聴者が曲をリクエスト・削除したとき、またはリクエストに失敗したときに、OBS に通知カードを表示します。オンの場合は次を設定できます：
  - **X** / **Y**：左上からの通知の位置（px、初期値 16 / 16）
  - **通知の拡大縮小**：サイズの倍率（初期値 1.0）
  - **通知の外観をテスト**：テスト通知を OBS に送信します

各通知は 5 秒間表示され、同時に最大 3 件まで表示されます。

## 視聴者の使い方

初期設定の場合：

| コマンド | 動作 |
|------|------|
| `!sr <YouTube link>` | その動画をリクエストします |
| `!sr <search words>` | YouTube を検索し、最初の結果をリクエストします |
| `!remove` | その視聴者の最新のリクエストを削除します（再生中の曲は除く） |
| `!queue` | 次の 3 曲のリクエストを返信します |
| `!song` | 再生中の曲を返信します |

- 使えるリンク：`youtube.com/watch?v=…`、`youtu.be/…`、`youtube.com/live/…`、`youtube.com/shorts/…`、または 11 文字の動画 ID
- プレイリストのリンクは使えません
- リストが **リスト上限** に達しているとリクエストは失敗します
- 新しいリクエストは他の視聴者のリクエストの後ろ、デフォルトのプレイリストの曲より前に追加されます
- `!queue` と `!song` は、**チャットボットの返信を有効化** がオンの Twitch チャットでのみ動作します

## プレイリストタブ

### 再生コントロール

上部の行には、現在の曲のリクエスト者とタイトルが表示されます。ボタン：

- **再生** / **一時停止**：何も再生されていない場合は、リストの最初の曲から再生します
- **停止**：再生を停止します
- **次の曲**：次の曲にスキップします

曲の再生中はプログレスバーが表示され、ドラッグすると再生位置を移動できます。曲が終わると、次の曲が自動的に始まります。

:::note
アプリ起動時に自動では再生されません。**再生** を押して開始してください。
:::

### デフォルトのプレイリスト

YouTube プレイリストの URL を貼り付け、**順番に再生** または **ランダム再生** を選びます。リストが空になると、このプレイリストの曲が自動的に追加・再生されます。これらの曲はリストに **デフォルトリスト** と表示されます。

デフォルトのプレイリストは YouTube アカウントを通じて読み込まれるため、先に [YouTube 設定](../platforms/youtube-settings) で Google にログインしておく必要があります。

### 手動リクエスト

YouTube 動画の URL を貼り付けて **リストに追加** をクリック（または Enter）します。手動リクエストでは検索ワードは使えません。

### リスト

**リスト（n）** にはすべての曲が表示されます：プラットフォーム、リクエスト者、タイトル、動画 ID（クリックすると YouTube で開きます）。**削除** をクリックすると曲を削除します。再生中の曲を削除すると次の曲にスキップします。**クリア** でリスト全体を空にします。

## よくある質問

**Q：視聴者がコマンドを入力しても何も起きません。**
次の点を確認してください：
- 左メニューの **リクエスト曲** スイッチがオンになっている
- そのプラットフォームで **このプラットフォームからのリクエストを許可** にチェックが入っている
- Twitch の場合：Twitch チャットは [チャット](./chat) 機能で読み取られます。チャットページで Twitch をオフにしている場合（かつ [チャットボット](./chat-bot) が Twitch を使っていない場合）、Twitch のコマンドは受信されません

**Q：デフォルトのプレイリストが再生されません。**
設定で Google にログインしていること、URL がプレイリストのリンク（`list=` を含む）であることを確認してください。

:::info 試用版の制限
- 視聴者のチャットからのリクエストは製品版でのみ使用できます。試用版では、チャットからのリクエストは「体験版では視聴者のリクエストに対応していません」というメッセージで失敗します。**手動リクエスト** とデフォルトのプレイリストは使用できます
- OBS オーバーレイに透かしが表示されます

[試用版 / 製品版の比較](../getting-started/trial-comparison) を参照してください。
:::
