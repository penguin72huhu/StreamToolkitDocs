# 音声翻訳

ショートカットを押しながら話すと、Stream Toolkit が音声をテキストに変換して翻訳し、両方を字幕として OBS に表示します。

音声認識は Whisper モデルを使ってあなたのパソコン上で実行されます。その後、テキストは MyMemory で翻訳されます。

ページには **設定** と **外観** の 2 つのタブがあります。

## ステップ 1：OBS ソースを追加する

OBS ソース URL はページ上部に表示されています：

```
http://127.0.0.1:7272/voice-translate
```

**コピー** をクリックし、OBS にブラウザソースとして追加します。[OBS でソースを追加する方法](../getting-started/obs-source) を参照してください。音声翻訳は音を再生しないため、「OBS を介して音声を制御する」をオンにする必要はありません。

字幕はソースの下部に表示されます：上が元のテキスト、下が翻訳です。**字幕の表示時間** が過ぎるとフェードアウトします。

:::tip
左サイドバーの **音声翻訳** の横にあるスイッチ（**OBS 表示をオンにする**）をオンにしてください。ショートカットはオンの間だけ動作します。
:::

## ステップ 2：ショートカットを設定する

**ショートカット（押している間録音、離すと認識）** の下で：

1. **クリックしてショートカットを設定** をクリックします
2. 使いたいキーの組み合わせを押してから離します。**Esc** でキャンセルします
3. ショートカットを削除するには **クリア** をクリックします

その組み合わせが別の機能ですでに使われている場合、ボタンに **ショートカットの競合** と表示され、ショートカットは保存されません。

ショートカットは Stream Toolkit がアクティブウィンドウでなくても動作します。話している間は **押し続け**、**離す** と認識・翻訳します。録音は 15 秒で自動的に停止します。

ショートカットの下にある **REC** ボタンをマウスで押し続けても同じように使えます：押すと録音、離すと翻訳します。[クイックツール](./quick-tools) ウィンドウにも同じ **REC** ボタンがあります。

## ステップ 3：認識の設定

| 項目 | 説明 |
|-------|-------------|
| **モデルの状態** | **読み込み中 xx%**、**準備完了**、**モデルの読み込みに失敗しました** のいずれかを表示します。**準備完了** と表示されたら録音できます |
| **Whisper モデル** | **Tiny（最速、約 40MB）**、**Base（推奨、約 75MB）**（初期設定）、**Small（最も高精度、約 245MB）**。モデルは初回使用時にダウンロードされます。モデルを変更すると再読み込みされます |
| **音声言語** | あなたが話す言語。初期設定は繁体字中国語です |
| **マイク** | 録音に使うマイク。**システム既定** は Windows の既定の入力デバイスを使います |

## ステップ 4：翻訳の設定

| 項目 | 説明 |
|-------|-------------|
| **字幕の表示時間** | 字幕が画面に表示される時間、1–30 秒。初期値は 5 |
| **対象言語** | 翻訳先の言語。初期設定は英語です |
| **翻訳先が English のとき Whisper 翻訳を使用** | 対象言語が英語のとき、MyMemory の代わりに Whisper が翻訳します。（無料で上限なし、ただし遅延が大きくなります。）他の対象言語では効果はありません |
| **翻訳サービス** | MyMemory |

### Email（任意）

MyMemory は無料です。1 日の上限は Email を入力するかどうかで変わります：

- Email なし：5,000 文字/日
- Email あり：50,000 文字/日（無料、MyMemory への登録は不要）

Email を入力して **保存** をクリックします。この Email は **チャット翻訳と共有** されます。

下のバーには **本日使用済み（概算、毎日 UTC 08:00 リセット）** が表示されます。上限に達すると **使い切りました** と表示されます。

## ステップ 5：外観

**外観** タブでは字幕の見た目を変更できます。変更はすぐに保存されます。

- **プレビュー**：サンプルの字幕を表示します。横のカラーボックスはプレビューの背景だけを変更します
- **配置**：**左寄せ**（初期設定）、**中央**、**右寄せ**
- **フォント**：**元の言語**（元のテキスト）と **対象言語**（翻訳）の 2 行があります。各行でフォント、色、サイズ（8–120 px）を設定します。初期値は元のテキストが 14 px、翻訳が 22 px です
- **影**：テキストの影の色
- **初期設定に戻す**：初期の外観に戻します

## よくある質問

**Q：ショートカットを押しても何も起きません。**
左サイドバーの **音声翻訳** の横にあるスイッチがオンになっていること、**モデルの状態** が **準備完了** になっていることを確認してください。

**Q：録音はできますが、OBS に字幕が表示されません。**
MyMemory が翻訳できない場合（例えば 1 日の上限に達した場合）、字幕は表示されません。**本日使用済み** のバーを確認してください。Email を入力すると上限が上がります。対象言語が英語の場合は、上限のない **翻訳先が English のとき Whisper 翻訳を使用** をオンにすることもできます。
