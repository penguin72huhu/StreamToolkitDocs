# テーマ

Steam Workshop を通じてオーバーレイのデザインを共有・ダウンロードできます。テーマには次の機能の外観を含めることができます：

- [チャット](./chat)
- [支援目標バー](./donate)
- [支援通知](./donate-alert)
- [新規フォロワー通知](./fan-alert)
- [視聴者誕生日通知](./birthday-alert)
- [支援履歴ボード](./sponsors)
- [リアルタイム投票](./vote)
- [時計](./clock)
- [Twitch 目標バー](./goal)：**フォロー目標**、**サブスク目標**、**Bits 目標**

左メニューの一番下にある **🎨 テーマ** から開きます。ページには **マイテーマ** と **ダウンロードしたテーマ** の 2 つのタブがあります。Steam が起動している必要があります。

## 機能ページでテーマを探して適用する

上記の各機能で **カスタム CSS** セクションを開き、**Workshop テーマを閲覧** をクリックします：

1. **テーマを探す** には、この機能用の Workshop テーマが一覧表示されます。**テーマ名を検索** に入力して **検索** をクリックするか、**前のページ** / **次のページ** でページを移動します
2. サムネイルをクリックするとプレビュー画像が表示されます
3. **適用** をクリックします。テーマがサブスクライブ・ダウンロードされ、この機能に適用されます
4. **サブスクライブ済み** には、この機能用にすでにサブスクライブしたテーマが一覧表示されます

テーマを適用している間、ページには **使用中のテーマ：（名前）** と **元に戻す** ボタンが表示され、カスタム CSS は読み取り専用になります。**元に戻す** をクリックすると自分の設定に戻ります。

## ダウンロードしたテーマ

Steam でサブスクライブしたすべてのテーマが一覧表示されます。サブスクライブしたテーマは自動では適用されません。カードのボタンを使ってください。OBS にはすぐに反映されます。

各カードには、プレビュー、名前、いずれかの機能で使用中なら **使用中**、テーマに **含まれる機能**（✓ は現在そのテーマを使用中の機能）が表示されます。

| ボタン | 機能 |
|------|------|
| **すべて適用** | テーマに含まれるすべての機能に適用します。別のテーマを使用中の機能がある場合は、置き換えの確認が表示されます |
| **選んで適用…** | 適用する機能を選びます |
| **すべて元に戻す** | このテーマを使用中のすべての機能を、適用前の自分の設定に戻します |
| **選んで元に戻す…** | 元に戻す機能を選びます |
| **サブスクライブを解除** | サブスクライブを解除します。テーマが使用中の場合は、先にその機能を元に戻します |

適用後、画面下部に変更内容が 30 秒間表示され、**元に戻す** ボタンで取り消せます。

:::note
- 元に戻すと自分の設定に戻ります。置き換えられたテーマには戻りません
- テーマ適用中に行った外観の変更は、元に戻した後は保持されません
:::

- **ダウンロード中…**：Steam を起動したままにしてください。ダウンロードが終わると適用できます
- **削除されたテーマ（#id）**：テーマが Steam のサブスクライブ一覧から外れていますが、まだ使用中の機能があります。画像が表示されない可能性があるため、元に戻すことをおすすめします
- Steam が起動していない場合は、Steam を起動して **更新** をクリックしてください

## マイテーマ：テーマをアップロードする

1. 共有したい機能の外観を、それぞれのページで設定します
2. **マイテーマ** で **新しいテーマをアップロード** をクリックします
3. 以下を入力します：
   - **テーマ名**（必須）
   - **テーマの説明**
   - **含まれる機能**（1 つ以上）
   - **プレビュー画像**（必須、最大 1MB）：**プレビュー画像を選択** をクリックします
4. テーマ内のすべての画像、フォント、音声を配布する権利があることを確認するチェックボックスにチェックを入れます。個人利用や非商用利用のみに限定されたライセンスの素材はアップロードできません
5. **テーマをアップロード** をクリックします

「まずブラウザで Steam Workshop の規約に同意すると、あなたのテーマが公開されます」と表示された場合は、規約に同意するとテーマが公開されます。

### アップロードしたテーマの管理

アップロードした各テーマには次のボタンがあります：

- **ダウンロードして適用**：公開中のテーマを自分の機能に適用します。現在の外観設定は上書きされます
- **編集**：現在の外観設定を同じテーマに再アップロードします。テーマをダウンロードしていない場合、既存のプレビュー画像は引き継がれないため、新しい画像を選ぶ必要があります
- **Steam で管理**：Steam でテーマを開きます

:::info 試用版の制限
テーマ（Steam Workshop）は製品版でのみ使用できます。試用版では **🎨 テーマ** を開けず、テーマを適用することもできません。

[試用版 / 製品版の比較](../getting-started/trial-comparison) を参照してください。
:::
