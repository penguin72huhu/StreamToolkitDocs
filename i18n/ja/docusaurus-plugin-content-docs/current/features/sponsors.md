# 支援履歴ボード

最近の支援を一覧で配信画面に表示します：プラットフォームアイコン、支援者名、金額、メッセージ。

## OBS ソース URL

```
http://127.0.0.1:7272/sponsors
```

**支援履歴ボード の設定** ページ上部の URL をコピーし、OBS にブラウザソースとして追加します。[OBS でソースを追加する方法](../getting-started/obs-source) を参照してください。

左サイドバーの **支援履歴ボード** の横にあるスイッチで、OBS でのボードの表示/非表示を切り替えます。オフにするとボードはフェードアウトします。オフの間も支援は記録されます。

## 設定タブ

### 連携プラットフォーム

記録する支援のプラットフォームにチェックを入れます：**Twitch**、**YouTube**、**PayPal**、**Stripe**、**O'Pay**、**ECPay**。緑のドットは接続済みを意味します。接続されていない場合は **（未接続）** と表示されます。これらのチェックボックスはボードにのみ影響し、支援目標バーや支援通知には影響しません。

**Twitch ⚙️**（Twitch が接続済みでチェックが入っているときに表示）：

1. **Bits とサブスクを計算**、**Bits のみ計算**、**サブスクのみ計算** から選びます
2. **再サブスクを含める**：再サブスクを記録するかどうか（サブスクを数える場合に表示）
3. **未満 [N] Bits は計算に含めない**：チェックを入れて最小値を入力すると、それより少ない応援は記録されません（Bits を数える場合に表示）
4. **保存** をクリックします

**YouTube ⚙️**：

- **視聴者名を @ハンドルの代わりに表示**：Google でログインした後にのみ使用できます。
- **カウント対象**：**スーパーチャット**、**スーパーステッカー**、**メンバー加入**、**メンバー継続**、**ギフト メンバーシップ**、**ジュエル**。**ジュエル** には Google ログインが必要です。ジュエルのギフトは、金額の代わりにジュエルアイコンとジュエル数で表示されます。

YouTube のライブチャットが連携されていない場合、**チャット URL が未接続です** と、**自動接続**（Google ログインが必要）、**手動で入力**（設定のチャット URL 欄に移動）が表示されます。メンバーシップのイベントにチェックを入れているのにメンバー価格が設定されていない場合は、**⚠ メンバー価格が未設定** をクリックして設定してください。[YouTube 設定](../platforms/youtube-settings) を参照してください。

PayPal、Stripe、O'Pay、ECPay の接続方法は [PayPal](../payments/paypal)、[Stripe](../payments/stripe)、[O'Pay](../payments/opay)、[ECPay](../payments/ecpay) を参照してください。

### 設定

| 項目 | 説明 |
|-------|-------------|
| **自国の通貨に自動換算** | 初期設定でオン。設定ページで設定した **サポート通貨** に換算した金額を表示します。 |
| **最大表示件数** | 保持する記録の数（1–100）。初期値：20。上限を超えて新しい支援が届くと、最も古い記録が削除されます。 |

## 外観タブ

### プレビュー

**プレビュー** の横のカラーピッカーでプレビューの背景を変更できます。**追加アニメーションをテスト** をクリックすると、サンプルの記録で登場アニメーションを再生します。サンプルは履歴に保存されません。

**初期設定に戻す** をクリックすると、初期の外観に戻ります。

### 表示設定

- **プラットフォーム icon を表示**：各記録にプラットフォームのアイコンを表示します。
- **出現方向**：**上から下**（初期設定）、**下から上**、**左から右**、**右から左**。

### フォント

**タイトル**（支援者名）、**本文**（メッセージ）、**金額** のフォント、色、サイズ（8–72 px）を設定します。

### 背景色

- **デフォルト**：すべての記録の背景色。
- **+ 範囲を追加**：**金額** の範囲（**最低** 〜 **最高**）付きの色を追加します。金額がその範囲に入る記録は、代わりにその色を使います。最低または最高を空欄にすると、その側は無制限になります。**✕** をクリックすると範囲を削除します。

**自国の通貨に自動換算** がオンの場合、範囲は換算後の金額と比較されます。

### カスタム CSS

**カスタム CSS** を展開すると、ボードの CSS を編集できます。**初期設定に戻す** で初期 CSS に戻し、**素材を管理** で素材管理を開きます。ここでは Steam Workshop のテーマも適用できます。テーマを適用している間、CSS は読み取り専用です。[テーマ](./themes) を参照してください。

## 履歴タブ

### 手動追加（テスト用）

プラットフォームを選び、**名前**、**金額**、任意の **メッセージ（任意）** を入力して **追加** をクリックします。記録が追加されるのは、そのプラットフォームが **連携プラットフォーム** でチェックされている場合のみです。金額はサポート通貨として扱われます。

### 履歴

保存された記録と記録数を一覧表示します。

- **🗑** をクリックしてから **削除の確認** をクリックすると、記録を 1 件削除します。
- **クリア** をクリックすると、すべての記録を削除します。先に確認が表示されます。元に戻せません。

:::info 試用版
カスタム CSS は製品版でのみ使用できます。実際の決済サービス（PayPal / Stripe / O'Pay / ECPay）と YouTube のメンバーシップイベント・ジュエルは試用版では使用できず、OBS のボードに透かしが表示されます。[試用版 / 製品版の比較](../getting-started/trial-comparison) を参照してください。
:::

## よくある質問

**Q：テスト通知がボードに表示されます。**
設定ページの **テスト通知** は実際の支援と同じように扱われるため、そのプラットフォームにチェックが入っていればここにも記録されます。**履歴** タブで削除してください。
