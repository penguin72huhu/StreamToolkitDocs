# チャット

**チャット** は Twitch と YouTube のチャットを 1 つのオーバーレイにまとめて表示し、自動翻訳も利用できます。自分だけに見える透明なデスクトップウィンドウにチャットを表示することもできます。

## OBS ソース URL

```
http://127.0.0.1:7272/chat
```

ブラウザソースとして追加します：[OBS でソースを追加する方法](../getting-started/obs-source)。このオーバーレイには音声はありません。

:::info
メッセージがオーバーレイに送られるのは、サイドバーの **チャット** スイッチがオンの間だけです。オフの間もチャットは受信されるため、チャットを読み取る機能（投票、抽選、リクエスト曲など）は引き続き動作します。
:::

## 始める前に

表示したいプラットフォームを接続します：

- [Twitch 設定](../platforms/twitch)
- [YouTube 設定](../platforms/youtube-settings)

設定ページには **設定** と **外観** の 2 つのタブがあります。

## 設定タブ

### プラットフォーム

- **プラットフォーム icon を表示（Twitch / YouTube）** — 各メッセージの前に <img src={require('@site/static/img/twitch-icon.png').default} alt="Twitch" className="inline-icon" /> / <img src={require('@site/static/img/youtube-icon.png').default} alt="YouTube" className="inline-icon" /> アイコンを表示します

プラットフォームごとにカードがあります。プラットフォーム名の横のドットは、接続済みかつ有効のときに緑に点灯します。Twitch が接続されていない場合は **（未接続）**、YouTube チャットが連携されていない場合は **チャット URL が未接続です** と表示されます。

| オプション | 説明 |
|--------|-------------|
| **チャットを有効化** | このプラットフォームのメッセージを表示します |
| **アイコンを表示** | 視聴者のアイコンを表示します |
| **バッジを表示**（Twitch）/ **バッジを表示（メンバーアイコン）**（YouTube） | バッジを表示します |
| **視聴者名を @ハンドルの代わりに表示** | YouTube のみ。Google でログインするまでは使用できません |

YouTube チャットが有効なのに連携されていない場合、カードに 2 つのボタンが表示されます：

- **自動接続** — 現在の配信を自動で見つけます（Google ログインが必要）
- **手動で入力** — 設定ページに移動し、チャット URL を貼り付けます

**最大メッセージ数**：画面に残すメッセージの数（5–200、初期値 50）。

### 自動翻訳

1. **翻訳を有効化** にチェックを入れます
2. **対象言語**：メッセージの翻訳先の言語。初期設定の **画面の言語に従う** は、アプリの表示言語を使います
3. **翻訳しない言語**（任意）：チェックを入れた言語のメッセージはそのまま表示されます。ポルトガル語の PT-BR と PT-PT は区別できないため、どちらかにチェックを入れると両方とも翻訳されません

**翻訳サービス** は **MyMemory** で、API キーは不要です。

- **Email（任意）**：Email なしの場合、1 日の上限は 5,000 文字です。Email を入力して **保存** をクリックすると 50,000 文字に増えます（無料、MyMemory への登録は不要）
- 下のバーには本日の概算使用量が表示されます。毎日 UTC 08:00 にリセットされます

### テスト

- **テストメッセージを送信** — ランダムなサンプルメッセージをオーバーレイに送信します
- **クリア** — オーバーレイのメッセージをすべて消去します

**接続に失敗しました。サーバーが起動していない可能性があります** と表示された場合は、Stream Toolkit のローカルサーバーが応答していません。

### デスクトップチャットウィンドウ

ゲームの上に、常に手前に表示される小さな透明ウィンドウでチャットを表示します。自分にしか見えないため、モニター 1 台での配信に便利です。

1. **ウィンドウを開く** をクリックします（またはタスクトレイアイコンを右クリックして **デスクトップチャットを開く** を選びます）
2. ロック解除中は、上部のバーをドラッグしてウィンドウを移動し、端をドラッグしてサイズを変更できます
3. 位置が決まったら **🔒 ロック** をクリックします。クリックはウィンドウを通り抜けてゲームに届くようになります。ロックを解除するには、ウィンドウにマウスを乗せて右上に表示される 🔓 をクリックするか、設定ページの **🔓 ロック解除** をクリックします

**位置をリセット** でウィンドウを初期位置に戻します。

| 設定 | 説明 |
|---------|-------------|
| **表示スタイル** | **名前とメッセージのみ**（初期設定）または **OBS のチャットと同じ** |
| **文字サイズ** | 12–32 px、初期値 16。**名前とメッセージのみ** の場合のみ |
| **文字の不透明度** | 10–100%、初期値 100% |
| **背景の不透明度** | 0–100%、初期値 40% |
| **メッセージのフェードアウト** | 0–120 秒、初期値 0。各メッセージはこの秒数が経つとフェードアウトし、フェードアウトしたメッセージはスクロールで戻れません。0 の場合はフェードアウトせず、ロック解除中は上にスクロールして以前のメッセージを確認できます（最大メッセージ数まで） |
| **配信画面に映さない** | 初期設定でオン。OBS の画面キャプチャにウィンドウが映らないため、視聴者にチャットが二重に見えることはありません。スクリーンショットや Discord の画面共有にも映りません |

:::tip
ゲームのフルスクリーン中にウィンドウが見えない場合は、ゲームを「ボーダーレスウィンドウ」または「ウィンドウモード」にしてください。ウィンドウの位置とサイズは **テストメッセージを送信** で確認できます。
:::

## 外観タブ

### プレビュー

タブの上部にはリアルタイムプレビューが表示されます。**プレビュー** の横のカラーピッカーはプレビューの背景だけを変更します。**アイコン**、**バッジ**、**プラットフォーム icon** のチェックボックスはプレビューの表示だけを切り替えます。

### 外観設定

**初期設定に戻す** で初期の外観（テーマを適用している場合はそのテーマの外観）に戻します。

- **表示方向**：**上から下**、**下から上**（初期設定）、**左から右**、**右から左**
- **テキスト** — **ニックネーム** と **メッセージ** を個別に設定します：
  - フォント、サイズ（px）、色。ニックネームは **元の色**（視聴者のプラットフォーム上の色）または **カスタム色** を選べます
  - **縁取り**：色、**不透明度**、**太さ**
  - **影**：色、**不透明度**、**ぼかし**、X / Y オフセット
- **アイコンサイズ**：**プラットフォームicon**、**アイコン**、**バッジ** の倍率（0.1–5x）
- **色**：各メッセージの **背景色**

### カスタム CSS

**カスタム CSS** を展開すると、オーバーレイの CSS を直接編集できます。**素材を管理** で CSS から参照する画像をアップロードできます。**初期設定に戻す** で初期 CSS に戻します。[テーマ](./themes) も参照してください。

:::tip
カスタム CSS で外観設定の項目を `!important` 付きで設定すると、その項目は外観設定でグレー表示になります（「この設定はカスタム CSS で制御されています」）。テーマを適用している間は CSS が読み取り専用になるため、編集する前に元に戻してください。
:::

## 試用版の制限

:::info
- 自動翻訳をオンにすると、チャットオーバーレイに透かしが表示されます
- **カスタム CSS** は製品版でのみ使用できます
- **デスクトップチャットウィンドウ** は製品版でのみ使用できます

[試用版 / 製品版の比較](../getting-started/trial-comparison) を参照してください。
