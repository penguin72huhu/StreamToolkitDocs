# Tastenkürzel

**⌨️ Tastenkürzel** unten im linken Menü listet alle eingerichteten Tastenkürzel an einem Ort auf.

## Übersicht der Tastenkürzel

Jede Zeile zeigt die Tastenkombination und was sie auslöst, z. B. `Timer › (Timername) › Start / Pause`. Klicke auf eine Zeile, um die Einstellungsseite der jeweiligen Funktion zu öffnen und das Tastenkürzel dort zu ändern. Auf dieser Seite selbst werden Tastenkürzel nicht bearbeitet.

Ist noch nichts eingerichtet, wird „Noch keine Tastenkürzel eingerichtet.“ angezeigt.

## Funktionen mit Tastenkürzeln

| Funktion | Was das Tastenkürzel bewirkt |
|------|------|
| [Stream-Highlight-Markierung](./highlight) | Fügt eine Markierung hinzu |
| [Media Board](./multimedia) | Spielt einen Sound ab / zeigt ein Bild / spielt ein Video ab (ein Tastenkürzel pro Element) |
| [Sprachübersetzung](./voice-translate) | Das Tastenkürzel der Sprachübersetzung |
| [OBS-Szenensteuerung](./obs-scene) | **Szene wechseln** / **Quellen umschalten** |
| [Timer](./timer) | **Start / Pause**, **Runde**, **Zurücksetzen** (pro Timer) |

## Tastenkürzel festlegen

[Stream-Highlight-Markierung](./highlight), [OBS-Szenensteuerung](./obs-scene) und [Timer](./timer) verwenden dasselbe Tastenkürzel-Feld. Für Media Board und Sprachübersetzung siehe die jeweiligen Seiten.

1. Klicke auf die Tastenkürzel-Schaltfläche
2. Drücke die Tastenkombination, z. B. `Ctrl+Shift+F1`
3. Lass alle Tasten los, um sie zu speichern

- Drücke während der Aufnahme **Esc**, um abzubrechen
- Wird die Kombination bereits von einem anderen Tastenkürzel verwendet, erscheint ein Konflikthinweis und sie wird nicht gespeichert. Wähle dann eine andere Kombination
- Klicke auf **✕** (bzw. die Löschen-Schaltfläche) daneben, um das Tastenkürzel zu entfernen
- Die Ziffernblocktasten sind von den Zifferntasten der Hauptreihe getrennt: `Num1` und `1` sind unterschiedliche Tastenkürzel

Tastenkürzel funktionieren auch, wenn Stream Toolkit im Hintergrund läuft, z. B. während du spielst.
