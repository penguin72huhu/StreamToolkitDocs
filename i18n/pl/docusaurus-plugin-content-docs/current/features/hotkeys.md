# Skróty klawiszowe

**⌨️ Skróty klawiszowe** na dole lewego menu zbierają w jednym miejscu wszystkie skonfigurowane skróty.

## Przegląd skrótów

Każdy wiersz pokazuje kombinację klawiszy i to, co uruchamia, np. `Timer › (nazwa timera) › Start / Pauza`. Kliknij wiersz, aby otworzyć stronę ustawień danej funkcji i tam go zmienić. Na tej stronie nie edytuje się skrótów.

Jeśli nic nie zostało jeszcze skonfigurowane, wyświetla się „Nie skonfigurowano jeszcze żadnych skrótów.”

## Funkcje ze skrótami klawiszowymi

| Funkcja | Działanie skrótu |
|------|------|
| [Znacznik najlepszych momentów streamu](./highlight) | Dodaje znacznik |
| [Media Board](./multimedia) | Odtwarza dźwięk / pokazuje obraz / odtwarza wideo (jeden skrót na element) |
| [Tłumaczenie głosu](./voice-translate) | Skrót tłumaczenia głosu |
| [Sterowanie scenami OBS](./obs-scene) | **Zmień scenę** / **Przełącz źródła** |
| [Timer](./timer) | **Start / Pauza**, **Okrążenie**, **Resetuj** (dla każdego timera) |

## Ustawianie skrótu

[Znacznik najlepszych momentów streamu](./highlight), [Sterowanie scenami OBS](./obs-scene) i [Timer](./timer) korzystają z tego samego pola skrótu. W przypadku Media Board i Tłumaczenia głosu zajrzyj na ich własne strony.

1. Kliknij przycisk skrótu
2. Naciśnij kombinację klawiszy, np. `Ctrl+Shift+F1`
3. Puść wszystkie klawisze, aby ją zapisać

- Naciśnij **Esc** podczas nagrywania, aby anulować
- Jeśli kombinacja jest już używana przez inny skrót, pojawi się komunikat o konflikcie i nie zostanie ona zapisana. Wybierz inną kombinację
- Kliknij **✕** (lub przycisk czyszczenia) obok, aby usunąć skrót
- Klawisze bloku numerycznego są oddzielne od klawiszy cyfr w głównym rzędzie: `Num1` i `1` to różne skróty

Skróty działają nawet wtedy, gdy Stream Toolkit jest w tle, np. podczas gry.
