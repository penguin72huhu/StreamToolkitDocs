# YouTube Ustawienia (nowe)

Stream Toolkit łączy Twój kanał YouTube przez logowanie Google — nie trzeba tworzyć ani wpisywać klucza API.

## Krok 1: Połącz konto YouTube

1. Otwórz Stream Toolkit
2. Kliknij **Ustawienia** w lewym dolnym menu
3. Znajdź **YouTube** w połączeniach platform i kliknij **Połącz konto**
4. Otworzy się okno potwierdzenia. Przeczytaj Warunki korzystania z YouTube i Politykę prywatności, a następnie kliknij **Zgadzam się i loguję**
5. Przeglądarka otworzy stronę logowania Google. Wybierz konto Google, do którego należy Twój kanał YouTube (jeśli kanałów jest kilka — ten, na którym streamujesz)
6. Sprawdź żądane uprawnienia i kliknij **Dalej** / **Zezwól**

Po zakończeniu YouTube w Ustawieniach pokaże **Połączono: nazwa kanału**.

## Rozłączanie

Kliknij **Rozłącz** obok YouTube. Dostęp Stream Toolkit zostanie też usunięty z Twojego konta Google.

## Najczęściej zadawane pytania

**Q: Czy nadal potrzebuję klucza API YouTube?**
Nie. Wystarczy zalogować się przez Google.

**Q: Zalogowałem się na zły kanał**
Kliknij **Rozłącz**, połącz ponownie i wybierz właściwe konto lub kanał.

**Q: Po zalogowaniu w przeglądarce nic się nie dzieje**
Podczas logowania nie zamykaj Stream Toolkit — przeglądarka przekazuje mu wynik. Jeśli nadal nic się nie zmienia, kliknij ponownie Połącz konto.
