# Atalhos

**⌨️ Atalhos**, no fundo do menu esquerdo, lista num único local todos os atalhos que configurou.

## Visão geral dos atalhos

Cada linha mostra a combinação de teclas e o que ela aciona, por exemplo `Temporizador › (nome do temporizador) › Iniciar / Pausar`. Clique numa linha para abrir a página de definições dessa funcionalidade e alterá-lo lá. Os atalhos não são editados nesta página.

Se ainda não houver nada configurado, mostra "Ainda não há atalhos configurados."

## Funcionalidades com atalhos

| Funcionalidade | O que o atalho faz |
|------|------|
| [Marcador de destaques da stream](./highlight) | Adiciona um marcador |
| [Media Board](./multimedia) | Reproduz um som / mostra uma imagem / reproduz um vídeo (um atalho por item) |
| [Tradução de voz](./voice-translate) | O atalho da tradução de voz |
| [Controlo de cenas do OBS](./obs-scene) | **Mudar de cena** / **Alternar fontes** |
| [Temporizador](./timer) | **Iniciar / Pausar**, **Volta**, **Repor** (por temporizador) |

## Definir um atalho

O [Marcador de destaques da stream](./highlight), o [Controlo de cenas do OBS](./obs-scene) e o [Temporizador](./timer) partilham o mesmo campo de atalho. Para o Media Board e a Tradução de voz, consulte as respetivas páginas.

1. Clique no botão do atalho
2. Prima a combinação de teclas, por exemplo `Ctrl+Shift+F1`
3. Solte todas as teclas para a guardar

- Prima **Esc** durante a gravação para cancelar
- Se a combinação já estiver a ser usada por outro atalho, aparece uma mensagem de conflito e não é guardada. Escolha outra combinação
- Clique em **✕** (ou no botão de limpar) ao lado para remover o atalho
- As teclas do teclado numérico são distintas das teclas numéricas da fila principal: `Num1` e `1` são atalhos diferentes

Os atalhos funcionam mesmo com o Stream Toolkit em segundo plano, por exemplo enquanto está num jogo.
