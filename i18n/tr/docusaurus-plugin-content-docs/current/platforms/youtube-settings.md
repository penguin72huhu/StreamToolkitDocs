# YouTube Ayarlar (yeni)

Stream Toolkit, YouTube kanalınızı Google ile giriş yaparak bağlar; API anahtarı oluşturmanız veya girmeniz gerekmez.

## Adım 1: YouTube Hesabını Bağla

1. Stream Toolkit'ı açın
2. Sol alt menüdeki **Ayarlar** seçeneğine tıklayın
3. Platform Bağlantıları altında **YouTube** seçeneğini bulun ve **Hesabı bağla** butonuna tıklayın
4. Bir onay penceresi açılır. YouTube Hizmet Şartları ile Gizlilik Politikası'nı okuyun ve **Kabul et ve giriş yap** butonuna tıklayın
5. Tarayıcı Google giriş sayfasını açar. YouTube kanalınızın sahibi olan Google hesabını seçin (birden fazla kanal varsa yayın yaptığınızı seçin)
6. İstenen izinleri kontrol edin ve **Devam** / **İzin ver** butonuna tıklayın

Tamamlandığında Ayarlar'da YouTube **Bağlandı: kanal adı** olarak görünür.

## Bağlantıyı kesme

YouTube'un yanındaki **Bağlantıyı kes** butonuna tıklayın. Stream Toolkit'in Google hesabınızdaki erişimi de kaldırılır.

## Sıkça Sorulan Sorular

**Q: Hâlâ YouTube API anahtarı gerekiyor mu?**
Hayır. Google ile giriş yapmanız yeterli.

**Q: Yanlış kanalla giriş yaptım**
**Bağlantıyı kes** butonuna tıklayın, ardından tekrar bağlanıp doğru hesabı veya kanalı seçin.

**Q: Tarayıcıda giriş yaptıktan sonra hiçbir şey olmuyor**
Giriş yaparken Stream Toolkit'i açık tutun; tarayıcı sonucu uygulamaya gönderir. Yine güncellenmezse Hesabı bağla'ya tekrar tıklayın.
