# 스트림 하이라이트 마커

방송 중에 단축키를 누르면 하이라이트가 "방송 시작 후 몇 분 몇 초"에 있었는지 기록합니다. 나중에 편집할 때 시간 목록을 이용해 다시보기(VOD)에서 하이라이트를 찾을 수 있습니다.

마커는 Stream Toolkit에 저장됩니다. 이 기능에는 OBS 오버레이가 없으므로 OBS 소스를 추가할 필요가 없습니다.

페이지에는 **설정**과 **하이라이트 기록** 두 개의 탭이 있습니다.

:::tip
왼쪽 사이드바에서 **스트림 하이라이트 마커** 옆의 스위치를 켜세요. 스위치가 꺼져 있으면 단축키나 **MARK** 버튼으로 마커가 추가되지 않습니다.
:::

## 1단계: 소스 선택

**소스**는 방송 시간을 계산하는 방식을 결정합니다:

| 소스 | 시간 계산 방식 | 필요 조건 |
|--------|----------------------------|-------------|
| **Twitch** | 현재 Twitch 방송이 시작된 후 경과한 시간 | Twitch 연결. [Twitch 설정](../platforms/twitch) 참고 |
| **YouTube** | 현재 YouTube 라이브 방송이 시작된 후 경과한 시간 | Google 로그인. [YouTube 설정](../platforms/youtube-settings) 참고 |
| **수동 정렬**(기본값) | 이 페이지의 수동 타이머 값 | 없음 |

**Twitch**와 **YouTube** 옆의 점은 연결 여부를 나타냅니다. 연결되지 않았으면 옵션에 **(연결 안 됨)** 또는 **(google에 로그인하지 않음)**이 표시됩니다.

방송 중이 아닐 때(또는 **수동 정렬**에서 타이머가 멈춰 있을 때) 마커를 추가하면 시간이 **방송 중이 아님**으로 기록됩니다. **Twitch** 소스에서는 Twitch가 방금 시작한 방송을 아직 인식하지 못했을 경우를 대비해 Stream Toolkit이 몇 번 재시도하므로, 이 결과가 표시되기까지 약 20초가 걸릴 수 있습니다.

### 수동 타이머

**수동 정렬**을 선택하면 **수동 타이머**가 나타납니다:

1. 현재 방송 시간을 `HH:MM:SS` 형식으로 입력합니다(예: 방송을 시작하는 순간이면 `00:00:00`)
2. **동기화 타이머 시작**을 클릭합니다. 타이머가 입력한 값부터 시간을 셉니다
3. 모든 마커는 타이머의 현재 값을 사용합니다
4. **정지**를 클릭하면 타이머가 멈춥니다

### 표시할 때 Twitch 클립 생성

이 옵션은 소스가 **Twitch**일 때만 나타납니다. 켜면 마커를 추가할 때마다 Twitch 클립도 생성됩니다.

- 방송 중이어야 합니다. 클립 길이는 약 30초입니다
- 클립은 크리에이터 대시보드 → 콘텐츠 → 클립에 저장됩니다
- 마커를 추가하면 페이지에 **Twitch 클립 생성됨** 또는 실패 이유(**라이브 중이 아닙니다**, **권한 부족 — Twitch를 다시 연결하세요**, **Twitch가 연결되지 않음**, **실패 — 다시 시도하세요**)가 표시됩니다

## 2단계: 단축키 설정

기본 단축키는 `Ctrl+Shift+M`입니다. 변경하려면:

1. 단축키 버튼을 클릭합니다
2. 원하는 키 조합을 누른 후 손을 뗍니다. **Esc**를 누르면 취소됩니다
3. 제거하려면 **지우기**를 클릭합니다

키 조합이 이미 다른 기능에서 사용 중이면 버튼에 **이 단축키는 이미 사용됨**이 표시되고 단축키가 저장되지 않습니다. 단축키는 Stream Toolkit이 활성 창이 아닐 때도 동작합니다.

단축키 아래의 **MARK** 버튼을 클릭해도 됩니다. 단축키와 같은 동작을 합니다. [빠른 도구](./quick-tools) 창에도 **MARK** 버튼이 있습니다.

## 3단계: 방송 중에 마커 추가

1. (선택) 마커를 추가하기 전에 **표시 이름**에 이름을 입력합니다. 비워 두면 마커에 자동으로 번호가 붙습니다(`精華標記_1`, `精華標記_2`, …)
2. 단축키를 누르거나 **MARK**를 클릭합니다

입력한 이름은 다음 마커 하나에만 사용되며, 이후 입력란이 비워집니다.

## 하이라이트 기록

**하이라이트 기록** 탭에는 모든 마커가 최신순으로 나열됩니다. 각 행에는 방송 시간, 이름, 소스, 마커를 추가한 날짜와 시간이 표시됩니다.

- **복사**: 마커를 `[날짜] 이름 🎬 방송 시간 (소스)` 형식의 텍스트로 복사합니다
- **🗑️**: 클릭한 후 **삭제 확인**을 클릭하면 마커가 삭제됩니다
- **Twitch 클립 열기**: 이 마커에 대해 Twitch 클립이 생성된 경우 나타납니다. Twitch에서 클립을 엽니다
