# 타이머

방송 화면에 카운트다운 타이머나 스톱워치를 표시합니다. 카운트다운은 버튼을 클릭하거나, Twitch 팔로우, 구독, Bits, 후원에 따라 자동으로 시간을 늘리거나 줄일 수 있습니다.

페이지에는 **설정**과 **타이머 만들기** 두 개의 탭이 있습니다. 먼저 타이머를 만든 다음 **설정**에서 제어합니다.

## 1단계: 타이머 만들기

1. 왼쪽 사이드바에서 **타이머**를 열고 **타이머 만들기** 탭으로 전환합니다
2. **내 타이머**에서 **추가**를 클릭합니다. 초기 시간 10분과 세 가지 시간 옵션(+30초, +1분, +5분)이 있는 새 카운트다운 타이머가 만들어집니다
3. 타이머 카드를 클릭하면 편집할 수 있습니다. 카드의 **✕**를 클릭하면 해당 타이머가 삭제됩니다

**미리보기**에 선택한 타이머의 모습이 표시됩니다. 옆의 색상 상자로 미리보기 배경을 바꿀 수 있습니다.

## 2단계: 타이머 설정

### 타이머 모드

- **카운트다운**: 초기 시간부터 거꾸로 셉니다
- **스톱워치**: 0부터 시간을 세며 랩을 기록할 수 있습니다. 스톱워치 모드에는 초기 시간, 경고 시간, 종료 사운드, 시간 옵션이 없습니다

### 이름

타이머 목록, 드롭다운, 빠른 도구에 표시되는 이름입니다.

### 초기 시간

카운트다운의 시작 시간(시, 분, 초)입니다. 옆에 총 초 수가 표시됩니다.

### 경고 시간

남은 시간이 이 값에 도달하면 타이머 텍스트가 **외관**에서 설정한 **경고** 색상으로 바뀝니다. 경고를 사용하지 않으려면 0으로 둡니다.

### 카운트다운 종료 사운드

카운트다운이 0이 되었을 때 재생되는 사운드입니다. **없음** 또는 기본 제공 사운드(**차임벨**, **코인**, **종소리**, **팝**, **팡파르**) 중 하나를 선택합니다. **▶**를 클릭하면 테스트할 수 있습니다. 직접 준비한 파일을 사용하려면 **사운드 선택**을 클릭하고 소재 관리에서 선택합니다.

사운드는 OBS 브라우저 소스에서 재생되므로, 타이머 소스의 **OBS를 통해 오디오 제어**를 켜세요. [OBS에서 소스 추가하는 방법](../getting-started/obs-source)을 참고하세요.

### 시간 옵션

시간 옵션은 카운트다운의 시간 추가/차감 버튼입니다. 타이머마다 최대 20개까지 만들 수 있습니다.

추가하려면 **시간 옵션 추가** 양식을 작성합니다:

1. **트리거 소스**: 이 옵션을 자동으로 적용할 조건을 선택합니다
   - **수동**: 버튼을 클릭할 때만 적용됩니다
   - **팔로우**: 새 Twitch 팔로우마다 적용됩니다
   - **Twitch Bits**: Bits 응원 시 적용됩니다
   - **Twitch 신규 구독**: Twitch 구독 시 적용됩니다
   - **후원**: 후원 시 적용됩니다. **후원 플랫폼**에서 **YouTube**, **O'Pay**, **ECPay**, **PayPal** 중 어느 것을 계산할지 선택합니다
2. **Twitch Bits**와 **후원**은 다음도 설정합니다:
   - **트리거 기준**: 한 단계에 해당하는 Bits 또는 후원 금액
   - **환산 방식**: **정수배 트리거** 또는 **비율 환산**(아래 예시 참고)
3. **시간 추가**: **＋** 또는 **－**를 선택한 후 시, 분, 초를 설정합니다
4. **추가**를 클릭합니다

옵션을 변경하려면 **편집**을 클릭해 양식을 수정한 후 **저장**(또는 **취소**)을 클릭합니다. **✕**를 클릭하면 삭제됩니다. 자동 트리거가 있는 옵션에는 🔗와 트리거 이름이 표시됩니다.

**환산 예시**: 트리거 기준 100 bits, 시간 추가 +1분, 시청자가 250 bits를 응원한 경우:

- **정수배 트리거**: 기준의 정수배만 계산 → 2 × 1분 = **+2분**
- **비율 환산**: 250 ÷ 100 × 1분 → **+2분 30초**

후원은 기준과 비교하기 전에 App 설정에서 선택한 통화로 금액을 환산합니다.

:::note
- 자동 트리거는 카운트다운 타이머에만 적용됩니다
- 자동 트리거가 있는 시간 옵션도 제어판에 버튼으로 표시되므로 직접 클릭할 수도 있습니다
- **Twitch 신규 구독**은 구독 이벤트 한 번에 한 번 적용됩니다. 여러 구독을 한꺼번에 선물해도 한 번만 적용됩니다. 재구독은 [Twitch 목표 바](./goal)에서 **재구독 계산**이 켜져 있을 때만 적용됩니다
:::

### 제어 단축키

이 타이머의 키보드 단축키를 설정합니다:

- **시작／일시정지**
- **랩 단축키**(스톱워치 전용)
- **재설정 단축키**

[단축키](./hotkeys)도 참고하세요.

## 3단계: 외관

| 설정 | 설명 |
|---------|-------------|
| **글꼴** | 시간 텍스트의 글꼴 |
| **글자 크기** | 12–300 px |
| **글자 색상** | **보통**: **단색** 또는 **그라데이션**(두 가지 색상과 **각도**). **경고**(카운트다운 전용): 경고 시간에 도달한 후 사용하는 색상 |
| **배경 색상** | 시간 뒤의 배경 |
| **테두리** | 외곽선 색상, **투명도**, **두께**(0–20 px) |
| **그림자** | 그림자 색상, **투명도**, **흐림**, **X** / **Y** 오프셋 |

## 4단계: 표시 모드 선택 및 OBS 소스 추가

**설정** 탭으로 전환합니다. **제어판**에서 **표시 모드**를 선택합니다:

| 모드 | 설명 | OBS 소스 URL |
|------|-------------|----------------|
| **단일 타이머** | OBS에는 선택한 타이머만 표시됩니다. **현재 타이머** 드롭다운으로 타이머를 전환합니다 | `http://127.0.0.1:7272/timer` |
| **다중 타이머** | 각 타이머가 자체 URL을 가지며 OBS에 개별적으로 추가할 수 있습니다 | `http://127.0.0.1:7272/timer/<timer ID>` |

**다중 타이머** 모드에서는 **표시에 추가**에서 타이머를 선택합니다. 추가한 타이머마다 **OBS 소스 주소**가 있는 카드가 생깁니다. **복사**를 클릭해 복사합니다. 카드의 **✕**를 클릭하면 표시에서 제거됩니다.

복사한 URL을 OBS에 브라우저 소스로 추가합니다. [OBS에서 소스 추가하는 방법](../getting-started/obs-source)을 참고하세요.

:::tip
왼쪽 사이드바에서 **타이머** 옆의 스위치(**OBS 표시 켜기**)도 켜세요. 스위치가 꺼져 있으면 OBS에서 타이머가 숨겨집니다.
:::

## 5단계: 타이머 제어

**설정** 탭의 각 타이머 카드에는 다음이 있습니다:

- **시작** / **일시정지**: 스톱워치에서는 일시정지 버튼이 **정지**로 표시됩니다. 0에 도달한 카운트다운은 재설정하거나 시간을 추가하기 전까지 시작할 수 없습니다
- **랩**(스톱워치 전용): 실행 중에 랩을 기록합니다. 랩은 카드 아래에 시간과 이전 랩과의 차이가 함께 표시됩니다
- **재설정**: 타이머를 멈추고 초기 시간(스톱워치는 0)으로 되돌리며 랩을 지웁니다
- **시간 추가**(카운트다운 전용): 시간 옵션마다 버튼이 하나씩 있습니다

진행 중인 시간은 설정 페이지가 아니라 OBS 오버레이에만 표시됩니다. 현재 시간도 표시되는 [빠른 도구](./quick-tools) 창에서도 타이머를 제어할 수 있습니다.
