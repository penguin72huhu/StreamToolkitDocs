# OBS 장면 제어

**OBS 장면 제어**를 사용하면 전역 단축키나 [빠른 도구](./quick-tools)로 방송 소프트웨어의 장면을 전환하고 소스를 표시/숨길 수 있습니다. **OBS Studio**, **Streamlabs**, **Meld Studio**를 지원합니다.

이 기능에는 오버레이가 없으므로 OBS에 브라우저 소스로 추가할 것이 없습니다.

:::info
단축키는 사이드바의 **OBS 장면 제어** 스위치가 켜져 있을 때만 동작합니다. Stream Toolkit 창이 트레이로 최소화되어 있어도 동작합니다.
:::

설정 페이지에는 **연결 설정**과 **단축키 설정** 두 개의 탭이 있습니다.

## 연결 설정 탭

### 1단계: 소프트웨어 선택

**방송 소프트웨어**에서 **OBS Studio**, **Streamlabs**, **Meld Studio** 중 하나를 선택합니다. 연결이 해제된 상태에서만 변경할 수 있습니다.

소프트웨어마다 단축키와 장면 목록을 따로 저장하므로, 소프트웨어를 전환하면 해당 소프트웨어의 설정이 표시됩니다.

### 2단계: 소프트웨어 준비

#### OBS Studio

1. OBS에서 **Tools → WebSocket Server Settings**를 엽니다
2. **Enable WebSocket server**를 체크합니다
3. **Show Connect Info**를 클릭해 비밀번호를 확인합니다
4. Stream Toolkit에서 **호스트**(기본값 `localhost`), **포트**(기본값 `4455`), **비밀번호**를 입력합니다

#### Streamlabs / Meld Studio

별도 설정이 필요 없습니다. 프로그램을 실행해 두기만 하면 됩니다.

### 3단계: 연결

**연결**을 클릭합니다. **상태**가 **연결됨**으로 바뀝니다(OBS와 Meld는 버전 번호도 표시됩니다). **연결 해제**를 클릭하면 연결이 끊어집니다.

**시작 시 자동 연결**(기본적으로 켜짐): Stream Toolkit을 시작할 때와 기능 스위치를 켤 때 자동으로 연결합니다. 기능 스위치를 끄면 연결이 해제됩니다.

### 장면

**장면** 섹션에는 장면과 각 장면의 소스 개수가 나열되며, 현재 장면은 강조 표시됩니다. 방송 소프트웨어에서 장면을 변경한 후 **새로고침**을 클릭하면 최신 목록을 가져옵니다.

연결이 해제된 상태에서도 마지막으로 가져온 목록이 표시됩니다.

## 단축키 설정 탭

단축키를 설정하려면 **클릭하여 단축키 설정**을 클릭한 후 키 조합을 누릅니다. `Esc`를 누르면 취소됩니다. 키 조합이 이미 다른 기능에서 사용 중이면 **단축키 충돌**이 표시되고 저장되지 않습니다. 단축키 옆의 **✕**를 클릭하면 단축키가 지워집니다.

### 장면 전환

1. **추가**를 클릭합니다
2. 단축키를 설정합니다
3. 전환할 장면을 선택합니다

행 끝의 **✕**를 클릭하면 삭제됩니다.

### 소스 표시 전환

단축키 하나로 같은 장면의 여러 소스를 동시에 제어할 수 있습니다.

1. **추가**를 클릭합니다
2. 단축키를 설정합니다
3. **이름**을 입력합니다(선택 — 빠른 도구에서 버튼 이름으로 사용되며, 비워 두면 장면 이름을 사용합니다)
4. 소스가 속한 장면을 선택합니다
5. **소스 추가**를 클릭하고 소스를 선택한 후 **표시**, **숨김**, **전환** 중 하나를 선택합니다(기본값 **전환**)
6. 소스를 더 추가하려면 5단계를 반복합니다

항목의 장면을 바꾸면 소스 목록이 지워집니다.

:::tip
방송 소프트웨어에 더 이상 존재하지 않는 장면이나 소스는 빨간색으로 표시됩니다. 드롭다운에서 다시 선택하세요.
:::

## 빠른 도구에서 사용하기

기능이 켜져 있고 단축키 항목이 하나 이상 있으면 [빠른 도구](./quick-tools)에 항목마다 버튼이 있는 **OBS 장면 제어** 카드가 표시됩니다. 버튼을 클릭하면 해당 단축키를 누른 것과 같은 동작을 합니다.

## 오류 메시지

단축키나 버튼을 사용할 때 다음 메시지가 나타날 수 있습니다:

| 메시지 | 의미 |
|---------|---------|
| **OBS에 연결되지 않았습니다** | 연결되지 않았습니다. **연결 설정** 탭으로 이동해 **연결**을 클릭하세요 |
| **장면 “…”을(를) 찾을 수 없습니다** | 방송 소프트웨어에서 장면 이름이 바뀌었거나 삭제되었습니다 |
| **소스를 찾을 수 없습니다: …** | 해당 소스가 장면에 더 이상 존재하지 않습니다 |

## 체험판 제한

:::info
체험판에서는 단축키 항목을 모두 합쳐 **1**개(장면 전환과 소스 표시 전환 합계)까지 만들 수 있습니다. [체험판 / 정식판 비교](../getting-started/trial-comparison)를 참고하세요.
:::

## 자주 묻는 질문

**Q: OBS에 연결할 수 없다고 나왔는데, OBS를 연 뒤에도 다시 시도하지 않나요?**
첫 연결 시도가 실패하면(예: OBS가 아직 실행되지 않은 경우) Stream Toolkit은 계속 재시도하지 않습니다. 방송 소프트웨어를 연 후 **연결**을 클릭하세요. 한 번 연결에 성공한 후에는 연결이 끊어지면 자동으로 다시 연결합니다.
