# 채팅방

**채팅방**은 Twitch와 YouTube 채팅을 하나의 오버레이에 함께 표시하며, 자동 번역도 선택할 수 있습니다. 본인만 볼 수 있는 투명한 데스크톱 창에 채팅을 표시할 수도 있습니다.

## OBS 소스 URL

```
http://127.0.0.1:7272/chat
```

브라우저 소스로 추가합니다: [OBS에서 소스 추가하는 방법](../getting-started/obs-source). 이 오버레이는 소리가 없습니다.

:::info
사이드바의 **채팅방** 스위치가 켜져 있을 때만 메시지가 오버레이로 전송됩니다. 스위치가 꺼져 있어도 채팅은 계속 수신되므로, 채팅을 읽는 기능(투표, 추첨, 노래 신청 등)은 계속 동작합니다.
:::

## 시작하기 전에

표시할 플랫폼을 연결합니다:

- [Twitch 설정](../platforms/twitch)
- [YouTube 설정](../platforms/youtube-settings)

설정 페이지에는 **설정**과 **외관** 두 개의 탭이 있습니다.

## 설정 탭

### 플랫폼

- **플랫폼 icon 표시 (Twitch / YouTube)** — 각 메시지 앞에 <img src={require('@site/static/img/twitch-icon.png').default} alt="Twitch" className="inline-icon" /> / <img src={require('@site/static/img/youtube-icon.png').default} alt="YouTube" className="inline-icon" /> 아이콘을 표시합니다

플랫폼마다 카드가 있습니다. 연결되어 있고 사용 중이면 플랫폼 이름 옆의 점이 초록색으로 켜집니다. Twitch가 연결되어 있지 않으면 **(연결 안 됨)**, YouTube 채팅이 연결되어 있지 않으면 **채팅방 주소가 연결되지 않음**이 표시됩니다.

| 옵션 | 설명 |
|--------|-------------|
| **채팅방 사용** | 이 플랫폼의 메시지를 표시합니다 |
| **프로필 사진 표시** | 시청자의 프로필 사진을 표시합니다 |
| **배지 표시** (Twitch) / **배지 표시 (멤버 아이콘)** (YouTube) | 배지를 표시합니다 |
| **@핸들 대신 시청자 이름 표시** | YouTube 전용. Google로 로그인해야 사용할 수 있습니다 |

YouTube 채팅이 사용 중이지만 연결되어 있지 않으면 카드에 버튼 두 개가 나타납니다:

- **자동 연결** — 현재 방송을 자동으로 찾습니다(Google 로그인 필요)
- **직접 입력** — 설정 페이지로 이동하여 채팅 URL을 붙여넣습니다

**최대 메시지 수**: 화면에 유지할 메시지 수(5–200, 기본값 50).

### 자동 번역

1. **번역 사용**을 체크합니다
2. **목표 언어**: 메시지를 번역할 언어입니다. 기본값인 **인터페이스 언어 따르기**는 App의 인터페이스 언어를 사용합니다
3. **번역하지 않을 언어**(선택): 체크한 언어의 메시지는 번역하지 않고 그대로 둡니다. 포르투갈어 PT-BR과 PT-PT는 구분할 수 없으므로, 둘 중 하나를 체크하면 둘 다 건너뜁니다

**번역 서비스**는 API 키가 필요 없는 **MyMemory**입니다.

- **Email (선택)**: 이메일이 없으면 일일 할당량은 5,000자입니다. 이메일을 입력하고 **저장**을 클릭하면 50,000자로 늘어납니다(무료, MyMemory 가입 불필요)
- 아래 바는 오늘 사용한 대략적인 양을 표시합니다. 매일 08:00 UTC에 초기화됩니다

### 테스트

- **테스트 메시지 보내기** — 무작위 샘플 메시지를 오버레이에 보냅니다
- **지우기** — 오버레이의 모든 메시지를 지웁니다

**연결 실패 — 서버가 실행되지 않았을 수 있습니다**가 표시되면 Stream Toolkit의 로컬 서버가 응답하지 않는 것입니다.

### 데스크톱 채팅방 창

게임 위에 항상 맨 위에 표시되는 작은 투명 창으로 채팅을 보여 줍니다. 본인만 볼 수 있어 모니터 하나로 방송할 때 편리합니다.

1. **창 열기**를 클릭합니다(또는 트레이 아이콘을 마우스 오른쪽 버튼으로 클릭하고 **데스크톱 채팅방 열기**를 선택합니다)
2. 잠금 해제 상태에서는 상단 바를 드래그해 창을 옮기고, 가장자리를 드래그해 크기를 조절합니다
3. 위치가 정해지면 **🔒 잠금**을 클릭합니다. 그러면 클릭이 창을 통과해 게임으로 전달됩니다. 잠금을 해제하려면 창 위로 마우스를 옮겨 오른쪽 위에 나타나는 🔓를 클릭하거나, 설정 페이지에서 **🔓 잠금 해제**를 클릭합니다

**위치 초기화**를 누르면 창이 기본 위치로 돌아갑니다.

| 설정 | 설명 |
|---------|-------------|
| **표시 스타일** | **이름 + 내용만**(기본값) 또는 **OBS 채팅방과 동일** |
| **글자 크기** | 12–32 px, 기본값 16. **이름 + 내용만**에서만 적용됩니다 |
| **글자 불투명도** | 10–100%, 기본값 100% |
| **배경 불투명도** | 0–100%, 기본값 40% |
| **메시지 페이드아웃** | 0–120초, 기본값 0. 각 메시지가 이 시간이 지나면 사라지며, 사라진 메시지는 스크롤해서 다시 볼 수 없습니다. 0이면 사라지지 않으며, 잠금 해제 상태에서 위로 스크롤해 이전 메시지를 볼 수 있습니다(최대 메시지 수까지) |
| **방송 화면에서 숨기기** | 기본적으로 켜져 있습니다. OBS 디스플레이 캡처에 창이 잡히지 않으므로 시청자에게 채팅이 두 번 보이지 않습니다. 스크린샷이나 Discord 화면 공유에도 나타나지 않습니다 |

:::tip
게임이 전체 화면일 때 창이 보이지 않으면 게임을 테두리 없는 창 모드 또는 창 모드로 바꾸세요. **테스트 메시지 보내기**로 창의 위치와 크기를 확인할 수 있습니다.
:::

## 외관 탭

### 미리보기

탭 상단에 실시간 미리보기가 표시됩니다. **미리보기** 옆의 색상 선택기는 미리보기 배경만 바꿉니다. **프로필 사진**, **배지**, **플랫폼 icon** 체크박스는 미리보기에 표시되는 내용만 바꿉니다.

### 외관 설정

**기본값 복원**을 누르면 기본 외관(테마가 적용되어 있으면 해당 테마의 외관)으로 돌아갑니다.

- **등장 방향**: **위에서 아래로**, **아래에서 위로**(기본값), **왼쪽에서 오른쪽으로**, **오른쪽에서 왼쪽으로**
- **텍스트** — **닉네임**과 **메시지**를 각각 설정합니다:
  - 글꼴, 크기(px), 색상. 닉네임은 **원본 색상**(시청자의 플랫폼 색상) 또는 **사용자 정의 색상**을 선택할 수 있습니다
  - **외곽선**: 색상, **투명도**, **두께**
  - **그림자**: 색상, **투명도**, **흐림**, X / Y 오프셋
- **아이콘 크기**: **플랫폼 icon**, **프로필 사진**, **배지**의 배율(0.1–5x)
- **색상**: 각 메시지의 **배경 색상**

### 사용자 정의 CSS

**사용자 정의 CSS**를 펼치면 오버레이의 CSS를 직접 편집할 수 있습니다. **소재 관리**로 CSS에서 참조할 이미지를 업로드할 수 있습니다. **기본값 복원**을 누르면 기본 CSS로 돌아갑니다. [테마 스타일](./themes)도 참고하세요.

:::tip
사용자 정의 CSS에서 `!important`로 외관 항목을 설정하면 외관 설정에서 해당 항목이 회색으로 비활성화됩니다("이 설정은 사용자 정의 CSS로 제어됩니다"). 테마가 적용된 동안에는 CSS가 읽기 전용이므로, 편집하려면 먼저 복원하세요.
:::

## 체험판 제한

:::info
- 자동 번역을 켜면 채팅방 오버레이에 워터마크가 추가됩니다
- **사용자 정의 CSS**는 정식판에서만 사용할 수 있습니다
- **데스크톱 채팅방 창**은 정식판에서만 사용할 수 있습니다

[체험판 / 정식판 비교](../getting-started/trial-comparison)를 참고하세요.
:::
