# Twitch 목표 바

방송 화면에 Twitch 팔로워, 구독, Bits 목표의 진행 바를 표시합니다. 목표 유형마다 바, 설정, OBS URL이 따로 있습니다.

:::note 시작하기 전에
목표 바는 Twitch 이벤트를 계산하므로 먼저 Twitch 계정을 연결하세요. [Twitch 설정](../platforms/twitch)을 참고하세요.
:::

## 1단계: 목표 유형 선택 및 OBS 소스 추가

페이지 상단에서 목표 유형을 선택합니다: **팔로우**, **구독**, **Bits**. 버튼 아래의 **OBS 주소**가 선택에 맞게 바뀝니다. **복사**를 클릭해 복사합니다.

| 목표 유형 | OBS 소스 URL |
|-----------|----------------|
| **팔로우** | `http://127.0.0.1:7272/goal/follow` |
| **구독** | `http://127.0.0.1:7272/goal/sub` |
| **Bits** | `http://127.0.0.1:7272/goal/bits` |

표시할 바마다 OBS에 별도의 브라우저 소스로 추가합니다. [OBS에서 소스 추가하는 방법](../getting-started/obs-source)을 참고하세요. 목표 바는 소리가 없으므로 "OBS를 통해 오디오 제어"를 켤 필요가 없습니다.

:::tip
왼쪽 사이드바에서 **Twitch 목표 바** 옆의 스위치(**OBS 표시 켜기**)도 켜세요. 스위치가 꺼져 있으면 OBS에서 바가 숨겨집니다.
:::

## 2단계: 목표 설정

아래의 모든 설정은 상단에서 선택한 목표 유형에 적용됩니다.

- **제목**: 바에 표시되는 제목 텍스트
- **목표**: 목표 수치(0 이상의 정수)
- **진행도**: 현재 수, 목표, 백분율을 표시합니다

### 진행도 계산 방식

| 목표 유형 | 진행도에 더해지는 것 |
|-----------|----------------------|
| **팔로우** | 새 팔로우마다 1이 더해집니다. Twitch가 연결되어 있는 동안에는 30초마다 Twitch에서 채널의 전체 팔로워 수와도 동기화됩니다. **동기화**를 클릭하면 바로 동기화합니다 |
| **구독** | 새 구독과 선물 구독(여러 구독을 선물하면 선물한 구독 수만큼 더해짐). 재구독은 **재구독 계산**이 켜져 있을 때만 계산됩니다 |
| **Bits** | 응원할 때마다 응원한 Bits 수만큼 더해집니다 |

### 구독 옵션

**구독**에서만 표시됩니다:

- **Tier별 가중치**: 켜면 높은 등급의 구독이 진행도에 더 많이 더해집니다. 끄면 모든 구독이 1씩 더해집니다
- **재구독 계산**: 켜면 재구독 메시지도 진행도에 더해집니다

### 진행도 초기화

**구독**과 **Bits**에는 **진행도 초기화** 버튼이 있습니다. 클릭한 후 **초기화 확인**을 클릭하면 현재 수가 0으로 돌아갑니다. 목표 수치는 유지됩니다.

**팔로우**는 수치가 Twitch 팔로워 총수를 따르므로 초기화 버튼이 없습니다.

## 3단계: 외관 조정

### 미리보기

상단의 **미리보기**에 선택한 목표 유형의 바가 표시됩니다. 옆의 색상 상자로 미리보기 배경을 바꿀 수 있습니다. **달성 미리보기**를 체크하면 목표를 달성했을 때의 바 모습을 볼 수 있습니다.

### 외관 설정

| 설정 | 설명 |
|---------|-------------|
| **배경 색상** | 바의 배경 |
| **진행 바 색상** | 채워진 부분의 색상 |
| **달성 색상** | 목표 달성 후 채움 색상 |
| **제목 글자** | 제목의 글꼴, 색상, 크기(8–72 px) |
| **목표 글자** | 숫자의 글꼴, 색상, 크기(8–72 px) |
| **백분율** | 백분율의 글꼴, 색상, 크기(8–72 px) |

**기본값 복원**을 클릭하면 선택한 목표 유형의 외관이 복원됩니다.

### 사용자 정의 CSS

**사용자 정의 CSS**를 클릭하면 편집기가 펼쳐집니다. 목표 유형마다 CSS가 따로 있습니다. 배치와 구조에 사용하세요. 색상, 글꼴, 크기는 위의 외관 설정에서 설정합니다.

- **기본값 복원**: 기본 CSS로 되돌립니다
- **소재 관리**: CSS에서 사용할 이미지를 관리하는 소재 관리를 엽니다

CSS에서 `!important`로 속성을 덮어쓰면 어차피 CSS가 우선하므로 해당 외관 설정 항목이 잠깁니다.

:::info 체험판 제한
- **사용자 정의 CSS**는 정식판에서만 사용할 수 있습니다
- OBS 오버레이에 워터마크가 표시됩니다

자세한 내용은 [체험판 / 정식판 비교](../getting-started/trial-comparison)를 참고하세요.
:::
