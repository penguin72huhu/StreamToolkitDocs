# 단축키

왼쪽 메뉴 하단의 **⌨️ 단축키**에서 설정한 모든 단축키를 한곳에서 볼 수 있습니다.

## 단축키 한눈에 보기

각 행에는 키 조합과 실행되는 동작이 표시됩니다(예: `타이머 › (타이머 이름) › 시작／일시정지`). 행을 클릭하면 해당 기능의 설정 페이지가 열리며, 그곳에서 변경할 수 있습니다. 이 페이지에서는 단축키를 편집하지 않습니다.

아직 설정된 단축키가 없으면 "아직 설정된 단축키가 없습니다."가 표시됩니다.

## 단축키를 지원하는 기능

| 기능 | 단축키 동작 |
|------|------|
| [스트림 하이라이트 마커](./highlight) | 마커를 추가합니다 |
| [미디어 보드](./multimedia) | 사운드 재생 / 이미지 표시 / 영상 재생(항목마다 단축키 하나) |
| [음성 번역](./voice-translate) | 음성 번역 단축키 |
| [OBS 장면 제어](./obs-scene) | **장면 전환** / **소스 표시 전환** |
| [타이머](./timer) | **시작 / 일시정지**, **랩**, **재설정**(타이머별) |

## 단축키 설정

[스트림 하이라이트 마커](./highlight), [OBS 장면 제어](./obs-scene), [타이머](./timer)는 같은 단축키 입력란을 사용합니다. 미디어 보드와 음성 번역은 각 페이지를 참고하세요.

1. 단축키 버튼을 클릭합니다
2. 키 조합을 누릅니다(예: `Ctrl+Shift+F1`)
3. 모든 키에서 손을 떼면 저장됩니다

- 입력 중에 **Esc**를 누르면 취소됩니다
- 키 조합이 이미 다른 단축키에서 사용 중이면 충돌 메시지가 표시되고 저장되지 않습니다. 다른 조합을 선택하세요
- 옆의 **✕**(또는 지우기 버튼)를 클릭하면 단축키가 제거됩니다
- 숫자 키패드의 키는 메인 키보드의 숫자 키와 구분됩니다. `Num1`과 `1`은 서로 다른 단축키입니다

단축키는 게임 중처럼 Stream Toolkit이 백그라운드에 있을 때도 동작합니다.
