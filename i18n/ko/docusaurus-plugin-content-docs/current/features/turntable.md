# 룰렛

나만의 경품 돌림판을 만들어 방송에서 돌립니다. 항목별 가중치, 돌림판 색상, 당첨된 항목을 이후에 제외할지 여부를 설정할 수 있습니다.

페이지에는 **설정**, **돌림판 만들기**, **기록** 세 개의 탭이 있습니다. 먼저 돌림판을 만든 다음 **설정**에서 돌립니다.

## 1단계: 돌림판 만들기

1. 왼쪽 사이드바에서 **룰렛**을 열고 **돌림판 만들기** 탭으로 전환합니다
2. **내 돌림판**에서 **추가**를 클릭합니다. "돌림판 1"(이후 "돌림판 2" 등)이라는 이름의 새 돌림판이 나타납니다
3. 돌림판 카드를 클릭하면 편집할 수 있습니다. 카드의 **✕**를 클릭하면 해당 돌림판이 삭제됩니다

### 돌림판 제목

돌림판의 이름을 입력합니다. 돌림판 목록, 드롭다운, 기록에 사용됩니다.

### 돌림판 내용

1. **내용 편집**을 클릭합니다
2. 항목을 **한 줄에 하나씩** 입력합니다
3. **확인**을 클릭합니다

### 가중치

돌림판에 항목이 생기면 항목마다 **가중치** 입력란이 생깁니다(최솟값 1, 기본값 1). 항목의 칸 크기와 당첨 확률은 모두 가중치에 비례합니다. 예를 들어 가중치가 2인 항목은 가중치가 1인 항목보다 당첨 확률이 두 배입니다.

### 돌림판 테마 색상

- **미니멀**: 기본 제공 흰색·회색 배색
- **사용자 정의**: 나만의 배색을 만듭니다. **이름**을 입력하고 **색상 (3–5색)**을 고른 후(**＋**로 색상 추가, **✕**로 제거) **추가**를 클릭합니다

사용자 정의 테마를 변경하려면 **✎** 버튼을, 삭제하려면 **✕**를 클릭합니다. 사용자 정의 테마는 [추첨](./lottery)의 룰렛 애니메이션 배색으로도 사용할 수 있습니다.

### 추첨 후 항목 삭제

켜면 당첨된 항목이 다음 회전 전에 돌림판에서 제외됩니다. **초기화**를 클릭하면 모든 항목이 돌아옵니다.

## 2단계: 표시 모드 선택 및 OBS 소스 추가

**설정** 탭으로 전환하고 **표시 모드**를 선택합니다:

| 모드 | 설명 | OBS 소스 URL |
|------|-------------|----------------|
| **단일 돌림판** | OBS에는 선택한 돌림판만 표시됩니다. **현재 사용 중인 돌림판** 드롭다운으로 돌림판을 전환합니다 | `http://127.0.0.1:7272/turntable` |
| **다중 돌림판** | OBS에 여러 돌림판을 동시에 표시할 수 있습니다. 돌림판마다 URL이 따로 있습니다 | `http://127.0.0.1:7272/turntable/<wheel ID>` |

**다중 돌림판** 모드에서는 **돌림판 표시에 추가**에서 돌림판을 선택합니다. 추가한 돌림판마다 **OBS 소스 주소**가 있는 카드가 생깁니다. **복사**를 클릭해 복사합니다. 카드의 **✕**를 클릭하면 해당 돌림판이 표시에서 제거됩니다.

복사한 URL을 OBS에 브라우저 소스로 추가합니다. [OBS에서 소스 추가하는 방법](../getting-started/obs-source)을 참고하세요. 룰렛은 소리가 없으므로 "OBS를 통해 오디오 제어"를 켤 필요가 없습니다.

:::tip
왼쪽 사이드바에서 **룰렛** 옆의 스위치(**OBS 표시 켜기**)도 켜세요. 스위치가 꺼져 있으면 오버레이가 숨겨진 상태로 유지됩니다.
:::

## 3단계: 돌리기

**설정** 탭의 각 돌림판 카드에서:

- **돌리기**: 회전을 시작합니다. 애니메이션이 끝나면 오버레이에 결과가 표시됩니다. 돌림판에 항목이 없거나 아직 회전 중일 때는 버튼을 클릭할 수 없습니다
- **초기화**: 제외된 항목을 되돌리고, 돌림판을 초기화하며, 현재 **당첨 명단**을 지웁니다

카드의 **당첨 명단**에는 마지막 **초기화** 이후의 모든 결과가 모입니다.

[빠른 도구](./quick-tools) 창에서도 **돌리기**와 **초기화**를 사용할 수 있습니다.

## 기록

**기록** 탭에는 첫 회전부터 다음 **초기화**까지를 한 라운드로 하여 라운드마다 기록이 하나씩 남습니다. 시간, 돌림판 제목, 당첨자가 표시됩니다. 최근 30일간의 돌림판 기록만 보관합니다. 기록을 삭제하려면 🗑을 클릭한 후 **삭제 확인**을 클릭합니다.

:::info 체험판 제한
- 돌림판은 **1**개만 만들 수 있습니다
- OBS 오버레이에 워터마크가 표시됩니다

자세한 내용은 [체험판 / 정식판 비교](../getting-started/trial-comparison)를 참고하세요.
:::
