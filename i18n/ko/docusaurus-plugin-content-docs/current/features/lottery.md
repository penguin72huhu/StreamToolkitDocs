# 추첨

시청자가 Twitch 또는 YouTube 채팅에 키워드를 입력해 참가합니다. 참가를 마감하면 무작위로 당첨자를 뽑으며, 추첨 애니메이션이 OBS 오버레이에 재생됩니다.

## OBS 소스 URL

```
http://127.0.0.1:7272/lottery
```

페이지 상단의 **OBS 소스 주소** 옆에 있는 **복사**를 클릭한 후 OBS에 브라우저 소스로 추가합니다. [OBS에서 소스 추가하는 방법](../getting-started/obs-source)을 참고하세요. 추첨은 소리가 없으므로 "OBS를 통해 오디오 제어"를 켤 필요가 없습니다.

:::tip
왼쪽 사이드바에서 **추첨** 옆의 스위치(**OBS 표시 켜기**)도 켜세요. 스위치가 꺼져 있으면 오버레이가 숨겨진 상태로 유지됩니다.
:::

페이지에는 **설정**과 **기록** 두 개의 탭이 있습니다.

## 설정

### 투표 플랫폼

**Twitch** 또는 **YouTube**를 클릭해 어느 플랫폼의 채팅으로 참가할 수 있는지 선택합니다. 둘 다 선택할 수도 있습니다. 연결되지 않은 플랫폼에는 **(연결 안 됨)**(Twitch) 또는 **채팅방 주소가 연결되지 않음**(YouTube)이 표시됩니다. 연결 방법은 [Twitch 설정](../platforms/twitch)과 [YouTube 설정](../platforms/youtube-settings)을 참고하세요.

### 추첨 키워드

이 키워드가 포함된 채팅 메시지를 보낸 시청자가 참가합니다. 시청자는 추첨마다 한 번만 참가할 수 있습니다. 키워드가 비어 있으면 **수집 시작**을 클릭할 수 없습니다.

### 추첨 시간

참가를 받는 시간(초)입니다. 기본값은 300이며 범위는 10–3600입니다.

### 최대 참가 인원

이 인원이 참가하면 참가가 일찍 마감됩니다. `0`을 입력하면 제한이 없습니다.

### 추첨 후 항목 삭제

켜면 당첨자가 다음 추첨 전에 참가자에서 제외되므로, 해당 추첨에서 다시 뽑히지 않습니다.

### 안내 텍스트

참가를 받는 동안 오버레이에 표시되는 안내로, 시청자에게 키워드와 참가자 수를 알려 줍니다. 글꼴, 색상, 크기(px)를 설정합니다.

### 추첨 애니메이션

- **ID 빠른 전환**(기본값): 참가를 받는 동안 참가자 이름이 화면에 떠다니고, 추첨할 때 빠르게 순환합니다
  - **수집 화면 글꼴**: 글꼴, 글자 크기, 이름 칩의 색상(최대 5가지)
  - **추첨 애니메이션 글꼴**: 추첨 중 순환하는 이름의 글꼴과 글자 크기
  - **기본값 복원**: 이 설정들을 복원합니다
- **룰렛 애니메이션**: 참가자를 돌림판에 배치하고 돌려서 당첨자를 뽑습니다. 배색을 선택합니다: **미니멀** 또는 [룰렛](./turntable)에서 만든 사용자 정의 테마

참가를 받는 동안에는 플랫폼, 키워드, 시간, 최대 참가 인원, 추첨 후 항목 삭제, 애니메이션 유형을 변경할 수 없습니다.

## 추첨 진행

1. **수집 시작**을 클릭합니다. 패널에 **수집 중…**, 남은 시간, 참가자 수가 표시됩니다
2. 참가를 받는 동안 **참가자 이름 수동 입력**에 이름을 입력하고 **추가**를 클릭(또는 Enter)할 수 있습니다. 이미 명단에 있는 이름이면 "이 ID는 이미 명단에 있습니다"가 표시됩니다
3. 시간이 끝나기 전에 참가를 마감하려면 **수집 종료**를 클릭합니다. 시간이 다 되거나 **최대 참가 인원**에 도달해도 참가가 마감됩니다. 그러면 패널에 **시간 종료!**가 표시됩니다
4. **추첨 시작**을 클릭합니다. 오버레이에 애니메이션이 재생되고, 끝나면 **당첨자** 아래에 당첨자가 표시됩니다
5. 당첨자를 더 뽑으려면 **다시 추첨**을 클릭합니다

어느 단계에서든 **추첨 취소**를 클릭하면 모든 참가자와 당첨자가 지워지고 오버레이가 대기 상태로 돌아갑니다.

## 기록

**기록** 탭에는 추첨마다 시간, 키워드, 참가자 수가 담긴 기록이 하나씩 남습니다. 기록을 펼치면 당첨자와 전체 참가자 명단을 볼 수 있습니다. 최근 30일간의 추첨 기록만 보관합니다. 기록을 삭제하려면 🗑을 클릭한 후 **삭제 확인**을 클릭합니다.

:::info 체험판 제한
OBS 오버레이에 워터마크가 표시됩니다. 자세한 내용은 [체험판 / 정식판 비교](../getting-started/trial-comparison)를 참고하세요.
:::
