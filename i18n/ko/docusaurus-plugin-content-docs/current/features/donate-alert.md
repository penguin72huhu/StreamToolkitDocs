# 후원 알림

누군가 후원하면 이미지, 사운드, 후원자 이름, 금액, 메시지가 담긴 알림을 표시합니다.

## OBS 소스 URL

```
http://127.0.0.1:7272/donate-alert
```

**후원 알림 설정** 페이지 상단에서 URL을 복사하여 OBS에 브라우저 소스로 추가합니다. [OBS에서 소스 추가하는 방법](../getting-started/obs-source)을 참고하세요.

:::warning
알림에는 소리가 재생됩니다. 브라우저 소스 속성에서 **OBS를 통해 오디오 제어**를 체크하지 않으면 방송에서 소리가 들리지 않습니다.
:::

왼쪽 사이드바에서 **후원 알림** 옆의 스위치로 알림을 켜거나 끕니다. 스위치가 꺼져 있으면 알림(테스트 알림 포함)이 표시되지 않지만, 후원은 계속 [후원 기록판](./sponsors)에 기록됩니다.

여러 후원이 짧은 간격으로 들어오면 알림이 대기열에 들어가 차례대로 표시됩니다.

## 설정 탭

### 연동 플랫폼

알림을 표시할 플랫폼을 체크합니다: **Twitch**, **YouTube**, **PayPal**, **Stripe**, **O'Pay**, **ECPay**. 초록색 점은 플랫폼이 연결되었다는 뜻이며, 그렇지 않으면 **(연결 안 됨)**이 표시됩니다. 이 체크박스는 알림에만 적용되며, 후원 바나 후원 기록판에는 영향을 주지 않습니다.

**Twitch ⚙️** (Twitch가 연결되어 있고 체크되어 있을 때 표시):

1. **Bits와 구독 계산**, **Bits만 계산**, **구독만 계산** 중에서 선택합니다
2. **재구독 계산**: 재구독 시 알림을 표시할지 여부(구독을 계산할 때 표시)
3. **미만 [N] Bits는 계산에 포함하지 않음**: 체크하고 최솟값을 입력하면 그보다 적은 응원은 알림이 표시되지 않습니다(Bits를 계산할 때 표시)
4. **저장**을 클릭합니다

**YouTube ⚙️**:

- **@핸들 대신 시청자 이름 표시**: Google로 로그인한 후에만 사용할 수 있습니다.
- **집계 항목**: **슈퍼챗**, **슈퍼 스티커**, **신규 멤버**, **멤버십 갱신**, **멤버십 선물**, **주얼**. **주얼**은 Google 로그인이 필요합니다.

YouTube 라이브 채팅이 연결되어 있지 않으면 **채팅방 주소가 연결되지 않음**과 함께 **자동 연결**(Google 로그인 필요)과 **직접 입력**(설정의 채팅 URL 필드로 이동)이 표시됩니다. 멤버십 이벤트를 체크했지만 멤버십 가격이 설정되어 있지 않으면 **⚠ 멤버십 가격 미설정**을 클릭해 설정하세요. [YouTube 설정](../platforms/youtube-settings)을 참고하세요.

PayPal, Stripe, O'Pay, ECPay 연결 방법은 [PayPal](../payments/paypal), [Stripe](../payments/stripe), [O'Pay](../payments/opay), [ECPay](../payments/ecpay)를 참고하세요.

### 설정

| 항목 | 설명 |
|-------|-------------|
| **자신의 통화로 자동 환산** | 기본적으로 켜져 있습니다. 설정 페이지에서 지정한 **후원 통화**로 환산한 금액을 표시합니다. |
| **표시 시간** | 각 알림이 화면에 표시되는 시간(초). 기본값: 6. |

## 외관 탭

### 미리보기

미리보기는 OBS 소스와 같은 페이지를 사용합니다. **미리보기** 옆의 색상 선택기로 미리보기 배경을 바꿀 수 있으며, **▶ 애니메이션 다시 재생**을 클릭하면 알림 애니메이션을 다시 재생합니다.

### 통일 스타일 / 플랫폼별 개별

- **통일 스타일**: 모든 플랫폼이 같은 알림 스타일을 사용합니다.
- **플랫폼별 개별**: 플랫폼마다 각자의 스타일을 사용합니다. 아래 버튼(**Twitch**, **YouTube**, **O'Pay**, **ECPay**, **PayPal**, **Stripe**)으로 플랫폼을 선택하고 설정을 편집합니다. 처음 전환하면 아직 사용자 정의하지 않은 플랫폼은 현재 통일 스타일을 복사하며, 카운트다운 바 색상은 플랫폼마다 따로 갖습니다.

**기본값 복원**을 누르면 편집 중인 스타일이 기본 스타일로 돌아갑니다.

### 이미지

- **이미지 선택**: 소재 관리에서 이미지를 선택합니다. 이미지가 없으면 하트 이모지가 표시됩니다. **지우기**를 누르면 이미지가 제거됩니다.
- **이미지 크기**: 1–400 px.
- **이미지 위치**: **왼쪽**, **오른쪽**, **위쪽**, **아래쪽**.

### 사운드

기본 제공 사운드를 선택합니다: **없음**, **차임벨**(기본값), **코인**, **종소리**, **팝**, **팡파르**. **▶**를 클릭하면 들어볼 수 있습니다. **사운드 선택**을 클릭하면 소재 관리에서 직접 준비한 사운드 파일을 사용할 수 있습니다.

### 텍스트 표시

- **기본값**: 금액, 후원자 이름, 메시지를 각각 다른 줄에 표시합니다.
- **사용자 정의 텍스트**: 직접 문구를 작성합니다. 후원자 이름은 `{name}`, 금액은 `{amount}`를 사용합니다. 예: `{name}님, {amount} 후원 감사합니다!`

### 텍스트와 색상

- **텍스트**: **금액**, **후원자 이름**, **메시지**(사용자 정의 텍스트 모드에서는 **사용자 정의 텍스트** 포함)의 글꼴, 크기, 색상을 설정합니다.
- **색상**: **배경**, **그림자**, **카운트다운 바**.

### 사용자 정의 CSS

**사용자 정의 CSS**를 펼치면 편집 중인 스타일(통일 스타일 또는 선택한 플랫폼)의 CSS를 편집할 수 있습니다. **기본값 복원**을 누르면 템플릿 CSS로 돌아가고, **소재 관리**를 누르면 소재 관리가 열립니다. 여기서 Steam Workshop 테마도 적용할 수 있습니다. 테마가 적용된 동안에는 CSS가 읽기 전용입니다. [테마 스타일](./themes)을 참고하세요.

## 알림 테스트

**설정** 페이지에서 **후원 플랫폼 연동** 옆의 **알림 테스트**를 클릭합니다:

1. **테스트 이름**, **테스트 메시지**, **테스트 금액**을 입력하고 **테스트 플랫폼**을 선택합니다
2. **테스트 알림 보내기**를 클릭합니다

**YouTube Super Chat 테스트** 섹션에서는 원본 **금액 문자열**(예: `$5.00`, `¥500`, `NT$150`)을 입력하고 **테스트 Super Chat 보내기**를 클릭해 금액 파싱과 통화 환산을 테스트할 수 있습니다.

:::note
테스트 알림은 실제 후원과 똑같이 처리됩니다. [후원 바](./donate)와 [후원 기록판](./sponsors)에서 해당 플랫폼이 체크되어 있으면 그곳에도 추가됩니다.
:::

:::info 체험판
사용자 정의 CSS는 정식판에서만 사용할 수 있습니다. 실제 결제 서비스(PayPal / Stripe / O'Pay / ECPay)와 YouTube 멤버십 이벤트, 주얼은 체험판에서 사용할 수 없으며, OBS의 알림에 워터마크가 표시됩니다. [체험판 / 정식판 비교](../getting-started/trial-comparison)를 참고하세요.
:::

## 자주 묻는 질문

**Q: 방송에서 소리가 나지 않나요?**
브라우저 소스 속성에서 **OBS를 통해 오디오 제어**가 체크되어 있는지, OBS 믹서에서 해당 소스가 음소거되어 있지 않은지 확인하세요. 또한 **사운드**가 **없음**으로 설정되어 있지 않은지 확인하세요.

**Q: OBS 소스를 늦게 추가했는데, 이전 알림이 다시 재생되나요?**
아니요. 새로 열린 소스는 연결된 이후에 도착한 알림만 표시합니다.
