# 새 팔로워 알림

누군가 Twitch에서 팔로우하거나 YouTube 채널을 구독하면 방송 화면에 알림을 표시합니다.

## OBS 소스 URL

```
http://127.0.0.1:7272/fan-alert
```

**새 팔로워 알림 설정** 페이지 상단에서 URL을 복사하여 OBS에 브라우저 소스로 추가합니다. [OBS에서 소스 추가하는 방법](../getting-started/obs-source)을 참고하세요.

:::warning
알림에는 소리가 재생됩니다. 브라우저 소스 속성에서 **OBS를 통해 오디오 제어**를 체크하지 않으면 방송에서 소리가 들리지 않습니다.
:::

왼쪽 사이드바에서 **새 팔로워 알림** 옆의 스위치로 알림을 켜거나 끕니다. 스위치가 꺼져 있으면 새 팔로워가 표시되지도 기록되지도 않으며, 테스트 버튼도 동작하지 않습니다.

여러 팔로워가 짧은 간격으로 들어오면 알림이 대기열에 들어가 차례대로 표시됩니다. 이 오버레이는 자체 대기열을 사용하므로 [후원 알림](./donate-alert) 뒤에서 기다리지 않습니다.

## 설정 탭

### 연동 플랫폼

알림을 표시할 플랫폼을 체크합니다: **Twitch**와 **YouTube**(기본적으로 둘 다 체크됨). 초록색 점은 플랫폼이 연결되었다는 뜻이며, 그렇지 않으면 **인증 안 됨**이 표시됩니다.

- **Twitch**: 새 팔로우마다 즉시 알림이 표시됩니다. 먼저 Twitch를 연결하세요: [Twitch 설정](../platforms/twitch).
- **YouTube**: 새 구독자. 먼저 Google로 로그인하세요: [YouTube 설정](../platforms/youtube-settings).

YouTube 구독자를 찾는 방식:

- YouTube에는 실시간 "새 구독자" 이벤트가 없으므로, App이 1.5분마다 YouTube에 최근 구독자를 요청합니다.
- 방송 중이고 YouTube 라이브 채팅이 해당 라이브 방송에 연결되어 있을 때만 확인합니다. 대기실이나 방송 종료 후에는 확인하지 않습니다.
- 방송 시작 전에 구독한 사람(확인 시작 약 5분 이전)은 알리지 않습니다.
- 페이지의 안내처럼 **YouTube는 구독을 공개한 시청자만 알리며, 몇 분에서 몇 시간 지연될 수 있습니다.**

### 설정

| 항목 | 설명 |
|-------|-------------|
| **표시 시간** | 각 알림이 화면에 표시되는 시간(초, 1–60). 기본값: 5. |
| **같은 시청자는 24시간에 한 번만 알림** | 기본적으로 꺼져 있습니다. 켜면 같은 시청자가 24시간 안에 다시 팔로우해도(예: 팔로우 취소 후 다시 팔로우) 표시되거나 기록되지 않습니다. |

### 알림 테스트

**테스트 알림 (Twitch)** 또는 **테스트 알림 (YouTube)**을 클릭하면 샘플 알림을 OBS에 보냅니다. 테스트 알림은 기록에 추가되지 않습니다.

새 팔로워 알림이 꺼져 있으면 테스트가 재생되지 않고 페이지에 **먼저 빠른 전환에서 새 팔로워 알림을 켜세요**가 표시됩니다.

## 외관 탭

### 미리보기

미리보기는 OBS 소스와 같은 페이지를 사용합니다. **미리보기** 옆의 색상 선택기로 미리보기 배경을 바꿀 수 있으며, **▶ 애니메이션 다시 재생**을 클릭하면 알림 애니메이션을 다시 재생합니다.

### 통일 스타일 / 플랫폼별 개별

- **통일 스타일**: Twitch와 YouTube가 같은 알림 스타일을 사용합니다.
- **플랫폼별 개별**: 플랫폼마다 각자의 스타일을 사용합니다. 아래 버튼으로 **Twitch** 또는 **YouTube**를 선택하고 설정을 편집합니다. 처음 전환하면 아직 사용자 정의하지 않은 플랫폼은 현재 통일 스타일을 복사하며, 카운트다운 바 색상은 플랫폼마다 따로 갖습니다.

**기본값 복원**을 누르면 편집 중인 스타일이 기본 스타일로 돌아갑니다.

### 이미지

- **이미지 선택**: 소재 관리에서 이미지를 선택합니다. 이미지가 없으면 하트 이모지가 표시됩니다. **지우기**를 누르면 이미지가 제거됩니다.
- **이미지 크기**: 1–400 px.
- **이미지 위치**: **왼쪽**, **오른쪽**, **위쪽**, **아래쪽**.

### 사운드

기본 제공 사운드를 선택합니다: **없음**, **차임벨**(기본값), **코인**, **종소리**, **팝**, **팡파르**. **▶**를 클릭하면 들어볼 수 있습니다. **사운드 선택**을 클릭하면 소재 관리에서 직접 준비한 사운드 파일을 사용할 수 있습니다.

### 사용자 정의 텍스트

알림에 표시할 문구를 작성합니다. 팔로워 이름은 `{name}`, 플랫폼 이름은 `{platform}`을 사용합니다. 비워 두면 기본 문구 `{name}님, 팔로우 감사합니다!`를 사용합니다.

### 텍스트와 색상

- **텍스트**: **사용자 정의 텍스트**와 **팔로워 이름**의 글꼴, 크기, 색상을 설정합니다.
- **색상**: **배경**, **그림자**, **카운트다운 바**.

### 사용자 정의 CSS

**사용자 정의 CSS**를 펼치면 편집 중인 스타일(통일 스타일 또는 선택한 플랫폼)의 CSS를 편집할 수 있습니다. **기본값 복원**을 누르면 템플릿 CSS로 돌아가고, **소재 관리**를 누르면 소재 관리가 열립니다. 여기서 Steam Workshop 테마도 적용할 수 있습니다. 테마가 적용된 동안에는 CSS가 읽기 전용입니다. [테마 스타일](./themes)을 참고하세요.

## 기록 탭

두 플랫폼의 최근 새 팔로워를 최신순으로 표시합니다(플랫폼, 이름, 시간). 기록은 App에만 표시되며 오버레이에는 표시되지 않습니다.

- 최대 100명까지 보관하며, 30일이 지난 항목은 자동으로 삭제됩니다.
- **지우기**를 클릭하면 목록을 비웁니다.

:::info 체험판
사용자 정의 CSS는 정식판에서만 사용할 수 있으며, OBS의 알림에 워터마크가 표시됩니다. [체험판 / 정식판 비교](../getting-started/trial-comparison)를 참고하세요.
:::

## 자주 묻는 질문

**Q: 방송에서 소리가 나지 않나요?**
브라우저 소스 속성에서 **OBS를 통해 오디오 제어**가 체크되어 있는지, OBS 믹서에서 해당 소스가 음소거되어 있지 않은지 확인하세요. 또한 **사운드**가 **없음**으로 설정되어 있지 않은지 확인하세요.

**Q: YouTube 구독자에게 알림이 표시되지 않았나요?**
공개 구독만 보고되며, YouTube가 보고하기까지 몇 분에서 몇 시간이 걸릴 수 있습니다. 또한 App은 방송 중이고 YouTube 라이브 채팅이 연결되어 있을 때만 확인합니다.

**Q: OBS 소스를 늦게 추가했는데, 이전 알림이 다시 재생되나요?**
아니요. 새로 열린 소스는 연결된 이후에 도착한 알림만 표시합니다. 이전 팔로워는 **기록** 탭에서 볼 수 있습니다.
