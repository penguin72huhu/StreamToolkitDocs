# 이모트 월

시청자가 채팅에서 이모트를 사용하면 이모트가 방송 화면 위로 떠다닙니다.

:::note 시작하기 전에
이모트 월은 채팅에서 이모트를 읽어 오므로, 먼저 사용하는 플랫폼을 연결하세요. [Twitch 설정](../platforms/twitch)과 [YouTube 설정](../platforms/youtube-settings)을 참고하세요.
:::

## 1단계: OBS 소스 추가

페이지 상단의 **OBS 소스 주소**를 복사합니다:

```
http://127.0.0.1:7272/emote-wall
```

OBS에 브라우저 소스로 추가합니다. [OBS에서 소스 추가하는 방법](../getting-started/obs-source)을 참고하세요. 이모트 월은 소리가 없으므로 "OBS를 통해 오디오 제어"를 켤 필요가 없습니다.

:::tip
왼쪽 사이드바에서 **이모트 월** 옆의 스위치(**OBS 표시 켜기**)도 켜세요. 스위치가 꺼져 있으면 채팅의 이모트가 오버레이로 전송되지 않습니다.
:::

## 2단계: 소스 선택

**소스** 아래에 **Twitch** 카드와 **YouTube** 카드가 있습니다. 각 카드에 연결 상태가 표시됩니다:

- Twitch 계정이 연결되어 있지 않으면 Twitch에 **(연결 안 됨)**이 표시됩니다
- YouTube 채팅이 연결되어 있지 않으면 YouTube에 **채팅방 주소가 연결되지 않음**이 표시됩니다

카드에서 **이모티콘 벽 사용**을 체크하면 해당 플랫폼 채팅의 이모트가 표시됩니다. 체크를 해제하면 해당 플랫폼을 무시합니다.

## 3단계: 애니메이션 설정

| 설정 | 설명 |
|---------|-------------|
| **이모티콘 크기** | 각 이모트의 크기, 16–256 px |
| **메시지당 최대 emote 수** | 채팅 메시지 하나에서 가져오는 이모트의 최대 개수(1–20) |
| **떠다니는 지속 시간** | 각 이모트가 떠다니는 시간, 1–30초 |
| **떠다니는 속도** | 50–500 px/s |

섹션 제목 옆의 **기본값 복원**을 클릭하면 네 가지 값이 모두 복원됩니다.

## 4단계: 테스트

**테스트 (OBS에 표시)**를 클릭하면 현재 설정으로 샘플 Twitch 이모트를 오버레이에 보냅니다. 테스트 이모트 개수는 **메시지당 최대 emote 수**를 따릅니다.
