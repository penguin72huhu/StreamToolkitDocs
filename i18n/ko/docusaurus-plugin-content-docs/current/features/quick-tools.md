# 빠른 도구

**빠른 도구**는 게임이나 OBS 옆에 띄워 둘 수 있는 작은 제어 창입니다. 메인 창으로 돌아가지 않고도 기능을 켜고 끄거나 자주 쓰는 조작을 할 수 있습니다.

## 빠른 도구 열기

다음 중 하나를 사용합니다:

- 메인 창 왼쪽 사이드바 상단의 **⚡ 빠른 도구**를 클릭합니다
- Stream Toolkit 트레이 아이콘을 마우스 오른쪽 버튼으로 클릭하고 **빠른 도구 열기**를 선택합니다

창이 이미 열려 있으면 두 번째 창을 열지 않고 기존 창을 앞으로 가져옵니다.

## 창

- **이동**: 제목 표시줄을 드래그합니다
- **📌 고정 / 고정 해제**: 창을 다른 창 위에 항상 표시합니다. 창을 열 때 고정이 켜져 있습니다
- **✕**: 창을 닫습니다

창은 App의 테마와 인터페이스 언어를 따릅니다.

## 빠른 스위치 패널

왼쪽 가장자리의 **›** 화살표를 클릭하면 **빠른 스위치** 패널이 펼쳐집니다. 모든 기능이 나열됩니다:

- 스위치로 기능을 켜거나 끕니다(메인 사이드바의 각 기능 옆 스위치와 동일)
- **⚙**(**설정 열기**)를 누르면 메인 창에서 해당 기능의 설정 페이지가 열립니다

패널 바깥을 클릭하거나 화살표를 다시 클릭하면 닫힙니다.

기능은 메인 사이드바와 같은 순서로 나열됩니다. 순서를 바꾸려면 메인 창 사이드바에서 기능 옆의 **⠿** 핸들을 드래그합니다.

## 기능 카드

조작할 수 있는 항목이 있는 기능은 켜져 있으면 카드로 표시됩니다. 카드는 처음에 접혀 있으며, 카드 제목을 클릭하면 펼치거나 접습니다. 이러한 기능이 하나도 켜져 있지 않으면 창에 **아직 켜진 기능 없음**이 표시됩니다.

| 기능 | 카드에서 할 수 있는 것 |
|---------|---------------------|
| [OBS 장면 제어](./obs-scene) | 연결 상태와, 설정한 장면 전환 또는 소스 표시 전환마다 버튼 하나(현재 장면은 강조 표시). 연결되지 않은 동안에는 버튼이 비활성화됩니다. 단축키 항목이 하나 이상 있을 때만 카드가 표시됩니다 |
| [음성 번역](./voice-translate) | **REC** 버튼 — 누르고 있으면 녹음하고, 손을 떼면 번역합니다 |
| [스트림 하이라이트 마커](./highlight) | **MARK** 버튼. 마커를 추가하면 플랫폼 아이콘과 타임스탬프가 5초 동안 표시됩니다 |
| [후원 바](./donate) | 진행 바와 함께 현재 / 목표 금액, **금액 수동 추가** 입력란과 **추가**, **초기화** |
| [타이머](./timer) | 표시 중인 각 타이머의 이름, 시간, **시작** / **일시정지**, **초기화**, 설정한 시간 추가 버튼. 스톱워치는 대신 **정지**와 **랩**을 표시합니다 |
| [룰렛](./turntable) | 표시 중인 각 룰렛의 **돌리기**와 **초기화** |
| [미디어 보드](./multimedia) | 고정한 이미지(표시 / 숨기기), 고정한 영상(재생), 고정한 사운드(재생) 버튼 |
| [노래 신청](./song-request) | **재생** / **일시정지**, **정지**, **다음 곡** |

조작에 단축키가 지정되어 있으면 버튼에 단축키가 표시됩니다.

여기서 조작할 것이 없는 기능(채팅방, Twitch 목표 바, 후원 알림, 후원 기록판, 시계, 이모트 월, 실시간 투표, 추첨, 채팅 봇)은 빠른 스위치 패널에 켜기/끄기 스위치만 있습니다.

:::tip
후원 바 카드의 **초기화**는 두 번 클릭해야 합니다. 첫 번째 클릭에서 버튼이 **초기화 확인**으로 바뀌고, 10초 안에 다시 클릭하면 금액이 0이 됩니다.
:::

:::info
타이머와 룰렛은 각 기능의 **표시 모드**를 따릅니다. **단일 타이머** / **단일 돌림판**에서는 현재 선택한 것만 표시되고, **다중 타이머** / **다중 돌림판**에서는 추가한 것만 표시됩니다. 하나도 없으면 카드에 **타이머 없음** / **돌림판 없음**이 표시됩니다.
:::
