# 설정

왼쪽 메뉴 하단의 **⚙️ 설정**을 클릭합니다. 이 페이지에는 App 전체 옵션, 플랫폼 연결, 후원 결제 서비스가 있습니다.

## 일반

| 옵션 | 기능 | 기본값 |
|------|------|------|
| **테마** | 인터페이스 표시 모드: **다크 그레이** 또는 **라이트** | 다크 그레이 |
| **언어** | 인터페이스 언어. 즉시 전환됩니다 | — |
| **X를 누르면 작업 표시줄로 최소화** | 창을 닫으면 종료하지 않고 트레이로 최소화합니다 | 켜짐 |
| **후원 통화** | 전역 통화 단위. 후원 바, 알림 및 모든 금액 표시에 사용됩니다 | 처음 실행할 때 시스템 언어에 따라 설정됩니다(예: 번체 중국어(대만) → TWD, 일본어 → JPY, 기타 → USD) |

## 플랫폼 연결

### Twitch

**계정 연결**을 클릭하고 브라우저에서 승인합니다. 연결되면 **@내 이름 연결됨**과 **연결 해제** 버튼이 표시됩니다. 전체 단계: [Twitch 설정](../platforms/twitch).

연결 후 **▸ 환산 설정**에서 Bits와 구독이 후원 통화로 얼마에 해당하는지 설정합니다:

- **수익 배분 방식**: **50 / 50** 또는 **70 / 30**
- **100 Bits당**, **Tier 1 구독**, **Tier 2 구독**, **Tier 3 구독**
- **저장**은 현재 통화에 대한 값을 저장하고, **기본값 복원**은 해당 통화의 기본 제공 값을 채웁니다

### YouTube

1. **계정 연결**을 클릭하고 Google로 로그인합니다. 단계별 안내: [YouTube 설정](../platforms/youtube-settings)
2. 연결되면 **연결됨: 채널 이름**이 표시됩니다. **연결 해제**를 누르면 계정 연결이 해제됩니다
3. 라이브 채팅을 찾는 방법을 선택합니다:
   - **현재 방송 자동 감지**: Google 로그인이 필요합니다. **연결**을 클릭하면 채널에서 현재 또는 예정된 방송을 찾습니다. 여러 개가 있으면 목록에서 하나를 선택합니다
   - **수동으로 URL 지정**: **채팅방 주소**를 붙여넣습니다
4. **프로그램을 켤 때마다 채팅방 주소 입력을 안내**: 선택 사항

YouTube 아래의 **▸ 환산 설정**에서 멤버십이 얼마에 해당하는지 설정합니다(YouTube는 멤버십 금액을 보내지 않습니다):

- **멤버십 등급 설정**: 등급 이름과 값을 추가합니다. 등급 이름은 YouTube 채널의 것과 정확히 같아야 합니다
- **목록에 없는 등급**: 표에 없는 등급에 사용할 값
- **선물 멤버십 등급**: 선물 멤버십을 어느 등급으로 계산할지
- 이벤트에서 확인되었지만 표에 없는 등급은 **표에 추가** / **무시**와 함께 표시됩니다

## 후원 플랫폼 연동

결제 서비스를 클릭하면 펼쳐집니다. 각 서비스에는 설정 안내로 연결되는 **여기서 튜토리얼 보기** 링크가 있습니다:

- [PayPal](../payments/paypal)
- [Stripe](../payments/stripe)
- [O'Pay](../payments/opay)
- [ECPay](../payments/ecpay)

### 알림 테스트

제목 옆의 **알림 테스트** 버튼을 누르면 테스트 창이 열립니다:

- **테스트 이름**, **테스트 메시지**, **테스트 금액**을 입력하고 **테스트 플랫폼**을 선택한 후 **테스트 알림 보내기**를 클릭합니다
- **YouTube Super Chat 테스트**: `$5.00` 또는 `NT$150` 같은 **금액 문자열**을 입력하고 **테스트 Super Chat 보내기**를 클릭하면 금액 파싱과 통화 환산을 테스트할 수 있습니다

## 정보

왼쪽 메뉴 상단의 "Stream Toolkit" 옆에 있는 **i** 버튼을 클릭하면 버전, 제작자, 공식 문서 링크를 볼 수 있습니다.
