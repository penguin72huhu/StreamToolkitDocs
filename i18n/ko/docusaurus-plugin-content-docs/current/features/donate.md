# 후원 바

방송 화면에 후원 목표를 향한 진행 바를 표시합니다. 선택한 플랫폼의 후원이 자동으로 합계에 더해집니다.

## OBS 소스 URL

```
http://127.0.0.1:7272/donate
```

**후원 바 설정** 페이지 상단에서 URL을 복사하여 OBS에 브라우저 소스로 추가합니다. [OBS에서 소스 추가하는 방법](../getting-started/obs-source)을 참고하세요.

왼쪽 사이드바에서 **후원 바** 옆의 스위치로 OBS에서 바를 표시하거나 숨깁니다. 끄면 바가 숨겨집니다.

## 통화

바는 **설정** 페이지에서 지정한 **후원 통화**를 사용합니다. 다른 통화의 후원은 이 통화로 환산한 후 더해집니다. 후원 통화를 환산할 수 없으면 바에 더해지지 않습니다(후원 알림과 후원 기록판에는 원래 통화로 표시됩니다).

## 설정 탭

### 연동 플랫폼

바에 계산할 후원의 플랫폼을 체크합니다:

- **Twitch** — Bits와 구독
- **YouTube**
- **PayPal**
- **Stripe**
- **O'Pay**
- **ECPay**

초록색 점은 플랫폼이 연결되었다는 뜻이며, 그렇지 않으면 **(연결 안 됨)**이 표시됩니다. 이 체크박스는 바에 계산할 항목만 결정합니다. 각자 플랫폼 목록을 가진 후원 알림이나 후원 기록판에는 영향을 주지 않습니다.

- **YouTube**: 라이브 채팅이 연결되어 있지 않으면 **채팅방 주소가 연결되지 않음**과 함께 두 개의 버튼, **자동 연결**(Google 로그인 필요)과 **직접 입력**(설정의 채팅 URL 필드로 이동)이 표시됩니다. [YouTube 설정](../platforms/youtube-settings)을 참고하세요.
- **YouTube ⚙️**: 바에 더할 **집계 항목**을 선택합니다: **슈퍼챗**, **슈퍼 스티커**, **신규 멤버**, **멤버십 갱신**, **멤버십 선물**, **주얼**. **주얼**은 Google 로그인이 필요합니다.
- 멤버십 이벤트를 하나라도 체크했지만 멤버십 가격이 설정되어 있지 않으면 **⚠ 멤버십 가격 미설정**이 표시됩니다. 클릭하면 설정으로 이동하며, YouTube **환산 설정**에서 등급별 가격을 입력합니다.
- Twitch Bits와 구독의 금액은 설정 → Twitch → **환산 설정**에서 지정합니다. [Twitch 설정](../platforms/twitch)을 참고하세요.
- PayPal, Stripe, O'Pay, ECPay 연결 방법은 [PayPal](../payments/paypal), [Stripe](../payments/stripe), [O'Pay](../payments/opay), [ECPay](../payments/ecpay)를 참고하세요.

### 현재 진행도

현재 합계, 목표, 백분율을 표시합니다.

| 항목 | 설명 |
|-------|-------------|
| **제목** | 선택 사항. 바 위에 표시됩니다. |
| **목표 금액** | 후원 통화 기준의 목표 금액입니다. |
| **수동 추가** | 금액을 입력하고 **추가**를 클릭하면(또는 Enter) 합계에 더해집니다. |
| **초기화** | 현재 합계를 0으로 되돌립니다. 먼저 확인 창이 표시됩니다. 되돌릴 수 없습니다. |

## 외관 탭

### 미리보기

미리보기는 샘플 금액으로 바를 표시합니다. **미리보기** 옆의 색상 선택기로 미리보기 배경을 바꿀 수 있습니다. **달성 미리보기**를 체크하면 목표를 달성한 상태의 바를 볼 수 있습니다.

### 글꼴과 색상

**기본값 복원**을 클릭하면 기본 외관으로 돌아갑니다.

- **글꼴**: **제목**, **금액**, **% 숫자**의 글꼴, 색상, 크기(8–72 px)를 설정합니다.
- **색상**: **배경**, **목표 바**(채움 색상), **목표 바 달성**(목표 달성 후 채움 색상)을 설정합니다.

### 사용자 정의 CSS

**사용자 정의 CSS**를 펼치면 바의 CSS를 편집할 수 있습니다. **기본값 복원**을 누르면 기본 CSS로 돌아가고, **소재 관리**를 누르면 CSS에서 사용할 이미지를 관리하는 소재 관리가 열립니다. 여기서 Steam Workshop 테마도 적용할 수 있습니다. 테마가 적용된 동안에는 복원하기 전까지 CSS가 읽기 전용입니다. [테마 스타일](./themes)을 참고하세요.

:::info 체험판
사용자 정의 CSS는 정식판에서만 사용할 수 있습니다. 실제 결제 서비스(PayPal / Stripe / O'Pay / ECPay)와 YouTube 멤버십 이벤트, 주얼은 체험판에서 사용할 수 없으며, 오버레이에 워터마크가 표시됩니다. [체험판 / 정식판 비교](../getting-started/trial-comparison)를 참고하세요.
:::

## 자주 묻는 질문

**Q: 테스트 알림을 보냈더니 합계가 올라갔나요?**
설정 페이지의 **알림 테스트**는 실제 후원으로 계산되므로 (해당 플랫폼이 체크되어 있으면) 바에 더해집니다. 테스트 후 **초기화**를 클릭해 합계를 0으로 되돌리세요.
