# 미디어 보드

클릭 한 번이나 단축키로 방송 화면에 이미지를 표시하고, 영상과 효과음을 재생합니다.

페이지에는 **이미지**, **영상**, **사운드** 세 개의 탭이 있습니다. 탭마다 OBS 소스 URL이 따로 있습니다.

| 탭 | OBS 소스 URL | OBS를 통해 오디오 제어 |
|-----|----------------|-----------------------|
| **이미지** | `http://127.0.0.1:7272/imageboard` | 필요 없음 |
| **영상** | `http://127.0.0.1:7272/videoboard` | 필요 |
| **사운드** | `http://127.0.0.1:7272/soundboard` | 필요 |

각 URL 옆의 **복사**를 클릭하고 OBS에 브라우저 소스로 추가합니다. [OBS에서 소스 추가하는 방법](../getting-started/obs-source)을 참고하세요. 영상과 사운드는 Stream Toolkit 안이 아니라 OBS 소스에서 재생되므로, 이 두 소스는 반드시 **OBS를 통해 오디오 제어**를 켜야 합니다. 그렇지 않으면 시청자에게 소리가 들리지 않습니다.

:::tip
왼쪽 사이드바에서 **미디어 보드** 옆의 스위치(**OBS 표시 켜기**)를 켜세요. 스위치가 꺼져 있으면 버튼이나 단축키 어느 쪽을 사용해도 이미지가 표시되지 않고 영상과 사운드가 재생되지 않습니다.
:::

## 공통 조작

이미지, 영상, 사운드는 모두 카드로 표시됩니다:

- 카드를 클릭하면 설정을 펼치거나 접습니다
- 카드 오른쪽의 체크박스: 체크하면 해당 항목이 [빠른 도구](./quick-tools)의 실행 도구에 표시됩니다. 새 항목은 기본적으로 체크되어 있습니다
- **✕**를 누르면 항목이 삭제됩니다
- 로컬 파일이 이동되거나 삭제되면 카드에 **파일을 찾을 수 없음**이 표시됩니다

### 단축키

항목마다 단축키를 설정할 수 있습니다:

1. 카드를 펼치고 단축키 버튼을 클릭합니다
2. 원하는 키 조합을 누른 후 손을 뗍니다. **Esc**를 누르면 취소됩니다
3. 단축키를 제거하려면 **지우기**를 클릭합니다

키 조합이 이미 다른 기능에서 사용 중이면 저장되지 않고 버튼에 충돌 메시지가 표시됩니다. 단축키는 Stream Toolkit이 활성 창이 아닐 때도 동작합니다. 모든 단축키는 [단축키](./hotkeys) 페이지에도 표시됩니다.

## 이미지

### 이미지 추가

1. **이미지 추가**를 클릭합니다
2. 파일(jpg, jpeg, png, gif)을 선택합니다. 파일 이름이 이미지 이름이 됩니다

카드를 펼치면 미리보기 이미지와 다음 설정이 표시됩니다:

- **이름**: 이미지 이름
- **파일 경로**: **다시 선택**을 클릭하면 다른 파일을 선택할 수 있습니다
- **단축키**: 한 번 누르면 이미지를 표시하고, 다시 누르면 숨깁니다
- **위치·크기 설정**: 아래를 참고하세요
- **이미지 삭제**: 이미지를 삭제합니다

### 표시와 숨기기

카드의 **○** 버튼을 클릭하면 OBS에 이미지가 표시되고 버튼이 **◉**로 바뀝니다. 다시 클릭하면 이미지가 숨겨집니다.

### 표시 설정

**여러 이미지 동시 표시 허용**은 기본적으로 꺼져 있습니다. 꺼져 있으면 이미지를 표시할 때 현재 표시 중인 이미지가 숨겨집니다. 켜면 여러 이미지를 동시에 표시할 수 있습니다.

### 위치·크기 설정

- **X 위치** / **Y 위치**: 단위는 px입니다. 0/0은 소스의 정중앙입니다. 양수는 오른쪽/아래, 음수는 왼쪽/위로 이동합니다
- **너비** / **높이**: 원본 크기 대비 %입니다. 100 = 원본 크기. 🔗 버튼은 가로세로 비율을 고정합니다(기본적으로 켜짐). 클릭하면 자유롭게 크기를 조절할 수 있습니다
- 이미지가 표시된 상태에서는 변경 사항이 OBS에 실시간으로 미리 표시됩니다
- **저장**은 변경 사항을 유지하고, **재설정**은 창을 열었을 때의 값으로 되돌리며, **취소**는 저장하지 않고 닫습니다

## 영상

{/* TODO: 截圖 — 影片分頁 */}

**영상 추가**를 클릭해 카드를 추가한 후 펼칩니다:

- **영상 이름**: 카드에 표시되는 이름
- **소스**: **YouTube** 또는 **로컬**
  - **YouTube**: **YouTube 주소**에 영상 링크를 붙여넣습니다. **분석 테스트**를 클릭해 확인합니다. 성공하면 "분석됨, 재생 시 자동으로 적용"이 표시됩니다
  - **로컬**: **파일 선택**을 클릭해 mp4, webm, ogg 파일을 선택합니다. 크기 제한은 200MB이며, 파일이 클수록 지연이 커집니다. 투명 배경을 사용하려면 WebM(VP9 Alpha) 영상을 사용하세요
- **순차 재생**: 영상을 반복 재생합니다
- **재생 시간**: **시작**과 **종료**(시, 분, 초, 밀리초)를 설정합니다. **종료**를 00:00으로 두면 끝까지 재생합니다
- **음량**: 0–100%
- **단축키**: 누르면 영상을 재생합니다. 영상이 재생 중일 때 다시 누르면 정지합니다
- **위치·크기 설정**: 이미지와 같은 위치·크기 항목입니다. **미리보기 반복**을 클릭하면 조절하는 동안 OBS에서 영상을 반복 재생하고, **미리보기 정지**를 누르면 멈춥니다. 다 되면 **저장** 또는 **취소**를 클릭합니다

카드의 **▶**를 클릭하면 OBS에서 영상을 재생합니다. **■**를 클릭하면 정지합니다.

## 사운드

{/* TODO: 截圖 — 音效分頁 */}

**사운드 추가**를 클릭해 카드를 추가한 후 펼칩니다:

- **사운드 이름**: 카드에 표시되는 이름
- **소스**: **YouTube 주소** 또는 **로컬 파일**
  - **YouTube 주소**: 링크를 붙여넣고 **분석 테스트**를 클릭해 확인합니다
  - **로컬 파일**: **파일 선택**을 클릭해 mp3, wav, ogg, flac, m4a, aac, opus 파일을 선택합니다
- **재생 시간**: **시작**과 **종료**를 설정합니다. **종료**를 00:00으로 두면 끝까지 재생합니다
- **음량**: 0–100%
- **단축키**: 누르면 사운드를 재생합니다

카드의 **▶**를 클릭하면 OBS에서 사운드를 재생합니다. **■**를 클릭하면 정지합니다. 사운드는 한 번에 하나만 재생됩니다. 다른 사운드를 재생하면 현재 사운드가 멈춥니다.

:::info 체험판 제한
- 이미지 **1**개, 영상 **1**개, 사운드 **1**개만 추가할 수 있습니다
- 이미지와 영상 오버레이에 워터마크가 표시됩니다

자세한 내용은 [체험판 / 정식판 비교](../getting-started/trial-comparison)를 참고하세요.
:::

## 자주 묻는 질문

**Q: 영상이나 사운드가 재생되는데 방송에서 소리가 나지 않나요?**
`/videoboard`와 `/soundboard` 소스에 **OBS를 통해 오디오 제어**가 체크되어 있는지, OBS 믹서에서 해당 소스가 음소거되어 있지 않은지 확인하세요.

**Q: 영상 파일을 선택할 수 없나요?**
mp4, webm, ogg 파일만 선택할 수 있으며 최대 200MB입니다. 파일이 더 크면 제한을 알리는 메시지가 표시되고 파일이 추가되지 않습니다.
