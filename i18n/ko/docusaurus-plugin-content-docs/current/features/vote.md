# 실시간 투표

방송에서 투표를 진행합니다. 시청자는 Twitch 또는 YouTube 채팅에 항목 번호를 입력해 투표하며, 결과는 OBS 오버레이에 실시간으로 업데이트됩니다.

## OBS 소스 URL

```
http://127.0.0.1:7272/vote
```

페이지 상단의 **OBS 소스 주소** 옆에 있는 **복사**를 클릭한 후 OBS에 브라우저 소스로 추가합니다. [OBS에서 소스 추가하는 방법](../getting-started/obs-source)을 참고하세요. 실시간 투표는 소리가 없으므로 "OBS를 통해 오디오 제어"를 켤 필요가 없습니다.

:::tip
왼쪽 사이드바에서 **실시간 투표** 옆의 스위치(**OBS 표시 켜기**)도 켜세요. 스위치가 꺼져 있으면 오버레이가 숨겨진 상태로 유지됩니다.
:::

페이지에는 **설정**, **외관**, **기록** 세 개의 탭이 있습니다.

## 투표 시작 (설정 탭)

### 투표 플랫폼

**Twitch** 또는 **YouTube**를 클릭해 어느 플랫폼의 채팅으로 투표할지 선택합니다. 둘 다 선택할 수도 있습니다. 연결되지 않은 플랫폼에는 **(연결 안 됨)**(Twitch) 또는 **채팅방 주소가 연결되지 않음**(YouTube)이 표시됩니다. 먼저 연결하세요:

- [Twitch 설정](../platforms/twitch)
- [YouTube 설정](../platforms/youtube-settings)

### 투표 제목

선택 사항입니다. 예: "오늘 밤 어떤 게임 할까요?"

### 투표 항목 (2–10개)

- 항목을 2개 이상 입력합니다. 최대 10개까지 만들 수 있습니다
- **+ 항목 추가**는 행을 추가하고, **×**는 행을 삭제합니다
- **기록 적용**을 누르면 최근 15개의 투표 중 하나를 선택해 제목과 항목을 채울 수 있습니다

편집하는 동안 OBS 오버레이에 제목과 항목이 미리 표시됩니다.

### 투표 시간

투표 길이(초)입니다. 기본값은 60이며 최솟값은 10입니다.

### 시작 / 중지

- **투표 시작**: 입력된 항목이 2개 이상이고, 연결된 플랫폼이 하나 이상 선택되어 있어야 합니다
- **투표 중지**: 투표를 일찍 종료합니다. 그렇지 않으면 시간이 다 되면 종료됩니다

투표가 진행되는 동안에는 플랫폼, 제목, 항목, 시간을 변경할 수 없습니다.

## 시청자 투표 방법

투표가 진행되는 동안 오버레이에 "채팅방에 항목 번호를 입력하면 투표할 수 있습니다 (예: 1)"가 표시됩니다.

- 메시지 전체가 `1` 또는 `1.`처럼 항목 번호여야 합니다. 공백은 무시됩니다. 다른 텍스트가 포함된 메시지는 계산되지 않습니다
- 시청자마다 한 표씩 투표할 수 있습니다. 다른 번호를 보내면 표가 새 항목으로 옮겨지며, 시간이 끝나기 전의 마지막 표가 계산됩니다

## 실시간 결과

투표 중에는 설정 아래에 **실시간 결과**가 나타나며 남은 시간, 항목별 득표 수와 백분율, 총 투표 수가 표시됩니다. 투표가 끝나면 **최종 결과**로 바뀝니다. **상세**를 클릭하면 Twitch와 YouTube별로 각 항목에 투표한 사람을 볼 수 있습니다.

## 외관

**외관** 탭 상단에 **미리보기**가 있습니다. 옆의 색상 선택기는 OBS 오버레이가 아니라 미리보기 배경만 바꿉니다.

- **글꼴**: **제목**, **안내**, **항목**, **카운트다운 초**, **득표 수**의 글꼴, 색상, **크기**(px)를 설정합니다
- **진행 바 색상**: 최대 5가지 색상을 항목 바에 순서대로 사용합니다. 각각 **단색** 또는 **그라데이션**으로 설정할 수 있으며, 그라데이션에는 **각도**도 있습니다
- **배경 색상**: 투표 카드의 배경
- **기본값 복원**: 기본 외관으로 되돌립니다. 테마가 적용되어 있으면 테마의 외관으로 되돌립니다

**사용자 정의 CSS**에서 직접 스타일을 작성할 수 있습니다. 외관을 공유하거나 다운로드하려면 [테마 스타일](./themes)을 참고하세요.

## 기록

**기록** 탭에는 각 투표의 제목, 시간, 항목 수, 총 투표 수가 나열됩니다. 투표를 펼치면 결과, 플랫폼별 득표 수, **상세**를 볼 수 있습니다. 최근 30일간의 투표 기록만 보관합니다. 기록을 삭제하려면 🗑을 클릭한 후 **삭제 확인**을 클릭합니다.

:::info 체험판 제한
- **사용자 정의 CSS**는 정식판에서만 사용할 수 있습니다
- OBS 오버레이에 워터마크가 표시됩니다

자세한 내용은 [체험판 / 정식판 비교](../getting-started/trial-comparison)를 참고하세요.
:::
