# 시계

방송 화면에 현재 시간을 표시하며, 날짜와 요일도 함께 표시할 수 있습니다.

## 1단계: OBS 소스 추가

페이지 상단의 **OBS 소스 주소**를 복사합니다:

```
http://127.0.0.1:7272/clock
```

OBS에 브라우저 소스로 추가합니다. [OBS에서 소스 추가하는 방법](../getting-started/obs-source)을 참고하세요. 시계는 소리가 없으므로 "OBS를 통해 오디오 제어"를 켤 필요가 없습니다.

:::tip
왼쪽 사이드바에서 **시계** 옆의 스위치(**OBS 표시 켜기**)도 켜세요. 스위치가 꺼져 있으면 OBS에서 시계가 숨겨집니다.
:::

## 미리보기

상단의 **미리보기**는 실제 OBS 오버레이를 보여 주며, 설정을 바꾸면 바로 업데이트됩니다. 옆의 색상 상자로 미리보기 배경을 바꿀 수 있습니다.

## 외관

| 설정 | 설명 |
|---------|-------------|
| **글꼴** | 시계의 모든 텍스트에 사용할 글꼴 |
| **스타일** | 시간, 날짜, 요일의 배치 방식: **Stack**, **Horizontal**, **One-Top-Two-Bottom**, **Two-Top-One-Bottom**. **줄 간격**은 **Horizontal**을 제외한 모든 배치에서, **항목 간격**은 **Stack**을 제외한 모든 배치에서 사용할 수 있습니다(둘 다 −200 ~ 200 px) |
| **순서** | **시간**, **날짜**, **요일** 블록을 드래그해 순서를 바꿉니다 |
| **텍스트** | **시간**, **날짜**, **요일**을 각각 설정합니다: **글자 크기**, 색상(**단색** 또는 두 가지 색상과 **각도**를 사용하는 **그라데이션**), **테두리** 색상, **투명도**, **두께**(0–7 px) |
| **그림자** | 그림자 색상, **투명도**, **흐림**, **X** / **Y** 오프셋. 모든 텍스트에 공통으로 적용됩니다 |

**기본값 복원** 버튼은 탭 상단에 있습니다.

### 사용자 정의 CSS

**사용자 정의 CSS**를 클릭하면 편집기가 펼쳐집니다. 기본 CSS에는 시계 각 부분(시간, 날짜, 요일과 그 컨테이너)의 선택자가 주석과 함께 나열되어 있습니다. 배치와 구조에 사용하세요. 색상, 글꼴, 크기는 위의 외관 설정에서 설정합니다.

- **기본값 복원**: 기본 CSS로 되돌립니다
- **소재 관리**: CSS에서 사용할 이미지를 관리하는 소재 관리를 엽니다

CSS에서 `!important`로 속성을 덮어쓰면 어차피 CSS가 우선하므로 해당 외관 설정 항목이 잠깁니다.

## 시계 형식

- **시간 표기**: **24시간** 또는 두 가지 12시간 옵션 중 하나입니다. **12시간 (오전/오후)**는 중국어 표기 上午 / 下午를, **12시간 (AM/PM)**은 AM/PM을 표시합니다
- **시간대**: UTC−12 ~ UTC+14. 기본값은 컴퓨터의 시간대입니다

## 표시 설정

- **초 표시**
- **날짜 표시**: 켜면 드롭다운에서 날짜 형식을 선택합니다. **연도 없음**으로 표시된 형식은 연도를 생략합니다
  - **날짜 0 채우기**: 한 자리 월과 일 앞에 0을 붙입니다(예: 2026/05/20)
  - **연도 형식**: 연도로 시작하는 형식에서 표시됩니다. **전체 (2026)** 또는 **축약 (26)**

  이 두 옵션은 숫자 형식(`/` 또는 `-` 사용)에만 적용됩니다. 글자로 쓰는 형식(예: "2026년 5월 20일")은 App의 인터페이스 언어를 따릅니다
- **요일 표시**: 켜면 요일 표기 방식을 선택합니다(예: **수요일**, **Wednesday**, **WED**, **Wed**)

:::info 체험판 제한
**사용자 정의 CSS**는 정식판에서만 사용할 수 있습니다. 자세한 내용은 [체험판 / 정식판 비교](../getting-started/trial-comparison)를 참고하세요.
:::
