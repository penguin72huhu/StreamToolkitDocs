# 후원 기록판

방송 화면에 최근 후원 목록(플랫폼 아이콘, 후원자 이름, 금액, 메시지)을 표시합니다.

## OBS 소스 URL

```
http://127.0.0.1:7272/sponsors
```

**후원 기록판 설정** 페이지 상단에서 URL을 복사하여 OBS에 브라우저 소스로 추가합니다. [OBS에서 소스 추가하는 방법](../getting-started/obs-source)을 참고하세요.

왼쪽 사이드바에서 **후원 기록판** 옆의 스위치로 OBS에서 기록판을 표시하거나 숨깁니다. 끄면 기록판이 서서히 사라집니다. 꺼져 있어도 후원은 계속 기록됩니다.

## 설정 탭

### 연동 플랫폼

후원을 기록할 플랫폼을 체크합니다: **Twitch**, **YouTube**, **PayPal**, **Stripe**, **O'Pay**, **ECPay**. 초록색 점은 플랫폼이 연결되었다는 뜻이며, 그렇지 않으면 **(연결 안 됨)**이 표시됩니다. 이 체크박스는 기록판에만 적용되며, 후원 바나 후원 알림에는 영향을 주지 않습니다.

**Twitch ⚙️** (Twitch가 연결되어 있고 체크되어 있을 때 표시):

1. **Bits와 구독 계산**, **Bits만 계산**, **구독만 계산** 중에서 선택합니다
2. **재구독 계산**: 재구독을 기록할지 여부(구독을 계산할 때 표시)
3. **미만 [N] Bits는 계산에 포함하지 않음**: 체크하고 최솟값을 입력하면 그보다 적은 응원은 기록되지 않습니다(Bits를 계산할 때 표시)
4. **저장**을 클릭합니다

**YouTube ⚙️**:

- **@핸들 대신 시청자 이름 표시**: Google로 로그인한 후에만 사용할 수 있습니다.
- **집계 항목**: **슈퍼챗**, **슈퍼 스티커**, **신규 멤버**, **멤버십 갱신**, **멤버십 선물**, **주얼**. **주얼**은 Google 로그인이 필요합니다. 주얼 선물은 금액 대신 주얼 아이콘과 주얼 개수로 표시됩니다.

YouTube 라이브 채팅이 연결되어 있지 않으면 **채팅방 주소가 연결되지 않음**과 함께 **자동 연결**(Google 로그인 필요)과 **직접 입력**(설정의 채팅 URL 필드로 이동)이 표시됩니다. 멤버십 이벤트를 체크했지만 멤버십 가격이 설정되어 있지 않으면 **⚠ 멤버십 가격 미설정**을 클릭해 설정하세요. [YouTube 설정](../platforms/youtube-settings)을 참고하세요.

PayPal, Stripe, O'Pay, ECPay 연결 방법은 [PayPal](../payments/paypal), [Stripe](../payments/stripe), [O'Pay](../payments/opay), [ECPay](../payments/ecpay)를 참고하세요.

### 설정

| 항목 | 설명 |
|-------|-------------|
| **자신의 통화로 자동 환산** | 기본적으로 켜져 있습니다. 설정 페이지에서 지정한 **후원 통화**로 환산한 금액을 표시합니다. |
| **최대 표시** | 보관할 기록 수(1–100). 기본값: 20. 이 수를 넘어 새 후원이 들어오면 가장 오래된 기록이 삭제됩니다. |

## 외관 탭

### 미리보기

**미리보기** 옆의 색상 선택기로 미리보기 배경을 바꿀 수 있습니다. **추가 애니메이션 테스트**를 클릭하면 샘플 기록으로 등장 애니메이션을 재생합니다. 샘플은 기록에 저장되지 않습니다.

**기본값 복원**을 클릭하면 기본 외관으로 돌아갑니다.

### 표시 설정

- **플랫폼 icon 표시**: 각 기록에 플랫폼 아이콘을 표시합니다.
- **등장 방향**: **위에서 아래로**(기본값), **아래에서 위로**, **왼쪽에서 오른쪽으로**, **오른쪽에서 왼쪽으로**.

### 글꼴

**제목**(후원자 이름), **본문**(메시지), **금액**의 글꼴, 색상, 크기(8–72 px)를 설정합니다.

### 배경 색상

- **기본값**: 모든 기록의 배경 색상입니다.
- **+ 범위 추가**: **금액** 범위(**최저** ~ **최고**)와 색상을 추가합니다. 금액이 범위에 들어가는 기록은 해당 색상을 사용합니다. 최저나 최고를 비워 두면 그쪽은 제한이 없습니다. **✕**를 클릭하면 범위가 제거됩니다.

**자신의 통화로 자동 환산**이 켜져 있으면 환산된 금액으로 범위를 비교합니다.

### 사용자 정의 CSS

**사용자 정의 CSS**를 펼치면 기록판의 CSS를 편집할 수 있습니다. **기본값 복원**을 누르면 기본 CSS로 돌아가고, **소재 관리**를 누르면 소재 관리가 열립니다. 여기서 Steam Workshop 테마도 적용할 수 있습니다. 테마가 적용된 동안에는 CSS가 읽기 전용입니다. [테마 스타일](./themes)을 참고하세요.

## 기록 탭

### 수동 추가 (테스트용)

플랫폼을 선택하고 **이름**, **금액**, 그리고 선택 사항인 **메시지 (선택)**를 입력한 후 **추가**를 클릭합니다. 해당 플랫폼이 **연동 플랫폼**에서 체크되어 있을 때만 기록이 추가됩니다. 금액은 후원 통화로 처리됩니다.

### 기록

저장된 기록을 기록 수와 함께 표시합니다.

- **🗑**을 클릭한 후 **삭제 확인**을 클릭하면 기록 하나가 삭제됩니다.
- **비우기**를 클릭하면 모든 기록이 삭제됩니다. 먼저 확인 창이 표시됩니다. 되돌릴 수 없습니다.

:::info 체험판
사용자 정의 CSS는 정식판에서만 사용할 수 있습니다. 실제 결제 서비스(PayPal / Stripe / O'Pay / ECPay)와 YouTube 멤버십 이벤트, 주얼은 체험판에서 사용할 수 없으며, OBS의 기록판에 워터마크가 표시됩니다. [체험판 / 정식판 비교](../getting-started/trial-comparison)를 참고하세요.
:::

## 자주 묻는 질문

**Q: 테스트 알림이 기록판에 표시되나요?**
설정 페이지의 **알림 테스트**는 실제 후원과 똑같이 처리되므로, 해당 플랫폼이 체크되어 있으면 여기에도 기록됩니다. **기록** 탭에서 삭제하세요.
