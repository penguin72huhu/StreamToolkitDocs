# 设置

点击左侧菜单底部的 **⚙️ 设置**。此页面包含 App 全局选项、平台连接与赞助金流。

## 一般

| 选项 | 作用 | 默认 |
|------|------|------|
| **主题** | 界面显示模式：**灰暗** 或 **明亮** | 灰暗 |
| **语言** | 界面语言，切换后立即生效 | — |
| **按 X 时缩小到任务栏** | 关闭窗口时改为最小化到系统托盘，而不是退出 | 开启 |
| **赞助货币** | 全局货币单位，用于赞助条、通知及所有其他金额显示 | 首次启动时依系统语言设置（例如繁体中文（台湾）→ TWD、日语 → JPY、其他 → USD） |

## 平台连接

### Twitch

点击 **连接账号** 并在浏览器中授权。连接后会显示 **已连接 @你的名称** 与 **断开连接** 按钮。完整步骤：[Twitch 设置](../platforms/twitch)。

连接后，**▸ 换算设置** 可设置 Bits 与订阅以你的赞助货币计算的价值：

- **分成机制**：**50 / 50** 或 **70 / 30**
- **每 100 Bits**、**Tier 1 订阅**、**Tier 2 订阅**、**Tier 3 订阅**
- **保存** 会保存当前货币的数值；**恢复默认** 会填入该货币的内置数值

### YouTube

1. 点击 **连接账号** 并登录 Google。详细步骤：[YouTube 设置](../platforms/youtube-settings)
2. 连接后会显示 **已连接：频道名称**。**断开连接** 可解除账号连接
3. 选择查找直播聊天室的方式：
   - **自动检测当前的直播**：需要登录 Google。点击 **连接** 在你的频道中搜索当前或即将开始的直播。若有多场，从列表中选择一场
   - **手动指定网址**：粘贴 **聊天室网址**
4. **每次开启程序时提示输入聊天室网址**：选填

YouTube 下的 **▸ 换算设置** 可设置会员的价值（YouTube 不会提供会员的金额）：

- **会员等级设置**：新增各等级名称与其价值。等级名称必须与你 YouTube 频道上的完全相同
- **未列出的等级**：不在表中的等级所使用的数值
- **赠送会员等级**：赠送会员要算作哪个等级
- 事件中出现但不在表中的等级会列出，并提供 **加入等级表** / **忽略**

### 测试通知

标题旁的 **测试通知** 按钮会打开测试窗口：

- 填写 **测试名称**、**测试留言**、**测试金额**，选择 **测试平台**，再点击 **发送测试通知**
- **YouTube 超级留言测试**：输入 **金额字符串**（例如 `$5.00` 或 `NT$150`），点击 **发送测试超级留言**，测试金额解析与货币换算
