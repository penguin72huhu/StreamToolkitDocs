# 主题样式

通过 Steam Workshop 分享与下载 Overlay 外观。一个主题可以包含以下功能的外观：

- [聊天室](./chat)
- [赞助条](./donate)
- [赞助通知](./donate-alert)
- [新粉丝通知](./fan-alert)
- [粉丝生日通知](./birthday-alert)
- [赞助记录板](./sponsors)
- [投票](./vote)
- [时钟](./clock)
- [Twitch 目标条](./goal)：**追随目标**、**订阅目标**、**小奇点目标**

从左侧菜单底部的 **🎨 主题样式** 打开。页面有两个标签页：**我的主题** 与 **下载的主题**。Steam 必须正在运行。

## 在功能页面查找并应用主题

在上方列出的各功能中，打开其 **自定义 CSS** 区块并点击 **浏览 Steam Workshop 主题**：

1. **探索主题** 列出此功能的 Workshop 主题。在 **搜索主题名称** 中输入后点击 **搜索**，或用 **上一页** / **下一页** 翻页
2. 点击缩略图可查看预览图
3. 点击 **应用**。主题会被订阅、下载并应用到此功能
4. **已订阅** 列出你已为此功能订阅的主题

应用主题期间，页面会显示 **使用中主题：（名称）** 与 **还原** 按钮，自定义 CSS 为只读。点击 **还原** 即可回到你自己的设置。

## 下载的主题

列出你在 Steam 上订阅的所有主题。订阅的主题不会自动应用 — 请使用卡片上的按钮。OBS 会立即更新。

每张卡片显示预览图、名称、有功能使用时显示 **使用中**，以及 **包含：** 主题涵盖的功能（✓ 标示当前正在使用它的功能）。

| 按钮 | 作用 |
|------|------|
| **一键应用** | 将主题应用到它包含的所有功能。若某个功能正在使用其他主题，会请你确认是否替换 |
| **选择应用…** | 选择要应用到哪些功能 |
| **一键还原** | 将所有使用此主题的功能恢复为应用前你自己的设置 |
| **选择还原…** | 选择要还原哪些功能 |
| **取消订阅** | 取消订阅。若主题正在使用中，会先还原那些功能 |

应用后，底部会显示 30 秒的变更消息，并附有可撤销的 **还原** 按钮。

:::note
- 还原会回到你自己的设置，而不是回到被替换掉的主题
- 应用主题期间所做的外观修改，在还原后不会保留
:::

- **下载中…**：请保持 Steam 开启，下载完成后即可应用
- **已移除的主题（#id）**：此主题已不在你的 Steam 订阅中，但仍有功能在使用它。图片可能无法显示，建议还原
- 若 Steam 没有运行，请启动 Steam 后点击 **刷新**

## 我的主题：上传主题

1. 在各功能自己的页面设置好要分享的外观
2. 在 **我的主题** 中点击 **上传新主题**
3. 填写：
   - **主题名称**（必填）
   - **主题说明**
   - **包含的功能**（至少一项）
   - **预览图片**（必填，最大 1MB）：点击 **选择预览图**
4. 勾选确认你拥有主题中每张图片、字体与音效的散布权利。仅限个人或非商业用途授权的素材不得上传
5. 点击 **上传主题**

若看到“请先在浏览器中同意 Steam Workshop 条款”，请同意条款，主题才能公开。

### 管理已上传的主题

每个已上传的主题都有：

- **下载并应用**：将已发布的主题应用到你的功能。这会覆盖你当前的外观设置
- **编辑**：将你当前的外观设置重新上传到同一个主题。若你尚未下载该主题，原本的预览图不会沿用，需要重新选一张
- **在 Steam 管理**：在 Steam 中打开该主题

:::info 试用版限制
主题样式（Steam Workshop）仅限正式版。试用版无法打开 **🎨 主题样式**，也无法应用主题。

请参考 [试用版 / 正式版比较](../getting-started/trial-comparison)。
:::
