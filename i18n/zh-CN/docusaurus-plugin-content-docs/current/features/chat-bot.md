# 聊天机器人

自动在你的聊天室发送消息：按设置的间隔发送定时留言，并在观众输入指令时自动回复关键字。机器人以你自己的账号发送消息。

聊天机器人没有 OBS Overlay，因此不需要添加网址。

:::tip
打开左侧菜单 **聊天机器人** 旁的开关。开关关闭时，机器人不会发送任何消息。
:::

页面有三个标签页：**设置**、**定时留言** 和 **关键字回复**。

## 设置标签页

在 **平台** 下点击 **Twitch** 即可开启（再点一次关闭）。Twitch 已连接时旁边的圆点会亮起，否则显示 **（未连接）**。请先连接 Twitch：[Twitch 设置](../platforms/twitch)。

**YouTube** 显示为 **即将推出**，目前还无法开启。

若没有连接任何平台，另外两个标签页会显示“尚未连接任何平台，机器人不会发送消息。”以及 **前往设置** 按钮。

## 定时留言

直播期间每隔一段时间发送一条消息。

1. 点击 **+ 新增**
2. 填写：
   - **内容**：要发送的文字（Twitch 最多 500 个字符）。内容永远是单行：按 Enter 没有作用，粘贴的换行会变成空格
   - **间隔**：每次发送间隔的分钟数（5–240，默认 15）
   - **最少聊天数**：距上次发送后需要有多少条新的聊天消息才会再次发送（0–100，默认 2），避免在没人说话的聊天室里一直刷屏
   - **平台**：要发送到哪些平台
3. 点击 **保存**

发送规则：

- 只在直播中发送。第一条会在开播满一个间隔后才发送，而不是一开播就发送
- 若多条定时留言同时到期，会错开发送而不是一次全部发出

## 关键字回复

当观众的消息以指令开头时自动回复。

1. 点击 **+ 新增**
2. 填写：
   - **指令**：选择前缀（`! @ # $ % & ~`），再输入一个不含空格的词，例如 `!dc`。会与聊天消息的第一个词比对，不分大小写
   - **回复**：要发送的文字。`{user}` 会替换成使用指令的观众名称
   - **冷却**：同一个指令再次回复前需要等待的秒数（0–3600，默认 5）
   - **平台**：要在哪些平台回复
3. 点击 **保存**

关键字回复随时有效，不论是否在直播。

指令不能与其他关键字回复重复，也不能与 [点歌](./song-request) 或 [抽奖](./lottery) 关键字已使用的指令重复。

## 管理列表

两个标签页中，每个项目都有：

- 左侧的勾选框，可开关该项目而不必删除
- 平台标签；标签变暗表示该平台在设置标签页中已关闭
- **编辑** 与 **删除**
