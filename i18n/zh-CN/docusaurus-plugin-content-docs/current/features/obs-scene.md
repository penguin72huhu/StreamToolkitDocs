# OBS场景控制

**OBS场景控制** 让你用全局快捷键或从 [快速工具](./quick-tools) 切换直播软件中的场景、显示／隐藏来源。支持 **OBS Studio**、**Streamlabs** 与 **Meld Studio**。

此功能没有 Overlay，因此不需要在 OBS 中添加浏览器源。

:::info
只有侧边栏的 **OBS场景控制** 开关开启时，快捷键才有效。即使 Stream Toolkit 窗口最小化到系统托盘，快捷键也有效。
:::

设置页面有两个标签页：**连接设置** 与 **快捷键设置**。

## 连接设置标签页

### 步骤一：选择软件

在 **直播软件** 下选择 **OBS Studio**、**Streamlabs** 或 **Meld Studio**。只有在未连接时才能更改。

每个软件各自保存自己的快捷键与场景列表，因此切换软件时会显示该软件自己的设置。

### 步骤二：准备软件

#### OBS Studio

1. 在 OBS 中打开 **工具 → WebSocket 服务器设置**
2. 勾选 **开启 WebSocket 服务器**
3. 点击 **显示连接信息** 查看密码
4. 在 Stream Toolkit 中填写 **主机**（默认 `localhost`）、**端口**（默认 `4455`）与 **密码**

#### Streamlabs / Meld Studio

不需要任何设置，只要程序正在运行即可。

### 步骤三：连接

点击 **连接**。**状态** 会变成 **已连接**（OBS 与 Meld 还会显示版本号）。点击 **断开连接** 可中断连接。

**启动时自动连接**（默认开启）：Stream Toolkit 启动时以及开启功能开关时自动连接。关闭功能开关会断开连接。

### 场景

**场景** 区块列出你的场景以及每个场景的来源数量；当前场景会高亮显示。在直播软件中更改场景后，点击 **刷新** 获取最新列表。

断开连接时，仍会显示最后一次获取的列表。

## 快捷键设置标签页

若要设置快捷键，点击 **点击设置快捷键**，再按下按键组合。按 `Esc` 取消。若该组合已被其他功能使用，会显示 **快捷键冲突** 且不会保存。点击快捷键旁的 **✕** 可清除它。

### 切换场景

1. 点击 **新增**
2. 设置快捷键
3. 选择要切换到的场景

点击该行末端的 **✕** 可删除。

### 开关来源

一个快捷键可以同时控制同一个场景中的多个来源。

1. 点击 **新增**
2. 设置快捷键
3. 输入 **名称**（选填 — 用作快速工具中的按钮名称；留空则使用场景名称）
4. 选择来源所在的场景
5. 点击 **新增来源**，选择一个来源，并选择 **显示**、**隐藏** 或 **切换**（默认 **切换**）
6. 重复步骤 5 以加入更多来源

更改某个项目的场景会清空它的来源列表。

:::tip
直播软件中已不存在的场景或来源会以红色标示。请从下拉菜单中重新选择。
:::

## 从快速工具使用

功能开启且至少有一个快捷键项目时，[快速工具](./quick-tools) 会显示 **OBS场景控制** 卡片，每个项目各有一个按钮。点击按钮的效果与按下对应的快捷键相同。

## 错误消息

使用快捷键或按钮时，可能会弹出以下消息：

| 消息 | 意思 |
|---------|---------|
| **尚未连接到 OBS** | 未连接 — 请到 **连接设置** 标签页点击 **连接** |
| **找不到场景“…”** | 该场景已在直播软件中被重命名或删除 |
| **找不到来源：…** | 这些来源已不存在于该场景中 |

## 试用版限制

:::info
试用版总共只能设置 **1** 个快捷键项目（切换场景与开关来源合计）。请参考 [试用版 / 正式版比较](../getting-started/trial-comparison)。
:::

## 常见问题

**Q：显示无法连上 OBS，打开 OBS 后也没有重试。**
若第一次连接就失败（例如 OBS 还没开启），Stream Toolkit 不会持续重试。请先打开直播软件，再点击 **连接**。连接成功过一次之后，若连接中断会自动重新连接。
