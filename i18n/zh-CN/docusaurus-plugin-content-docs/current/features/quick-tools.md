# 快速工具

**快速工具** 是一个小型控制窗口，可以开在游戏或 OBS 旁边。不必切回主窗口，就能开关功能并使用它们最常用的操作。

## 打开快速工具

以下任一方式皆可：

- 点击主窗口左侧菜单最上方的 **⚡ 快速工具**
- 在 Stream Toolkit 的系统托盘图标上点右键，选择 **打开快速工具**

若窗口已经打开，会将它带到最前面，而不会再打开第二个。

## 窗口

- **移动窗口**：拖动标题栏
- **📌 置顶 / 取消置顶**：让窗口保持在其他窗口上方。窗口打开时默认为置顶
- **✕**：关闭窗口

窗口会跟随 App 的主题与界面语言。

## 快速开关面板

点击左侧边缘的 **›** 箭头，即可滑出 **快速开关** 面板。面板列出所有功能：

- 开关可开启或关闭功能（与主窗口侧边栏中各功能旁的开关相同）
- **⚙**（**打开设置**）会打开主窗口并跳到该功能的设置页面

点击面板外侧或再点一次箭头即可关闭。

功能的排列顺序与主窗口侧边栏相同。若要更改顺序，请在主窗口侧边栏中拖动功能旁的 **⠿** 把手。

## 功能卡片

每个已开启且有可操作项目的功能都会显示为一张卡片。卡片默认为收起 — 点击卡片标题可展开或收起。若这些功能都没有开启，窗口会显示 **尚未开启任何功能**。

| 功能 | 卡片提供的操作 |
|---------|---------------------|
| [OBS场景控制](./obs-scene) | 连接状态，以及每个已设置的场景切换或来源开关各一个按钮（当前场景会高亮显示）。未连接时按钮无法使用。至少有一个快捷键项目时才会出现此卡片 |
| [语音翻译](./voice-translate) | **REC** 按钮 — 按住录音，放开即翻译 |
| [实况精彩标记](./highlight) | **MARK** 按钮。标记后会显示平台图标与时间戳 5 秒 |
| [赞助条](./donate) | 当前／目标金额与进度条、**手动新增金额** 栏位与 **新增**，以及 **归零** |
| [计时器](./timer) | 每个显示中的计时器：名称、时间、**开始** / **暂停**、**重置**，以及你设置的加时按钮。秒表则改为显示 **停止** 与 **单圈** |
| [转盘](./turntable) | 每个显示中的转盘：**启动** 与 **重置** |
| [实况效果板](./multimedia) | 已固定的图片（显示／隐藏）、已固定的视频（播放）与已固定的音效（播放）按钮 |
| [点歌](./song-request) | **播放** / **暂停**、**停止**、**下一首** |

若某个操作设置了快捷键，快捷键会显示在它的按钮上。

在这里没有可操作项目的功能（聊天室、Twitch 目标条、赞助通知、赞助记录板、时钟、表情墙、投票、抽奖、聊天机器人）只会在快速开关面板中显示开关。

:::tip
赞助条卡片上的 **归零** 需要点两次：第一次点击时按钮会变成 **确定归零**，在 10 秒内再点一次即可将金额归零。
:::

:::info
计时器与转盘依照各功能的 **显示模式**：**单一计时器** / **单一转盘** 只显示当前选择的那一个；**多计时器** / **多转盘** 只显示你加入的项目。若没有任何项目，卡片会显示 **尚无计时器** / **尚无转盘**。
:::
