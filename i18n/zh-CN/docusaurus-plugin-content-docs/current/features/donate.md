# 赞助条

在直播画面上显示朝赞助目标前进的进度条。你选择的平台的赞助会自动加进总额。

## OBS 来源网址

```
http://127.0.0.1:7272/donate
```

从 **赞助条 设置** 页面上方复制网址，在 OBS 中新增为浏览器源。请参考 [如何在 OBS 加入来源](../getting-started/obs-source)。

用左侧菜单 **赞助条** 旁的开关在 OBS 中显示或隐藏赞助条。开关关闭时赞助条会隐藏。

## 货币

赞助条使用 **设置** 页面中设置的 **赞助货币**。其他货币的赞助会先换算成此货币再加进总额。若赞助的货币无法换算，就不会加进赞助条（赞助通知与赞助记录板仍会以原始货币显示）。

## 设置标签页

### 对接平台

勾选要计入赞助条的平台：

- **Twitch** — Bits 与订阅
- **YouTube**
- **PayPal**
- **Stripe**
- **O'Pay**
- **ECPay**

绿点表示该平台已连接，否则该行显示 **（未连接）**。这些勾选框只决定赞助条计入哪些赞助，不影响赞助通知或赞助记录板，它们各有自己的平台列表。

- **YouTube**：若直播聊天室尚未连接，该行会显示 **未连接聊天室网址** 以及两个按钮：**自动连接**（需要登录 Google）与 **手动填写**（跳到设置页的聊天室网址栏位）。请参考 [YouTube 设置](../platforms/youtube-settings)。
- **YouTube ⚙️**：选择哪些 **计入项目** 要加进赞助条：**超级感谢**、**超级贴图**、**加入会员**、**会员续订**、**赠送会员**、**宝石**。**宝石** 需要登录 Google。
- 若勾选了任何会员事件但尚未设置会员价格，会出现 **⚠ 未设置会员价格**。点击它前往设置，在 YouTube 的 **换算设置** 中填写各等级价格。
- Twitch Bits 与订阅的价值在 设置 → Twitch → **换算设置** 中设置。请参考 [Twitch 设置](../platforms/twitch)。
- 连接 PayPal、Stripe、O'Pay 或 ECPay，请参考 [PayPal](../payments/paypal)、[Stripe](../payments/stripe)、[O'Pay](../payments/opay) 与 [ECPay](../payments/ecpay)。

### 当前进度

显示当前总额、目标与百分比。

| 栏位 | 说明 |
|-------|-------------|
| **标题** | 选填。显示在赞助条上方。 |
| **目标金额** | 目标金额，以你的赞助货币计算。 |
| **手动新增** | 输入金额后点击 **新增**（或按 Enter）加进总额。 |
| **归零** | 将当前总额归零。会先出现确认提示。此操作无法复原。 |

## 外观标签页

### 预览

预览以示范金额显示赞助条。用 **预览** 旁的取色器可以更改预览背景。勾选 **预览达成** 可查看达成目标时的样子。

### 字体与颜色

点击 **恢复默认** 恢复默认外观。

- **字体**：设置 **标题**、**金额** 与 **%数** 的字体、颜色与大小（8–72 px）。
- **颜色**：设置 **背景**、**目标条**（填充颜色）与 **目标条达成**（达成目标后的填充颜色）。

### 自定义 CSS

展开 **自定义 CSS** 可编辑赞助条的 CSS。**恢复默认** 会恢复默认 CSS，**管理素材** 打开素材管理，管理要在 CSS 中使用的图片。也可以在这里套用 Steam Workshop 主题。套用主题期间 CSS 为只读，恢复后才能编辑。请参考 [主题样式](./themes)。

:::info 试用版
自定义 CSS 仅限正式版。试用版无法使用真实金流（PayPal / Stripe / O'Pay / ECPay）以及 YouTube 会员事件与宝石，且 Overlay 会显示水印。请参考 [试用版 / 正式版比较](../getting-started/trial-comparison)。
:::

## 常见问题

**Q：发送测试通知后总额增加了。**
设置页的 **测试通知** 会被当成真正的赞助，因此会加进赞助条（若勾选了该平台）。测试完后点击 **归零** 将总额归零。
