# 时钟

在直播画面上显示当前时间，也可以同时显示日期与星期。

## 步骤一：添加 OBS 来源

复制页面上方的 **OBS 源网址**：

```
http://127.0.0.1:7272/clock
```

在 OBS 中将它添加为浏览器源。请参考 [如何在 OBS 加入来源](../getting-started/obs-source)。时钟不会播放声音，因此不需要勾选“通过 OBS 控制音频”。

:::tip
同时也要打开左侧菜单 **时钟** 旁的开关（**开启 OBS 显示**）。开关关闭时，时钟在 OBS 中会隐藏。
:::

## 预览

上方的 **预览** 显示实际的 OBS Overlay，并会随设置变更即时更新。用旁边的颜色框可更改预览背景。

预览下方有三个标签页：**外观**、**时钟格式** 和 **显示设置**。

## 外观

| 设置 | 说明 |
|---------|-------------|
| **字体** | 时钟所有文字的字体 |
| **样式** | 时间、日期与星期的排列方式：**Stack**、**Horizontal**、**One-Top-Two-Bottom** 或 **Two-Top-One-Bottom**。除 **Horizontal** 外的所有样式都可设置 **行距**，除 **Stack** 外的所有样式都可设置 **间距**（两者皆为 −200 到 200 px） |
| **顺序** | 拖动 **时间**、**日期** 与 **星期** 区块来改变顺序 |
| **文字** | 分别设置 **时间**、**日期** 与 **星期**：**字号**、颜色（**纯色**，或使用两种颜色与 **角度** 的 **渐变**），以及 **边框** 的颜色、**透明度** 与 **粗细**（0–7 px） |
| **阴影** | 阴影颜色、**透明度**、**模糊** 与 **X** / **Y** 偏移，所有文字共用 |

**恢复默认** 按钮位于标签页上方。

### 自定义 CSS

点击 **自定义 CSS** 展开编辑器。默认 CSS 以注释列出时钟各部分（时间、日期、星期及其容器）的选择器。请用它来调整布局与结构。颜色、字体与大小请在上方的外观设置中设置。

- **恢复默认**：恢复默认 CSS
- **管理素材**：打开素材管理，管理 CSS 中使用的图片

若你的 CSS 用 `!important` 覆盖了某个属性，对应的外观控件会被锁定，因为 CSS 无论如何都会优先生效。

## 时钟格式

- **时制**：**24 小时**、**12 小时（上午/下午）** 或 **12 小时（AM/PM）**
- **时区**：UTC−12 到 UTC+14。默认与你电脑的时区相同

## 显示设置

- **显示秒数**
- **显示日期**：开启后从下拉菜单选择日期格式。标有 **无年份** 的格式不显示年份
  - **日期补零**：个位数的月与日前面补零（例如 2026/05/20）
  - **年份格式**：以年份开头的格式才会显示。**完整（2026）** 或 **缩写（26）**

  这两个选项适用于数字格式（使用 `/` 或 `-`）。文字格式（例如“2026年5月20日”）则会跟随 App 的界面语言
- **显示星期**：开启后选择星期的写法（例如 **星期三**、**Wednesday**、**WED** 或 **Wed**）

:::info 试用版限制
**自定义 CSS** 仅限正式版。详情请参考 [试用版 / 正式版比较](../getting-started/trial-comparison)。
:::
