# 投票

在直播中进行投票。观众在 Twitch 或 YouTube 聊天室输入选项编号即可投票，结果会在 OBS Overlay 上即时更新。

## OBS 来源网址

```
http://127.0.0.1:7272/vote
```

点击页面上方 **OBS 源网址** 旁的 **复制**，再在 OBS 中添加为浏览器源。请参考 [如何在 OBS 加入来源](../getting-started/obs-source)。投票不会播放声音，因此不需要勾选“通过 OBS 控制音频”。

:::tip
同时也要打开左侧菜单 **投票** 旁的开关（**开启 OBS 显示**）。开关关闭时，Overlay 会保持隐藏。
:::

页面有三个标签页：**设置**、**外观** 和 **历史记录**。

## 开始投票（设置标签页）

### 投票平台

点击 **Twitch** 或 **YouTube** 选择哪个平台的聊天室可以投票。可以两个都选。未连接的平台会显示 **（未连接）**（Twitch）或 **未连接聊天室网址**（YouTube）。请先连接：

- [Twitch 设置](../platforms/twitch)
- [YouTube 设置](../platforms/youtube-settings)

### 投票标题

选填。例如：“今晚玩哪款游戏？”

### 投票选项（2–10 项）

- 至少输入 2 个选项，最多 10 个
- **+ 新增选项** 会新增一行，**×** 删除一行
- **应用历史** 可从最近 15 次投票中选一个，填入它的标题与选项

编辑期间，OBS Overlay 会预览标题与选项。

### 投票时间

投票时长（秒）。默认为 60，最少 10。

### 开始／停止

- **开始投票**：需要至少 2 个已填写的选项，以及至少一个已选择且已连接的平台
- **停止投票**：提前结束投票。否则会在时间到时结束

投票进行中无法更改平台、标题、选项或时间。

## 观众如何投票

投票进行中，Overlay 会显示“在聊天室输入选项编号即可投票（例：1）”。

- 整条消息必须是选项编号，例如 `1` 或 `1.`。空格会被忽略。含有其他文字的消息不计票
- 每位观众一票。若再发送不同的编号，票会移到新选项，以时间到之前的最后一票为准

## 实时结果

投票期间，设置下方会出现 **实时结果**，显示剩余时间、各选项的票数与百分比，以及总票数。投票结束后会变成 **最终结果**。点击 **详细** 可查看每个选项的投票者，按 Twitch 与 YouTube 分组。

## 外观

**外观** 标签页上方有 **预览**。旁边的取色器只会改变预览背景，不会改变 OBS Overlay。

- **字体**：设置 **标题**、**提示**、**选项**、**倒计时秒数** 与 **得票数** 的字体、颜色与 **大小**（px）
- **进度条颜色**：最多 5 种颜色，依序用于各选项的进度条。每种颜色可以是 **纯色** 或 **渐变**。渐变还可设置 **角度**
- **背景颜色**：投票卡片的背景
- **恢复默认**：恢复默认外观。若已套用主题，则恢复为该主题的外观

在 **自定义 CSS** 中可以编写自己的样式。若要分享或下载外观，请参考 [主题样式](./themes)。

## 历史记录

**历史记录** 标签页列出每次投票的标题、时间、选项数量与总票数。展开投票可查看结果、各平台的票数以及 **详细**。只保留最近 30 天的投票记录。若要删除记录，点击 🗑 再点击 **确认删除**。

:::info 试用版限制
- **自定义 CSS** 仅限正式版
- OBS Overlay 会显示水印

详情请参考 [试用版 / 正式版比较](../getting-started/trial-comparison)。
:::
