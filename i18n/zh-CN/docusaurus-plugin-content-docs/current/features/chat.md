# 聊天室

**聊天室** 将 Twitch 与 YouTube 的聊天消息整合在同一个 Overlay 中显示，并可选择自动翻译。也可以把聊天室显示在只有你看得到的透明桌面窗口中。

## OBS 来源网址

```
http://127.0.0.1:7272/chat
```

将它添加为浏览器源：[如何在 OBS 加入来源](../getting-started/obs-source)。此 Overlay 没有声音。

:::info
只有侧边栏的 **聊天室** 开关开启时，消息才会送到 Overlay。开关关闭时仍会接收聊天消息，因此需要读取聊天室的功能（投票、抽奖、点歌等）都能继续运作。
:::

## 开始之前

先连接要显示的平台：

- [Twitch 设置](../platforms/twitch)
- [YouTube 设置](../platforms/youtube-settings)

设置页面有两个标签页：**设置** 与 **外观**。

## 设置标签页

### 平台

- **显示平台 icon（Twitch / YouTube）** — 在每条消息前显示 <img src={require('@site/static/img/twitch-icon.png').default} alt="Twitch" className="inline-icon" /> / <img src={require('@site/static/img/youtube-icon.png').default} alt="YouTube" className="inline-icon" /> 图标

每个平台都有自己的卡片。平台已连接且已启用时，平台名称旁的圆点会亮绿灯；Twitch 未连接时显示 **（未连接）**，YouTube 聊天室未连接时显示 **未连接聊天室网址**。

| 选项 | 说明 |
|--------|-------------|
| **启用聊天室** | 显示此平台的消息 |
| **显示头像** | 显示观众头像 |
| **显示徽章**（Twitch）／**显示徽章（会员图标）**（YouTube） | 显示徽章 |
| **显示观众名称而非 @代称** | 仅限 YouTube。登录 Google 前无法使用 |

YouTube 聊天室已启用但尚未连接时，卡片上会出现两个按钮：

- **自动连接** — 自动找到你当前的直播（需要登录 Google）
- **手动填写** — 跳到设置页面粘贴聊天室网址

**最多消息数**：画面上保留的消息数量（5–200，默认 50）。

### 自动翻译

1. 勾选 **启用翻译**
2. **目标语言**：消息要翻译成的语言。默认的 **跟随界面语言** 会使用 App 的界面语言
3. **不翻译的语言**（选填）：勾选的语言的消息会保持原样。葡萄牙语 PT-BR 与 PT-PT 无法区分，因此勾选其中一个会同时跳过两者

**翻译服务** 为 **MyMemory**，不需要 API 密钥。

- **Email（选填）**：不填 Email 时每日额度为 5,000 字符；填入 Email 并点击 **保存** 可提高到 50,000 字符（免费，不需要注册 MyMemory）
- 下方的进度条显示今日大约已使用的量，每天 08:00 UTC 重置

### 测试

- **发送测试消息** — 发送一条随机示范消息到 Overlay
- **清除** — 清除 Overlay 上的所有消息

若出现 **连接失败，服务器可能未启动**，表示 Stream Toolkit 的本地服务器没有响应。

### 桌面聊天室窗口

在游戏画面上方以透明、置顶的小窗口显示聊天室。只有你看得到 — 适合单屏幕直播。

1. 点击 **打开窗口**（或在系统托盘图标上点右键，选择 **打开桌面聊天室**）
2. 未锁定时，拖动顶部栏可移动窗口，拖动边缘可调整大小
3. 放好位置后点击 **🔒 锁定**。之后点击会穿透窗口传到游戏。若要解锁，将鼠标移到窗口上，点击右上角出现的 🔓，或在设置页面点击 **🔓 解锁**

**重置位置** 会把窗口移回默认位置。

| 设置 | 说明 |
|---------|-------------|
| **外观样式** | **仅名字＋内容**（默认）或 **与 OBS 聊天室相同** |
| **字号** | 12–32 px，默认 16。仅适用于 **仅名字＋内容** |
| **文字不透明度** | 10–100%，默认 100% |
| **背景不透明度** | 0–100%，默认 40% |
| **消息淡出** | 0–120 秒，默认 0。每条消息在指定秒数后淡出，淡出的消息无法再往回滚动查看。设为 0 时不会淡出，未锁定时可以往上滚动查看较早的消息（最多到最多消息数） |
| **在直播画面中隐藏** | 默认开启。OBS 的显示器采集不会捕捉到这个窗口，观众就不会看到两份聊天室。截图或 Discord 屏幕共享中也不会出现 |

:::tip
若游戏全屏时看不到窗口，请将游戏切换为无边框窗口或窗口模式。可用 **发送测试消息** 确认窗口的位置与大小。
:::

## 外观标签页

### 预览

标签页上方会显示实时预览。**预览** 旁的取色器只会改变预览背景。**头像**、**徽章** 与 **平台 icon** 勾选框只会改变预览中显示的内容。

### 外观设置

**恢复默认** 会恢复默认外观（若已套用主题，则恢复为该主题的外观）。

- **进场方向**：**由上往下**、**由下往上**（默认）、**由左往右**、**由右往左**
- **文字** — 可分别设置 **昵称** 与 **消息**：
  - 字体、大小（px）与颜色。昵称可选择 **原始颜色**（观众在平台上的颜色）或 **自定义颜色**
  - **外框**：颜色、**透明度**、**粗细**
  - **阴影**：颜色、**透明度**、**模糊**、X / Y 偏移
- **图标大小**：**平台icon**、**头像** 与 **徽章** 的缩放比例（0.1–5 倍）
- **颜色**：每条消息的 **背景颜色**

### 自定义 CSS

展开 **自定义 CSS** 可直接编辑 Overlay 的 CSS。使用 **管理素材** 上传要在 CSS 中引用的图片。**恢复默认** 会恢复默认 CSS。另请参考 [主题样式](./themes)。

:::tip
若你的自定义 CSS 用 `!important` 设置了某个外观栏位，该栏位在外观设置中会变成灰色（“此设置由自定义 CSS 控制”）。套用主题时 CSS 为只读 — 请先恢复后再编辑。
:::

## 试用版限制

- 开启自动翻译时，聊天室 Overlay 会加上水印
- **自定义 CSS** 仅限正式版
- **桌面聊天室窗口** 仅限正式版

请参考 [试用版 / 正式版比较](../getting-started/trial-comparison)。
