# 点歌

观众用聊天室指令点 YouTube 歌曲，歌曲会在 OBS 中依序播放。你也可以自己加入歌曲，并设置没有点歌时播放的默认播放列表。

## OBS 来源网址

```
http://127.0.0.1:7272/song-request
```

点击页面上方 **OBS 源网址** 旁的 **复制**，再在 OBS 中添加为浏览器源。请参考 [如何在 OBS 加入来源](../getting-started/obs-source)。

:::warning
点歌会播放声音。请在浏览器源的属性中勾选 **通过 OBS 控制音频**，否则音乐不会传到直播中。
:::

:::tip
同时也要打开左侧菜单 **点歌** 旁的开关。只有开关开启时才会处理聊天室指令。
:::

页面有两个标签页：**设置** 与 **播放列表**。

## 设置标签页

### 平台

每个平台都有自己的卡片：

- **开放此平台点歌**：让该聊天室的观众可以点歌
- **启用聊天机器人回复**（仅限 Twitch，默认开启）：用你已连接的 Twitch 账号在 Twitch 聊天室回复每个指令的结果。只有 Twitch 已启用且已连接时才会显示

未连接的平台会显示 **（未连接）**（Twitch）或 **未连接聊天室网址**（YouTube）。请先连接：

- [Twitch 设置](../platforms/twitch)
- [YouTube 设置](../platforms/youtube-settings)

### 聊天室指令

| 栏位 | 默认 |
|------|--------|
| **指令前缀** | `!`（可从 `! @ # $ % & ~` 中选择） |
| **点歌指令** | `sr` |
| **删除点歌** | `remove` |
| **查看点歌列表** | `queue` |
| **查询当前歌曲** | `song` |
| **点歌冷却时间** | 3000 ms |

冷却时间按每位观众分别计算：点歌成功后，同一位观众需等待这段时间才能再次点歌。

### 设置

- **在画面显示视频**（默认开启）：关闭时视频在 OBS 中会隐藏，但仍会播放声音
- **列表上限**（1–100，默认 20）：列表中点播歌曲的最大数量。默认播放列表的歌曲不计入
- **显示点歌通知**（默认开启）：观众点歌、删除点歌或点歌失败时，在 OBS 显示通知卡片。开启后可设置：
  - **X** / **Y**：通知与左上角的距离（px，默认 16 / 16）
  - **通知缩放**：大小倍率（默认 1.0）
  - **测试通知外观**：发送一则测试通知到 OBS

每则通知停留 5 秒；同时最多显示 3 则。

## 观众如何使用

使用默认设置时：

| 指令 | 作用 |
|------|------|
| `!sr <YouTube link>` | 点播该视频 |
| `!sr <search words>` | 搜索 YouTube 并点播第一个结果 |
| `!remove` | 删除该观众最近一次的点歌（不包括正在播放的歌曲） |
| `!queue` | 回复接下来的 3 首点播歌曲 |
| `!song` | 回复正在播放的歌曲 |

- 接受的链接：`youtube.com/watch?v=…`、`youtu.be/…`、`youtube.com/live/…`、`youtube.com/shorts/…`，或 11 个字符的视频 ID
- 不接受播放列表链接
- 列表达到 **列表上限** 时点歌会失败
- 新的点歌会排在其他观众的点歌之后、默认播放列表歌曲之前
- `!queue` 与 `!song` 只在 Twitch 聊天室且开启 **启用聊天机器人回复** 时有效

## 播放列表标签页

### 播放控制

最上方一行显示当前歌曲的点歌者与标题。按钮：

- **播放** / **暂停**：若没有正在播放的歌曲，会从列表中的第一首开始
- **停止**：停止播放
- **下一首**：跳到下一首歌

歌曲播放时会出现进度条，拖动即可跳到指定位置。歌曲结束时会自动播放下一首。

:::note
App 启动时不会自动播放。请按 **播放** 开始。
:::

### 默认播放列表

粘贴 YouTube 播放列表网址，并选择 **循环播放** 或 **随机播放**。列表播完时，会自动从此播放列表加入一首歌并播放。这些歌曲在列表中显示为 **默认列表**。

默认播放列表是通过你的 YouTube 账号读取的，因此必须先在 [YouTube 设置](../platforms/youtube-settings) 中登录 Google。

### 手动点歌

粘贴 YouTube 视频网址后点击 **加入列表**（或按 Enter）。手动点歌不支持搜索关键字。

### 列表

**列表（n）** 显示所有歌曲：平台、点歌者、标题与视频 ID（点击可在 YouTube 上打开）。点击 **删除** 可移除歌曲；删除正在播放的歌曲会跳到下一首。**清空** 会清空整个列表。

## 常见问题

**Q：观众输入了指令，但没有任何反应？**
请确认：
- 左侧菜单的 **点歌** 开关已开启
- 该平台已勾选 **开放此平台点歌**
- Twitch：Twitch 聊天室是由 [聊天室](./chat) 功能读取的。若你在聊天室页面关闭了 Twitch（且 [聊天机器人](./chat-bot) 也没有使用 Twitch），就不会收到 Twitch 的指令

**Q：默认播放列表没有播放？**
请确认已在设置中登录 Google，且网址是播放列表链接（包含 `list=`）。

:::info 试用版限制
- 观众从聊天室点歌仅限正式版。试用版中，聊天室的点歌会失败并显示“试用版不支持观众点歌”。**手动点歌** 与默认播放列表仍可使用
- OBS Overlay 会显示水印

请参考 [试用版 / 正式版比较](../getting-started/trial-comparison)。
:::
