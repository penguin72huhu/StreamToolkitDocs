# 赞助记录板

在直播画面上显示最近的赞助列表：平台图标、赞助者名称、金额与留言。

## OBS 来源网址

```
http://127.0.0.1:7272/sponsors
```

从 **赞助记录板 设置** 页面上方复制网址，在 OBS 中新增为浏览器源。请参考 [如何在 OBS 加入来源](../getting-started/obs-source)。

用左侧菜单 **赞助记录板** 旁的开关在 OBS 中显示或隐藏记录板。开关关闭时，记录板会淡出。开关关闭期间仍会记录赞助。

## 设置标签页

### 对接平台

勾选要记录赞助的平台：**Twitch**、**YouTube**、**PayPal**、**Stripe**、**O'Pay**、**ECPay**。绿点表示该平台已连接，否则该行显示 **（未连接）**。这些勾选框只影响记录板，不影响赞助条或赞助通知。

**Twitch ⚙️**（Twitch 已连接且已勾选时显示）：

1. 选择 **计算 Bits 和订阅**、**仅计算 Bits** 或 **仅计算订阅**
2. **计算重新订阅**：是否记录重新订阅（计算订阅时显示）
3. **未满 [N] Bits 不计入计算**：勾选并输入最低数量，较小的 Cheer 就不会被记录（计算 Bits 时显示）
4. 点击 **保存**

**YouTube ⚙️**：

- **显示观众名称而非 @代称**：登录 Google 后才能使用。
- **计入项目**：**超级感谢**、**超级贴图**、**加入会员**、**会员续订**、**赠送会员**、**宝石**。**宝石** 需要登录 Google。宝石礼物会显示为宝石图标加宝石数量，而不是金额。

若 YouTube 直播聊天室尚未连接，该行会显示 **未连接聊天室网址**，以及 **自动连接**（需要登录 Google）与 **手动填写**（跳到设置页的聊天室网址栏位）。若勾选了会员事件但尚未设置会员价格，点击 **⚠ 未设置会员价格** 前往设置。请参考 [YouTube 设置](../platforms/youtube-settings)。

连接 PayPal、Stripe、O'Pay 或 ECPay，请参考 [PayPal](../payments/paypal)、[Stripe](../payments/stripe)、[O'Pay](../payments/opay) 与 [ECPay](../payments/ecpay)。

### 设置

| 栏位 | 说明 |
|-------|-------------|
| **自动换算成自身货币** | 默认开启。将金额换算成设置页中设置的 **赞助货币** 后显示。 |
| **最多显示** | 保留的记录数量（1–100）。默认：20。超过上限时有新赞助到达，最旧的记录会被移除。 |

## 外观标签页

### 预览

用 **预览** 旁的取色器可以更改预览背景。点击 **测试新增动画** 会用一笔示范记录播放进场动画。示范记录不会保存到历史记录。

点击 **恢复默认** 恢复默认外观。

### 显示设置

- **显示平台 icon**：在每笔记录上显示平台图标。
- **出现方向**：**上到下**（默认）、**下到上**、**左到右** 或 **右到左**。

### 字体

设置 **标题**（赞助者名称）、**正文**（留言）与 **金额** 的字体、颜色与大小（8–72 px）。

### 背景颜色

- **默认**：每笔记录的背景颜色。
- **+ 新增范围**：新增一个带有 **金额** 范围（**最低** ~ **最高**）的颜色。金额落在范围内的记录会改用该颜色。最低或最高留空表示该侧没有限制。点击 **✕** 移除范围。

开启 **自动换算成自身货币** 时，会以换算后的金额比对范围。

### 自定义 CSS

展开 **自定义 CSS** 可编辑记录板的 CSS。**恢复默认** 会恢复默认 CSS，**管理素材** 打开素材管理。也可以在这里套用 Steam Workshop 主题。套用主题期间 CSS 为只读。请参考 [主题样式](./themes)。

## 历史记录标签页

### 手动新增（测试用）

选择平台，输入 **名字**、**金额** 与选填的 **消息（选填）**，再点击 **新增**。只有在 **对接平台** 中勾选了该平台，记录才会加入。金额以你的赞助货币计算。

### 历史记录

列出已保存的记录与记录数量。

- 点击 **🗑** 再点击 **确认删除** 即可删除一笔记录。
- 点击 **清除** 删除所有记录。会先出现确认提示。此操作无法复原。

:::info 试用版
自定义 CSS 仅限正式版。试用版无法使用真实金流（PayPal / Stripe / O'Pay / ECPay）以及 YouTube 会员事件与宝石，且记录板在 OBS 中会显示水印。请参考 [试用版 / 正式版比较](../getting-started/trial-comparison)。
:::

## 常见问题

**Q：测试通知出现在记录板上。**
设置页的 **测试通知** 会被当成真正的赞助处理，因此若勾选了该平台，也会记录在这里。请到 **历史记录** 标签页删除。
