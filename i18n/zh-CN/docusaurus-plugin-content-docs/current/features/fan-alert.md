# 新粉丝通知

有人在 Twitch 追随你或订阅你的 YouTube 频道时，在直播画面上弹出通知。

## OBS 来源网址

```
http://127.0.0.1:7272/fan-alert
```

从 **新粉丝通知 设置** 页面上方复制网址，在 OBS 中新增为浏览器源。请参考 [如何在 OBS 加入来源](../getting-started/obs-source)。

:::warning
通知会播放音效。请在浏览器源的属性中勾选 **通过 OBS 控制音频**，否则直播中听不到声音。
:::

用左侧菜单 **新粉丝通知** 旁的开关开启或关闭通知。开关关闭时，新粉丝既不会显示也不会记录，测试按钮也无法使用。

多位粉丝在短时间内到达时，通知会排队依序显示。这个 Overlay 有自己的队列，因此不会排在 [赞助通知](./donate-alert) 后面等待。

## 设置标签页

### 对接平台

勾选要触发通知的平台：**Twitch** 与 **YouTube**（默认皆勾选）。绿点表示该平台已连接，否则该行显示 **尚未授权**。

- **Twitch**：每次有新追随都会立即触发通知。请先连接 Twitch：[Twitch 设置](../platforms/twitch)。
- **YouTube**：新订阅者。请先登录 Google：[YouTube 设置](../platforms/youtube-settings)。

YouTube 订阅者的侦测方式：

- YouTube 没有即时的“新订阅者”事件，因此 App 每 1.5 分钟向 YouTube 查询一次最近的订阅者。
- 只有在你直播中、且 YouTube 直播聊天室已连接到该场直播时才会查询。在等候室或直播结束后都不会查询。
- 在直播开始前订阅的人（比开始查询早约 5 分钟以上）不会被通知。
- 如页面上的提示所说：**YouTube只会通知公开订阅的观众，可能延迟数分钟到数小时。**

### 设置

| 栏位 | 说明 |
|-------|-------------|
| **显示时间** | 每则通知在画面上停留的秒数（1–60）。默认：5。 |
| **同一位观众 24 小时内只通知一次** | 默认关闭。开启后，同一位观众在 24 小时内再次追随（例如取消追随后又重新追随）时不会显示也不会记录。 |

### 测试通知

点击 **测试通知 (Twitch)** 或 **测试通知 (YouTube)**，会送一则示范通知到 OBS。测试通知不会加进历史记录。

若新粉丝通知已关闭，测试不会播放，页面会显示 **请先在快速开关开启新粉丝通知**。

## 外观标签页

### 预览

预览使用与 OBS 来源相同的页面。用 **预览** 旁的取色器可以更改预览背景，点击 **▶ 重播动画** 可再播放一次通知动画。

### 统一样式／各平台独立

- **统一样式**：Twitch 与 YouTube 使用相同的通知样式。
- **各平台独立**：每个平台有自己的样式。用下方按钮选择 **Twitch** 或 **YouTube** 并编辑其设置。第一次切换时，尚未自定义的平台会复制目前的统一样式，各自带有自己的倒计时条颜色。

**恢复默认** 会把正在编辑的样式恢复为默认样式。

### 图片

- **选择图片**：从素材管理选择图片。未选择时显示爱心表情符号。**清除** 移除图片。
- **图片大小**：1–400 px。
- **图片位置**：**靠左**、**靠右**、**上方** 或 **下方**。

### 音效

选择内置音效：**无**、**铃声**（默认）、**金币**、**钟声**、**弹出**、**号角**。点击 **▶** 试听。点击 **选择音效** 可从素材管理使用自己的音效文件。

### 自定义文字

填写通知上显示的文字。用 `{name}` 代表粉丝名称，`{platform}` 代表平台名称。留空则使用默认文字：`欢迎 {name} 成为新粉丝！`

### 文字与颜色

- **文字**：设置 **自定义文字** 与 **粉丝名称** 的字体、大小与颜色。
- **颜色**：**背景**、**阴影** 与 **倒计时条**。

### 自定义 CSS

展开 **自定义 CSS** 可编辑正在编辑的样式（统一样式或所选平台）的 CSS。**恢复默认** 会恢复模板 CSS，**管理素材** 打开素材管理。也可以在这里套用 Steam Workshop 主题。套用主题期间 CSS 为只读。请参考 [主题样式](./themes)。

## 历史记录标签页

列出两个平台最近的新粉丝，最新的在最前面：平台、名称与时间。历史记录只显示在 App 中，不会出现在 Overlay 上。

- 最多保留 100 位粉丝，超过 30 天的记录会自动移除。
- 点击 **清除** 清空列表。

:::info 试用版
自定义 CSS 仅限正式版，且通知在 OBS 中会显示水印。请参考 [试用版 / 正式版比较](../getting-started/trial-comparison)。
:::

## 常见问题

**Q：直播中没有声音？**
确认浏览器源属性中已勾选 **通过 OBS 控制音频**，且 OBS 混音器中该来源没有静音。也请确认 **音效** 不是设为 **无**。

**Q：YouTube 订阅者没有弹出通知。**
只有公开的订阅才会被回报，而且 YouTube 可能需要数分钟到数小时才会回报。App 也只会在你直播中且 YouTube 直播聊天室已连接时查询。

**Q：我比较晚才加入 OBS 来源，会补播之前的通知吗？**
不会。新开启的来源只会显示连接之后才到达的通知。较早的粉丝仍可在 **历史记录** 标签页中查看。
