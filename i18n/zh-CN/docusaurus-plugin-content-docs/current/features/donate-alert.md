# 赞助通知

有人赞助时，弹出带有图片、音效、赞助者名称、金额与留言的通知。

## OBS 来源网址

```
http://127.0.0.1:7272/donate-alert
```

从 **赞助通知 设置** 页面上方复制网址，在 OBS 中新增为浏览器源。请参考 [如何在 OBS 加入来源](../getting-started/obs-source)。

:::warning
通知会播放音效。请在浏览器源的属性中勾选 **通过 OBS 控制音频**，否则直播中听不到声音。
:::

用左侧菜单 **赞助通知** 旁的开关开启或关闭通知。开关关闭时不会显示任何通知（包括测试通知），但赞助仍会记录到 [赞助记录板](./sponsors)。

多笔赞助在短时间内到达时，通知会排队依序显示。

## 设置标签页

### 对接平台

勾选要触发通知的平台：**Twitch**、**YouTube**、**PayPal**、**Stripe**、**O'Pay**、**ECPay**。绿点表示该平台已连接，否则该行显示 **（未连接）**。这些勾选框只影响通知，不影响赞助条或赞助记录板。

**Twitch ⚙️**（Twitch 已连接且已勾选时显示）：

1. 选择 **计算 Bits 和订阅**、**仅计算 Bits** 或 **仅计算订阅**
2. **计算重新订阅**：重新订阅是否触发通知（计算订阅时显示）
3. **未满 [N] Bits 不计入计算**：勾选并输入最低数量，较小的 Cheer 就不会触发通知（计算 Bits 时显示）
4. 点击 **保存**

**YouTube ⚙️**：

- **显示观众名称而非 @代称**：登录 Google 后才能使用。
- **计入项目**：**超级感谢**、**超级贴图**、**加入会员**、**会员续订**、**赠送会员**、**宝石**。**宝石** 需要登录 Google。

若 YouTube 直播聊天室尚未连接，该行会显示 **未连接聊天室网址**，以及 **自动连接**（需要登录 Google）与 **手动填写**（跳到设置页的聊天室网址栏位）。若勾选了会员事件但尚未设置会员价格，点击 **⚠ 未设置会员价格** 前往设置。请参考 [YouTube 设置](../platforms/youtube-settings)。

连接 PayPal、Stripe、O'Pay 或 ECPay，请参考 [PayPal](../payments/paypal)、[Stripe](../payments/stripe)、[O'Pay](../payments/opay) 与 [ECPay](../payments/ecpay)。

### 设置

| 栏位 | 说明 |
|-------|-------------|
| **自动换算成自身货币** | 默认开启。将金额换算成设置页中设置的 **赞助货币** 后显示。 |
| **显示时间** | 每则通知在画面上停留的秒数。默认：6。 |

## 外观标签页

### 预览

预览使用与 OBS 来源相同的页面。用 **预览** 旁的取色器可以更改预览背景，点击 **▶ 重播动画** 可再播放一次通知动画。

### 统一样式／各平台独立

- **统一样式**：所有平台使用相同的通知样式。
- **各平台独立**：每个平台有自己的样式。用下方按钮选择平台（**Twitch**、**YouTube**、**O'Pay**、**ECPay**、**PayPal**、**Stripe**）并编辑其设置。第一次切换时，尚未自定义的平台会复制目前的统一样式，各自带有自己的倒计时条颜色。

**恢复默认** 会把正在编辑的样式恢复为默认样式。

### 图片

- **选择图片**：从素材管理选择图片。未选择时显示爱心表情符号。**清除** 移除图片。
- **图片大小**：1–400 px。
- **图片位置**：**靠左**、**靠右**、**上方** 或 **下方**。

### 音效

选择内置音效：**无**、**铃声**（默认）、**金币**、**钟声**、**弹出**、**号角**。点击 **▶** 试听。点击 **选择音效** 可从素材管理使用自己的音效文件。

### 文字显示

- **默认**：金额、赞助者名称与留言分行显示。
- **自定义文字**：自己写一行文字。用 `{name}` 代表赞助者名称，`{amount}` 代表金额，例如 `感谢 {name} 赞助 {amount}！`

### 文字与颜色

- **文字**：设置 **金额**、**赞助者名称** 与 **留言** 的字体、大小与颜色（自定义文字模式下还有 **自定义文字**）。
- **颜色**：**背景**、**阴影** 与 **倒计时条**。

### 自定义 CSS

展开 **自定义 CSS** 可编辑正在编辑的样式（统一样式或所选平台）的 CSS。**恢复默认** 会恢复模板 CSS，**管理素材** 打开素材管理。也可以在这里套用 Steam Workshop 主题。套用主题期间 CSS 为只读。请参考 [主题样式](./themes)。

## 测试通知

在 **设置** 页面，点击 **赞助平台对接** 旁的 **测试通知**：

1. 填写 **测试名称**、**测试留言** 与 **测试金额**，选择 **测试平台**
2. 点击 **发送测试通知**

**YouTube 超级留言测试** 区块可以输入原始的 **金额字符串**（例如 `$5.00`、`¥500`、`NT$150`），再点击 **发送测试超级留言**，测试金额解析与货币换算。

:::note
测试通知会被当成真正的赞助处理：若 [赞助条](./donate) 与 [赞助记录板](./sponsors) 中勾选了该平台，也会计入其中。
:::

:::info 试用版
自定义 CSS 仅限正式版。试用版无法使用真实金流（PayPal / Stripe / O'Pay / ECPay）以及 YouTube 会员事件与宝石，且通知在 OBS 中会显示水印。请参考 [试用版 / 正式版比较](../getting-started/trial-comparison)。
:::

## 常见问题

**Q：直播中没有声音？**
确认浏览器源属性中已勾选 **通过 OBS 控制音频**，且 OBS 混音器中该来源没有静音。也请确认 **音效** 不是设为 **无**。

**Q：我比较晚才加入 OBS 来源，会补播之前的通知吗？**
不会。新开启的来源只会显示连接之后才到达的通知。
