# 快捷键总览

左侧菜单底部的 **⌨️ 快捷键总览** 会把你设置过的所有快捷键集中列在同一处。

## 快捷键总览

每一行显示按键组合与它触发的动作，例如 `计时器 › （计时器名称） › 开始/暂停`。点击任一行会跳到该功能的设置页面，在那里修改。这个页面不能直接编辑快捷键。

若还没有设置任何快捷键，会显示“当前没有设置任何快捷键。”

## 支持快捷键的功能

| 功能 | 快捷键的作用 |
|------|------|
| [实况精彩标记](./highlight) | 新增标记 |
| [实况效果板](./multimedia) | 播放音效／显示图片／播放视频（每个项目一个快捷键） |
| [语音翻译](./voice-translate) | 语音翻译快捷键 |
| [OBS场景控制](./obs-scene) | **切换场景**／**开关来源** |
| [计时器](./timer) | **开始/暂停**、**计圈**、**重置**（每个计时器各自设置） |

## 设置快捷键

[实况精彩标记](./highlight)、[OBS场景控制](./obs-scene) 与 [计时器](./timer) 使用相同的快捷键栏位。实况效果板与语音翻译请参考各自的页面。

1. 点击快捷键按钮
2. 按下按键组合，例如 `Ctrl+Shift+F1`
3. 放开所有按键即可保存

- 录制时按 **Esc** 取消
- 若该组合已被其他快捷键使用，会出现冲突提示且不会保存。请换一个组合
- 点击旁边的 **✕**（或清除按钮）可移除快捷键
- 数字键盘与主键盘上排的数字键是分开的：`Num1` 与 `1` 是不同的快捷键

即使 Stream Toolkit 在后台（例如你正在玩游戏），快捷键也有效。
