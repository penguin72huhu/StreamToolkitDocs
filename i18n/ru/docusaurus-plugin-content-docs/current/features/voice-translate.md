# Голосовой перевод

Удерживайте горячую клавишу и говорите. Stream Toolkit превращает вашу речь в текст, переводит его и показывает обе строки как субтитры в OBS.

Распознавание речи выполняется на вашем компьютере с помощью модели Whisper. Затем текст переводится через MyMemory.

На странице две вкладки: **Настройки** и **Оформление**.

## Шаг 1: Добавьте источник OBS

URL источника для OBS показан вверху страницы:

```
http://127.0.0.1:7272/voice-translate
```

Нажмите **Копировать** и добавьте его в OBS как источник «Браузер». См. [Как добавить источники в OBS](../getting-started/obs-source). Голосовой перевод не воспроизводит звук, поэтому включать «Управлять аудио с помощью OBS» не нужно.

Субтитры появляются внизу источника: исходный текст сверху, перевод под ним. Они исчезают по истечении **Время показа субтитров**.

:::tip
Включите переключатель рядом с **Голосовой перевод** в левом меню (**Включить вывод в OBS**). Горячая клавиша работает, только пока он включён.
:::

## Шаг 2: Задайте горячую клавишу

В разделе **Горячая клавиша (удерживайте для записи, отпустите для распознавания)**:

1. Нажмите **Нажмите, чтобы задать горячую клавишу**
2. Нажмите нужное сочетание клавиш и отпустите его. Нажмите **Esc**, чтобы отменить
3. Чтобы удалить горячую клавишу, нажмите **Очистить**

Если сочетание уже используется другой функцией, на кнопке отображается **Конфликт горячих клавиш**, и горячая клавиша не сохраняется.

Горячая клавиша работает, даже когда Stream Toolkit не является активным окном. **Удерживайте** её, пока говорите, затем **отпустите**, чтобы распознать и перевести речь. Запись автоматически останавливается через 15 секунд.

Также можно удерживать мышью кнопку **REC** под горячей клавишей. Она работает так же: нажмите для записи, отпустите для перевода. В окне [Быстрые инструменты](./quick-tools) есть такая же кнопка **REC**.

## Шаг 3: Настройки распознавания

| Поле | Описание |
|-------|-------------|
| **Статус модели** | Показывает **Загрузка xx%**, **Готово** или **Не удалось загрузить модель**. Записывать можно, когда отображается **Готово** |
| **Модель Whisper** | **Tiny (самый быстрый, ~40MB)**, **Base (рекомендуется, ~75MB)** (по умолчанию) или **Small (самый точный, ~245MB)**. Модель загружается при первом использовании. При смене модели она перезагружается |
| **Язык речи** | Язык, на котором вы говорите. По умолчанию — традиционный китайский |
| **Микрофон** | Микрофон для записи. **Системный по умолчанию** использует устройство ввода Windows по умолчанию |

## Шаг 4: Настройки перевода

| Поле | Описание |
|-------|-------------|
| **Время показа субтитров** | Сколько субтитры остаются на экране, 1–30 секунд. По умолчанию 5 |
| **Целевой язык** | Язык, на который выполняется перевод. По умолчанию — английский |
| **Использовать перевод Whisper, когда целевой язык — English** | Если целевой язык — английский, переводит Whisper, а не MyMemory. (Бесплатно и без квоты, но выше задержка.) Для других целевых языков не действует |
| **Сервис перевода** | MyMemory |

### Email (необязательно)

MyMemory бесплатен. Его дневная квота зависит от того, указан ли email:

- Без email: 5,000 символов в день
- С email: 50,000 символов в день (бесплатно, регистрация в MyMemory не нужна)

Введите email и нажмите **Сохранить**. Этот email **Общий с переводом чата**.

Полоса ниже показывает **Использовано сегодня (примерно, сброс ежедневно в 08:00 UTC)**. Когда квота исчерпана, отображается **Квота исчерпана**.

## Шаг 5: Оформление

На вкладке **Оформление** можно изменить внешний вид субтитров. Изменения сохраняются сразу.

- **Предпросмотр**: показывает пример субтитров. Поле цвета рядом меняет только фон предпросмотра
- **Выравнивание**: **По левому краю** (по умолчанию), **По центру** или **По правому краю**
- **Шрифт**: одна строка для **Исходный язык** (исходный текст) и одна для **Целевой язык** (перевод). В каждой строке есть шрифт, цвет и размер (8–120 px). По умолчанию 14 px для исходного текста и 22 px для перевода
- **Тень**: цвет тени текста
- **Сбросить по умолчанию**: восстанавливает оформление по умолчанию

## Часто задаваемые вопросы

**Q: Я удерживаю горячую клавишу, но ничего не происходит.**
Проверьте, что переключатель рядом с **Голосовой перевод** в левом меню включён, а **Статус модели** показывает **Готово**.

**Q: Запись работает, но субтитры в OBS не появляются.**
Если MyMemory не может выполнить перевод (например, дневная квота исчерпана), субтитры не показываются. Проверьте полосу **Использовано сегодня**. Указание email повышает квоту. Если целевой язык — английский, можно также включить **Использовать перевод Whisper, когда целевой язык — English**, у которого нет квоты.
