# Таймер

Показывайте в трансляции таймеры обратного отсчёта или секундомеры. Обратный отсчёт может получать или терять время по нажатию кнопок или автоматически — от фолловеров, подписок и Bits в Twitch, а также от донатов.

На странице две вкладки: **Настройки** и **Создать таймер**. Сначала создайте таймер, затем управляйте им на вкладке **Настройки**.

## Шаг 1: Создайте таймер

1. Откройте **Таймер** в левом меню и перейдите на вкладку **Создать таймер**
2. В разделе **Мои таймеры** нажмите **Добавить**. Будет создан новый таймер обратного отсчёта с начальным временем 10 минут и тремя опциями времени (+30 с, +1 мин, +5 мин)
3. Нажмите на карточку таймера, чтобы изменить его. Нажмите **✕** на карточке, чтобы удалить этот таймер

**Предпросмотр** показывает, как выглядит выбранный таймер. С помощью поля цвета рядом можно изменить фон предпросмотра.

Под предпросмотром переключайтесь между **Настройки таймера** и **Оформление**.

## Шаг 2: Настройки таймера

### Режим отсчёта

- **Обратный отсчёт**: отсчитывает время вниз от начального
- **Секундомер**: отсчитывает время вверх от 0 и может записывать круги. В режиме секундомера нет начального времени, времени предупреждения, звука окончания и опций времени

### Имя

Название, отображаемое в списке таймеров, выпадающих списках и Быстрых инструментах.

### Начальное время

Начальное время обратного отсчёта в часах, минутах и секундах. Рядом отображается общее количество секунд.

### Время предупреждения

Когда оставшееся время достигает этого значения, текст таймера меняет цвет на **Предупреждение**, заданный в разделе **Оформление**. Оставьте 0, чтобы не использовать предупреждение.

### Звук окончания отсчёта

Звук, воспроизводимый, когда обратный отсчёт доходит до 0. Выберите **Нет** или один из встроенных звуков (**Колокольчик**, **Монета**, **Звон**, **Хлопок**, **Фанфары**). Нажмите **▶**, чтобы прослушать его. Чтобы использовать свой файл, нажмите **Выбрать звук** и выберите его в менеджере ресурсов.

Звук воспроизводится источником «Браузер» в OBS, поэтому для источника таймера включите **Управлять аудио с помощью OBS**. См. [Как добавить источники в OBS](../getting-started/obs-source).

### Опции времени

Опции времени — это кнопки добавления/убавления времени для обратного отсчёта. У каждого таймера их может быть до 20.

Чтобы добавить опцию, заполните форму **Добавить опцию времени**:

1. **Источник срабатывания**: выберите, что автоматически применяет эту опцию
   - **Вручную**: применяется только при нажатии кнопки
   - **Отслеживание**: применяется при каждом новом фолловере Twitch
   - **Twitch Bits**: применяется при чирах Bits
   - **Новая подписка Twitch**: применяется при подписках Twitch
   - **Донат**: применяется при донатах. В **Платформы донатов** выберите, какие из **YouTube**, **O'Pay**, **ECPay** и **PayPal** учитываются
2. Для **Twitch Bits** и **Донат** также задайте:
   - **Порог срабатывания**: количество Bits или сумма доната для одного шага
   - **Способ пересчёта**: **Срабатывание по кратным значениям** или **Пропорциональный пересчёт** (см. пример ниже)
3. **Добавить время**: выберите **＋** или **－**, затем задайте часы, минуты и секунды
4. Нажмите **Добавить**

Чтобы изменить опцию, нажмите её **Изменить**, измените форму, затем нажмите **Сохранить** (или **Отмена**). Нажмите **✕**, чтобы удалить её. Опции с автоматическим срабатыванием отмечены 🔗 и названием триггера.

**Пример пересчёта**: Порог срабатывания 100 bits, Добавить время +1 мин, зритель отправляет чир на 250 bits:

- **Срабатывание по кратным значениям**: учитываются только полные кратные порога → 2 × 1 мин = **+2 мин**
- **Пропорциональный пересчёт**: 250 ÷ 100 × 1 мин → **+2 мин 30 с**

Для донатов сумма перед сравнением с порогом пересчитывается в валюту, выбранную в Настройках приложения.

:::note
- Автоматические триггеры влияют только на таймеры обратного отсчёта
- Опции времени с автоматическим срабатыванием всё равно отображаются как кнопки на панели управления, поэтому их можно нажимать и вручную
- **Новая подписка Twitch** применяется один раз на каждое событие подписки: подарок из нескольких подписок применяет её один раз. Повторные подписки применяют её, только если включено **Учитывать повторные подписки** в [Полосе целей Twitch](./goal)
:::

### Горячие клавиши управления

Задайте горячие клавиши для этого таймера:

- **Старт/пауза**
- **Горячая клавиша круга** (только для секундомера)
- **Горячая клавиша сброса**

См. также [Горячие клавиши](./hotkeys).

## Шаг 3: Оформление

| Параметр | Описание |
|---------|-------------|
| **Шрифт** | Шрифт текста времени |
| **Размер шрифта** | 12–300 px |
| **Цвет текста** | **Обычный**: **Сплошной** или **Градиент** (два цвета и **Угол**). **Предупреждение** (только для обратного отсчёта): цвет, используемый после достижения времени предупреждения |
| **Цвет фона** | Фон за временем |
| **Рамка** | Цвет контура, **Прозрачность** и **Толщина** (0–20 px) |
| **Тень** | Цвет тени, **Прозрачность**, **Размытие** и смещение **X** / **Y** |

## Шаг 4: Выберите режим отображения и добавьте источник OBS

Перейдите на вкладку **Настройки**. В разделе **Панель управления** выберите **Режим отображения**:

| Режим | Описание | URL источника для OBS |
|------|-------------|----------------|
| **Один таймер** | OBS показывает только выбранный таймер. Переключайте таймеры в выпадающем списке **Текущий таймер** | `http://127.0.0.1:7272/timer` |
| **Несколько таймеров** | У каждого таймера свой URL, и его можно добавить в OBS отдельно | `http://127.0.0.1:7272/timer/<timer ID>` |

В режиме **Несколько таймеров** выберите таймеры в **Добавить на отображение**. Каждый добавленный таймер получает свою карточку со своим **URL источника для OBS**. Нажмите **Копировать**, чтобы скопировать его. Нажмите **✕** на карточке, чтобы убрать его с отображения.

Добавьте скопированный URL в OBS как источник «Браузер». См. [Как добавить источники в OBS](../getting-started/obs-source).

:::tip
Также включите переключатель рядом с **Таймер** в левом меню (**Включить вывод в OBS**). Пока он выключен, таймер в OBS скрыт.
:::

## Шаг 5: Управление таймером

На каждой карточке таймера на вкладке **Настройки** есть:

- **Старт** / **Пауза**: у секундомера кнопка паузы называется **Остановить**. Обратный отсчёт, дошедший до 0, нельзя запустить, пока вы не сбросите его или не добавите время
- **Круг** (только для секундомера): записывает круг во время работы. Круги перечисляются под карточкой со временем и разницей с предыдущим кругом
- **Сброс**: останавливает таймер и возвращает его к начальному времени (0 для секундомера), очищая круги
- **Добавить время** (только для обратного отсчёта): по одной кнопке на каждую опцию времени

Текущее время отображается только в оверлее OBS, а не на странице настроек. Также управлять таймерами можно из окна [Быстрые инструменты](./quick-tools), где тоже показывается текущее время.
