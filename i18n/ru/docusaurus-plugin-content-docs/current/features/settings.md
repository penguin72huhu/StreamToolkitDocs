# Настройки

Нажмите **⚙️ Настройки** внизу левого меню. На этой странице находятся общие параметры приложения, подключения платформ и платёжные шлюзы для донатов.

## Общие

| Параметр | Что делает | По умолчанию |
|------|------|------|
| **Тема** | Режим отображения интерфейса: **Тёмная** или **Светлая** | Тёмная |
| **Язык** | Язык интерфейса; переключается сразу | — |
| **При нажатии X сворачивать в трей** | Закрытие окна сворачивает его в трей вместо выхода из программы | Вкл. |
| **Валюта донатов** | Общая валюта, используемая полосой донатов, уведомлениями и всеми другими отображениями сумм | Задаётся при первом запуске по языку системы (например, китайский традиционный (Тайвань) → TWD, японский → JPY, остальные → USD) |

## Подключение платформ

### Twitch

Нажмите **Подключить аккаунт** и подтвердите авторизацию в браузере. После подключения отображается **Подключено @ваше-имя** и кнопка **Отключить**. Подробные шаги: [Настройки Twitch](../platforms/twitch).

После подключения в **▸ Настройки пересчёта** задаётся, сколько стоят Bits и подписки в вашей валюте донатов:

- **Механизм распределения дохода**: **50 / 50** или **70 / 30**
- **За 100 Bits**, **Подписка Tier 1**, **Подписка Tier 2**, **Подписка Tier 3**
- **Сохранить** сохраняет значения для текущей валюты; **Сбросить по умолчанию** подставляет встроенные значения для этой валюты

### YouTube

1. Нажмите **Подключить аккаунт** и войдите через Google. Пошагово: [Настройки YouTube](../platforms/youtube-settings)
2. После подключения отображается **Подключено: название канала**. **Отключить** отвязывает аккаунт
3. Выберите, как находить чат трансляции:
   - **Определять текущую трансляцию**: требуется вход через Google. Нажмите **Подключить**, чтобы найти на вашем канале текущую или запланированную трансляцию. Если их несколько, выберите одну из списка
   - **Указать URL вручную**: вставьте **URL чата**
4. **Запрашивать URL чата при каждом запуске программы**: необязательно

**▸ Настройки пересчёта** в разделе YouTube задают стоимость спонсорства (YouTube не передаёт сумму для спонсорства):

- **Настройки уровней спонсорства**: добавьте название каждого уровня и его стоимость. Названия уровней должны в точности совпадать с вашим каналом YouTube
- **Уровни не из списка**: стоимость для уровня, которого нет в таблице
- **Уровень подаренных спонсорств**: каким уровнем считаются подаренные спонсорства
- Уровни, встреченные в событиях, но отсутствующие в таблице, показываются с кнопками **Добавить в таблицу** / **Игнорировать**

## Интеграция платформ донатов

Нажмите на шлюз, чтобы развернуть его. У каждого есть ссылка **Инструкция здесь** на руководство по настройке:

- [PayPal](../payments/paypal)
- [Stripe](../payments/stripe)
- [O'Pay](../payments/opay)
- [ECPay](../payments/ecpay)

### Тест уведомления

Кнопка **Тест уведомления** рядом с заголовком открывает окно тестирования:

- Заполните **Тестовое имя**, **Тестовое сообщение**, **Тестовая сумма**, выберите **Тестовая платформа**, затем нажмите **Отправить тестовое уведомление**
- **Тест Super Chat YouTube**: введите **Строка суммы**, например `$5.00` или `NT$150`, и нажмите **Отправить тестовый Super Chat**, чтобы проверить распознавание суммы и пересчёт валюты

## О программе

Нажмите кнопку **i** рядом с «Stream Toolkit» вверху левого меню, чтобы увидеть версию, автора и ссылку на официальную документацию.

:::info Ограничения пробной версии
- **Интеграция платформ донатов** доступна только в полной версии
- **Настройки пересчёта** спонсорства YouTube доступны только в полной версии

См. [Сравнение пробной и полной версий](../getting-started/trial-comparison).
:::
