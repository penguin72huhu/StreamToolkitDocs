# Часы

Показывайте текущее время в трансляции, при желании — вместе с датой и днём недели.

## Шаг 1: Добавьте источник OBS

Скопируйте **URL источника для OBS** вверху страницы:

```
http://127.0.0.1:7272/clock
```

Добавьте его в OBS как источник «Браузер». См. [Как добавить источники в OBS](../getting-started/obs-source). Часы не воспроизводят звук, поэтому включать «Управлять аудио с помощью OBS» не нужно.

:::tip
Также включите переключатель рядом с **Часы** в левом меню (**Включить вывод в OBS**). Пока он выключен, часы в OBS скрыты.
:::

## Предпросмотр

**Предпросмотр** вверху показывает реальный оверлей OBS и обновляется при изменении настроек. С помощью поля цвета рядом можно изменить фон предпросмотра.

Под предпросмотром три вкладки: **Оформление**, **Формат часов** и **Настройки отображения**.

## Оформление

| Параметр | Описание |
|---------|-------------|
| **Шрифт** | Шрифт для всего текста часов |
| **Стиль** | Расположение времени, даты и дня недели: **Stack**, **Horizontal**, **One-Top-Two-Bottom** или **Two-Top-One-Bottom**. **Межстрочный интервал** доступен во всех вариантах, кроме **Horizontal**, а **Интервал** — во всех, кроме **Stack** (оба от −200 до 200 px) |
| **Порядок** | Перетаскивайте блоки **Время**, **Дата** и **День недели**, чтобы изменить их порядок |
| **Текст** | Отдельно для **Время**, **Дата** и **День недели**: **Размер шрифта**, цвет (**Сплошной** или **Градиент** с двумя цветами и **Угол**), а также цвет **Рамка**, **Прозрачность** и **Толщина** (0–7 px) |
| **Тень** | Цвет тени, **Прозрачность**, **Размытие** и смещение **X** / **Y**, общие для всего текста |

Кнопка **Сбросить по умолчанию** находится вверху вкладки.

### Свой CSS

Нажмите **Свой CSS**, чтобы развернуть редактор. CSS по умолчанию содержит селекторы для каждой части часов (время, дата, день недели и их контейнеры) с комментариями. Используйте его для расположения и структуры. Цвета, шрифты и размеры задаются в настройках оформления выше.

- **Сбросить по умолчанию**: восстанавливает CSS по умолчанию
- **Управление ресурсами**: открывает менеджер ресурсов для изображений, используемых в вашем CSS

Если ваш CSS переопределяет свойство с `!important`, соответствующий элемент управления оформлением блокируется, поскольку CSS всё равно имеет приоритет.

## Формат часов

- **Формат времени**: **24 часа** или один из двух 12-часовых вариантов: **12 часов (до/после полудня)** показывает китайские обозначения 上午 / 下午, а **12 часов (AM/PM)** — AM/PM
- **Часовой пояс**: от UTC−12 до UTC+14. По умолчанию совпадает с часовым поясом вашего компьютера

## Настройки отображения

- **Показывать секунды**
- **Показывать дату**: если включено, выберите формат даты в выпадающем списке. Форматы с пометкой **Без года** не содержат год
  - **Дата с ведущим нулём**: однозначные месяцы и дни показываются с ведущим нулём (например, 2026/05/20)
  - **Формат года**: отображается для форматов, начинающихся с года. **Полный (2026)** или **Сокращённый (26)**

  Эти два параметра относятся к числовым форматам (с `/` или `-`). Форматы, записанные словами (например, «20 мая 2026 г.»), следуют языку интерфейса приложения
- **Показывать день недели**: если включено, выберите, как записывается день недели (например, **среда**, **СР** или **ср**)

:::info Ограничения пробной версии
**Свой CSS** доступен только в полной версии. Подробнее см. [Сравнение пробной и полной версий](../getting-started/trial-comparison).
:::
