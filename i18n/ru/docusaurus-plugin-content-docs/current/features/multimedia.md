# Media Board

Показывайте изображения, воспроизводите видео и звуковые эффекты в трансляции одним нажатием или горячей клавишей.

На странице три вкладки: **Изображение**, **Видео** и **Звук**. У каждой вкладки свой URL источника для OBS.

| Вкладка | URL источника для OBS | Управлять аудио с помощью OBS |
|-----|----------------|-----------------------|
| **Изображение** | `http://127.0.0.1:7272/imageboard` | Не нужно |
| **Видео** | `http://127.0.0.1:7272/videoboard` | Обязательно |
| **Звук** | `http://127.0.0.1:7272/soundboard` | Обязательно |

Нажмите **Копировать** рядом с каждым URL и добавьте его в OBS как источник «Браузер». См. [Как добавить источники в OBS](../getting-started/obs-source). Видео и звуки воспроизводятся в источнике OBS, а не внутри Stream Toolkit, поэтому для этих двух источников обязательно включите **«Управлять аудио с помощью OBS»**, иначе зрители их не услышат.

:::tip
Включите переключатель рядом с **Media Board** в левом меню (**Включить вывод в OBS**). Пока он выключен, изображения не показываются, а видео и звуки не воспроизводятся — ни кнопками, ни горячими клавишами.
:::

## Общие элементы управления

Изображения, видео и звуки отображаются в виде карточек:

- Нажмите на карточку, чтобы развернуть или свернуть её настройки
- Флажок справа на карточке: если он отмечен, элемент появляется в панели запуска [Быстрых инструментов](./quick-tools). Новые элементы отмечены по умолчанию
- **✕** удаляет элемент
- Если локальный файл был перемещён или удалён, на карточке отображается **Файл не найден**

### Горячие клавиши

Каждому элементу можно назначить свою горячую клавишу:

1. Разверните карточку и нажмите кнопку горячей клавиши
2. Нажмите нужную комбинацию клавиш и отпустите её. Нажмите **Esc** для отмены
3. Чтобы удалить горячую клавишу, нажмите **Очистить**

Если комбинация уже используется другой функцией, она не сохраняется, а на кнопке отображается сообщение о конфликте. Горячая клавиша работает, даже когда окно Stream Toolkit не активно. Все горячие клавиши также перечислены на странице [Горячие клавиши](./hotkeys).

## Изображение

{/* TODO: 截圖 — 圖片分頁 */}

### Добавление изображения

1. Нажмите **Добавить изображение**
2. Выберите файл (jpg, jpeg, png или gif). Имя файла становится названием изображения

В развёрнутой карточке отображаются миниатюра и следующие настройки:

- **Имя**: название изображения
- **Путь к файлу**: нажмите **Выбрать заново**, чтобы выбрать другой файл
- **Горячая клавиша**: нажмите один раз, чтобы показать изображение, и ещё раз, чтобы скрыть
- **Задать позицию и размер**: см. ниже
- **Удалить изображение**: удаляет изображение

### Показ и скрытие

Нажмите кнопку **○** на карточке, чтобы показать изображение в OBS. Она сменится на **◉**. Нажмите ещё раз, чтобы скрыть изображение.

### Настройки отображения

**Разрешить одновременный показ нескольких изображений** по умолчанию выключено. Пока оно выключено, показ изображения скрывает текущее. Включите, чтобы показывать несколько изображений одновременно.

### Задать позицию и размер

- **Позиция X** / **Позиция Y**: в px. 0/0 — центр источника. Положительные значения сдвигают вправо/вниз, отрицательные — влево/вверх
- **Ширина** / **Высота**: в % от исходного размера. 100 = исходный размер. Кнопка 🔗 фиксирует пропорции (включено по умолчанию). Нажмите её для свободного масштабирования
- Пока изображение показано, изменения сразу видны в OBS
- **Сохранить** сохраняет изменения, **Сбросить** возвращает значения на момент открытия окна, **Отмена** закрывает окно без сохранения

## Видео

{/* TODO: 截圖 — 影片分頁 */}

Нажмите **Добавить видео**, чтобы добавить карточку, затем разверните её:

- **Название видео**: название, отображаемое на карточке
- **Источник**: **YouTube** или **Локальное**
  - **YouTube**: вставьте ссылку на видео в **URL YouTube**. Нажмите **Проверить разбор**, чтобы проверить её. При успехе отображается «Разобрано, применится автоматически при воспроизведении»
  - **Локальное**: нажмите **Выбрать файл**, чтобы выбрать файл mp4, webm или ogg. Ограничение размера — 200MB, чем больше файл, тем выше задержка. Для прозрачного фона используйте видео WebM (VP9 Alpha)
- **Циклическое воспроизведение**: повторяет видео
- **Время воспроизведения**: задайте **С** и **До** (часы, минуты, секунды, мс). Оставьте **До** равным 00:00, чтобы воспроизводить до конца
- **Громкость**: 0–100%
- **Горячая клавиша**: нажмите, чтобы воспроизвести видео. Повторное нажатие во время воспроизведения останавливает его
- **Задать позицию и размер**: те же поля позиции и размера, что и для изображений. Нажмите **Зациклить предпросмотр**, чтобы видео воспроизводилось в OBS по кругу, пока вы его настраиваете, и **Остановить предпросмотр**, чтобы остановить. По завершении нажмите **Сохранить** или **Отмена**

Нажмите **▶** на карточке, чтобы воспроизвести видео в OBS. Нажмите **■**, чтобы остановить.

## Звук

{/* TODO: 截圖 — 音效分頁 */}

Нажмите **Добавить звук**, чтобы добавить карточку, затем разверните её:

- **Название звука**: название, отображаемое на карточке
- **Источник**: **URL YouTube** или **Локальный файл**
  - **URL YouTube**: вставьте ссылку и нажмите **Проверить разбор**, чтобы проверить её
  - **Локальный файл**: нажмите **Выбрать файл**, чтобы выбрать файл mp3, wav, ogg, flac, m4a, aac или opus
- **Время воспроизведения**: задайте **С** и **До**. Оставьте **До** равным 00:00, чтобы воспроизводить до конца
- **Громкость**: 0–100%
- **Горячая клавиша**: нажмите, чтобы воспроизвести звук

Нажмите **▶** на карточке, чтобы воспроизвести звук в OBS. Нажмите **■**, чтобы остановить. Одновременно воспроизводится только один звук: запуск другого звука останавливает текущий.

:::info Ограничения пробной версии
- Можно добавить только **1** изображение, **1** видео и **1** звук
- В оверлеях изображений и видео отображается водяной знак

Подробнее см. [Сравнение пробной и полной версий](../getting-started/trial-comparison).
:::

## Часто задаваемые вопросы

**Q: Видео или звуки воспроизводятся, но в трансляции нет звука.**
Убедитесь, что для источников `/videoboard` и `/soundboard` включено **«Управлять аудио с помощью OBS»** и что источники не отключены в микшере аудио OBS.

**Q: Не получается выбрать видеофайл.**
Можно выбрать только файлы mp4, webm и ogg размером до 200MB. Если файл больше, появляется сообщение с ограничением, и файл не добавляется.
