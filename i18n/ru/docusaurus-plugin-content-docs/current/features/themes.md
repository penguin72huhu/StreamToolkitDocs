# Темы оформления

Делитесь оформлением оверлеев и скачивайте его через Steam Workshop. Тема может включать оформление следующих функций:

- [Чат](./chat)
- [Полоса донатов](./donate)
- [Уведомления о донатах](./donate-alert)
- [Оповещения о новых подписчиках](./fan-alert)
- [Дни рождения зрителей](./birthday-alert)
- [Панель донатов](./sponsors)
- [Опросы](./vote)
- [Часы](./clock)
- [Полоса целей Twitch](./goal): **Цель по подписчикам**, **Цель по подпискам**, **Цель по Bits**

Откройте раздел через **🎨 Темы оформления** внизу левого меню. На странице две вкладки: **Мои темы** и **Загруженные темы**. Steam должен быть запущен.

## Поиск и применение темы на странице функции

На странице каждой из перечисленных функций откройте раздел **Свой CSS** и нажмите **Обзор тем Workshop**:

1. **Найти темы** показывает темы Workshop для этой функции. Введите текст в поле **Поиск по названию темы** и нажмите **Поиск** или листайте страницы кнопками **Назад** / **Далее**
2. Нажмите на миниатюру, чтобы посмотреть изображение превью
3. Нажмите **Применить**. Тема будет подписана, загружена и применена к этой функции
4. **Подписки** показывает темы, на которые вы уже подписаны для этой функции

Пока тема применена, на странице отображается **Используемая тема: (название)** и кнопка **Восстановить**, а свой CSS доступен только для чтения. Нажмите **Восстановить**, чтобы вернуться к своим настройкам.

## Загруженные темы

Здесь перечислены все темы, на которые вы подписаны в Steam. Подписанные темы не применяются автоматически — используйте кнопки на карточке. OBS обновляется сразу.

На каждой карточке показаны превью, название, **Используется**, если тему использует какая-либо функция, и **Включает:** — функции, которые охватывает тема (✓ отмечает функции, использующие её сейчас).

| Кнопка | Что делает |
|------|------|
| **Применить всё** | Применяет тему ко всем функциям, которые она включает. Если функция использует другую тему, вас попросят подтвердить замену |
| **Выбрать…** | Выберите, к каким функциям её применить |
| **Восстановить всё** | Возвращает все функции, использующие эту тему, к вашим собственным настройкам, действовавшим до её применения |
| **Восстановить…** | Выберите, какие функции восстановить |
| **Отписаться** | Отменяет подписку. Если тема используется, эти функции сначала восстанавливаются |

После применения внизу на 30 секунд появляется сообщение о внесённых изменениях с кнопкой **Восстановить** для отмены.

:::note
- При восстановлении возвращаются ваши собственные настройки, а не заменённая тема
- Изменения оформления, сделанные, пока тема была применена, после восстановления не сохраняются
:::

- **Загрузка…**: не закрывайте Steam — применить тему можно будет после окончания загрузки
- **Удалённая тема (#id)**: темы больше нет в ваших подписках Steam, но некоторые функции всё ещё её используют. Изображения могут не отображаться, поэтому рекомендуется восстановить настройки
- Если Steam не запущен, запустите Steam и нажмите **Обновить**

## Мои темы: загрузка темы

1. Настройте оформление функций, которыми хотите поделиться, на их собственных страницах
2. На вкладке **Мои темы** нажмите **Загрузить новую тему**
3. Заполните:
   - **Название темы** (обязательно)
   - **Описание темы**
   - **Включённые функции** (хотя бы одна)
   - **Изображение превью** (обязательно, до 1MB): нажмите **Выбрать превью**
4. Отметьте флажок, подтверждающий, что у вас есть право распространять все изображения, шрифты и звуки в теме. Материалы, лицензированные только для личного или некоммерческого использования, загружать нельзя
5. Нажмите **Загрузить тему**

Если появилось сообщение «Сначала примите условия Steam Workshop в браузере», примите условия, чтобы тема стала публичной.

### Управление загруженными темами

У каждой загруженной темы есть:

- **Загрузить и применить**: применяет опубликованную тему к вашим функциям. Это перезаписывает текущие настройки оформления
- **Изменить**: заново загружает ваши текущие настройки оформления в ту же тему. Если вы не скачивали тему, существующее изображение превью не перенесётся, и нужно будет выбрать новое
- **Управлять в Steam**: открывает тему в Steam

:::info Ограничения пробной версии
Темы оформления (Steam Workshop) доступны только в полной версии. В пробной версии **🎨 Темы оформления** открыть нельзя, и темы применять нельзя.

См. [Сравнение пробной и полной версий](../getting-started/trial-comparison).
:::
