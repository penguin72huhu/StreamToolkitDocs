# Чат-бот

Автоматически публикует сообщения в вашем чате: сообщения по таймеру с заданным интервалом и ответы, когда зритель вводит команду. Бот пишет от имени вашего собственного аккаунта.

У чат-бота нет оверлея OBS, поэтому URL добавлять не нужно.

:::tip
Включите переключатель рядом с **Чат-бот** в левом меню. Пока он выключен, бот ничего не отправляет.
:::

На странице три вкладки: **Настройки**, **Сообщения по таймеру** и **Ответы на команды**.

## Вкладка «Настройки»

В разделе **Платформы** нажмите **Twitch**, чтобы включить его (нажмите ещё раз, чтобы выключить). Точка рядом загорается, когда Twitch подключён; иначе отображается **(не подключено)**. Сначала подключите Twitch: [Настройки Twitch](../platforms/twitch).

**YouTube** отмечен как **Скоро** и пока не может быть включён.

Если ни одна платформа не подключена, на двух других вкладках отображается «Ни одна платформа не подключена, поэтому бот ничего не отправит.» с кнопкой **К настройкам**.

## Сообщения по таймеру

Публикует сообщение через определённые промежутки времени, пока вы в эфире.

1. Нажмите **+ Добавить**
2. Заполните:
   - **Текст**: текст для публикации (до 500 символов в Twitch). Он всегда в одну строку: Enter ничего не делает, а вставленные переносы строк превращаются в пробелы
   - **Интервал**: минуты между публикациями (5–240, по умолчанию 15)
   - **Мин. сообщений**: сколько новых сообщений в чате нужно с момента последней публикации, прежде чем бот напишет снова (0–100, по умолчанию 2), чтобы он не писал в пустой чат
   - **Платформы**: куда публиковать
3. Нажмите **Сохранить**

Как происходит публикация:

- Только пока идёт ваша трансляция. Первая публикация появляется через полный интервал после начала эфира, а не в момент старта трансляции
- Если одновременно подходит время нескольких сообщений по таймеру, они распределяются по времени, а не публикуются вместе

## Ответы на команды

Отвечает, когда сообщение зрителя начинается с команды.

1. Нажмите **+ Добавить**
2. Заполните:
   - **Команда**: выберите префикс (`! @ # $ % & ~`), затем введите одно слово без пробелов, например `!dc`. Оно сравнивается с первым словом сообщения в чате без учёта регистра
   - **Ответ**: текст для публикации. `{user}` заменяется именем зрителя, который вызвал команду
   - **Перезарядка**: секунды до того, как та же команда сможет ответить снова (0–3600, по умолчанию 5)
   - **Платформы**: где отвечать
3. Нажмите **Сохранить**

Ответы на команды работают всегда — в эфире и вне его.

Команда не может совпадать с другим ответом на команду или с командой, уже используемой в [Заказе музыки](./song-request) или ключевым словом [Розыгрышей](./lottery).

## Управление списком

На обеих вкладках у каждого элемента есть:

- Флажок слева, чтобы включить или выключить элемент, не удаляя его
- Метки платформ; приглушённая метка означает, что эта платформа выключена на вкладке «Настройки»
- **Изменить** и **Удалить**
