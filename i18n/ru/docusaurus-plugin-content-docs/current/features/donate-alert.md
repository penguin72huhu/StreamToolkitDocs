# Уведомления о донатах

Когда кто-то отправляет донат, на экране появляется уведомление с изображением, звуком, именем донатера, суммой и сообщением.

## URL источника для OBS

```
http://127.0.0.1:7272/donate-alert
```

Скопируйте URL вверху страницы **Настройки Уведомления о донатах** и добавьте его в OBS как источник «Браузер». См. [Как добавить источники в OBS](../getting-started/obs-source).

:::warning
Уведомления воспроизводят звук. Включите **«Управлять аудио с помощью OBS»** в свойствах источника «Браузер», иначе звук не попадёт в трансляцию.
:::

Переключатель рядом с **Уведомления о донатах** в левом меню включает и выключает уведомления. Пока он выключен, уведомления не показываются (включая тестовые), но донаты по-прежнему записываются на [Панель донатов](./sponsors).

Если несколько донатов приходят почти одновременно, уведомления ставятся в очередь и показываются по одному.

## Вкладка «Настройки»

### Интеграция платформ

Отметьте платформы, которые должны вызывать уведомление: **Twitch**, **YouTube**, **PayPal**, **Stripe**, **O'Pay**, **ECPay**. Зелёная точка означает, что платформа подключена; иначе в строке отображается **(не подключено)**. Эти флажки влияют только на уведомления, а не на Полосу донатов или Панель донатов.

**Twitch ⚙️** (отображается, когда Twitch подключён и отмечен):

1. Выберите **Учитывать Bits и подписки**, **Учитывать только Bits** или **Учитывать только подписки**
2. **Учитывать повторные подписки**: вызывают ли повторные подписки уведомление (отображается, когда учитываются подписки)
3. **Менее [N] Bits не учитываются**: отметьте и введите минимум, чтобы небольшие cheer не вызывали уведомление (отображается, когда учитываются Bits)
4. Нажмите **Сохранить**

**YouTube ⚙️**:

- **Показывать имена зрителей вместо @идентификаторов**: доступно только после входа через Google.
- **Учитываемые события**: **Суперчат**, **Супер-стикер**, **Новый спонсор**, **Продление спонсорства**, **Подаренное спонсорство**, **Самоцветы**. Для **Самоцветы** нужен вход через Google.

Если чат трансляции YouTube не привязан, в строке отображается **URL чата не подключён** с кнопками **Автоподключение** (нужен вход через Google) и **Ввести вручную** (переход к полю URL чата в Настройках). Если отмечено событие спонсорства, но цены спонсорства не заданы, нажмите **⚠ Цены спонсорства не заданы**, чтобы задать их. См. [Настройки YouTube](../platforms/youtube-settings).

Чтобы подключить PayPal, Stripe, O'Pay или ECPay, см. [PayPal](../payments/paypal), [Stripe](../payments/stripe), [O'Pay](../payments/opay) и [ECPay](../payments/ecpay).

### Настройки

| Поле | Описание |
|-------|-------------|
| **Автоматически пересчитывать в свою валюту** | Включено по умолчанию. Показывает сумму, пересчитанную в **Валюта донатов**, заданную на странице Настройки. |
| **Длительность показа** | Сколько секунд каждое уведомление остаётся на экране. По умолчанию: 6. |

## Вкладка «Оформление»

### Предпросмотр

Предпросмотр использует ту же страницу, что и источник OBS. Палитрой рядом с **Предпросмотр** можно изменить фон предпросмотра, а кнопка **▶ Повторить анимацию** заново проигрывает анимацию уведомления.

### Единый стиль / Отдельно по платформам

- **Единый стиль**: все платформы используют один стиль уведомления.
- **Отдельно по платформам**: у каждой платформы свой стиль. Выберите платформу кнопками ниже (**Twitch**, **YouTube**, **O'Pay**, **ECPay**, **PayPal**, **Stripe**) и измените её настройки. При первом переключении платформы, которые вы ещё не настраивали, копируют текущий единый стиль, каждая со своим цветом шкалы обратного отсчёта.

**Сбросить по умолчанию** восстанавливает стиль по умолчанию для редактируемого стиля.

### Изображение

- **Выбрать изображение**: выберите изображение в менеджере ресурсов. Без него показывается эмодзи сердечка. **Очистить** удаляет изображение.
- **Размер изображения**: 1–400 px.
- **Позиция изображения**: **Слева**, **Справа**, **Сверху** или **Снизу**.

### Звук

Выберите встроенный звук: **Нет**, **Колокольчик** (по умолчанию), **Монета**, **Звон**, **Хлопок**, **Фанфары**. Нажмите **▶**, чтобы прослушать. Нажмите **Выбрать звук**, чтобы использовать собственный звуковой файл из менеджера ресурсов.

### Отображение текста

- **По умолчанию**: сумма, имя донатера и сообщение показываются на отдельных строках.
- **Свой текст**: напишите собственную строку. Используйте `{name}` для имени донатера и `{amount}` для суммы, например `Thanks {name} for donating {amount}!`

### Текст и цвет

- **Текст**: задайте шрифт, размер и цвет для **Сумма**, **Имя донатера** и **Сообщение** (а также **Свой текст** в режиме «Свой текст»).
- **Цвет**: **Фон**, **Тень** и **Шкала обратного отсчёта**.

### Свой CSS

Разверните **Свой CSS**, чтобы изменить CSS редактируемого стиля (единого или выбранной платформы). **Сбросить по умолчанию** восстанавливает CSS шаблона, а **Управление ресурсами** открывает менеджер ресурсов. Здесь же можно применять темы Мастерской Steam. Пока тема применена, CSS доступен только для чтения. См. [Темы оформления](./themes).

## Тестирование уведомлений

На странице **Настройки** нажмите **Тест уведомления** рядом с **Интеграция платформ донатов**:

1. Заполните **Тестовое имя**, **Тестовое сообщение** и **Тестовая сумма**, выберите **Тестовая платформа**
2. Нажмите **Отправить тестовое уведомление**

В разделе **Тест Super Chat YouTube** можно ввести исходную **Строка суммы** (например, `$5.00`, `¥500`, `NT$150`) и нажать **Отправить тестовый Super Chat**, чтобы проверить разбор суммы и пересчёт валюты.

:::note
Тестовое уведомление обрабатывается как настоящий донат: оно также добавляется на [Полосу донатов](./donate) и [Панель донатов](./sponsors), если там отмечены эти платформы.
:::

:::info Пробная версия
Свой CSS доступен только в полной версии. Реальные платёжные шлюзы (PayPal / Stripe / O'Pay / ECPay), события спонсорства YouTube и Самоцветы недоступны в пробной версии, а на уведомлении в OBS отображается водяной знак. См. [Сравнение пробной и полной версий](../getting-started/trial-comparison).
:::

## Часто задаваемые вопросы

**Q: В трансляции нет звука?**
Убедитесь, что в свойствах источника «Браузер» включено **«Управлять аудио с помощью OBS»** и что источник не отключён в микшере аудио OBS. Также проверьте, что для **Звук** не выбрано **Нет**.

**Q: Я добавил источник OBS позже. Будут ли воспроизведены прошлые уведомления?**
Нет. Только что открытый источник показывает лишь уведомления, пришедшие после его подключения.
