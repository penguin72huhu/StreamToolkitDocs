# Полоса целей Twitch

Показывайте в трансляции полосы прогресса для целей Twitch по фолловерам, подпискам и Bits. У каждого типа цели своя полоса, свои настройки и свой URL для OBS.

:::note Перед началом
Полосы целей считают события Twitch, поэтому сначала подключите аккаунт Twitch. См. [Настройки Twitch](../platforms/twitch).
:::

## Шаг 1: Выберите тип цели и добавьте источник OBS

Вверху страницы выберите тип цели: **Отслеживание**, **Подписки** или **Bits**. **URL OBS** под кнопками меняется соответственно. Нажмите **Копировать**, чтобы скопировать его.

| Тип цели | URL источника для OBS |
|-----------|----------------|
| **Отслеживание** | `http://127.0.0.1:7272/goal/follow` |
| **Подписки** | `http://127.0.0.1:7272/goal/sub` |
| **Bits** | `http://127.0.0.1:7272/goal/bits` |

Добавьте каждую полосу, которую хотите показывать, в OBS как отдельный источник «Браузер». См. [Как добавить источники в OBS](../getting-started/obs-source). Полосы целей не воспроизводят звук, поэтому включать «Управлять аудио с помощью OBS» не нужно.

:::tip
Также включите переключатель рядом с **Полоса целей Twitch** в левом меню (**Включить вывод в OBS**). Пока он выключен, полосы в OBS скрыты.
:::

## Шаг 2: Задайте цель

Все настройки ниже относятся к типу цели, выбранному вверху.

- **Заголовок**: текст заголовка на полосе
- **Цель**: целевое число (целые числа, 0 или больше)
- **Прогресс**: показывает текущее значение, цель и процент

### Как считается прогресс

| Тип цели | Что увеличивает прогресс |
|-----------|----------------------|
| **Отслеживание** | Каждый новый фолловер добавляет 1. Пока Twitch подключён, значение также каждые 30 секунд синхронизируется с общим числом фолловеров вашего канала в Twitch. Нажмите **Синхронизировать**, чтобы синхронизировать сразу |
| **Подписки** | Новые и подаренные подписки (подарок из нескольких подписок добавляет число подаренных подписок). Повторные подписки учитываются, только если включено **Учитывать повторные подписки** |
| **Bits** | Каждый чир добавляет количество отправленных Bits |

### Параметры подписок

Отображаются только для **Подписки**:

- **Взвешивать по Tier (T1=+1, T2=+2, T3=+6)**: если включено, подписки более высокого уровня добавляют больше к прогрессу. Если выключено, каждая подписка добавляет 1
- **Учитывать повторные подписки**: если включено, сообщения о повторной подписке тоже увеличивают прогресс

### Сброс прогресса

У **Подписки** и **Bits** есть кнопка **Сбросить прогресс**. Нажмите её, затем **Да, сбросить**, чтобы вернуть текущее значение к 0. Целевое число сохраняется.

У **Отслеживание** кнопки сброса нет, поскольку значение следует общему числу фолловеров в Twitch.

## Шаг 3: Настройте оформление

### Предпросмотр

**Предпросмотр** вверху показывает полосу выбранного типа цели. С помощью поля цвета рядом можно изменить фон предпросмотра. Отметьте **Предпросмотр достижения**, чтобы увидеть, как выглядит полоса после достижения цели.

### Настройки оформления

| Параметр | Описание |
|---------|-------------|
| **Цвет фона** | Фон полосы |
| **Цвет полосы прогресса** | Цвет заполненной части |
| **Цвет при достижении** | Цвет заполнения после достижения цели |
| **Текст заголовка** | Шрифт, цвет и размер (8–72 px) заголовка |
| **Текст цели** | Шрифт, цвет и размер (8–72 px) чисел |
| **Проценты** | Шрифт, цвет и размер (8–72 px) процента |

Нажмите **Сбросить по умолчанию**, чтобы восстановить оформление выбранного типа цели.

### Свой CSS

Нажмите **Свой CSS**, чтобы развернуть редактор. У каждого типа цели свой CSS. Используйте его для расположения и структуры. Цвета, шрифты и размеры задаются в настройках оформления выше.

- **Сбросить по умолчанию**: восстанавливает CSS по умолчанию
- **Управление ресурсами**: открывает менеджер ресурсов для изображений, используемых в вашем CSS

Если ваш CSS переопределяет свойство с `!important`, соответствующий элемент управления оформлением блокируется, поскольку CSS всё равно имеет приоритет.

:::info Ограничения пробной версии
- **Свой CSS** доступен только в полной версии
- В оверлее OBS отображается водяной знак

Подробнее см. [Сравнение пробной и полной версий](../getting-started/trial-comparison).
:::
