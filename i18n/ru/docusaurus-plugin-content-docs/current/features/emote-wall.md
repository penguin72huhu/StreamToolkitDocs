# Стена эмоций

Когда зрители используют эмодзи в чате, они проплывают по экрану вашей трансляции.

:::note Перед началом
Стена эмоций берёт эмодзи из чата, поэтому сначала подключите используемые платформы. См. [Настройки Twitch](../platforms/twitch) и [Настройки YouTube](../platforms/youtube-settings).
:::

## Шаг 1: Добавьте источник OBS

Скопируйте **URL источника для OBS** вверху страницы:

```
http://127.0.0.1:7272/emote-wall
```

Добавьте его в OBS как источник «Браузер». См. [Как добавить источники в OBS](../getting-started/obs-source). Стена эмоций не воспроизводит звук, поэтому включать «Управлять аудио с помощью OBS» не нужно.

:::tip
Также включите переключатель рядом с **Стена эмоций** в левом меню (**Включить вывод в OBS**). Пока он выключен, эмодзи из чата не отправляются в оверлей.
:::

## Шаг 2: Выберите источники

В разделе **Источник** есть карточка для **Twitch** и карточка для **YouTube**. На каждой карточке показан статус подключения:

- Twitch показывает **(не подключено)**, если ваш аккаунт Twitch не подключён
- YouTube показывает **URL чата не подключён**, если чат YouTube не подключён

Отметьте **Включить стену эмодзи** на карточке, чтобы показывать эмодзи из чата этой платформы. Снимите флажок, чтобы игнорировать эту платформу.

## Шаг 3: Настройки анимации

| Параметр | Описание |
|---------|-------------|
| **Размер эмодзи** | Размер каждого эмодзи, 16–256 px |
| **Максимум эмодзи на сообщение** | Сколько эмодзи максимум берётся из одного сообщения чата (1–20) |
| **Длительность полёта** | Сколько длится полёт каждого эмодзи, 1–30 секунд |
| **Скорость полёта** | 50–500 px/s |

Нажмите **Сбросить по умолчанию** рядом с заголовком раздела, чтобы восстановить все четыре значения.

## Шаг 4: Тест

Нажмите **Тест (показать в OBS)**, чтобы отправить в оверлей примеры эмодзи Twitch с текущими настройками. Количество тестовых эмодзи соответствует значению **Максимум эмодзи на сообщение**.
