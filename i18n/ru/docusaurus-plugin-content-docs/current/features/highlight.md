# Метка лучших моментов трансляции

Нажмите горячую клавишу во время трансляции, чтобы записать, «на какой минуте эфира» случился яркий момент. Позже по списку времён можно найти эти моменты в записи трансляции при монтаже.

Метки сохраняются в Stream Toolkit. У этой функции нет оверлея OBS, поэтому добавлять источник OBS не нужно.

На странице две вкладки: **Настройки** и **История хайлайтов**.

:::tip
Включите переключатель рядом с **Метка лучших моментов трансляции** в левом меню. Пока он выключен, ни горячая клавиша, ни кнопка **MARK** не добавляют метку.
:::

## Шаг 1: Выберите источник

**Источник** определяет, как вычисляется время трансляции:

| Источник | Как вычисляется время | Требование |
|--------|----------------------------|-------------|
| **Twitch** | Время с начала текущей трансляции Twitch | Подключённый Twitch. См. [Настройки Twitch](../platforms/twitch) |
| **YouTube** | Время с начала текущей трансляции YouTube | Вход через Google. См. [Настройки YouTube](../platforms/youtube-settings) |
| **Ручное выравнивание** (по умолчанию) | Значение ручного таймера на этой странице | Нет |

Точка рядом с **Twitch** и **YouTube** показывает, подключена ли платформа. Если нет, у варианта отображается **(не подключено)** или **(вход в Google не выполнен)**.

Если поставить метку, когда вы не в эфире (или, для **Ручное выравнивание**, когда таймер остановлен), время записывается как **Трансляция не идёт**. С источником **Twitch** этот результат может появиться примерно через 20 секунд, потому что Stream Toolkit делает несколько повторных попыток на случай, если Twitch ещё не зарегистрировал только что начатую трансляцию.

### Ручной таймер

Когда выбрано **Ручное выравнивание**, появляется **Ручной таймер**:

1. Введите текущее время трансляции в формате `HH:MM:SS` (например, `00:00:00` в момент начала эфира)
2. Нажмите **Начать синхронизацию**. Таймер начинает отсчёт вверх от этого значения
3. Каждая метка использует текущее значение таймера
4. Нажмите **Остановить**, чтобы остановить таймер

### Создавать клип Twitch при отметке

Этот параметр появляется, только если источник — **Twitch**. Если он включён, каждая метка также создаёт клип Twitch.

- Должен идти эфир. Клип длится около 30 секунд
- Клипы сохраняются в «Панель управления → Контент → Клипы»
- После отметки на странице отображается **Клип Twitch создан** или причина ошибки: **Вы не в эфире**, **Недостаточно прав; переподключите Twitch**, **Twitch не подключен** или **Ошибка; повторите позже**

## Шаг 2: Задайте горячую клавишу

Горячая клавиша по умолчанию — `Ctrl+Shift+M`. Чтобы изменить её:

1. Нажмите кнопку горячей клавиши
2. Нажмите нужное сочетание клавиш и отпустите его. Нажмите **Esc**, чтобы отменить
3. Чтобы удалить её, нажмите **Очистить**

Если сочетание уже используется другой функцией, на кнопке отображается **Эта горячая клавиша уже используется**, и она не сохраняется. Горячая клавиша работает, даже когда Stream Toolkit не является активным окном.

Также можно нажать кнопку **MARK** под горячей клавишей. Она делает то же самое, что и горячая клавиша. В окне [Быстрые инструменты](./quick-tools) тоже есть кнопка **MARK**.

## Шаг 3: Отмечайте во время трансляции

1. (Необязательно) Перед отметкой введите имя в поле **Название метки**. Если оставить его пустым, метки нумеруются автоматически (`精華標記_1`, `精華標記_2`, …)
2. Нажмите горячую клавишу или кнопку **MARK**

Введённое имя используется только для следующей метки, после чего поле очищается.

## История хайлайтов

На вкладке **История хайлайтов** перечислены все метки, сначала новые. В каждой строке показаны время трансляции, имя, источник, а также дата и время отметки.

- **Копировать**: копирует метку как текст в формате `[date] name 🎬 stream time (source)`
- **🗑️**: нажмите, затем **Подтвердить удаление**, чтобы удалить метку
- **Открыть клип Twitch**: появляется, если для этой метки был создан клип Twitch. Открывает клип в Twitch
