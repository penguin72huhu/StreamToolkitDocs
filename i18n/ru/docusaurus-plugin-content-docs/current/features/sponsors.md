# Панель донатов

Показывает в трансляции список последних донатов: значок платформы, имя донатера, сумму и сообщение.

## URL источника для OBS

```
http://127.0.0.1:7272/sponsors
```

Скопируйте URL вверху страницы **Настройки Панель донатов** и добавьте его в OBS как источник «Браузер». См. [Как добавить источники в OBS](../getting-started/obs-source).

С помощью переключателя рядом с **Панель донатов** в левом меню можно показать или скрыть панель в OBS. Когда он выключен, панель плавно исчезает. Донаты при этом продолжают записываться.

## Вкладка «Настройки»

### Интеграция платформ

Отметьте платформы, донаты с которых нужно записывать: **Twitch**, **YouTube**, **PayPal**, **Stripe**, **O'Pay**, **ECPay**. Зелёная точка означает, что платформа подключена; иначе в строке отображается **(не подключено)**. Эти флажки влияют только на панель, а не на Полосу донатов или Уведомления о донатах.

**Twitch ⚙️** (отображается, когда Twitch подключён и отмечен):

1. Выберите **Учитывать Bits и подписки**, **Учитывать только Bits** или **Учитывать только подписки**
2. **Учитывать повторные подписки**: записывать ли повторные подписки (отображается, когда учитываются подписки)
3. **Менее [N] Bits не учитываются**: отметьте и введите минимум, чтобы небольшие чиры не записывались (отображается, когда учитываются Bits)
4. Нажмите **Сохранить**

**YouTube ⚙️**:

- **Показывать имена зрителей вместо @идентификаторов**: доступно только после входа через Google.
- **Учитываемые события**: **Суперчат**, **Супер-стикер**, **Новый спонсор**, **Продление спонсорства**, **Подаренное спонсорство**, **Самоцветы**. Для **Самоцветы** требуется вход через Google. Подарки Самоцветами отображаются значком самоцвета с их количеством вместо денежной суммы.

Если чат трансляции YouTube не привязан, в строке отображается **URL чата не подключён** с кнопками **Автоподключение** (требуется вход через Google) и **Ввести вручную** (переводит к полю URL чата в Настройках). Если отмечено событие спонсорства, но цены спонсорства не заданы, нажмите **⚠ Цены спонсорства не заданы**, чтобы задать их. См. [Настройки YouTube](../platforms/youtube-settings).

Как подключить PayPal, Stripe, O'Pay или ECPay, см. [PayPal](../payments/paypal), [Stripe](../payments/stripe), [O'Pay](../payments/opay) и [ECPay](../payments/ecpay).

### Настройки

| Поле | Описание |
|-------|-------------|
| **Автоматически пересчитывать в свою валюту** | Включено по умолчанию. Показывает суммы, пересчитанные в **Валюта донатов**, заданную на странице Настройки. |
| **Максимум показывать** | Сколько записей хранить (1–100). По умолчанию: 20. Когда приходит новый донат сверх этого лимита, самая старая запись удаляется. |

## Вкладка «Оформление»

### Предпросмотр

С помощью палитры цвета рядом с **Предпросмотр** можно изменить фон предпросмотра. Нажмите **Тест анимации добавления**, чтобы воспроизвести анимацию появления на примере записи. Пример не сохраняется в истории.

Нажмите **Сбросить по умолчанию**, чтобы восстановить оформление по умолчанию.

### Настройки отображения

- **Показывать иконку платформы**: показывать значок платформы у каждой записи.
- **Направление появления**: **Сверху вниз** (по умолчанию), **Снизу вверх**, **Слева направо** или **Справа налево**.

### Шрифт

Задайте шрифт, цвет и размер (8–72 px) для **Заголовок** (имя донатера), **Основной текст** (сообщение) и **Сумма**.

### Цвет фона

- **По умолчанию**: цвет фона для всех записей.
- **+ Добавить диапазон**: добавьте цвет с диапазоном **Сумма** (**Минимум** ~ **Максимум**). Записи, сумма которых попадает в диапазон, используют этот цвет. Оставьте Минимум или Максимум пустым, чтобы не ограничивать эту сторону. Нажмите **✕**, чтобы удалить диапазон.

Когда включено **Автоматически пересчитывать в свою валюту**, диапазон сравнивается с пересчитанной суммой.

### Свой CSS

Разверните **Свой CSS**, чтобы редактировать CSS панели. **Сбросить по умолчанию** восстанавливает CSS по умолчанию, а **Управление ресурсами** открывает менеджер ресурсов. Здесь также можно применять темы из Steam Workshop. Пока тема применена, CSS доступен только для чтения. См. [Темы оформления](./themes).

## Вкладка «История»

### Добавить вручную (для теста)

Выберите платформу, введите **Имя**, **Сумма** и при желании **Сообщение (необязательно)**, затем нажмите **Добавить**. Запись добавляется, только если эта платформа отмечена в разделе **Интеграция платформ**. Сумма считается в вашей валюте донатов.

### История

Показывает сохранённые записи и их количество.

- Нажмите **🗑**, а затем **Подтвердить удаление**, чтобы удалить одну запись.
- Нажмите **Очистить**, чтобы удалить все записи. Сначала появляется подтверждение. Это действие нельзя отменить.

:::info Пробная версия
Свой CSS доступен только в полной версии. Реальные платёжные шлюзы (PayPal / Stripe / O'Pay / ECPay), события спонсорства YouTube и Самоцветы недоступны в пробной версии, а на панели в OBS отображается водяной знак. См. [Сравнение пробной и полной версий](../getting-started/trial-comparison).
:::

## Часто задаваемые вопросы

**Q: Тестовые уведомления появляются на панели.**
**Тест уведомления** на странице Настройки обрабатывается как настоящий донат, поэтому он тоже записывается здесь, если эта платформа отмечена. Удалите его на вкладке **История**.
