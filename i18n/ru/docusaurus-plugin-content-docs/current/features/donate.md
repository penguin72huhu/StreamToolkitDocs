# Полоса донатов

Показывает в трансляции полосу прогресса к цели по донатам. Донаты с выбранных вами платформ автоматически добавляются к общей сумме.

## URL источника для OBS

```
http://127.0.0.1:7272/donate
```

Скопируйте URL вверху страницы **Настройки Полоса донатов** и добавьте его в OBS как источник «Браузер». См. [Как добавить источники в OBS](../getting-started/obs-source).

С помощью переключателя рядом с **Полоса донатов** в левом меню можно показать или скрыть полосу в OBS. Когда он выключен, полоса скрыта.

## Валюта

Полоса использует **Валюта донатов**, заданную на странице **Настройки**. Донаты в других валютах перед добавлением пересчитываются в эту валюту. Если валюту доната невозможно пересчитать, он не добавляется к полосе (Уведомления о донатах и Панель донатов всё равно показывают его в исходной валюте).

## Вкладка «Настройки»

### Интеграция платформ

Отметьте платформы, донаты с которых должны учитываться в полосе:

- **Twitch** — Bits и подписки
- **YouTube**
- **PayPal**
- **Stripe**
- **O'Pay**
- **ECPay**

Зелёная точка означает, что платформа подключена; иначе в строке отображается **(не подключено)**. Эти флажки определяют только то, что учитывает полоса. Они не влияют на Уведомления о донатах и Панель донатов, у которых свои списки платформ.

- **YouTube**: если чат трансляции не привязан, в строке отображается **URL чата не подключён** с двумя кнопками: **Автоподключение** (требуется вход через Google) и **Ввести вручную** (переводит к полю URL чата в Настройках). См. [Настройки YouTube](../platforms/youtube-settings).
- **YouTube ⚙️**: выберите, какие **Учитываемые события** добавляются к полосе: **Суперчат**, **Супер-стикер**, **Новый спонсор**, **Продление спонсорства**, **Подаренное спонсорство**, **Самоцветы**. Для **Самоцветы** требуется вход через Google.
- Если отмечено хотя бы одно событие спонсорства, но цены спонсорства не заданы, появляется **⚠ Цены спонсорства не заданы**. Нажмите на него, чтобы перейти в Настройки и ввести цены уровней в разделе YouTube **Настройки пересчёта**.
- Стоимость Twitch Bits и подписок задаётся в Настройки → Twitch → **Настройки пересчёта**. См. [Настройки Twitch](../platforms/twitch).
- Как подключить PayPal, Stripe, O'Pay или ECPay, см. [PayPal](../payments/paypal), [Stripe](../payments/stripe), [O'Pay](../payments/opay) и [ECPay](../payments/ecpay).

### Текущий прогресс

Показывает текущую сумму, цель и процент.

| Поле | Описание |
|-------|-------------|
| **Заголовок** | Необязательно. Отображается над полосой. |
| **Целевая сумма** | Целевая сумма в вашей валюте донатов. |
| **Добавить вручную** | Введите сумму и нажмите **Добавить** (или Enter), чтобы добавить её к общей сумме. |
| **Обнулить** | Сбрасывает текущую сумму до нуля. Сначала появляется подтверждение. Это действие нельзя отменить. |

## Вкладка «Оформление»

### Предпросмотр

Предпросмотр показывает полосу с примерными суммами. С помощью палитры цвета рядом с **Предпросмотр** можно изменить фон предпросмотра. Отметьте **Предпросмотр достижения**, чтобы увидеть полосу в завершённом состоянии.

### Шрифт и цвет

Нажмите **Сбросить по умолчанию**, чтобы восстановить оформление по умолчанию.

- **Шрифт**: задайте шрифт, цвет и размер (8–72 px) для **Заголовок**, **Сумма** и **Проценты**.
- **Цвет**: задайте **Фон**, **Шкала цели** (цвет заполнения) и **Шкала цели достигнута** (цвет заполнения после достижения цели).

### Свой CSS

Разверните **Свой CSS**, чтобы редактировать CSS полосы. **Сбросить по умолчанию** восстанавливает CSS по умолчанию, а **Управление ресурсами** открывает менеджер ресурсов для изображений, которые вы хотите использовать в CSS. Здесь также можно применять темы из Steam Workshop. Пока тема применена, CSS доступен только для чтения, пока вы её не восстановите. См. [Темы оформления](./themes).

:::info Пробная версия
Свой CSS доступен только в полной версии. Реальные платёжные шлюзы (PayPal / Stripe / O'Pay / ECPay), события спонсорства YouTube и Самоцветы недоступны в пробной версии, а в оверлее отображается водяной знак. См. [Сравнение пробной и полной версий](../getting-started/trial-comparison).
:::

## Часто задаваемые вопросы

**Q: После отправки тестового уведомления сумма увеличилась.**
**Тест уведомления** на странице Настройки считается настоящим донатом, поэтому добавляется к полосе (если эта платформа отмечена). После тестирования нажмите **Обнулить**, чтобы сбросить сумму до нуля.
