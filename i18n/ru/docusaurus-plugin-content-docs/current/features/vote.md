# Опросы

Проводите опрос в трансляции. Зрители голосуют, вводя номер варианта в чате Twitch или YouTube, а результаты обновляются в реальном времени в оверлее OBS.

## URL источника для OBS

```
http://127.0.0.1:7272/vote
```

Нажмите **Копировать** рядом с **URL источника для OBS** вверху страницы, затем добавьте его в OBS как источник «Браузер». См. [Как добавить источники в OBS](../getting-started/obs-source). Опросы не воспроизводят звук, поэтому включать «Управлять аудио с помощью OBS» не нужно.

:::tip
Также включите переключатель рядом с **Опросы** в левом меню (**Включить вывод в OBS**). Пока он выключен, оверлей скрыт.
:::

На странице три вкладки: **Настройки**, **Оформление** и **История**.

## Запуск опроса (вкладка «Настройки»)

### Платформа голосования

Нажмите **Twitch** или **YouTube**, чтобы выбрать, в чате какой платформы можно голосовать. Можно выбрать обе. Неподключённая платформа показывает **(не подключено)** для Twitch или **URL чата не подключён** для YouTube. Сначала подключите её:

- [Настройки Twitch](../platforms/twitch)
- [Настройки YouTube](../platforms/youtube-settings)

### Заголовок голосования

Необязательно. Например: «Во что играем сегодня?»

### Варианты голосования (2–10 шт.)

- Введите не менее 2 вариантов. Максимум — 10
- **+ Добавить вариант** добавляет строку, а **×** удаляет её
- **Применить из истории** позволяет выбрать один из 15 последних опросов и подставить его заголовок и варианты

Во время редактирования оверлей OBS показывает предпросмотр заголовка и вариантов.

### Время голосования

Длительность опроса в секундах. По умолчанию 60, минимум 10.

### Запуск / остановка

- **Начать голосование**: нужны как минимум 2 заполненных варианта и хотя бы одна выбранная подключённая платформа
- **Остановить голосование**: досрочно завершает опрос. Иначе он завершается, когда истекает время

Пока опрос идёт, нельзя менять платформы, заголовок, варианты или длительность.

## Как голосуют зрители

Пока идёт опрос, в оверлее отображается «Введите номер варианта в чате, чтобы проголосовать (например: 1)».

- Всё сообщение должно состоять из номера варианта, например `1` или `1.`. Пробелы игнорируются. Сообщение с любым другим текстом не засчитывается
- У каждого зрителя один голос. Если он отправит другой номер, его голос переходит к новому варианту, и засчитывается последний голос до окончания времени

## Результаты в реальном времени

Во время опроса под настройками появляется блок **Результаты в реальном времени** с оставшимся временем, количеством голосов и процентом для каждого варианта, а также общим числом голосов. После завершения опроса он меняется на **Итоговые результаты**. Нажмите **Подробнее**, чтобы увидеть, кто за какой вариант проголосовал, с разбивкой по Twitch и YouTube.

## Оформление

На вкладке **Оформление** вверху есть **Предпросмотр**. Палитра цвета рядом меняет только фон предпросмотра, а не оверлей OBS.

- **Шрифт**: задайте шрифт, цвет и **Размер** (px) для **Заголовок**, **Подсказка**, **Вариант**, **Секунды отсчёта** и **Число голосов**
- **Цвет полосы прогресса**: до 5 цветов, которые по порядку используются для полос вариантов. Каждый может быть **Сплошной** или **Градиент**. У градиентов также есть **Угол**
- **Цвет фона**: фон карточки опроса
- **Сбросить по умолчанию**: восстанавливает оформление по умолчанию. Если применена тема, восстанавливается оформление темы

В разделе **Свой CSS** можно написать собственные стили. Чтобы поделиться оформлением или скачать его, см. [Темы оформления](./themes).

## История

На вкладке **История** перечислены заголовок, время, количество вариантов и общее число голосов каждого опроса. Разверните опрос, чтобы увидеть его результаты, количество голосов по платформам и **Подробнее**. Хранится история опросов только за последние 30 дней. Чтобы удалить запись, нажмите 🗑, а затем **Подтвердить удаление**.

:::info Ограничения пробной версии
- **Свой CSS** доступен только в полной версии
- В оверлее OBS отображается водяной знак

Подробнее см. [Сравнение пробной и полной версий](../getting-started/trial-comparison).
:::
