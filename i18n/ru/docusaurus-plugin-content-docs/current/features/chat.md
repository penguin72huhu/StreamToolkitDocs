# Чат

**Чат** показывает чаты Twitch и YouTube вместе в одном оверлее, с возможностью автоперевода. Также чат можно показывать в прозрачном окне на рабочем столе, которое видите только вы.

## URL источника для OBS

```
http://127.0.0.1:7272/chat
```

Добавьте его как источник «Браузер»: [Как добавить источники в OBS](../getting-started/obs-source). У этого оверлея нет звука.

:::info
Сообщения отправляются в оверлей, только пока включён переключатель **Чат** в боковом меню. Когда он выключен, чат всё равно принимается, поэтому функции, читающие чат (опросы, розыгрыши, заказ музыки и т. д.), продолжают работать.
:::

## Перед началом

Подключите платформы, которые хотите показывать:

- [Настройки Twitch](../platforms/twitch)
- [Настройки YouTube](../platforms/youtube-settings)

На странице настроек две вкладки: **Настройки** и **Оформление**.

## Вкладка «Настройки»

### Платформы

- **Показывать иконку платформы (Twitch / YouTube)** — показывает значок <img src={require('@site/static/img/twitch-icon.png').default} alt="Twitch" className="inline-icon" /> / <img src={require('@site/static/img/youtube-icon.png').default} alt="YouTube" className="inline-icon" /> перед каждым сообщением

У каждой платформы своя карточка. Точка рядом с названием платформы загорается зелёным, когда платформа подключена и включена; если Twitch не подключён, отображается **(не подключено)**, а если чат YouTube не привязан — **URL чата не подключён**.

| Параметр | Описание |
|--------|-------------|
| **Включить чат** | Показывать сообщения этой платформы |
| **Показывать аватар** | Показывать аватар зрителя |
| **Показывать значки** (Twitch) / **Показывать значки (иконки участников)** (YouTube) | Показывать значки |
| **Показывать имена зрителей вместо @идентификаторов** | Только для YouTube. Недоступно, пока вы не войдёте через Google |

Когда чат YouTube включён, но не привязан, на его карточке появляются две кнопки:

- **Автоподключение** — автоматически находит вашу текущую трансляцию (требуется вход через Google)
- **Ввести вручную** — переводит на страницу настроек, где можно вставить URL чата

**Максимум сообщений**: сколько сообщений хранится на экране (5–200, по умолчанию 50).

### Автоперевод

1. Отметьте **Включить перевод**
2. **Целевой язык**: язык, на который переводятся сообщения. Значение по умолчанию, **Следовать за языком интерфейса**, использует язык интерфейса приложения
3. **Языки без перевода** (необязательно): сообщения на отмеченных языках остаются без изменений. Португальский PT-BR и PT-PT различить невозможно, поэтому выбор любого из них пропускает оба

**Сервис перевода** — **MyMemory**, для которого не нужен API-ключ.

- **Email (необязательно)**: без email дневная квота — 5,000 символов; введите email и нажмите **Сохранить**, чтобы повысить её до 50,000 символов (бесплатно, регистрация в MyMemory не нужна)
- Полоса ниже показывает примерный объём, использованный сегодня. Сброс происходит ежедневно в 08:00 UTC

### Тест

- **Отправить тестовое сообщение** — отправляет в оверлей случайное пример-сообщение
- **Очистить** — удаляет все сообщения из оверлея

Если появляется **Не удалось подключиться — сервер, возможно, не запущен**, значит локальный сервер Stream Toolkit не отвечает.

### Окно чата на рабочем столе

Показывает чат в небольшом прозрачном окне поверх игры. Его видите только вы — удобно для стрима с одним монитором.

1. Нажмите **Открыть окно** (или щёлкните правой кнопкой мыши по значку в трее и выберите **Открыть чат на рабочем столе**)
2. Пока окно не закреплено, перетаскивайте верхнюю панель, чтобы переместить его, и края — чтобы изменить размер
3. Когда окно на месте, нажмите **🔒 Закрепить**. После этого щелчки проходят сквозь окно в игру. Чтобы открепить окно, наведите на него мышь и нажмите появившийся в правом верхнем углу 🔓 или нажмите **🔓 Открепить** на странице настроек

**Сбросить положение** возвращает окно в положение по умолчанию.

| Параметр | Описание |
|---------|-------------|
| **Стиль** | **Только имя и сообщение** (по умолчанию) или **Как чат в OBS** |
| **Размер шрифта** | 12–32 px, по умолчанию 16. Только для **Только имя и сообщение** |
| **Непрозрачность текста** | 10–100%, по умолчанию 100% |
| **Непрозрачность фона** | 0–100%, по умолчанию 40% |
| **Скрывать сообщения** | 0–120 секунд, по умолчанию 0. Каждое сообщение исчезает через указанное число секунд, и исчезнувшие сообщения нельзя прокрутить назад. При 0 ничего не исчезает, и в открепленном окне можно прокрутить вверх к прошлым сообщениям (до Максимума сообщений) |
| **Скрывать из захвата трансляции** | Включено по умолчанию. «Захват экрана» в OBS не захватывает окно, поэтому зрители не видят чат дважды. Окно также не попадает на скриншоты и в демонстрацию экрана Discord |

:::tip
Если окно не видно, когда игра в полноэкранном режиме, переключите игру в режим «Окно без рамки» или «Оконный». Используйте **Отправить тестовое сообщение**, чтобы проверить положение и размер окна.
:::

## Вкладка «Оформление»

### Предпросмотр

Вверху вкладки отображается предпросмотр в реальном времени. Палитра цвета рядом с **Предпросмотр** меняет только фон предпросмотра. Флажки **Аватар**, **Значки** и **Иконка платформы** меняют только то, что показывается в предпросмотре.

### Настройки оформления

**Сбросить по умолчанию** восстанавливает оформление по умолчанию (или оформление применённой темы, если тема применена).

- **Направление появления**: **Сверху вниз**, **Снизу вверх** (по умолчанию), **Слева направо**, **Справа налево**
- **Текст** — задаётся отдельно для **Ник** и **Сообщение**:
  - Шрифт, размер (px) и цвет. Для ника можно выбрать **Исходный цвет** (цвет зрителя на платформе) или **Свой цвет**
  - **Обводка**: цвет, **Прозрачность**, **Толщина**
  - **Тень**: цвет, **Прозрачность**, **Размытие**, смещение X / Y
- **Размер иконок**: масштаб для **Иконка платформы**, **Аватар** и **Значки** (0.1–5x)
- **Цвет**: **Цвет фона** каждого сообщения

### Свой CSS

Разверните **Свой CSS**, чтобы напрямую редактировать CSS оверлея. С помощью **Управление ресурсами** можно загрузить изображения для использования в CSS. **Сбросить по умолчанию** восстанавливает CSS по умолчанию. См. также [Темы оформления](./themes).

:::tip
Если ваш CSS задаёт одно из полей оформления с `!important`, это поле в настройках оформления становится неактивным («Эта настройка управляется своим CSS»). Когда применена тема, CSS доступен только для чтения — восстановите настройки перед редактированием.
:::

## Ограничения пробной версии

:::info
- Включение автоперевода добавляет водяной знак в оверлей чата
- **Свой CSS** доступен только в полной версии
- **Окно чата на рабочем столе** доступно только в полной версии

См. [Сравнение пробной и полной версий](../getting-started/trial-comparison).
:::
