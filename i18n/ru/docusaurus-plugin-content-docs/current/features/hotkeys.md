# Горячие клавиши

**⌨️ Горячие клавиши** внизу левого меню — это список всех настроенных вами горячих клавиш в одном месте.

## Обзор горячих клавиш

В каждой строке показаны сочетание клавиш и действие, которое оно запускает, например `Таймер › (название таймера) › Старт / Пауза`. Нажмите на строку, чтобы открыть страницу настроек этой функции и изменить клавишу там. На этой странице горячие клавиши не редактируются.

Если ничего ещё не настроено, отображается «Горячие клавиши ещё не настроены.»

## Функции с горячими клавишами

| Функция | Что делает горячая клавиша |
|------|------|
| [Метка лучших моментов трансляции](./highlight) | Добавляет метку |
| [Media Board](./multimedia) | Воспроизводит звук / показывает изображение / воспроизводит видео (одна клавиша на каждый элемент) |
| [Голосовой перевод](./voice-translate) | Горячая клавиша голосового перевода |
| [Управление сценами OBS](./obs-scene) | **Смена сцены** / **Переключение источников** |
| [Таймер](./timer) | **Старт/пауза**, **Круг**, **Сброс** (для каждого таймера) |

## Назначение горячей клавиши

[Метка лучших моментов трансляции](./highlight), [Управление сценами OBS](./obs-scene) и [Таймер](./timer) используют одинаковое поле горячей клавиши. Для Media Board и Голосового перевода см. их собственные страницы.

1. Нажмите кнопку горячей клавиши
2. Нажмите сочетание клавиш, например `Ctrl+Shift+F1`
3. Отпустите все клавиши, чтобы сохранить его

- Нажмите **Esc** во время записи, чтобы отменить
- Если сочетание уже используется другой горячей клавишей, появится сообщение о конфликте и оно не будет сохранено. Выберите другое сочетание
- Нажмите **✕** (или кнопку очистки) рядом, чтобы удалить горячую клавишу
- Клавиши цифровой клавиатуры отличаются от цифровых клавиш основного ряда: `Num1` и `1` — разные горячие клавиши

Горячие клавиши работают, даже когда Stream Toolkit находится в фоне, например пока вы в игре.
