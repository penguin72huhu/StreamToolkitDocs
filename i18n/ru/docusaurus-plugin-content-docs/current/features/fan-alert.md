# Оповещения о новых подписчиках

Показывает оповещение в трансляции, когда кто-то подписывается на вас на Twitch (follow) или на ваш канал YouTube.

## URL источника для OBS

```
http://127.0.0.1:7272/fan-alert
```

Скопируйте URL вверху страницы **Настройки Оповещения о новых подписчиках** и добавьте его в OBS как источник «Браузер». См. [Как добавить источники в OBS](../getting-started/obs-source).

:::warning
Оповещения воспроизводят звук. Включите **«Управлять аудио с помощью OBS»** в свойствах источника «Браузер», иначе звук не попадёт в трансляцию.
:::

Переключатель рядом с **Оповещения о новых подписчиках** в левом меню включает и выключает оповещения. Пока он выключен, новые подписчики не показываются и не записываются, а тестовые кнопки тоже не работают.

Если несколько подписчиков приходят почти одновременно, оповещения ставятся в очередь и показываются по одному. У этого оверлея собственная очередь, поэтому он никогда не ждёт [Уведомления о донатах](./donate-alert).

## Вкладка «Настройки»

### Интеграция платформ

Отметьте платформы, которые должны вызывать оповещение: **Twitch** и **YouTube** (обе отмечены по умолчанию). Зелёная точка означает, что платформа подключена; иначе в строке отображается **Нет авторизации**.

- **Twitch**: каждый новый фолловер сразу вызывает оповещение. Сначала подключите Twitch: [Настройки Twitch](../platforms/twitch).
- **YouTube**: новые подписчики канала. Сначала войдите через Google: [Настройки YouTube](../platforms/youtube-settings).

Как определяются подписчики YouTube:

- У YouTube нет события «новый подписчик» в реальном времени, поэтому приложение каждые 1,5 минуты запрашивает у YouTube список ваших последних подписчиков.
- Проверка выполняется только во время эфира, когда чат трансляции YouTube подключён к этой трансляции. В режиме ожидания и после окончания трансляции проверка не выполняется.
- Зрители, подписавшиеся до начала трансляции (более чем примерно за 5 минут до начала проверки), не объявляются.
- Как сказано в подсказке на странице: **YouTube оповещает только о зрителях с открытыми подписками; задержка — от минут до часов.**

### Настройки

| Поле | Описание |
|-------|-------------|
| **Длительность показа** | Сколько секунд каждое оповещение остаётся на экране (1–60). По умолчанию: 5. |
| **Одного и того же зрителя — не чаще раза в 24 часа** | По умолчанию выключено. Если включено, повторная подписка того же зрителя в течение 24 часов (например, отписка и повторная подписка) не показывается и не записывается. |

### Тестирование оповещений

Нажмите **Тестовое оповещение (Twitch)** или **Тестовое оповещение (YouTube)**, чтобы отправить пример оповещения в OBS. Тестовые оповещения не добавляются в историю.

Если Оповещения о новых подписчиках выключены, тест не воспроизводится, а на странице отображается **Сначала включите оповещения о новых подписчиках в быстрых переключателях**.

## Вкладка «Оформление»

### Предпросмотр

Предпросмотр использует ту же страницу, что и источник OBS. Палитрой рядом с **Предпросмотр** можно изменить фон предпросмотра, а кнопка **▶ Повторить анимацию** заново проигрывает анимацию оповещения.

### Единый стиль / Отдельно по платформам

- **Единый стиль**: Twitch и YouTube используют один стиль оповещения.
- **Отдельно по платформам**: у каждой платформы свой стиль. Выберите **Twitch** или **YouTube** кнопками ниже и измените настройки. При первом переключении платформы, которые вы ещё не настраивали, копируют текущий единый стиль, каждая со своим цветом шкалы обратного отсчёта.

**Сбросить по умолчанию** восстанавливает стиль по умолчанию для редактируемого стиля.

### Изображение

- **Выбрать изображение**: выберите изображение в менеджере ресурсов. Без него показывается эмодзи сердечка. **Очистить** удаляет изображение.
- **Размер изображения**: 1–400 px.
- **Позиция изображения**: **Слева**, **Справа**, **Сверху** или **Снизу**.

### Звук

Выберите встроенный звук: **Нет**, **Колокольчик** (по умолчанию), **Монета**, **Звон**, **Хлопок**, **Фанфары**. Нажмите **▶**, чтобы прослушать. Нажмите **Выбрать звук**, чтобы использовать собственный звуковой файл из менеджера ресурсов.

### Свой текст

Напишите строку, которая показывается в оповещении. Используйте `{name}` для имени подписчика и `{platform}` для названия платформы. Оставьте поле пустым, чтобы использовать текст по умолчанию: `Добро пожаловать, {name}! Спасибо за подписку`

### Текст и цвет

- **Текст**: задайте шрифт, размер и цвет для **Свой текст** и **Имя подписчика**.
- **Цвет**: **Фон**, **Тень** и **Шкала обратного отсчёта**.

### Свой CSS

Разверните **Свой CSS**, чтобы изменить CSS редактируемого стиля (единого или выбранной платформы). **Сбросить по умолчанию** восстанавливает CSS шаблона, а **Управление ресурсами** открывает менеджер ресурсов. Здесь же можно применять темы Мастерской Steam. Пока тема применена, CSS доступен только для чтения. См. [Темы оформления](./themes).

## Вкладка «История»

Показывает недавних новых подписчиков с обеих платформ, сначала самые новые: платформа, имя и время. История отображается только в приложении и никогда не выводится в оверлей.

- Хранится до 100 подписчиков, записи старше 30 дней удаляются автоматически.
- Нажмите **Очистить**, чтобы очистить список.

:::info Пробная версия
Свой CSS доступен только в полной версии, а на оповещении в OBS отображается водяной знак. См. [Сравнение пробной и полной версий](../getting-started/trial-comparison).
:::

## Часто задаваемые вопросы

**Q: В трансляции нет звука?**
Убедитесь, что в свойствах источника «Браузер» включено **«Управлять аудио с помощью OBS»** и что источник не отключён в микшере аудио OBS. Также проверьте, что для **Звук** не выбрано **Нет**.

**Q: Подписчик YouTube не получил оповещение.**
Сообщается только об открытых подписках, и YouTube может сообщать о них с задержкой от минут до часов. Кроме того, приложение проверяет подписчиков только во время эфира с подключённым чатом трансляции YouTube.

**Q: Я добавил источник OBS позже. Будут ли воспроизведены прошлые оповещения?**
Нет. Только что открытый источник показывает лишь оповещения, пришедшие после его подключения. Более ранние подписчики по-прежнему есть на вкладке **История**.
