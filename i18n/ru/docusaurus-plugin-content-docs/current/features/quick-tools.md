# Быстрые инструменты

**Быстрые инструменты** — это небольшое окно управления, которое можно держать открытым рядом с игрой или OBS. Оно позволяет включать и выключать функции и пользоваться их основными элементами управления, не возвращаясь в главное окно.

## Открытие быстрых инструментов

Используйте любой из способов:

- Нажмите **⚡ Быстрые инструменты** вверху левого меню главного окна
- Щёлкните правой кнопкой мыши по значку Stream Toolkit в трее и выберите **Открыть быстрые инструменты**

Если окно уже открыто, оно выводится на передний план, а второе не открывается.

## Окно

- **Перемещение**: перетащите строку заголовка
- **📌 Закрепить / Открепить**: держит окно поверх других окон. При открытии окна закрепление включено
- **✕**: закрывает окно

Окно использует тему и язык интерфейса приложения.

## Панель быстрого переключения

Нажмите стрелку **›** у левого края, чтобы выдвинуть панель **Быстрое переключение**. В ней перечислены все функции:

- Переключатель включает или выключает функцию (так же, как переключатель рядом с каждой функцией в главном меню)
- **⚙** (**Открыть настройки**) открывает главное окно на странице настроек этой функции

Щёлкните за пределами панели или снова нажмите стрелку, чтобы закрыть её.

Функции перечислены в том же порядке, что и в главном меню. Чтобы изменить порядок, перетащите маркер **⠿** рядом с функцией в меню главного окна.

## Карточки функций

Каждая включённая функция, у которой есть элементы управления, отображается в виде карточки. Изначально карточки свёрнуты — нажмите на заголовок карточки, чтобы развернуть или свернуть её. Если ни одна из этих функций не включена, в окне отображается **Ни одна функция не включена**.

| Функция | Что есть на карточке |
|---------|---------------------|
| [Управление сценами OBS](./obs-scene) | Статус подключения и по одной кнопке на каждую настроенную смену сцены или переключение источников (текущая сцена подсвечена). Пока подключения нет, кнопки неактивны. Карточка появляется, только если есть хотя бы одна запись горячей клавиши |
| [Голосовой перевод](./voice-translate) | Кнопка **REC** — удерживайте для записи, отпустите для перевода |
| [Метка лучших моментов трансляции](./highlight) | Кнопка **MARK**. После отметки на 5 секунд показываются значок платформы и временная метка |
| [Полоса донатов](./donate) | Текущая / целевая сумма с полосой прогресса, поле **Добавить сумму вручную** с кнопкой **Добавить**, а также **Обнулить** |
| [Таймер](./timer) | Для каждого отображаемого таймера: название, время, **Старт** / **Пауза**, **Сбросить** и настроенные вами кнопки добавления времени. У секундомеров вместо этого — **Остановить** и **Круг** |
| [Колесо удачи](./turntable) | Для каждого отображаемого колеса: **Запустить** и **Сбросить** |
| [Media Board](./multimedia) | Кнопки для закреплённых изображений (показать / скрыть), закреплённых видео (воспроизвести) и закреплённых звуков (воспроизвести) |
| [Заказ музыки](./song-request) | **Играть** / **Пауза**, **Остановить**, **Следующая** |

Если элементу управления назначена горячая клавиша, она отображается на его кнопке.

Функции, которыми здесь нечего управлять (Чат, Полоса целей Twitch, Уведомления о донатах, Панель донатов, Часы, Стена эмоций, Опросы, Розыгрыши, Чат-бот), имеют в панели быстрого переключения только переключатель вкл/выкл.

:::tip
Кнопку **Обнулить** на карточке Полосы донатов нужно нажать дважды: после первого нажатия кнопка меняется на **Да, обнулить**, а второе нажатие в течение 10 секунд обнуляет сумму.
:::

:::info
Таймеры и колёса следуют **Режиму отображения** каждой функции: в режиме **Один таймер** / **Одно колесо** показывается только выбранный в данный момент; в режиме **Несколько таймеров** / **Несколько колёс** показываются только добавленные вами. Если их нет, на карточке отображается **Таймеров пока нет** / **Колёс пока нет**.
:::
