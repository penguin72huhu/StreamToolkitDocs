# 隱私權政策

最後更新：2026 年 10 月 21 日

本隱私權政策說明 Stream Toolkit（以下稱「本程式」）如何處理你的資料。本程式是在你的電腦上執行的直播工具，由 SnowPompom（以下稱「我們」）開發。

## 摘要

- 你的設定、紀錄和登入資訊**都存在你自己的電腦上**。
- 我們只有在提供特定功能時，才會經手少量資料，例如轉交金流平台的付款通知。這些資料用完即刪，或在 3 天內自動刪除。
- 我們**不會**出售你的資料，也不會用於廣告。

## 1. 存在你電腦上的資料

本程式把以下資料存在你電腦的使用者資料夾（Windows 為 `%APPDATA%\stream-toolkit`）：

- **設定**：各功能的設定、外觀、自訂 CSS、快捷鍵等。
- **紀錄**：贊助紀錄、投票與抽獎紀錄、精華標記、點歌清單、新粉絲紀錄等。其中可能包含觀眾在直播聊天室公開顯示的名稱和留言，以及 Twitch 新追隨者、YouTube 新訂閱者的名稱。
- **登入資訊與金鑰**：Twitch、YouTube／Google 的登入權杖，以及你填入的 API 金鑰、金流平台金鑰。這些資料以作業系統提供的加密方式保存，存在一個獨立的檔案裡，**不會透過 Steam Cloud 同步**。

如果你在 Steam 開啟了 Steam Cloud，一般設定會同步到你的 Steam 帳號，以便在其他電腦上使用；登入資訊與金鑰不在同步範圍內。

你可以隨時刪除上述資料夾來清除所有本機資料。

## 2. 經過我們伺服器的資料

本程式使用一個由我們管理、架設在 Cloudflare 上的伺服器（以下稱「伺服器」），只用於下列用途：

| 用途 | 經手的資料 | 保存期限 |
|---|---|---|
| Twitch 登入 | Twitch 授權碼與登入權杖（代為向 Twitch 交換與更新） | 不保存，轉交後即丟棄 |
| YouTube（Google）登入 | Google 授權碼與登入權杖（因本程式的 Google 用戶端密鑰保存在伺服器上，由伺服器代為向 Google 交換與更新） | 不保存，轉交後即丟棄 |
| 金流平台的贊助通知（綠界、歐付寶、PayPal、Stripe） | 付款通知內容：付款人填寫的名稱、留言、金額、幣別、交易編號 | 3 天後自動刪除 |
| 金流平台串接設定 | 你提供的金流平台金鑰（用來驗證並解密付款通知），以及本程式隨機產生的使用者識別碼 | 保存到你移除該設定為止 |
| 意見回報 | 你填寫的內容、你選擇附加的圖片、電腦規格、本程式的設定與執行狀態、近期執行紀錄（密碼、金鑰與登入權杖已遮蔽；觀眾資料只記錄筆數） | 轉寄到我們的 Discord 頻道，用於排查問題 |
| 匯率 | 不傳送你的資料，只取得公開匯率 | 不適用 |

使用者識別碼是本程式第一次執行時隨機產生的編號，不包含你的姓名、信箱或任何帳號資訊，只用來把金流平台的付款通知送到正確的電腦。

## 3. 第三方服務

本程式會依你啟用的功能，直接連線到下列第三方服務。這些服務如何處理資料，依各自的隱私權政策：

- **Twitch**：讀取聊天室、追隨／訂閱／小奇點等事件、建立精華片段。
- **YouTube／Google**：讀取直播聊天室與直播資訊（見第 4 節）。
- **DeepL、MyMemory**：聊天室翻譯與語音翻譯。**要翻譯的文字**會傳送給你選擇的翻譯服務。
- **語音辨識**：在你的電腦上執行，**錄音不會上傳**。第一次使用時會從 Hugging Face 下載辨識模型。
- **7TV、BetterTTV、FrankerFaceZ**：取得表情符號圖片。
- **Google Fonts**：overlay 使用網路字型時載入。
- **綠界、歐付寶、PayPal、Stripe**：你自行在這些平台設定收款，付款通知經由我們的伺服器轉交給本程式（見第 2 節）。
- **Steam**：購買、更新、Steam Cloud 與工作坊主題。
- **Discord**：意見回報的轉寄目的地。

## 4. YouTube API 服務

本程式使用 **YouTube API 服務**。使用本程式的 YouTube 相關功能，即表示你同意受 [YouTube 服務條款](https://www.youtube.com/t/terms)約束；Google 如何處理資料，請參閱 [Google 隱私權政策](https://policies.google.com/privacy)。

當你在本程式用 Google 帳號登入時，本程式會依你授權的範圍使用以下 YouTube 資料：

| 資料 | 用途 |
|---|---|
| 你的頻道名稱與 ID | 顯示登入的是哪個頻道；確保聊天機器人只在你自己的直播發言 |
| 你的直播（標題、狀態、開播時間、聊天室 ID） | 自動偵測目前的直播、連接該場聊天室、計算精華標記的時間 |
| 直播聊天室訊息 | 讓聊天機器人回覆與發送定時留言；查詢尚未記錄過的寶石禮物的寶石數 |
| 你頻道的最近訂閱者（名稱與頻道 ID；僅限公開訂閱的觀眾） | 新粉絲通知，只在你直播中時查詢 |
| 你頻道的會員等級名稱 | 按下「從 YouTube 匯入等級」時，帶入會員等級設定 |
| 聊天室觀眾公開的頻道名稱 | 開啟對應選項時，以觀眾的顯示名稱取代 @代稱 |
| 公開的影片標題與播放清單內容 | 顯示連接的直播標題；點歌的預設播放清單 |

如果你在舊版本填過自己的 YouTube API 金鑰，上述公開資料的查詢可能會改用該金鑰，而不是你的 Google 登入。

這些資料只用於上述功能，只存在你的電腦上，不會傳送到我們的伺服器（登入時的權杖交換除外，見第 2 節），也不會分享給任何第三方。從 YouTube 取得的資料會在使用時即時讀取；本程式保存在你電腦上的觀眾顯示名稱、新粉絲紀錄、已通知過的訂閱者清單，最長保存 30 天後重新取得或刪除。你匯入的會員等級名稱屬於你的設定，會保留到你修改或刪除為止。

**撤銷授權**：你可以隨時在本程式的設定頁，按 YouTube 旁的「解除連結」，同時會撤銷本程式在你 Google 帳戶的存取權；也可以到 [Google 帳戶的第三方存取權設定](https://myaccount.google.com/connections)移除本程式的存取權。撤銷後，本程式會停止存取你的 YouTube 資料，你可以刪除第 1 節所述的資料夾來移除本機資料。

## 5. 兒童

本程式不是為 13 歲以下兒童設計，我們也不會刻意收集兒童的資料。

## 6. 資料安全

金鑰與登入權杖以作業系統提供的加密方式保存在你的電腦上。與我們伺服器和第三方服務之間的連線都使用 HTTPS 加密。

## 7. 你的權利

你可以隨時：

- 刪除本機資料：刪除第 1 節所述的資料夾。
- 移除伺服器上的金流平台設定：在本程式清除該平台的金鑰。
- 要求刪除我們保存的任何資料：寫信到下方信箱，我們會在 30 天內處理。
