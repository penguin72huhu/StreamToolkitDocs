# 時鐘

在直播畫面上顯示目前時間，並可加上日期與星期。

## 步驟一：加入 OBS 來源

複製頁面上方的 **OBS 來源網址**：

```
http://127.0.0.1:7272/clock
```

將它加入 OBS 瀏覽器來源，詳見 [如何在 OBS 加入來源](../getting-started/obs-source.md)。時鐘不會播放聲音，不需勾選「使用 OBS 控制音訊」。

:::tip
記得同時打開左側選單 **時鐘** 旁的開關（**開啟 OBS 顯示**）。開關關閉時，OBS 上不會顯示時鐘。
:::

## 預覽

上方的 **預覽** 就是實際的 OBS 畫面，修改設定會即時反映。旁邊的色塊可以更換預覽背景色。

預覽下方有三個分頁：**外觀**、**時鐘格式**、**顯示設定**。

## 外觀

| 設定 | 說明 |
|------|------|
| **字型** | 時鐘所有文字的字型 |
| **樣式** | 時間、日期、星期的排列方式：**Stack**、**Horizontal**、**One-Top-Two-Bottom**、**Two-Top-One-Bottom**。除 **Horizontal** 外可調 **行距**，除 **Stack** 外可調 **間距**（皆為 −200～200 px） |
| **順序** | 拖曳 **時間**、**日期**、**星期** 區塊調整先後順序 |
| **文字** | **時間**、**日期**、**星期** 各自設定：**字體大小**、顏色（**純色**，或 **漸層** 搭配兩個顏色與 **角度**），以及 **邊框** 的顏色、**透明度**、**粗度**（0–7 px） |
| **陰影** | 陰影顏色、**透明度**、**模糊**、**X** / **Y** 偏移，所有文字共用 |

**恢復預設** 按鈕在分頁最上方。

### 自訂 CSS

點 **自訂 CSS** 展開編輯區。預設 CSS 已附註解，列出時鐘各部分（時間、日期、星期與外層容器）的選擇器。自訂 CSS 用來調整版面結構；顏色、字型、字級請用上方的外觀設定。

- **恢復預設**：還原預設 CSS
- **管理素材**：開啟素材管理，管理 CSS 中使用的圖片

若 CSS 用 `!important` 覆寫了某個屬性，對應的外觀設定欄位會被鎖定，因為最後生效的會是 CSS。

## 時鐘格式

- **時制**：**24 小時**、**12 小時（上午/下午）** 或 **12 小時（AM/PM）**
- **時區**：UTC−12 至 UTC+14，預設為電腦目前的時區

## 顯示設定

- **顯示秒數**
- **顯示日期**：勾選後可從下拉選單選擇日期格式，標示 **無年份** 的格式不顯示年份
  - **日期補零**：個位數的月、日前面補 0（例如 2026/05/20）
  - **年份格式**：選用以年份開頭的格式時才會出現，可選 **完整（2026）** 或 **縮寫（26）**

  這兩個選項只對數字格式（以 `/` 或 `-` 分隔）有效；文字格式（例如「2026年5月20日」）會依 App 介面語言顯示
- **顯示星期**：勾選後可選擇星期的寫法（例如 **星期三**、**Wednesday**、**WED**、**Wed**）

:::info 試用版限制
**自訂 CSS** 僅限正式版。詳見 [試用版 / 正式版比較](../getting-started/trial-comparison.md)。
:::
