# 實況效果板

直播時用點擊或快捷鍵顯示圖片、播放影片和音效。

頁面分成 **圖片**、**影片**、**音效** 三個分頁，每個分頁各有自己的 OBS 來源網址。

| 分頁 | OBS 來源網址 | 使用 OBS 控制音訊 |
|------|--------------|-------------------|
| **圖片** | `http://127.0.0.1:7272/imageboard` | 不需要 |
| **影片** | `http://127.0.0.1:7272/videoboard` | 必須勾選 |
| **音效** | `http://127.0.0.1:7272/soundboard` | 必須勾選 |

點各網址旁的 **複製**，再到 OBS 新增為瀏覽器來源，詳見 [如何在 OBS 加入來源](../getting-started/obs-source.md)。影片和音效是在 OBS 來源裡播放，不是在 Stream Toolkit 程式內播放，所以這兩個來源一定要勾選 **使用 OBS 控制音訊**，否則觀眾聽不到聲音。

:::tip
請打開左側選單 **實況效果板** 旁的開關（**開啟 OBS 顯示**）。開關關閉時，不論用按鈕或快捷鍵，圖片都無法顯示，影片和音效也不會播放。
:::

## 共通操作

圖片、影片、音效都以卡片列出：

- 點卡片可以展開或收合設定
- 卡片右側的勾選框：勾選後會顯示在 [快速工具](./quick-tools.md) 的啟動工具中。新增的項目預設為勾選
- **✕** 刪除該項目
- 本地檔案被移動或刪除時，卡片會顯示 **找不到檔案**

### 快捷鍵

每個項目都可以設定自己的快捷鍵：

1. 展開卡片，點快捷鍵按鈕
2. 按下想要的按鍵組合後放開；按 **Esc** 可取消
3. 要移除快捷鍵，點 **清除**

如果這組按鍵已被其他功能使用，不會儲存，按鈕會顯示衝突提示。即使 Stream Toolkit 不是目前的視窗，快捷鍵也有效。所有快捷鍵也會列在 [快捷鍵總覽](./hotkeys.md) 頁面。

## 圖片

{/* TODO: 截圖 — 圖片分頁 */}

### 新增圖片

1. 點 **新增圖片**
2. 選擇檔案（jpg、jpeg、png、gif），檔名會成為圖片名稱

展開卡片會看到縮圖和以下設定：

- **名稱**：圖片名稱
- **檔案路徑**：點 **重選** 可以換成其他檔案
- **快捷鍵**：按一次顯示圖片，再按一次隱藏
- **設定位置大小**：見下方說明
- **刪除圖片**：刪除這張圖片

### 顯示與隱藏

點卡片上的 **○** 按鈕，圖片就會顯示在 OBS，按鈕變成 **◉**；再點一次即隱藏。

### 顯示設定

**允許同時顯示多張圖片** 預設為關閉。關閉時，顯示一張圖片會把目前顯示中的圖片換掉；打開後可以同時顯示多張圖片。

### 設定位置大小

- **X 位置** / **Y 位置**：單位 px。0/0 為來源正中央，正值往右/下，負值往左/上
- **寬** / **高**：原始尺寸的 %，100 = 原始大小。🔗 按鈕為等比縮放（預設開啟），點一下可改為自由縮放
- 圖片顯示中時，調整會即時反映在 OBS 上
- **儲存** 保留變更，**重置** 回到開啟視窗時的數值，**取消** 不儲存直接關閉

## 影片

{/* TODO: 截圖 — 影片分頁 */}

點 **新增影片** 新增一張卡片，展開後設定：

- **影片名稱**：卡片上顯示的名稱
- **來源**：**YouTube** 或 **本地**
  - **YouTube**：在 **YouTube 網址** 貼上影片連結，點 **測試解析** 確認；成功會顯示「已解析，播放時自動套用」
  - **本地**：點 **選擇檔案** 選 mp4、webm 或 ogg 檔。大小上限 200MB，檔案越大延遲越久。需要透明背景請使用 WebM（VP9 Alpha）影片
- **循環播放**：重複播放影片
- **播放時間**：設定 **從** 和 **到**（時、分、秒、毫秒）。**到** 保持 00:00 代表播到結尾
- **音量**：0–100%
- **快捷鍵**：按下播放影片；影片播放中再按一次則停止
- **設定位置大小**：位置與大小欄位與圖片相同。點 **預覽循環** 可在 OBS 上循環播放影片，方便邊看邊調整，點 **停止預覽** 停止。調整完點 **儲存** 或 **取消**

點卡片上的 **▶** 會在 OBS 播放影片，點 **■** 停止。

## 音效

{/* TODO: 截圖 — 音效分頁 */}

點 **新增音效** 新增一張卡片，展開後設定：

- **音效名稱**：卡片上顯示的名稱
- **來源**：**YouTube 網址** 或 **本地檔案**
  - **YouTube 網址**：貼上連結，點 **測試解析** 確認
  - **本地檔案**：點 **選擇檔案** 選 mp3、wav、ogg、flac、m4a、aac 或 opus 檔
- **播放時間**：設定 **從** 和 **到**。**到** 保持 00:00 代表播到結尾
- **音量**：0–100%
- **快捷鍵**：按下播放音效

點卡片上的 **▶** 會在 OBS 播放音效，點 **■** 停止。同一時間只會播放一個音效，播放另一個音效時會停掉目前的音效。

:::info 試用版限制
- 圖片、影片、音效各只能新增 **1** 個
- 圖片和影片的 OBS 畫面會顯示浮水印

詳見 [試用版 / 正式版比較](../getting-started/trial-comparison.md)。
:::

## 常見問題

**Q：影片或音效有播放，但直播聽不到聲音？**
請確認 `/videoboard` 和 `/soundboard` 兩個來源都已勾選 **使用 OBS 控制音訊**，且在 OBS 混音器中沒有被靜音。

**Q：選不到我的影片檔？**
只能選 mp4、webm、ogg 檔，且大小不能超過 200MB。檔案過大時會跳出提示，不會加入。
