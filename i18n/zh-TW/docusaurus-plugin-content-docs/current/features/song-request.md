# 點歌

觀眾在聊天室用指令點 YouTube 歌曲，歌曲會在 OBS 依序播放。你也可以自己加歌，並設定沒人點歌時播放的預設播放清單。

## OBS 來源網址

```
http://127.0.0.1:7272/song-request
```

在頁面上方 **OBS 來源網址** 旁點 **複製**，再加入 OBS 瀏覽器來源，做法請看 [如何在 OBS 加入來源](../getting-started/obs-source.md)。

:::warning
點歌會播放聲音。請在瀏覽器來源屬性中勾選 **使用 OBS 控制音訊**，否則音樂不會出現在直播中。
:::

:::tip
另外要打開左側選單 **點歌** 旁的開關。開關關閉時，聊天室指令不會被處理。
:::

頁面分成 **設定**、**播放清單** 兩個分頁。

## 設定分頁

### 平台

每個平台各有一張卡片：

- **開放此平台點歌**：讓該平台聊天室的觀眾可以點歌
- **啟用聊天機器人回覆**（只有 Twitch，預設開啟）：用你連結的 Twitch 帳號在聊天室回覆每個指令的結果。Twitch 開放點歌且已連接時才會出現

還沒連接的平台，Twitch 會顯示 **（未連接）**，YouTube 會顯示 **未連結聊天室網址**。請先完成連接：

- [Twitch 設定](../platforms/twitch.md)
- [YouTube 設定](../platforms/youtube-settings.md)

### 聊天室指令

| 欄位 | 預設值 |
|------|--------|
| **指令前綴** | `!`（可選 `! @ # $ % & ~`） |
| **點歌指令** | `sr` |
| **刪除點歌** | `remove` |
| **查看點歌清單** | `queue` |
| **查詢目前歌曲** | `song` |
| **點歌冷卻時間** | 3000 ms |

冷卻時間以每位觀眾分開計算：點歌成功後，同一位觀眾要等這段時間才能再點。

### 設定

- **在畫面顯示影片**（預設開啟）：關閉後 OBS 畫面不顯示影片，但聲音照常播放
- **清單上限**（1–100，預設 20）：清單中觀眾點的歌最多幾首。預設播放清單的歌不算在內
- **顯示點歌通知**（預設開啟）：觀眾點歌、刪歌或點歌失敗時，在 OBS 顯示通知卡片。開啟後可以設定：
  - **X**／**Y**：通知距離左上角的位置（px，預設 16／16）
  - **通知縮放**：大小倍率（預設 1.0）
  - **測試通知外觀**：送一則測試通知到 OBS

每則通知顯示 5 秒，同時最多顯示 3 則。

## 觀眾怎麼點歌

以預設設定為例：

| 指令 | 作用 |
|------|------|
| `!sr <YouTube 網址>` | 點這部影片 |
| `!sr <搜尋關鍵字>` | 在 YouTube 搜尋，點第一個結果 |
| `!remove` | 刪除自己最近點的一首（播放中的歌不能刪） |
| `!queue` | 回覆接下來 3 首觀眾點的歌 |
| `!song` | 回覆目前播放的歌 |

- 可用的網址：`youtube.com/watch?v=…`、`youtu.be/…`、`youtube.com/live/…`、`youtube.com/shorts/…`，或 11 碼的影片 ID
- 不接受播放清單網址
- 清單達到 **清單上限** 時，點歌會失敗
- 新點的歌會排在其他觀眾點的歌後面、預設播放清單的歌前面
- `!queue` 和 `!song` 只在 Twitch 聊天室、且開啟 **啟用聊天機器人回覆** 時有作用

## 播放清單分頁

### 播放控制

最上方顯示目前歌曲是誰點的和歌名。按鈕：

- **播放**／**暫停**：沒有播放中的歌時，從清單第一首開始
- **停止**：停止播放
- **下一首**：跳到下一首

播放時會出現進度條，拖曳可以跳到指定位置。一首播完會自動播下一首。

:::note
開啟程式時不會自動播放，請按 **播放** 開始。
:::

### 預設播放清單

貼上 YouTube 播放清單網址，並選擇 **循環播放** 或 **隨機播放**。清單播完時，會自動從這個播放清單加一首歌並播放。這些歌在清單中會標示為 **預設清單**。

預設播放清單需要透過你的 YouTube 帳號讀取，所以必須先在 [YouTube 設定](../platforms/youtube-settings.md) 登入 Google。

### 手動點歌

貼上 YouTube 影片網址，點 **加入清單**（或按 Enter）。手動點歌不支援搜尋關鍵字。

### 清單

**清單（n）** 列出所有歌曲：平台、點歌者、歌名和影片 ID（點擊可在 YouTube 開啟）。點 **刪除** 移除單首；刪掉正在播放的歌會直接跳下一首。**清空** 會清掉整個清單。

## 常見問題

**Q：觀眾輸入指令卻沒反應？**
請確認：
- 左側選單 **點歌** 的開關已打開
- 該平台已勾選 **開放此平台點歌**
- Twitch：Twitch 聊天室是由 [聊天室](./chat.md) 功能讀取的。如果你在聊天室頁面關閉了 Twitch（且 [聊天機器人](./chat-bot.md) 沒有使用 Twitch），就收不到 Twitch 的指令

**Q：預設播放清單沒有播放？**
請確認設定頁已登入 Google，而且網址是播放清單網址（含 `list=`）。

:::info 試用版限制
- 觀眾從聊天室點歌只有正式版能用。試用版中，觀眾點歌會失敗並顯示「試用版不支援觀眾點歌」。**手動點歌** 和預設播放清單仍可使用
- OBS 畫面會顯示浮水印

詳見 [試用版 / 正式版比較](../getting-started/trial-comparison.md)。
:::
