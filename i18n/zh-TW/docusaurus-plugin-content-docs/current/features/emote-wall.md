# 表情符號牆

觀眾在聊天室使用表情符號時，這些表情符號會飄過直播畫面。

:::note 開始前
表情符號牆是從聊天室讀取表情符號，請先連結要使用的平台，詳見 [Twitch 設定](../platforms/twitch.md) 與 [YouTube 設定](../platforms/youtube-settings.md)。
:::

## 步驟一：加入 OBS 來源

複製頁面上方的 **OBS 來源網址**：

```
http://127.0.0.1:7272/emote-wall
```

將它加入 OBS 瀏覽器來源，詳見 [如何在 OBS 加入來源](../getting-started/obs-source.md)。表情符號牆不會播放聲音，不需勾選「使用 OBS 控制音訊」。

:::tip
記得同時打開左側選單 **表情符號牆** 旁的開關（**開啟 OBS 顯示**）。開關關閉時，聊天室的表情符號不會送到 OBS 畫面。
:::

## 步驟二：選擇來源

**來源** 區塊中有 **Twitch** 與 **YouTube** 兩張卡片，會顯示各自的連線狀態：

- Twitch 帳號未連結時，顯示 **（未連接）**
- YouTube 聊天室未連線時，顯示 **未連結聊天室網址**

勾選卡片中的 **啟用表情符號牆**，就會顯示該平台聊天室的表情符號；取消勾選則忽略該平台。

## 步驟三：動畫設定

| 設定 | 說明 |
|------|------|
| **貼圖大小** | 每個表情符號的大小，16–256 px |
| **每則訊息最多 emote 數** | 每則聊天訊息最多取幾個表情符號（1–20） |
| **飄動持續時間** | 每個表情符號飄動的時間，1–30 秒 |
| **飄動速度** | 50–500 px/s |

點區塊標題旁的 **恢復預設** 可還原這四項設定。

## 步驟四：測試

點 **測試（在 OBS 顯示）**，會依目前設定送出範例 Twitch 表情符號到 OBS 畫面，數量依 **每則訊息最多 emote 數** 而定。
