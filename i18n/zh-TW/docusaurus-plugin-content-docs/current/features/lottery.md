# 抽獎

觀眾在 Twitch 或 YouTube 聊天室輸入關鍵字就能參加。收集結束後隨機抽出中獎者，OBS 畫面會播放抽獎動畫。

## OBS 來源網址

```
http://127.0.0.1:7272/lottery
```

在頁面上方 **OBS 來源網址** 旁點 **複製**，再加入 OBS 瀏覽器來源，做法請看 [如何在 OBS 加入來源](../getting-started/obs-source.md)。抽獎沒有音效，不用勾「使用 OBS 控制音訊」。

:::tip
另外要打開左側選單 **抽獎** 旁的開關（**開啟 OBS 顯示**）。開關關閉時，OBS 畫面不會顯示抽獎。
:::

頁面分成 **設定**、**歷史紀錄** 兩個分頁。

## 設定

### 投票平台

點 **Twitch**／**YouTube** 選擇哪個平台的聊天室可以參加，兩個都能選。還沒連接的平台，Twitch 會顯示 **（未連接）**，YouTube 會顯示 **未連結聊天室網址**。連接方式請看 [Twitch 設定](../platforms/twitch.md)、[YouTube 設定](../platforms/youtube-settings.md)。

### 抽獎關鍵字

觀眾在聊天室發送的訊息只要包含這個關鍵字，就算參加。每位觀眾每次抽獎只能參加一次。關鍵字空白時，**開始收集** 不能按。

### 抽獎時間

收集參加者的時間，單位是秒。預設 300，範圍 10–3600。

### 人數上限

參加人數到達上限時，會提前結束收集。填 `0` 代表不限人數。

### 抽取後刪除選項

開啟後，抽中的人會在下一次抽獎前從參加名單移除，同一場抽獎不會再被抽到。

### 提示文字

收集期間顯示在 OBS 畫面上的提示，會告訴觀眾關鍵字和目前參加人數。可以設定字型、顏色和大小（px）。

### 抽獎動畫

- **ID 快速輪換**（預設）：收集期間，參加者名稱會飄在畫面上，抽獎時名稱會快速輪換
  - **收集畫面字型**：字型、字體大小，以及名稱標籤的顏色（最多 5 色）
  - **抽獎動畫字型**：抽獎時輪換名稱的字型和字體大小
  - **恢復預設**：還原以上設定
- **轉盤動畫**：參加者會排在轉盤上，轉動後抽出中獎者。配色可以選 **極簡**，或是在 [轉盤](./turntable.md) 建立的自訂主題

收集期間不能修改平台、關鍵字、抽獎時間、人數上限、抽取後刪除選項和動畫類型。

## 進行抽獎

1. 點 **開始收集**，面板會顯示 **收集中…**、剩餘秒數和參加人數
2. 收集期間，可以在 **手動輸入參加者名稱** 輸入名稱，再點 **新增**（或按 Enter）。名稱已經在名單裡的話，會顯示「此 ID 已在名單中」
3. 想在時間到之前結束收集，就點 **結束收集**。時間到或達到 **人數上限** 也會自動結束，面板會顯示 **時間到！**
4. 點 **開始抽獎**，OBS 畫面會播放動畫，動畫結束後中獎者會出現在 **中獎者** 欄位
5. 想再抽一位，就點 **再次抽取**

任何階段都可以點 **取消抽獎**，會清空參加者和中獎者，OBS 畫面也會回到等待狀態。

## 歷史紀錄

**歷史紀錄** 分頁中，每場抽獎一筆紀錄，包含時間、關鍵字和參加人數。展開後可以看到中獎者和完整參加名單。只保留最近 30 天的抽獎紀錄。要刪除紀錄，請點 🗑 再點 **確認刪除**。

:::info 試用版限制
OBS 畫面會顯示浮水印。詳見 [試用版 / 正式版比較](../getting-started/trial-comparison.md)。
:::
