# Twitch目標條

在直播畫面上顯示 Twitch 追隨、訂閱、小奇點的目標進度條。每種目標各有獨立的進度條、設定與 OBS 網址。

:::note 開始前
目標條是依 Twitch 事件計算，請先連結 Twitch 帳號，詳見 [Twitch 設定](../platforms/twitch.md)。
:::

## 步驟一：選擇目標類型並加入 OBS 來源

在頁面最上方選擇目標類型：**追隨**、**訂閱** 或 **小奇點**。下方的 **OBS 網址** 會跟著切換，點 **複製** 即可複製。

| 目標類型 | OBS 來源網址 |
|---------|-------------|
| **追隨** | `http://127.0.0.1:7272/goal/follow` |
| **訂閱** | `http://127.0.0.1:7272/goal/sub` |
| **小奇點** | `http://127.0.0.1:7272/goal/bits` |

要顯示幾條，就在 OBS 各加一個瀏覽器來源，詳見 [如何在 OBS 加入來源](../getting-started/obs-source.md)。目標條不會播放聲音，不需勾選「使用 OBS 控制音訊」。

:::tip
記得同時打開左側選單 **Twitch目標條** 旁的開關（**開啟 OBS 顯示**）。開關關閉時，OBS 上不會顯示目標條。
:::

## 步驟二：設定目標

以下設定都只套用到上方目前選取的目標類型。

- **標題**：顯示在目標條上的標題文字
- **目標**：目標數字（0 以上的整數）
- **進度**：顯示目前數量、目標與百分比

### 進度怎麼計算

| 目標類型 | 計入進度的事件 |
|---------|--------------|
| **追隨** | 每有一個新追隨 +1。Twitch 連線期間，也會每 30 秒與 Twitch 上的頻道追隨總人數同步一次；點 **同步** 可立即同步 |
| **訂閱** | 新訂閱與贈送訂閱（一次贈送多份時，加上贈送的份數）。重新訂閱只有在勾選 **計算重新訂閱** 時才計入 |
| **小奇點** | 每次 Cheer 加上該次的小奇點數量 |

### 訂閱選項

僅 **訂閱** 會顯示：

- **依 Tier 加權**：勾選時，等級越高的訂閱計入的點數越多；不勾選時，每個訂閱都只算 1
- **計算重新訂閱**：勾選時，重新訂閱訊息也會計入進度

### 重置進度

**訂閱** 與 **小奇點** 有 **重置進度** 按鈕。點下後再按 **確定重置**，目前數量會歸 0，目標數字保留不變。

**追隨** 沒有重置按鈕，因為它的數量是跟著 Twitch 追隨總人數走。

## 步驟三：調整外觀

### 預覽

上方的 **預覽** 會顯示目前目標類型的進度條。旁邊的色塊可以更換預覽背景色；勾選 **預覽達成** 可查看達標時的樣子。

### 外觀設定

| 設定 | 說明 |
|------|------|
| **背景顏色** | 進度條的底色 |
| **進度條顏色** | 已填滿部分的顏色 |
| **達標顏色** | 達成目標後的填滿顏色 |
| **標題字** | 標題的字型、顏色、大小（8–72 px） |
| **目標字** | 數字的字型、顏色、大小（8–72 px） |
| **百分比** | 百分比的字型、顏色、大小（8–72 px） |

點 **恢復預設** 可還原目前目標類型的外觀。

### 自訂 CSS

點 **自訂 CSS** 展開編輯區。每種目標類型各有一份 CSS，用來調整版面結構；顏色、字型、字級請用上方的外觀設定。

- **恢復預設**：還原預設 CSS
- **管理素材**：開啟素材管理，管理 CSS 中使用的圖片

若 CSS 用 `!important` 覆寫了某個屬性，對應的外觀設定欄位會被鎖定，因為最後生效的會是 CSS。

:::info 試用版限制
- **自訂 CSS** 僅限正式版
- OBS 畫面會顯示浮水印

詳見 [試用版 / 正式版比較](../getting-started/trial-comparison.md)。
:::
