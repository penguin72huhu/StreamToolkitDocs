# 轉盤

自訂轉盤選項，直播時一鍵轉動抽出結果。每個選項可以設定權重，也可以設定轉盤配色，以及抽中後是否刪除選項。

頁面分成 **設定**、**建立轉盤**、**歷史紀錄** 三個分頁。請先建立轉盤，再到 **設定** 分頁轉動。

## 步驟一：建立轉盤

1. 從左側選單打開 **轉盤**，切到 **建立轉盤** 分頁
2. 在 **我的轉盤** 點 **新增**，會出現名為「轉盤 1」（之後依序為「轉盤 2」…）的新轉盤
3. 點轉盤卡片就能編輯；點卡片上的 **✕** 會刪除該轉盤

### 轉盤標題

轉盤名稱，會顯示在轉盤列表、下拉選單和歷史紀錄裡。

### 轉盤內容

1. 點 **編輯內容**
2. 輸入選項，**每行一個**
3. 點 **確認**

### 權重

轉盤有選項後，每個選項旁會出現 **權重** 欄位（最小 1，預設 1）。權重越高，該選項在轉盤上的區塊越大，被抽中的機率也越高。例如權重 2 的選項，被抽中的機率是權重 1 的兩倍。

### 轉盤主題色

- **極簡**：內建的白灰配色
- **自訂**：建立自己的配色。輸入 **名稱**，在 **顏色（3–5 色）** 選色（**＋** 加一色、**✕** 移除），再點 **新增**

想修改自訂主題就點 **✎**，想刪除就點 **✕**。自訂主題也會出現在 [抽獎](./lottery.md) 轉盤動畫的配色選項裡。

### 抽取後刪除選項

開啟後，抽中的選項會在下一次轉動前從轉盤移除。點 **重置** 就會恢復所有選項。

## 步驟二：選擇顯示模式並加入 OBS

切到 **設定** 分頁，選擇 **顯示模式**：

| 模式 | 說明 | OBS 來源網址 |
|------|------|-------------|
| **單一轉盤** | OBS 只顯示選定的那個轉盤，可在 **目前使用的轉盤** 下拉選單切換 | `http://127.0.0.1:7272/turntable` |
| **多轉盤** | OBS 可同時顯示多個轉盤，每個轉盤有自己的網址 | `http://127.0.0.1:7272/turntable/<轉盤ID>` |

**多轉盤** 模式下，在 **加入轉盤顯示** 選擇要加入的轉盤。每個加入的轉盤都有自己的卡片，上面有 **OBS 來源網址**，點 **複製** 即可複製。點卡片右上 **✕** 可以把該轉盤從顯示中移除。

把複製的網址加入 OBS 瀏覽器來源，做法請看 [如何在 OBS 加入來源](../getting-started/obs-source.md)。轉盤沒有音效，不用勾「使用 OBS 控制音訊」。

:::tip
另外要打開左側選單 **轉盤** 旁的開關（**開啟 OBS 顯示**）。開關關閉時，OBS 畫面不會顯示轉盤。
:::

## 步驟三：轉動轉盤

在 **設定** 分頁的轉盤卡片上：

- **啟動**：開始轉動。動畫結束後，OBS 畫面會顯示抽中結果。轉盤沒有選項或還在轉動時，這個按鈕不能按
- **重置**：恢復被刪除的選項、轉盤歸位，並清空目前的 **中獎名單**

卡片上的 **中獎名單** 會記下上次 **重置** 之後的所有結果。

[快速工具](./quick-tools.md) 視窗也可以使用 **啟動**／**重置**。

## 歷史紀錄

**歷史紀錄** 分頁的每一筆紀錄，代表從第一次轉動到下次 **重置** 為止的一輪，內容包含時間、轉盤標題和中獎名單。只保留最近 30 天的轉盤紀錄。要刪除紀錄，請點 🗑 再點 **確認刪除**。

:::info 試用版限制
- 只能建立 **1** 個轉盤
- OBS 畫面會顯示浮水印

詳見 [試用版 / 正式版比較](../getting-started/trial-comparison.md)。
:::
