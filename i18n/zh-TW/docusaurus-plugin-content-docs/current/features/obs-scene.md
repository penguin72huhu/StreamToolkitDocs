# OBS場景控制

**OBS場景控制** 讓你用全域快捷鍵或 [快速工具](./quick-tools.md) 切換直播軟體的場景、顯示／隱藏來源。支援 **OBS Studio**、**Streamlabs**、**Meld Studio**。

這個功能沒有 overlay 畫面，不需要在 OBS 新增瀏覽器來源。

:::info
左側選單的 **OBS場景控制** 開關開啟時，快捷鍵才會作用。Stream Toolkit 視窗縮到系統匣時快捷鍵一樣有效。
:::

設定頁分成 **連線設定** 與 **快捷鍵設定** 兩個分頁。

## 連線設定分頁

### 步驟一：選擇直播軟體

在 **直播軟體** 選擇 **OBS Studio**、**Streamlabs** 或 **Meld Studio**。只有在未連線時才能切換。

每個直播軟體各自保存自己的快捷鍵與場景清單，切換軟體後會顯示該軟體自己的設定。

### 步驟二：準備直播軟體

#### OBS Studio

1. 在 OBS 開啟 **工具 → WebSocket 伺服器設定**
2. 勾選 **啟用 WebSocket 伺服器**
3. 點 **顯示連線資訊** 查看密碼
4. 回到 Stream Toolkit，填入 **主機**（預設 `localhost`）、**連接埠**（預設 `4455`）、**密碼**

#### Streamlabs／Meld Studio

不需要額外設定，開著即可連線。

### 步驟三：連線

點 **連線**，**狀態** 變成 **已連線** 即完成（OBS 與 Meld 會一併顯示版本號）。點 **中斷連線** 可中斷。

**啟動時自動連線**（預設開啟）：Stream Toolkit 啟動時，以及開啟功能開關時自動連線。關閉功能開關會中斷連線。

### 場景

**場景** 區塊會列出所有場景與各自的來源數量，目前場景會標示出來。在直播軟體改過場景後，點 **重新整理** 取得最新清單。

未連線時會顯示上次取得的清單。

## 快捷鍵設定分頁

設定快捷鍵：點 **點擊設定快捷鍵**，再按下按鍵組合。按 `Esc` 取消。若該組合已被其他功能使用，會顯示 **快捷鍵衝突** 且不會儲存。點快捷鍵旁的 **✕** 可清除。

### 切換場景

1. 點 **新增**
2. 設定快捷鍵
3. 選擇要切換到的場景

點該列最後的 **✕** 可刪除。

### 開關來源

一組快捷鍵可同時控制同一場景中的多個來源。

1. 點 **新增**
2. 設定快捷鍵
3. 輸入 **名稱**（選填，作為快速工具中的按鈕文字；留空則顯示場景名稱）
4. 選擇來源所在的場景
5. 點 **新增來源**，選擇來源並設定 **顯示**、**隱藏** 或 **切換**（預設 **切換**）
6. 要控制更多來源就重複步驟 5

更換這組的場景時，已加入的來源會被清空。

## 在快速工具中使用

功能開啟且至少有一組快捷鍵設定時，[快速工具](./quick-tools.md) 會出現 **OBS場景控制** 卡片，每組設定各有一個按鈕。點按鈕的效果與按下快捷鍵相同。

## 錯誤訊息

使用快捷鍵或按鈕時可能跳出以下訊息：

| 訊息 | 意思 |
|------|------|
| **尚未連線到 OBS** | 尚未連線，請到 **連線設定** 分頁點 **連線** |
| **找不到場景「…」** | 該場景已在直播軟體中改名或刪除 |
| **找不到來源：…** | 這些來源已不在該場景中 |

## 試用版限制

:::info
試用版最多只能新增 **1** 組快捷鍵（切換場景與開關來源合計）。詳見 [試用版 / 正式版比較](../getting-started/trial-comparison.md)。
:::

## 常見問題

**Q：顯示找不到 OBS，打開 OBS 後也沒有自動重連？**
第一次連線就失敗時（例如當時 OBS 還沒開），Stream Toolkit 不會一直重試。請先開啟直播軟體，再點 **連線**。只要成功連線過一次，之後連線中斷時就會自動重新連線。
