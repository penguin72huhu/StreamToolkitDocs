# 語音翻譯

按住快捷鍵說話，Stream Toolkit 會把語音轉成文字、翻譯，並把原文和譯文一起顯示成 OBS 字幕。

語音辨識使用 Whisper 模型，在你自己的電腦上執行；辨識出的文字再透過 MyMemory 翻譯。

頁面分成 **設定**、**外觀** 兩個分頁。

## 步驟一：新增 OBS 來源

頁面上方會顯示 OBS 來源網址：

```
http://127.0.0.1:7272/voice-translate
```

點 **複製**，再到 OBS 新增為瀏覽器來源，詳見 [如何在 OBS 加入來源](../getting-started/obs-source.md)。語音翻譯不會播放聲音，不需要勾選「使用 OBS 控制音訊」。

字幕會出現在來源的下方：上面一行是原文，下面一行是譯文，經過 **字幕顯示時間** 後淡出。

:::tip
請打開左側選單 **語音翻譯** 旁的開關（**開啟 OBS 顯示**）。開關關閉時，快捷鍵不會作用。
:::

## 步驟二：設定快捷鍵

在 **快捷鍵（按住錄音，放開辨識）**：

1. 點 **點擊設定快捷鍵**
2. 按下想要的按鍵組合後放開；按 **Esc** 可取消
3. 要移除快捷鍵，點 **清除**

如果這組按鍵已被其他功能使用，按鈕會顯示 **快捷鍵衝突**，不會儲存。

即使 Stream Toolkit 不是目前的視窗，快捷鍵也有效。說話時 **按住** 快捷鍵，說完 **放開** 就會開始辨識並翻譯。單次錄音最長 15 秒，超過會自動停止。

也可以用滑鼠按住快捷鍵下方的 **REC** 按鈕，用法相同：按住錄音、放開翻譯。[快速工具](./quick-tools.md) 視窗也有同樣的 **REC** 按鈕。

## 步驟三：辨識設定

| 欄位 | 說明 |
|------|------|
| **模型狀態** | 顯示 **載入中 xx%**、**已就緒** 或 **模型載入失敗**。顯示 **已就緒** 後才能錄音 |
| **Whisper 模型** | **Tiny（最快，約 40MB）**、**Base（建議，約 75MB）**（預設）、**Small（最準，約 245MB）**。第一次使用某個模型時會先下載；切換模型會重新載入 |
| **語音語言** | 你說話的語言，預設為繁體中文 |
| **麥克風** | 錄音用的麥克風。**系統預設** 會使用 Windows 的預設輸入裝置 |

## 步驟四：翻譯設定

| 欄位 | 說明 |
|------|------|
| **字幕顯示時間** | 字幕停留在畫面上的秒數，1–30 秒，預設 5 秒 |
| **目標語言** | 要翻譯成的語言，預設為英文 |
| **翻譯目標為 English 時使用 Whisper 翻譯** | 目標語言為英文時，改用 Whisper 翻譯，不經過 MyMemory（免費且無額度，但延遲較高）。目標語言不是英文時沒有作用 |
| **翻譯服務** | MyMemory |

### Email（選填）

MyMemory 免費使用，每日額度依是否填 email 而不同：

- 不填：每日 5,000 字元
- 填入 email：每日 50,000 字元（免費，不需在 MyMemory 註冊）

輸入 email 後點 **儲存**。這個 email **與聊天室翻譯共用**。

下方的進度條會顯示 **今日已用（粗估，每日 UTC 08:00 重置）**，額度用完時會顯示 **已用滿**。

## 步驟五：外觀

在 **外觀** 分頁可以調整字幕樣式，修改後會立即儲存。

- **預覽**：顯示範例字幕。旁邊的顏色框只改變預覽的背景色
- **排列**：**置左**（預設）、**置中**、**置右**
- **字體**：**原始語言**（原文）和 **目標語言**（譯文）各一列，每列可設定字型、顏色、大小（8–120 px）。預設原文 14 px、譯文 22 px
- **陰影**：文字陰影的顏色
- **恢復預設**：還原為預設外觀

## 常見問題

**Q：按住快捷鍵沒有反應？**
請確認左側選單 **語音翻譯** 旁的開關已打開，且 **模型狀態** 顯示 **已就緒**。

**Q：有錄到音，但 OBS 沒有出現字幕？**
MyMemory 翻譯失敗時（例如每日額度已用完）不會顯示字幕。請查看 **今日已用** 進度條；填入 email 可以提高額度。如果目標語言是英文，也可以開啟 **翻譯目標為 English 時使用 Whisper 翻譯**，這個方式沒有額度限制。
