# 計時器

在直播畫面上顯示倒數計時或碼表。倒數計時可以手動按按鈕加減時間，也可以在 Twitch 追隨、訂閱、小奇點或贊助時自動加減。

頁面分為 **設定** 與 **建立計時器** 兩個分頁。請先建立計時器，再到 **設定** 分頁控制。

## 步驟一：建立計時器

1. 點左側選單的 **計時器**，切換到 **建立計時器** 分頁
2. 在 **我的計時器** 點 **新增**，會建立一個倒數計時器，初始時間 10 分鐘，並附三個時間選項（+30 秒、+1 分、+5 分）
3. 點計時器卡片即可編輯；點卡片上的 **✕** 可刪除該計時器

**預覽** 會顯示目前選取計時器的樣子，旁邊的色塊可以更換預覽背景色。

## 步驟二：計時器設定

### 計時模式

- **倒數計時**：從初始時間往下倒數
- **碼表**：從 0 往上計時，可以計圈。碼表模式沒有初始時間、警示時間、結束音效與時間選項

### 名稱

顯示在計時器清單、下拉選單與快速工具中的名稱。

### 初始時間

倒數的起始時間，以時、分、秒設定，旁邊會顯示換算後的總秒數。

### 警示時間

剩餘時間到達此數值時，時間文字會改用 **外觀** 中設定的 **警示** 顏色。設為 0 表示不警示。

### 倒數結束音效

倒數歸 0 時播放的音效。可選 **無** 或內建音效（**鈴聲**、**金幣**、**鐘聲**、**彈出**、**號角**），點 **▶** 可試聽。要用自己的音檔，點 **選擇音效** 從素材管理中挑選。

音效是由 OBS 瀏覽器來源播放，請在計時器來源勾選 **使用 OBS 控制音訊**，詳見 [如何在 OBS 加入來源](../getting-started/obs-source.md)。

### 時間選項

時間選項就是倒數計時的加減時間按鈕，每個計時器最多 20 個。

在 **新增時間選項** 表單中設定：

1. **觸發來源**：選擇什麼情況會自動套用此選項
   - **手動**：只有手動點按鈕時才套用
   - **追隨**：每有一個新的 Twitch 追隨時套用
   - **Twitch Bits**：收到小奇點時套用
   - **Twitch 新訂閱**：收到 Twitch 訂閱時套用
   - **贊助**：收到贊助時套用。可在 **贊助平台** 勾選要計入的 **YouTube**、**歐付寶**、**綠界**、**PayPal**
2. 選 **Twitch Bits** 或 **贊助** 時，還要設定：
   - **觸發門檻**：每一級所需的小奇點數或贊助金額
   - **換算方式**：**整數倍觸發** 或 **按比例換算**（見下方範例）
3. **加時間**：選 **＋** 或 **－**，再設定時、分、秒
4. 點 **新增**

要修改選項，點該選項的 **編輯**，改完表單後點 **儲存**（或 **取消**）；點 **✕** 可刪除。設有自動觸發的選項會標示 🔗 與觸發來源名稱。

**換算範例**：觸發門檻 100 bits、加時間 +1 分，觀眾送出 250 bits：

- **整數倍觸發**：只計算門檻的完整倍數 → 2 × 1 分 = **+2 分**
- **按比例換算**：250 ÷ 100 × 1 分 → **+2 分 30 秒**

贊助金額會先換算成 App 設定中選擇的幣別，再與門檻比較。

:::note
- 自動觸發只會影響倒數計時器
- 設有自動觸發的時間選項，在控制台中仍會顯示為按鈕，也可以手動點擊
- **Twitch 新訂閱** 每個訂閱事件套用一次：一次贈送多份訂閱只會套用一次。重新訂閱只有在 [Twitch目標條](./goal.md) 勾選 **計算重新訂閱** 時才會套用
:::

### 控制快捷鍵

為這個計時器設定快捷鍵：

- **開始／暫停**
- **計圈快捷鍵**（僅碼表）
- **重設快捷鍵**

另見 [快捷鍵](./hotkeys.md)。

## 步驟三：外觀

| 設定 | 說明 |
|------|------|
| **字型** | 時間文字的字型 |
| **字體大小** | 12–300 px |
| **字體顏色** | **正常**：**純色** 或 **漸層**（兩個顏色加 **角度**）。**警示**（僅倒數計時）：到達警示時間後使用的顏色 |
| **背景顏色** | 時間後方的背景 |
| **邊框** | 外框顏色、**透明度**、**粗度**（0–20 px） |
| **陰影** | 陰影顏色、**透明度**、**模糊**、**X** / **Y** 偏移 |

## 步驟四：選擇顯示模式並加入 OBS 來源

切換到 **設定** 分頁，在 **控制台** 選擇 **顯示模式**：

| 模式 | 說明 | OBS 來源網址 |
|------|------|-------------|
| **單一計時器** | OBS 只顯示目前選定的計時器，用 **當前計時器** 下拉選單切換 | `http://127.0.0.1:7272/timer` |
| **多計時器** | 每個計時器各有獨立網址，可分別加入 OBS | `http://127.0.0.1:7272/timer/<計時器 ID>` |

**多計時器** 模式下，從 **加入顯示** 選擇計時器。每個加入的計時器會有自己的卡片與 **OBS 來源網址**，點 **複製** 即可複製；點卡片上的 **✕** 可從顯示移除。

將複製的網址加入 OBS 瀏覽器來源，詳見 [如何在 OBS 加入來源](../getting-started/obs-source.md)。

:::tip
記得同時打開左側選單 **計時器** 旁的開關（**開啟 OBS 顯示**）。開關關閉時，OBS 上不會顯示計時器。
:::

## 步驟五：控制計時器

**設定** 分頁的每張計時器卡片有：

- **開始** / **暫停**：碼表的暫停按鈕顯示為 **停止**。倒數已歸 0 時無法開始，需先重設或加時間
- **計圈**（僅碼表）：計時中記錄一圈。各圈會列在卡片下方，顯示時間與和上一圈的差距
- **重設**：停止計時並回到初始時間（碼表回到 0），同時清除計圈紀錄
- **加時間**（僅倒數計時）：每個時間選項一個按鈕

計時中的時間只會顯示在 OBS 畫面上，設定頁不顯示。也可以從 [快速工具](./quick-tools.md) 視窗控制計時器，視窗中也會顯示目前時間。
