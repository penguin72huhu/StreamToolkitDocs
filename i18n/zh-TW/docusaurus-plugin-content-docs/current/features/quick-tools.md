# 快速工具

**快速工具**是一個小型操作視窗，可以放在遊戲或 OBS 旁邊。不用切回主視窗，就能開關功能、使用各功能最常用的操作。

## 開啟快速工具

以下任一方式：

- 點主視窗左側選單最上方的 **⚡ 快速工具**
- 在系統匣的 Stream Toolkit 圖示按右鍵，選 **開啟快速工具**

視窗已開啟時，會直接帶到最前面，不會再開第二個。

## 視窗操作

- **移動**：拖曳標題列
- **📌 置頂 / 取消置頂**：讓視窗保持在其他視窗上方。視窗開啟時預設為置頂
- **✕**：關閉視窗

視窗會跟隨 App 的主題與介面語言。

## 快速開關面板

點視窗左緣的 **›** 箭頭，會滑出 **快速開關** 面板，列出所有功能：

- 開關：開啟或關閉該功能（與主視窗左側選單每個功能旁的開關相同）
- **⚙**（**開啟設定**）：叫出主視窗並跳到該功能的設定頁

點面板外面或再點一次箭頭即可收起。

功能的排列順序與主視窗左側選單相同。要調整順序，請在主視窗左側選單拖曳功能旁的 **⠿**。

## 功能卡片

已開啟、且有可操作項目的功能會顯示成卡片。卡片預設收合，點卡片標題即可展開或收合。若這些功能都沒開啟，視窗會顯示 **尚未開啟任何功能**。

| 功能 | 卡片內容 |
|------|---------|
| [OBS場景控制](./obs-scene.md) | 連線狀態，以及每組已設定的切換場景／開關來源各一個按鈕（目前場景會標示）。未連線時按鈕無法按。至少新增一組快捷鍵後才會顯示這張卡片 |
| [語音翻譯](./voice-translate.md) | **REC** 按鈕：按住錄音，放開後翻譯 |
| [實況精華標記](./highlight.md) | **MARK** 按鈕。標記後會顯示平台圖示與時間點 5 秒 |
| [贊助條](./donate.md) | 目前金額／目標金額與進度條、**手動新增金額** 欄位與 **新增** 按鈕、**歸零** |
| [計時器](./timer.md) | 每個顯示中的計時器：名稱、時間、**開始**／**暫停**、**重置**，以及你設定的加時按鈕。碼表則改為 **停止** 與 **單圈** |
| [轉盤](./turntable.md) | 每個顯示中的轉盤：**啟動**、**重置** |
| [實況效果板](./multimedia.md) | 已釘選的圖片（顯示／隱藏）、影片（播放）、音效（播放）按鈕 |
| [點歌](./song-request.md) | **播放**／**暫停**、**停止**、**下一首** |

若該操作有設定快捷鍵，按鈕上會顯示快捷鍵。

在這裡沒有可操作項目的功能（聊天室、Twitch目標條、贊助通知、贊助紀錄板、時鐘、表情符號牆、投票、抽獎、聊天機器人），只會在快速開關面板中提供開關。

:::tip
贊助條卡片的 **歸零** 需要按兩次：第一次按下後按鈕會變成 **確定歸零**，10 秒內再按一次才會把金額歸零。
:::

:::info
計時器與轉盤會依照各自的 **顯示模式** 顯示：**單一計時器**／**單一轉盤** 只顯示目前選定的那一個；**多計時器**／**多轉盤** 只顯示你加入的項目。若沒有可顯示的項目，卡片會顯示 **尚無計時器**／**尚無轉盤**。
:::
