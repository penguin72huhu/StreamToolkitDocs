# 贊助通知

有人贊助時，在直播畫面跳出包含圖片、音效、贊助者名稱、金額與留言的通知。

## OBS 來源網址

```
http://127.0.0.1:7272/donate-alert
```

從 **贊助通知 設定** 頁上方複製網址，在 OBS 新增為瀏覽器來源。請參考 [如何在 OBS 加入來源](../getting-started/obs-source.md)。

:::warning
贊助通知會播放音效，請在瀏覽器來源內容中勾選 **使用 OBS 控制音訊**，否則直播中聽不到聲音。
:::

左側選單 **贊助通知** 旁的開關控制是否顯示通知。關閉時不會跳出任何通知（包含測試通知），但贊助仍會記錄到 [贊助紀錄板](./sponsors.md)。

短時間內多筆贊助時，通知會排隊依序顯示。

## 設定分頁

### 串接平台

勾選要跳通知的平台：**Twitch**、**YouTube**、**PayPal**、**Stripe**、**歐付寶**、**綠界**。綠點代表已連接；未連接會顯示 **（未連接）**。這裡的勾選只影響贊助通知，不影響贊助條與贊助紀錄板。

**Twitch ⚙️**（Twitch 已連接且有勾選時出現）：

1. 選擇 **計算小奇點和訂閱**、**僅計算小奇點** 或 **僅計算訂閱**
2. **計算重新訂閱**：重新訂閱是否跳通知（有計算訂閱時出現）
3. **未滿 [N] 小奇點不列入計算**：勾選並填入門檻，低於門檻的小奇點不跳通知（有計算小奇點時出現）
4. 點 **儲存**

**YouTube ⚙️**：

- **顯示觀眾名稱而非 @代稱**：需先登入 Google 才能勾選。
- **計入項目**：**超級感謝**、**超級貼圖**、**加入會員**、**會員續訂**、**贈送會員**、**寶石**。**寶石** 需先登入 Google。

若尚未連結 YouTube 聊天室，會顯示 **未連結聊天室網址** 以及 **自動連結**（需先登入 Google）與 **手動填寫**（跳到設定頁的聊天室網址欄位）。若有勾選會員相關項目但尚未設定會員價格，點 **⚠ 未設定會員價格** 即可前往設定。請參考 [YouTube 設定](../platforms/youtube-settings.md)。

PayPal、Stripe、歐付寶、綠界的串接方式請參考 [PayPal](../payments/paypal.md)、[Stripe](../payments/stripe.md)、[歐付寶](../payments/opay.md)、[綠界](../payments/ecpay.md)。

### 設定

| 欄位 | 說明 |
|------|------|
| **自動換算成自身貨幣** | 預設開啟。金額會換算成設定頁的 **贊助貨幣** 顯示 |
| **顯示時間** | 每則通知停留的秒數，預設 6 秒 |

## 外觀分頁

### 預覽

預覽使用與 OBS 來源相同的頁面。**預覽** 旁的顏色可更換預覽背景，點 **▶ 重播動畫** 可再播放一次通知動畫。

### 統一樣式／各平台獨立

- **統一樣式**：所有平台共用同一套通知樣式。
- **各平台獨立**：每個平台各自一套樣式。用下方按鈕（**Twitch**、**YouTube**、**歐付寶**、**綠界**、**PayPal**、**Stripe**）選擇平台後再調整。第一次切換時，尚未自訂過的平台會沿用目前的統一樣式，倒數條則套用各平台自己的顏色。

**恢復預設** 會把目前編輯中的樣式還原為預設。

### 圖片

- **選擇圖片**：從素材管理中挑選圖片。未設定時顯示愛心符號。**清除** 可移除圖片。
- **圖片大小**：1–400 px。
- **圖片位置**：**靠左**、**靠右**、**上方**、**下方**。

### 音效

選擇內建音效：**無**、**鈴聲**（預設）、**金幣**、**鐘聲**、**彈出**、**號角**。點 **▶** 試聽。點 **選擇音效** 可從素材管理使用自己的音效檔。

### 文字顯示

- **預設**：金額、贊助者名稱、留言分行顯示。
- **自訂文字**：自己寫一行文字，用 `{name}` 代入贊助者名稱、`{amount}` 代入金額，例如 `感謝 {name} 贊助 {amount}！`

### 文字與顏色

- **文字**：分別設定 **金額**、**贊助者名稱**、**留言** 的字型、大小與顏色（自訂文字模式下另有 **自訂文字**）。
- **顏色**：**背景**、**陰影**、**倒數條**。

### 自訂 CSS

展開 **自訂 CSS** 可編輯目前樣式（統一或所選平台）的 CSS。**恢復預設** 會還原範本 CSS，**管理素材** 可開啟素材管理。這裡也能套用 Steam 工作坊主題；套用主題後 CSS 為唯讀。請參考 [主題樣式](./themes.md)。

## 測試通知

在 **設定** 頁 **贊助平台串接** 旁點 **測試通知**：

1. 填入 **測試名稱**、**測試留言**、**測試金額**，並選擇 **測試平台**
2. 點 **發送測試通知**

下方的 **YouTube 超級留言測試** 可直接輸入原始 **金額字串**（例如 `$5.00`、`¥500`、`NT$150`），點 **發送測試超級留言** 測試金額解析與幣別換算。

:::note
測試通知會當作一筆真實贊助處理：若 [贊助條](./donate.md) 與 [贊助紀錄板](./sponsors.md) 有勾選該平台，也會一併計入。
:::

:::info 試用版
自訂 CSS 僅限正式版。試用版無法使用真實金流（PayPal / Stripe / 歐付寶 / 綠界）以及 YouTube 會員相關項目與寶石，且 OBS 中的通知會顯示浮水印。詳見 [試用版 / 正式版比較](../getting-started/trial-comparison.md)。
:::

## 常見問題

**Q：直播中沒有聲音？**
確認瀏覽器來源已勾選 **使用 OBS 控制音訊**，且 OBS 混音器中該來源沒有靜音。也請確認 **音效** 不是設為 **無**。

**Q：比較晚才加入 OBS 來源，會補播之前的通知嗎？**
不會。新開啟的來源只會顯示連上之後收到的通知。
