# 設定

點左側選單最下方的 **⚙️ 設定**。這裡是全域選項、平台連結和贊助金流串接。

## 一般設定

| 選項 | 說明 | 預設 |
|------|------|------|
| **主題** | 介面顯示模式：**灰暗** 或 **明亮** | 灰暗 |
| **語言** | 介面顯示語言，切換後立即生效 | — |
| **按 X 時縮小到工具列** | 關閉視窗時改為縮小到右下角工具列，不會結束程式 | 開啟 |
| **贊助貨幣** | 全域貨幣單位，影響贊助條、通知彈窗等所有金額顯示 | 首次啟動時依系統語系決定（例如繁體中文（台灣）→ TWD、日文 → JPY，其他 → USD） |

## 平台連結

### Twitch

點 **連結帳號**，在瀏覽器完成授權。連結後會顯示 **已連結 @你的帳號** 和 **解除連結** 按鈕。完整步驟請看 [Twitch 設定](../platforms/twitch.md)。

連結後可以展開 **▸ 換算設定**，設定小奇點和訂閱換算成贊助貨幣的金額：

- **分潤機制**：**50 / 50** 或 **70 / 30**
- **每 100 奇點**、**Tier 1 訂閱**、**Tier 2 訂閱**、**Tier 3 訂閱**
- **儲存** 會儲存目前貨幣的數值；**恢復預設** 會帶入該貨幣的內建數值

### YouTube

1. 點 **連結帳號**，用 Google 帳號登入。詳細步驟請看 [YouTube 設定](../platforms/youtube-settings.md)
2. 連結後會顯示 **已連結：頻道名稱**；點 **解除連結** 可取消連結
3. 選擇聊天室的連接方式：
   - **自動偵測目前的直播**：需要先登入 Google。點 **連結** 會在你的頻道搜尋正在直播或即將開始的直播；有多場時可以從清單選擇
   - **手動指定網址**：貼上 **聊天室網址**
4. **每次開啟程式時提示輸入聊天室網址**：可選

YouTube 下方的 **▸ 換算設定** 用來設定會員的金額（YouTube 的會員事件不會帶金額）：

- **會員等級**：新增每個等級名稱和金額。等級名稱須與 YouTube 頻道設定完全一致
- **未列出的等級**：等級不在表中時使用的金額
- **贈送會員等級**：贈送的會員要算哪個等級
- 收到但不在表中的等級會列出來，可以點 **加入等級表** 或 **忽略**

### 測試通知

標題旁的 **測試通知** 按鈕會開啟測試視窗：

- 填入 **測試名稱**、**測試留言**、**測試金額**，選擇 **測試平台**，點 **發送測試通知**
- **YouTube 超級留言測試**：在 **金額字串** 輸入例如 `$5.00` 或 `NT$150`，點 **發送測試超級留言**，可以測試金額解析與幣別換算
