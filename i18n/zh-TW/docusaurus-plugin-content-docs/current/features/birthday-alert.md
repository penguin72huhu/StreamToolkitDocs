# 粉絲生日通知

把觀眾的生日登記到名單上。名單上的觀眾在生日當天或之後幾天內、於直播中在聊天室說話時，直播畫面會跳出生日通知。每位觀眾每次生日只通知一次。

## OBS 來源網址

```
http://127.0.0.1:7272/birthday-alert
```

從 **粉絲生日通知 設定** 頁上方複製網址，在 OBS 新增為瀏覽器來源。請參考 [如何在 OBS 加入來源](../getting-started/obs-source.md)。

:::warning
粉絲生日通知會播放音效，請在瀏覽器來源內容中勾選 **使用 OBS 控制音訊**，否則直播中聽不到聲音。
:::

打開左側選單 **粉絲生日通知** 旁的開關。開啟後才會連線聊天室、開始比對生日。**測試通知** 與 **重播** 按鈕在開關關閉時也能使用。

頁面有三個分頁：**設定**、**觀眾名單**、**外觀**。

## 運作方式

- 名單上的觀眾從生日當天起、到你設定的天數內在聊天室說話，就會跳出通知。生日前不會通知。
- 每位觀眾每次生日只通知一次。12/28 的生日在 1/2 才通知，仍算是前一年的生日。
- 只有在觀眾說話的那個平台正在直播時才會通知。未開台、或程式還無法判斷是否開台時，觀眾說話不會跳通知、也不會記錄；等開台後他再說話才會跳。
- YouTube 聊天室連線時載入的歷史留言不算數，所以重新啟動程式不會替關閉期間說過話的人跳通知。
- 2/29 的生日在非閏年以 2/28 計算。

## 設定分頁

### 聊天室連線

開關開啟時才會顯示，列出各平台聊天室是否已連上：

- **Twitch**：若尚未設定頻道，會顯示 **尚未設定 Twitch 頻道，請先連結 Twitch** 與 **前往設定**。請先連接 Twitch：[Twitch 設定](../platforms/twitch.md)。
- **YouTube**：聊天室未連上時，會顯示 **自動連結** 與 **手動填寫**（跳到設定頁的聊天室網址欄位）。若使用自動連結且已登入 Google，會顯示 **開播後如果還沒連上，請到聊天室頁面按連線**。請參考 [YouTube 設定](../platforms/youtube-settings.md) 與 [聊天室](./chat.md)。

平台連上後，還會顯示 **直播中**、**未開台** 或 **無法判斷是否開台**。只有 **直播中** 才會跳通知。

### 設定

| 欄位 | 說明 |
|------|------|
| **生日後幾天內說話會通知** | 0–30，預設 7。0 = 只有生日當天 |
| **顯示時間** | 每則通知停留的秒數（1–60），預設 6 秒 |

### 測試通知

點 **測試通知**，用測試觀眾與今天的日期在 OBS 顯示一則範例通知。只顯示在 OBS，不會寫入紀錄；左側選單的開關關著也能測試。按鈕會短暫變成 **已送出**。

## 觀眾名單分頁

### 新增觀眾

有兩種新增方式：

- **＋ 從最近聊天的人新增**：挑一位最近說過話的觀眾。表單會以他的名稱當備註名稱、帳號直接綁定，生日預設為今天。
- **＋ 手動新增**：自己輸入帳號名稱。

**最近聊天的人** 會列出聊天室連線期間說過話的觀眾（最多 200 位，保留 30 天）。點 **重新整理** 可更新列表。已在名單上的觀眾會顯示 **已登記**，無法重複選取。列表較長時會出現搜尋框。

填寫表單：

1. **備註名稱**：你對這位觀眾的稱呼，例如 `小明`。可留空。
2. **生日**：月與日（不含年份）。
3. **帳號**：至少要有一個帳號。一位觀眾可以有多個帳號，例如同時有 Twitch 與 YouTube。
   - **＋ 手動輸入帳號**：選擇 **Twitch** 或 **YouTube** 並輸入名稱。Twitch 請填帳號或顯示名稱；YouTube 請填 @代稱或頻道名稱。
   - **＋ 從最近聊天的人加入**：加入一個已綁定的帳號。
   - **✕** 可移除帳號。
4. 點 **儲存**（或按 Enter）。**取消**（或按 Esc）可關閉表單。

### 手動輸入的名字與綁定

手動輸入的名字，會在這位觀眾第一次說話時綁定帳號。比對時不分大小寫，也會忽略開頭的 `@`。名字可能重複，建議從最近聊天的人裡挑。

YouTube 建議輸入 @代稱；聊天室頁面沒勾 **顯示觀眾名稱而非 @代稱** 時，輸入頻道名稱可能綁不上。

名單上每個帳號會顯示：

- **已綁定：[名稱]**：帳號已綁定。
- **待綁定：[名稱]**：手動輸入、尚未綁定的名字。
- **新綁定**：這位觀眾說話時，程式自動綁定了這個帳號。請確認是不是本人，是的話點 **✓ 確認無誤**，不是的話點 **解除綁定**。
- **此帳號已登記在「[名稱]」**：輸入的名字比對到一個已屬於名單上其他觀眾的帳號。同一個帳號只能登記在一位觀眾，請把這裡的名字改掉，或刪掉其中一筆。

**解除綁定** 會在該帳號下方開啟輸入框。解除後會改用框內的名字比對（可修改），等這位觀眾下次說話時重新綁定。

### 名單

正在生日期間、還沒通知的觀眾排在最前面，接著依下一個生日的先後排序。超過 5 位觀眾時會出現搜尋框。每位觀眾會顯示：

- **等待說話**：現在是這位觀眾的生日期間，他在聊天室說話就會跳出通知。
- **🎂 已通知 [日期]**：這次生日已經通知過。
- **▶ 重播**：在 OBS 再顯示一次這位觀眾的通知。隨時都能用，不會寫入紀錄。
- **編輯**：修改備註名稱、生日或帳號。修改生日後，新的日期可以再次觸發通知。
- **刪除**：點 **刪除** 後再點 **確認刪除**。

## 外觀分頁

### 預覽

預覽使用與 OBS 來源相同的頁面。**預覽** 旁的顏色可更換預覽背景，點 **▶ 重播動畫** 可再播放一次通知動畫。

### 統一樣式／各平台獨立

- **統一樣式**：Twitch 與 YouTube 共用同一套通知樣式。
- **各平台獨立**：每個平台各自一套樣式。用下方按鈕選擇 **Twitch** 或 **YouTube** 後再調整。第一次切換時，尚未自訂過的平台會沿用目前的統一樣式，倒數條則套用各平台自己的顏色。

**恢復預設** 會把目前編輯中的樣式還原為預設。

### 圖片

- **選擇圖片**：從素材管理中挑選圖片。未設定時顯示蛋糕符號。**清除** 可移除圖片。
- **圖片大小**：1–400 px。
- **圖片位置**：**靠左**、**靠右**、**上方**、**下方**。

### 音效

選擇內建音效：**無**、**鈴聲**（預設）、**金幣**、**鐘聲**、**彈出**、**號角**。點 **▶** 試聽。點 **選擇音效** 可從素材管理使用自己的音效檔。

### 自訂文字

輸入通知上顯示的文字。留空則使用預設文字：`{name} 生日快樂！` 可使用：

| 代入碼 | 代入內容 |
|--------|----------|
| `{name}` | 觀眾在聊天室的名稱 |
| `{label}` | 備註名稱（未填時使用聊天室名稱） |
| `{birthday}` | 生日，例如 `10/20` |
| `{MM}` `{DD}` | 兩位數的月和日，可自組格式，例如 `{MM}/{DD}` |
| `{date}` | 依通知畫面語言顯示的生日 |
| `{platform}` | 平台名稱 |

### 文字與顏色

- **文字**：分別設定 **自訂文字** 與 **觀眾名稱** 的字型、大小與顏色。
- **顏色**：**背景**、**陰影**、**倒數條**。

### 自訂 CSS

展開 **自訂 CSS** 可編輯目前樣式（統一或所選平台）的 CSS。**恢復預設** 會還原範本 CSS，**管理素材** 可開啟素材管理。這裡也能套用 Steam 工作坊主題；套用主題後 CSS 為唯讀。請參考 [主題樣式](./themes.md)。

:::info 試用版
- 名單最多 3 位。若名單中超過 3 位（例如來自正式版的存檔），多出的觀眾會顯示為鎖定 🔒：不會觸發通知，也無法編輯或重播。
- 自訂 CSS 僅限正式版。
- OBS 中的通知會顯示浮水印。

詳見 [試用版 / 正式版比較](../getting-started/trial-comparison.md)。
:::

## 常見問題

**Q：直播中沒有聲音？**
確認瀏覽器來源已勾選 **使用 OBS 控制音訊**，且 OBS 混音器中該來源沒有靜音。也請確認 **音效** 不是設為 **無**。

**Q：觀眾生日當天有說話，卻沒有跳通知？**
確認左側選單的開關已開啟、**設定** 分頁的 **聊天室連線** 中該平台顯示 **直播中**，以及名單上的帳號顯示 **已綁定**，或手動輸入的名字與他在聊天室的名稱相符。如果通知跳出時 OBS 沒開，可以用 **▶ 重播**。

**Q：比較晚才加入 OBS 來源，會補播之前的通知嗎？**
不會。新開啟的來源只會顯示連上之後收到的通知。可在 **觀眾名單** 分頁點 **▶ 重播** 再顯示一次。
