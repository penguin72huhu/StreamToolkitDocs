# 贊助紀錄板

在直播畫面上列出最近的贊助：平台圖示、贊助者名稱、金額與留言。

## OBS 來源網址

```
http://127.0.0.1:7272/sponsors
```

從 **贊助紀錄板 設定** 頁上方複製網址，在 OBS 新增為瀏覽器來源。請參考 [如何在 OBS 加入來源](../getting-started/obs-source.md)。

左側選單 **贊助紀錄板** 旁的開關控制 OBS 是否顯示。關閉時紀錄板會淡出，但贊助仍會照常記錄。

## 設定分頁

### 串接平台

勾選要記錄的平台：**Twitch**、**YouTube**、**PayPal**、**Stripe**、**歐付寶**、**綠界**。綠點代表已連接；未連接會顯示 **（未連接）**。這裡的勾選只影響贊助紀錄板，不影響贊助條與贊助通知。

**Twitch ⚙️**（Twitch 已連接且有勾選時出現）：

1. 選擇 **計算小奇點和訂閱**、**僅計算小奇點** 或 **僅計算訂閱**
2. **計算重新訂閱**：是否記錄重新訂閱（有計算訂閱時出現）
3. **未滿 [N] 小奇點不列入計算**：勾選並填入門檻，低於門檻的小奇點不記錄（有計算小奇點時出現）
4. 點 **儲存**

**YouTube ⚙️**：

- **顯示觀眾名稱而非 @代稱**：需先登入 Google 才能勾選。
- **計入項目**：**超級感謝**、**超級貼圖**、**加入會員**、**會員續訂**、**贈送會員**、**寶石**。**寶石** 需先登入 Google。寶石禮物會以寶石圖示加數量顯示，而不是金額。

若尚未連結 YouTube 聊天室，會顯示 **未連結聊天室網址** 以及 **自動連結**（需先登入 Google）與 **手動填寫**（跳到設定頁的聊天室網址欄位）。若有勾選會員相關項目但尚未設定會員價格，點 **⚠ 未設定會員價格** 即可前往設定。請參考 [YouTube 設定](../platforms/youtube-settings.md)。

PayPal、Stripe、歐付寶、綠界的串接方式請參考 [PayPal](../payments/paypal.md)、[Stripe](../payments/stripe.md)、[歐付寶](../payments/opay.md)、[綠界](../payments/ecpay.md)。

### 設定

| 欄位 | 說明 |
|------|------|
| **自動換算成自身貨幣** | 預設開啟。金額會換算成設定頁的 **贊助貨幣** 顯示 |
| **最多顯示** | 保留幾筆紀錄（1–100），預設 20 筆。超過時新贊助進來會移除最舊的一筆 |

## 外觀分頁

### 預覽

**預覽** 旁的顏色可更換預覽背景。點 **測試新增動畫** 會用一筆範例紀錄播放進場動畫，範例不會存進歷史紀錄。

點 **恢復預設** 可還原預設外觀。

### 顯示設定

- **顯示平台 icon**：每筆紀錄顯示平台圖示。
- **出現方向**：**上到下**（預設）、**下到上**、**左到右**、**右到左**。

### 字型

分別設定 **標題**（贊助者名稱）、**內文**（留言）、**金額** 的字型、顏色與大小（8–72 px）。

### 背景顏色

- **預設**：所有紀錄的背景顏色。
- **+ 新增範圍**：新增一個顏色並設定 **金額** 範圍（**最低** ~ **最高**），金額落在範圍內的紀錄改用該顏色。最低或最高留空表示該側不設限。點 **✕** 刪除範圍。

開啟 **自動換算成自身貨幣** 時，範圍是以換算後的金額比較。

### 自訂 CSS

展開 **自訂 CSS** 可編輯紀錄板的 CSS。**恢復預設** 會還原預設 CSS，**管理素材** 可開啟素材管理。這裡也能套用 Steam 工作坊主題；套用主題後 CSS 為唯讀。請參考 [主題樣式](./themes.md)。

## 歷史紀錄分頁

### 手動新增（測試用）

選擇平台，填入 **名字**、**金額** 與 **訊息（選填）**，點 **新增**。只有在 **串接平台** 有勾選該平台時才會新增。金額以你的贊助貨幣計。

### 歷史紀錄

列出已儲存的紀錄與筆數。

- 點 **🗑** 再點 **確認刪除** 可刪除單筆紀錄。
- 點 **清空** 可刪除全部紀錄，會先跳出確認視窗，無法復原。

:::info 試用版
自訂 CSS 僅限正式版。試用版無法使用真實金流（PayPal / Stripe / 歐付寶 / 綠界）以及 YouTube 會員相關項目與寶石，且 OBS 中的紀錄板會顯示浮水印。詳見 [試用版 / 正式版比較](../getting-started/trial-comparison.md)。
:::

## 常見問題

**Q：測試通知也出現在紀錄板上？**
設定頁的 **測試通知** 會當作一筆真實贊助處理，若該平台有勾選也會記錄到這裡。可在 **歷史紀錄** 分頁刪除。
