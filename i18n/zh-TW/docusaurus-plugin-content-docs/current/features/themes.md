# 主題樣式

透過 Steam 工作坊分享和下載 OBS 畫面的外觀。主題可以包含以下功能的外觀：

- [聊天室](./chat.md)
- [贊助條](./donate.md)
- [贊助通知](./donate-alert.md)
- [新粉絲通知](./fan-alert.md)
- [粉絲生日通知](./birthday-alert.md)
- [贊助紀錄板](./sponsors.md)
- [投票](./vote.md)
- [時鐘](./clock.md)
- [Twitch目標條](./goal.md)：**追隨目標**、**訂閱目標**、**小奇點目標**

從左側選單最下方的 **🎨 主題樣式** 開啟。頁面分成 **我的主題**、**下載的主題** 兩個分頁。使用時需要開著 Steam。

## 在功能頁尋找並套用主題

在上面列出的功能頁中，打開 **自訂 CSS** 區塊，點 **瀏覽工作坊主題**：

1. **探索主題** 會列出這個功能的工作坊主題。可以在 **搜尋主題名稱** 輸入後點 **搜尋**，或用 **上一頁**／**下一頁** 翻頁
2. 點縮圖可以查看預覽圖
3. 點 **套用**，主題會自動訂閱、下載並套用到這個功能
4. **已訂閱** 會列出你已經訂閱、而且適用這個功能的主題

套用主題期間，頁面會顯示 **使用中主題：（名稱）** 和 **還原** 按鈕，自訂 CSS 會變成唯讀。點 **還原** 可以回到你自己的設定。

## 下載的主題

列出你在 Steam 訂閱的所有主題。訂閱的主題不會自動套用，請用卡片上的按鈕，OBS 畫面會立即更新。

每張卡片會顯示預覽圖、名稱、有功能正在使用時的 **使用中** 標記，以及 **包含：** 主題涵蓋的功能（打 ✓ 的是目前正在使用的功能）。

| 按鈕 | 作用 |
|------|------|
| **一鍵套用** | 套用到主題包含的所有功能。若某功能正在使用其他主題，會先請你確認是否取代 |
| **選擇套用…** | 自己勾選要套用的功能 |
| **一鍵還原** | 把使用這個主題的功能，全部改回套用前你自己的設定 |
| **選擇還原…** | 自己勾選要還原的功能 |
| **取消訂閱** | 取消訂閱。如果主題正在使用，會先還原那些功能的設定 |

套用後，畫面下方會顯示結果 30 秒，可以點 **還原** 復原這次套用。

:::note
- 還原會回到你自己原本的設定，不會回到被取代的主題
- 套用期間修改的外觀設定，還原後不會保留
:::

- **下載中…**：請保持 Steam 開啟，下載完成後即可套用
- **已移除的主題（#編號）**：主題已不在你的 Steam 訂閱中，但仍有功能在使用，圖片可能顯示異常，建議還原
- 如果 Steam 沒開，請開啟 Steam 後點 **重新整理**

## 我的主題：上傳主題

1. 先到各功能頁設定好要分享的外觀
2. 在 **我的主題** 點 **上傳新主題**
3. 填寫：
   - **主題名稱**（必填）
   - **主題說明**
   - **包含的功能**（至少勾一項）
   - **預覽圖片**（必填，1MB 以內）：點 **選擇預覽圖**
4. 勾選確認主題中的圖片、字型與音效皆為你擁有散布權利的素材。僅限個人或非商業用途授權的素材不得上傳
5. 點 **上傳主題**

如果看到「請先在瀏覽器中同意 Steam 工作坊條款」，請先同意條款，主題才會公開。

### 管理已上傳的主題

每個已上傳的主題都有：

- **下載並套用**：把已發布的主題套用到你的功能。會覆蓋你目前的外觀設定
- **編輯**：以你目前的外觀設定重新上傳到同一個主題。若尚未下載此主題，原本的預覽圖不會沿用，需要重新選一張
- **在 Steam 管理**：在 Steam 開啟這個主題

:::info 試用版限制
主題樣式（Steam 工作坊）只有正式版能用。試用版無法開啟 **🎨 主題樣式**，也無法套用主題。

詳見 [試用版 / 正式版比較](../getting-started/trial-comparison.md)。
:::
