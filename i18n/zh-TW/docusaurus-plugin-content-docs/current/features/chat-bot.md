# 聊天機器人

自動在聊天室發訊息：每隔一段時間發的定時留言，以及觀眾輸入指令時的關鍵字回覆。機器人會用你自己的帳號發言。

聊天機器人沒有 OBS 畫面，不需要加入 OBS 來源。

:::tip
請打開左側選單 **聊天機器人** 旁的開關。開關關閉時，機器人不會發送任何訊息。
:::

頁面分成 **設定**、**定時留言**、**關鍵字回覆** 三個分頁。

## 設定分頁

在 **平台** 點 **Twitch** 開啟（再點一次關閉）。Twitch 已連接時旁邊的圓點會亮起，否則會顯示 **（未連接）**。請先完成連接：[Twitch 設定](../platforms/twitch.md)。

**YouTube** 目前顯示 **即將推出**，還不能開啟。

沒有連接任何平台時，另外兩個分頁會顯示「尚未連接任何平台，機器人不會發送訊息。」和 **前往設定** 按鈕。

## 定時留言

開台時每隔一段時間發一則訊息。

1. 點 **+ 新增**
2. 填寫：
   - **內容**：要發的文字（Twitch 最多 500 字）。訊息只會有一行：按 Enter 沒有作用，貼上的換行會變成空白
   - **間隔**：每幾分鐘發一次（5–240，預設 15）
   - **最少聊天數**：上次發送後，聊天室要有幾則新訊息才會再發（0–100，預設 2），避免沒人說話時一直發
   - **平台**：要發到哪些平台
3. 點 **儲存**

發送規則：

- 只在開台時發送。開台後要過一個完整間隔才會發第一則，不會一開台就發
- 好幾則同時到時間時，會分開發，不會一次全部洗出來

## 關鍵字回覆

觀眾訊息以指令開頭時自動回覆。

1. 點 **+ 新增**
2. 填寫：
   - **指令**：選擇前綴（`! @ # $ % & ~`），再輸入一個不含空白的字，例如 `!dc`。會與聊天訊息的第一個字比對，不分大小寫
   - **回覆**：要回覆的文字。`{user}` 會換成觸發指令的觀眾名稱
   - **冷卻**：同一個指令要隔幾秒才能再回覆（0–3600，預設 5）
   - **平台**：要在哪些平台回覆
3. 點 **儲存**

關鍵字回覆不論有沒有開台都會回應。

指令不能和其他關鍵字回覆重複，也不能和 [點歌](./song-request.md) 的指令或 [抽獎](./lottery.md) 的關鍵字相同。

## 管理列表

兩個分頁的每個項目都有：

- 左邊的勾選框：暫時停用或啟用，不用刪除
- 平台標籤：變暗代表該平台已在「設定」分頁關閉
- **編輯**、**刪除**
