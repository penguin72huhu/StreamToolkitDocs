# 投票

在直播中發起投票。觀眾在 Twitch 或 YouTube 聊天室輸入選項編號就能投票，結果會即時顯示在 OBS 畫面上。

## OBS 來源網址

```
http://127.0.0.1:7272/vote
```

在頁面上方 **OBS 來源網址** 旁點 **複製**，再加入 OBS 瀏覽器來源，做法請看 [如何在 OBS 加入來源](../getting-started/obs-source.md)。投票沒有音效，不用勾「使用 OBS 控制音訊」。

:::tip
另外要打開左側選單 **投票** 旁的開關（**開啟 OBS 顯示**）。開關關閉時，OBS 畫面不會顯示投票。
:::

頁面分成 **設定**、**外觀**、**歷史紀錄** 三個分頁。

## 發起投票（設定分頁）

### 投票平台

點 **Twitch**／**YouTube** 選擇哪個平台的聊天室可以投票，兩個都能選。還沒連接的平台，Twitch 會顯示 **（未連接）**，YouTube 會顯示 **未連結聊天室網址**。請先完成連接：

- [Twitch 設定](../platforms/twitch.md)
- [YouTube 設定](../platforms/youtube-settings.md)

### 投票標題

可以不填，例如「今晚玩哪款遊戲？」

### 投票選項（2–10 項）

- 至少要填 2 個選項，最多 10 個
- **+ 新增選項** 會多一列，**×** 會刪除該列
- **套用歷史** 可以從最近 15 次投票中挑一筆，自動帶入它的標題和選項

編輯的時候，OBS 畫面會即時預覽標題和選項。

### 投票時間

投票長度，單位是秒。預設 60，最少 10。

### 開始／停止

- **開始投票**：至少要填 2 個選項，而且至少選一個已連接的平台，才能開始
- **停止投票**：提前結束投票。沒按的話，時間到就會自動結束

投票進行中不能修改平台、標題、選項和時間。

## 觀眾怎麼投票

投票進行中，OBS 畫面會顯示「在聊天室輸入選項編號即可投票（例：1）」。

- 整則訊息只能是選項編號，例如 `1` 或 `1.`，空白會被忽略。訊息裡有其他文字就不算
- 每位觀眾只算一票。改傳其他編號就會改投新選項，以時間到之前的最後一次為準

## 即時結果

投票期間，設定下方會出現 **即時結果**，顯示剩餘秒數、各選項票數與百分比，以及總票數。投票結束後會變成 **最終結果**。點 **詳細** 可以看到每個選項的投票者，並依 Twitch／YouTube 分開列出。

## 外觀

**外觀** 分頁最上方是 **預覽**。旁邊的顏色選擇只會改預覽的背景，不會影響 OBS 畫面。

- **字體**：分別設定 **標題**、**提示**、**選項**、**倒數秒數**、**得票數** 的字型、顏色和 **大小**（px）
- **進度條顏色**：最多 5 色，依序套用到各選項的長條。每個顏色可以選 **純色** 或 **漸層**，漸層還能設定 **角度**
- **背景顏色**：投票框的背景
- **恢復預設**：還原預設外觀。如果有套用主題，會還原成主題的外觀

**自訂 CSS** 可以自己寫樣式。想分享或下載外觀，請看 [主題樣式](./themes.md)。

## 歷史紀錄

**歷史紀錄** 分頁會列出每次投票的標題、時間、選項數和總票數。展開後可以看到各選項結果、各平台票數，還能點 **詳細**。只保留最近 30 天的投票紀錄。要刪除紀錄，請點 🗑 再點 **確認刪除**。

:::info 試用版限制
- **自訂 CSS** 只有正式版能用
- OBS 畫面會顯示浮水印

詳見 [試用版 / 正式版比較](../getting-started/trial-comparison.md)。
:::
