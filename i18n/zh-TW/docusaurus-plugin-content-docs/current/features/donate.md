# 贊助條

在直播畫面上顯示贊助目標的進度條。勾選平台的贊助會自動累加到總額。

## OBS 來源網址

```
http://127.0.0.1:7272/donate
```

從 **贊助條 設定** 頁上方複製網址，在 OBS 新增為瀏覽器來源。請參考 [如何在 OBS 加入來源](../getting-started/obs-source.md)。

左側選單 **贊助條** 旁的開關控制 OBS 是否顯示。關閉時贊助條會隱藏。

## 貨幣

贊助條使用 **設定** 頁的 **贊助貨幣**。其他幣別的贊助會先換算成這個貨幣再累加。若某筆贊助的幣別無法換算，就不會加進贊助條（贊助通知與贊助紀錄板仍會以原幣別顯示）。

## 設定分頁

### 串接平台

勾選要計入贊助條的平台：

- **Twitch**：小奇點與訂閱
- **YouTube**
- **PayPal**
- **Stripe**
- **歐付寶**
- **綠界**

綠點代表已連接；未連接會顯示 **（未連接）**。這裡的勾選只決定贊助條算不算該平台，不影響贊助通知與贊助紀錄板，兩者各有自己的平台設定。

- **YouTube**：若尚未連結聊天室，會顯示 **未連結聊天室網址** 和兩個按鈕：**自動連結**（需先登入 Google）與 **手動填寫**（跳到設定頁的聊天室網址欄位）。請參考 [YouTube 設定](../platforms/youtube-settings.md)。
- **YouTube ⚙️**：選擇 **計入項目**：**超級感謝**、**超級貼圖**、**加入會員**、**會員續訂**、**贈送會員**、**寶石**。**寶石** 需先登入 Google。
- 若有勾選會員相關項目但尚未設定會員價格，會出現 **⚠ 未設定會員價格**。點一下即可前往設定頁，在 YouTube 的 **換算設定** 填入各會員等級的價格。
- Twitch 小奇點與訂閱的換算金額在 設定 → Twitch → **換算設定**。請參考 [Twitch 設定](../platforms/twitch.md)。
- PayPal、Stripe、歐付寶、綠界的串接方式請參考 [PayPal](../payments/paypal.md)、[Stripe](../payments/stripe.md)、[歐付寶](../payments/opay.md)、[綠界](../payments/ecpay.md)。

### 目前進度

顯示目前累積金額、目標與百分比。

| 欄位 | 說明 |
|------|------|
| **標題** | 選填，顯示在進度條上方 |
| **目標金額** | 目標金額，單位為贊助貨幣 |
| **手動新增** | 輸入金額後點 **新增**（或按 Enter）即加到總額 |
| **歸零** | 把目前累積金額清為 0，會先跳出確認視窗，無法還原 |

## 外觀分頁

### 預覽

預覽以範例金額顯示贊助條。**預覽** 旁的顏色可更換預覽背景；勾選 **預覽達成** 可查看達標後的樣子。

### 字型與顏色

點 **恢復預設** 可還原預設外觀。

- **字型**：分別設定 **標題**、**金額**、**%數** 的字型、顏色與大小（8–72 px）。
- **顏色**：設定 **背景**、**目標條**（進度填色）、**目標條達成**（達標後的填色）。

### 自訂 CSS

展開 **自訂 CSS** 可編輯贊助條的 CSS。**恢復預設** 會還原預設 CSS，**管理素材** 可管理要在 CSS 中使用的圖片。這裡也能套用 Steam 工作坊主題；套用主題後 CSS 為唯讀，需先還原才能編輯。請參考 [主題樣式](./themes.md)。

:::info 試用版
自訂 CSS 僅限正式版。試用版無法使用真實金流（PayPal / Stripe / 歐付寶 / 綠界）以及 YouTube 會員相關項目與寶石，且 OBS 畫面會顯示浮水印。詳見 [試用版 / 正式版比較](../getting-started/trial-comparison.md)。
:::

## 常見問題

**Q：送出測試通知後，贊助條金額增加了？**
設定頁的 **測試通知** 會當作一筆真實贊助處理，所以會加進贊助條（若該平台有勾選）。測試完後點 **歸零** 即可清除。
