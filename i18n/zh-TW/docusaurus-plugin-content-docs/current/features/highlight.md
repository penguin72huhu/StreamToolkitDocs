# 實況精華標記

直播中按下快捷鍵，記下精華片段發生在「開台後第幾分幾秒」。之後剪輯直播回放時，就能照著這份時間清單找到精華。

標記會儲存在 Stream Toolkit 中。這個功能沒有 OBS 畫面，不需要新增 OBS 來源。

頁面分成 **設定**、**精華紀錄** 兩個分頁。

:::tip
請打開左側選單 **實況精華標記** 旁的開關。開關關閉時，快捷鍵和 **MARK** 按鈕都不會新增標記。
:::

## 步驟一：選擇來源

**來源** 決定直播時間怎麼計算：

| 來源 | 時間計算方式 | 需求 |
|------|--------------|------|
| **Twitch** | 目前這場 Twitch 直播開始至今的時間 | 已連接 Twitch，詳見 [Twitch 設定](../platforms/twitch.md) |
| **YouTube** | 目前這場 YouTube 直播開始至今的時間 | 登入 Google，詳見 [YouTube 設定](../platforms/youtube-settings.md) |
| **手動對齊**（預設） | 本頁手動計時器的數值 | 無 |

**Twitch**、**YouTube** 旁的小圓點表示是否已連接；未連接時會顯示 **（未連接）** 或 **（尚未登入 Google）**。

如果在沒有開台時標記（**手動對齊** 則是計時器沒有在跑時），時間會記為 **尚未開台**。使用 **Twitch** 來源時，這個結果可能要等約 20 秒才會出現，因為 Stream Toolkit 會重試幾次，以防剛開台時 Twitch 還沒登記到直播。

### 手動計時器

選擇 **手動對齊** 時會出現 **手動計時器**：

1. 以 `HH:MM:SS` 輸入目前的直播時間（例如剛開台時輸入 `00:00:00`）
2. 點 **開始同步計時**，計時器會從該數值開始往上計時
3. 之後每次標記都使用計時器當下的數值
4. 點 **停止** 停止計時

### 標記時建立 Twitch 精華片段

只有來源為 **Twitch** 時才會出現這個選項。開啟後，每次標記都會同時建立一段 Twitch 精華片段（Clip）。

- 需正在直播，片段長度約 30 秒
- 片段儲存在「創作者儀表板 → 內容 → 剪輯」中
- 標記後頁面會顯示 **已建立 Twitch 精華片段**，或失敗原因：**未在直播，無法建立**、**權限不足，請重新連接 Twitch**、**尚未連接 Twitch**、**建立失敗，請稍後再試**

## 步驟二：設定快捷鍵

預設快捷鍵為 `Ctrl+Shift+M`。要更改：

1. 點快捷鍵按鈕
2. 按下想要的按鍵組合後放開；按 **Esc** 可取消
3. 要移除快捷鍵，點 **清除**

如果這組按鍵已被其他功能使用，按鈕會顯示 **此快捷鍵已用過**，不會儲存。即使 Stream Toolkit 不是目前的視窗，快捷鍵也有效。

也可以點快捷鍵下方的 **MARK** 按鈕，效果和按快捷鍵相同。[快速工具](./quick-tools.md) 視窗也有 **MARK** 按鈕。

## 步驟三：直播中標記

1. （選填）標記前先在 **標記名稱** 輸入名稱。留空會自動編號（`精華標記_1`、`精華標記_2`…）
2. 按下快捷鍵或點 **MARK**

輸入的名稱只會套用到下一筆標記，標記後欄位會清空。

## 精華紀錄

**精華紀錄** 分頁會列出所有標記，最新的在最上面。每筆會顯示直播時間、名稱、來源，以及標記當下的日期時間。

- **複製**：把這筆標記複製成文字，格式為 `[日期] 名稱 🎬 直播時間 (來源)`
- **🗑️**：點下後再點 **確認刪除** 即刪除該筆標記
- **開啟 Twitch 精華**：該筆標記有建立 Twitch 精華片段時才會出現，點下會在 Twitch 開啟該片段
