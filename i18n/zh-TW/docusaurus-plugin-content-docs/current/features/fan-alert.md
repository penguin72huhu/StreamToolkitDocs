# 新粉絲通知

有人追隨你的 Twitch 或訂閱你的 YouTube 頻道時，在直播畫面跳出通知。

## OBS 來源網址

```
http://127.0.0.1:7272/fan-alert
```

從 **新粉絲通知 設定** 頁上方複製網址，在 OBS 新增為瀏覽器來源。請參考 [如何在 OBS 加入來源](../getting-started/obs-source.md)。

:::warning
新粉絲通知會播放音效，請在瀏覽器來源內容中勾選 **使用 OBS 控制音訊**，否則直播中聽不到聲音。
:::

左側選單 **新粉絲通知** 旁的開關控制是否顯示通知。關閉時新粉絲不會跳通知、也不會記錄，測試按鈕也無法使用。

短時間內多位新粉絲時，通知會排隊依序顯示。這個來源有自己的佇列，不會排在 [贊助通知](./donate-alert.md) 後面。

## 設定分頁

### 串接平台

勾選要跳通知的平台：**Twitch**、**YouTube**（預設都勾選）。綠點代表已連接；未連接會顯示 **尚未授權**。

- **Twitch**：每次有人追隨就立即跳通知。請先連接 Twitch：[Twitch 設定](../platforms/twitch.md)。
- **YouTube**：新訂閱者。請先登入 Google：[YouTube 設定](../platforms/youtube-settings.md)。

YouTube 新訂閱者的偵測方式：

- YouTube 沒有即時的「新訂閱」事件，所以程式每 1.5 分鐘向 YouTube 查詢一次最近的訂閱者。
- 只在直播中、且 YouTube 聊天室已連上這場直播時才會查詢；等待室與直播結束後都不會查詢。
- 開播前就訂閱的人（早於開始查詢前約 5 分鐘）不會跳通知。
- 如頁面上的提示：**YouTube只會通知公開訂閱的觀眾，可能延遲數分鐘到數小時。**

### 設定

| 欄位 | 說明 |
|------|------|
| **顯示時間** | 每則通知停留的秒數（1–60），預設 5 秒 |
| **同一位觀眾 24 小時內只通知一次** | 預設關閉。開啟後，同一位觀眾 24 小時內再次追隨（例如取消追隨後又追隨）不會跳通知，也不會記錄 |

### 測試通知

點 **測試通知 (Twitch)** 或 **測試通知 (YouTube)**，在 OBS 顯示一則範例通知。測試通知不會寫入歷史紀錄。

若新粉絲通知是關閉的，測試不會播放，頁面會顯示 **請先在快速開關開啟新粉絲通知**。

## 外觀分頁

### 預覽

預覽使用與 OBS 來源相同的頁面。**預覽** 旁的顏色可更換預覽背景，點 **▶ 重播動畫** 可再播放一次通知動畫。

### 統一樣式／各平台獨立

- **統一樣式**：Twitch 與 YouTube 共用同一套通知樣式。
- **各平台獨立**：每個平台各自一套樣式。用下方按鈕選擇 **Twitch** 或 **YouTube** 後再調整。第一次切換時，尚未自訂過的平台會沿用目前的統一樣式，倒數條則套用各平台自己的顏色。

**恢復預設** 會把目前編輯中的樣式還原為預設。

### 圖片

- **選擇圖片**：從素材管理中挑選圖片。未設定時顯示愛心符號。**清除** 可移除圖片。
- **圖片大小**：1–400 px。
- **圖片位置**：**靠左**、**靠右**、**上方**、**下方**。

### 音效

選擇內建音效：**無**、**鈴聲**（預設）、**金幣**、**鐘聲**、**彈出**、**號角**。點 **▶** 試聽。點 **選擇音效** 可從素材管理使用自己的音效檔。

### 自訂文字

輸入通知上顯示的文字，用 `{name}` 代入粉絲名稱、`{platform}` 代入平台名稱。留空則使用預設文字：`歡迎 {name} 成為新粉絲！`

### 文字與顏色

- **文字**：分別設定 **自訂文字** 與 **粉絲名稱** 的字型、大小與顏色。
- **顏色**：**背景**、**陰影**、**倒數條**。

### 自訂 CSS

展開 **自訂 CSS** 可編輯目前樣式（統一或所選平台）的 CSS。**恢復預設** 會還原範本 CSS，**管理素材** 可開啟素材管理。這裡也能套用 Steam 工作坊主題；套用主題後 CSS 為唯讀。請參考 [主題樣式](./themes.md)。

## 歷史紀錄分頁

列出兩個平台最近的新粉絲，最新的在最上面，顯示平台、名稱與時間。歷史紀錄只在程式內顯示，不會出現在 OBS 畫面上。

- 最多保留 100 位，超過 30 天的紀錄會自動刪除。
- 點 **清除** 可清空列表。

:::info 試用版
自訂 CSS 僅限正式版，且 OBS 中的通知會顯示浮水印。詳見 [試用版 / 正式版比較](../getting-started/trial-comparison.md)。
:::

## 常見問題

**Q：直播中沒有聲音？**
確認瀏覽器來源已勾選 **使用 OBS 控制音訊**，且 OBS 混音器中該來源沒有靜音。也請確認 **音效** 不是設為 **無**。

**Q：YouTube 有人訂閱卻沒跳通知？**
YouTube 只會回報公開訂閱的觀眾，而且可能延遲數分鐘到數小時。程式也只在直播中、且 YouTube 聊天室已連上時才會查詢。

**Q：比較晚才加入 OBS 來源，會補播之前的通知嗎？**
不會。新開啟的來源只會顯示連上之後收到的通知。之前的新粉絲仍可在 **歷史紀錄** 分頁查看。
