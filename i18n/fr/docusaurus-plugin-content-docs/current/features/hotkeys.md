# Raccourcis

**⌨️ Raccourcis**, en bas du menu de gauche, liste au même endroit tous les raccourcis que vous avez configurés.

## Vue d'ensemble des raccourcis

Chaque ligne affiche la combinaison de touches et ce qu'elle déclenche, par ex. `Minuteur › (nom du minuteur) › Démarrer / Pause`. Cliquez sur une ligne pour ouvrir la page de réglages de cette fonctionnalité et le modifier. Les raccourcis ne se modifient pas sur cette page.

Si aucun raccourci n'est encore configuré, elle affiche « Aucun raccourci configuré pour le moment. »

## Fonctionnalités avec raccourcis

| Fonctionnalité | Action du raccourci |
|------|------|
| [Marqueur de temps fort du stream](./highlight) | Ajoute un marqueur |
| [Media Board](./multimedia) | Joue un son / affiche une image / lit une vidéo (un raccourci par élément) |
| [Traduction vocale](./voice-translate) | Le raccourci de traduction vocale |
| [Contrôle des scènes OBS](./obs-scene) | **Changer de scène** / **Basculer les sources** |
| [Minuteur](./timer) | **Démarrer / Pause**, **Tour**, **Réinitialiser** (par minuteur) |

## Définir un raccourci

[Marqueur de temps fort du stream](./highlight), [Contrôle des scènes OBS](./obs-scene) et [Minuteur](./timer) partagent le même champ de raccourci. Pour Media Board et Traduction vocale, consultez leurs pages respectives.

1. Cliquez sur le bouton du raccourci
2. Appuyez sur la combinaison de touches, par ex. `Ctrl+Shift+F1`
3. Relâchez toutes les touches pour l'enregistrer

- Appuyez sur **Esc** pendant l'enregistrement pour annuler
- Si la combinaison est déjà utilisée par un autre raccourci, un message de conflit apparaît et elle n'est pas enregistrée. Choisissez une autre combinaison
- Cliquez sur **✕** (ou sur le bouton d'effacement) à côté pour supprimer le raccourci
- Les touches du pavé numérique sont distinctes des touches numériques de la rangée principale : `Num1` et `1` sont des raccourcis différents

Les raccourcis fonctionnent même lorsque Stream Toolkit est en arrière-plan, par ex. pendant que vous jouez.
