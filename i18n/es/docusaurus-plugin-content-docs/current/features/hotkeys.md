# Atajos de teclado

**⌨️ Atajos de teclado**, en la parte inferior del menú izquierdo, muestra en un solo lugar todos los atajos que has configurado.

## Resumen de atajos

Cada fila muestra la combinación de teclas y lo que activa, p. ej. `Temporizador › (nombre del temporizador) › Iniciar / Pausar`. Haz clic en una fila para abrir la página de configuración de esa función y cambiarlo allí. Los atajos no se editan en esta página.

Si todavía no hay ninguno configurado, muestra "Aún no hay atajos configurados."

## Funciones con atajos

| Función | Qué hace el atajo |
|------|------|
| [Marcador de momentos destacados de stream](./highlight) | Agrega un marcador |
| [Media Board](./multimedia) | Reproduce un sonido / muestra una imagen / reproduce un video (un atajo por elemento) |
| [Traducción de voz](./voice-translate) | El atajo de traducción de voz |
| [Control de escenas OBS](./obs-scene) | **Cambiar de escena** / **Alternar fuentes** |
| [Temporizador](./timer) | **Iniciar / Pausar**, **Vuelta**, **Restablecer** (por temporizador) |

## Configurar un atajo

[Marcador de momentos destacados de stream](./highlight), [Control de escenas OBS](./obs-scene) y [Temporizador](./timer) comparten el mismo campo de atajo. Para Media Board y Traducción de voz, consulta sus propias páginas.

1. Haz clic en el botón del atajo
2. Presiona la combinación de teclas, p. ej. `Ctrl+Shift+F1`
3. Suelta todas las teclas para guardarlo

- Presiona **Esc** mientras se graba para cancelar
- Si otro atajo ya usa esa combinación, aparece un mensaje de conflicto y no se guarda. Elige otra combinación
- Haz clic en **✕** (o en el botón para borrar) junto a él para quitar el atajo
- Las teclas del teclado numérico son distintas de las teclas numéricas de la fila principal: `Num1` y `1` son atajos diferentes

Los atajos funcionan incluso mientras Stream Toolkit está en segundo plano, p. ej. mientras estás en un juego.
