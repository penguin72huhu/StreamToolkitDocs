# Atalhos

**⌨️ Atalhos**, na parte inferior do menu à esquerda, lista em um só lugar todos os atalhos que você configurou.

## Visão geral dos atalhos

Cada linha mostra a combinação de teclas e o que ela aciona, ex.: `Temporizador › (nome do temporizador) › Iniciar / Pausar`. Clique em uma linha para abrir a página de configurações daquele recurso e alterá-lo lá. Os atalhos não são editados nesta página.

Se nada estiver configurado ainda, aparece "Nenhum atalho configurado ainda."

## Recursos com atalhos

| Recurso | O que o atalho faz |
|------|------|
| [Marcador de destaques da stream](./highlight) | Adiciona uma marcação |
| [Media Board](./multimedia) | Toca um som / mostra uma imagem / reproduz um vídeo (um atalho por item) |
| [Tradução de voz](./voice-translate) | O atalho da tradução de voz |
| [Controle de cenas do OBS](./obs-scene) | **Trocar de cena** / **Alternar fontes** |
| [Temporizador](./timer) | **Iniciar / Pausar**, **Volta**, **Redefinir** (por temporizador) |

## Definir um atalho

[Marcador de destaques da stream](./highlight), [Controle de cenas do OBS](./obs-scene) e [Temporizador](./timer) usam o mesmo campo de atalho. Para Media Board e Tradução de voz, veja as páginas de cada um.

1. Clique no botão do atalho
2. Pressione a combinação de teclas, ex.: `Ctrl+Shift+F1`
3. Solte todas as teclas para salvar

- Pressione **Esc** durante a gravação para cancelar
- Se a combinação já estiver em uso por outro atalho, aparece uma mensagem de conflito e ela não é salva. Escolha outra combinação
- Clique em **✕** (ou no botão de limpar) ao lado para remover o atalho
- As teclas do teclado numérico são diferentes das teclas numéricas da fileira principal: `Num1` e `1` são atalhos diferentes

Os atalhos funcionam mesmo com o Stream Toolkit em segundo plano, ex.: enquanto você está em um jogo.
