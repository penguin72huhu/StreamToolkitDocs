# Klávesové zkratky

**⌨️ Klávesové zkratky** v dolní části levého menu zobrazují na jednom místě všechny klávesové zkratky, které jste nastavili.

## Přehled klávesových zkratek

Každý řádek ukazuje kombinaci kláves a akci, kterou spouští, např. `Časovač › (název časovače) › Start / Pauza`. Kliknutím na řádek otevřete stránku nastavení dané funkce a zkratku změníte tam. Na této stránce se zkratky neupravují.

Pokud zatím nic nastaveno není, zobrazí se „Zatím nejsou nastaveny žádné zkratky.“

## Funkce s klávesovými zkratkami

| Funkce | Co zkratka dělá |
|------|------|
| [Značka nejlepších okamžiků streamu](./highlight) | Přidá značku |
| [Media Board](./multimedia) | Přehraje zvuk / zobrazí obrázek / přehraje video (jedna zkratka pro každou položku) |
| [Překlad řeči](./voice-translate) | Zkratka pro překlad řeči |
| [Ovládání scén OBS](./obs-scene) | **Přepnout scénu** / **Přepnout zdroje** |
| [Časovač](./timer) | **Spustit / pozastavit**, **Zkratka mezičasu**, **Zkratka resetu** (pro každý časovač zvlášť) |

## Nastavení klávesové zkratky

[Značka nejlepších okamžiků streamu](./highlight), [Ovládání scén OBS](./obs-scene) a [Časovač](./timer) používají stejné pole pro zkratku. Pro Media Board a Překlad řeči viz jejich vlastní stránky.

1. Klikněte na tlačítko zkratky
2. Stiskněte kombinaci kláves, např. `Ctrl+Shift+F1`
3. Uvolněním všech kláves ji uložíte

- Během nahrávání zrušíte zadání klávesou **Esc**
- Pokud je kombinace již použita jinou zkratkou, zobrazí se zpráva o konfliktu a zkratka se neuloží. Zvolte jinou kombinaci
- Kliknutím na **✕** (nebo na tlačítko pro vymazání) vedle zkratky ji odstraníte
- Klávesy numerické klávesnice jsou oddělené od číselných kláves v hlavní řadě: `Num1` a `1` jsou různé zkratky

Klávesové zkratky fungují, i když je Stream Toolkit na pozadí, např. když hrajete hru.
