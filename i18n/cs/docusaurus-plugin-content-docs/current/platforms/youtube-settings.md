# YouTube Nastavení (nové)

Stream Toolkit připojí váš kanál YouTube přihlášením přes Google, takže nemusíte vytvářet ani zadávat klíč API.

## Krok 1: Připojit účet YouTube

1. Otevřete Stream Toolkit
2. Klikněte na **Nastavení** v levém dolním menu
3. V sekci Připojení platformy najděte **YouTube** a klikněte na **Připojit účet**
4. Otevře se potvrzovací okno. Přečtěte si Smluvní podmínky YouTube a Zásady ochrany osobních údajů a klikněte na **Souhlasit a přihlásit**
5. Prohlížeč otevře přihlašovací stránku Google. Vyberte účet Google, kterému patří váš kanál YouTube (má-li více kanálů, vyberte ten, na kterém streamujete)
6. Zkontrolujte požadovaná oprávnění a klikněte na **Pokračovat** / **Povolit**

Po dokončení se u YouTube v Nastavení zobrazí **Připojeno: název kanálu**.

## Odpojení

Klikněte na **Odpojit** vedle YouTube. Přístup Stream Toolkit bude odebrán i z vašeho účtu Google.

## Často kladené otázky

**Q: Potřebuji ještě klíč API YouTube?**
Ne. Stačí se přihlásit přes Google.

**Q: Přihlásil jsem se ke špatnému kanálu**
Klikněte na **Odpojit**, připojte se znovu a vyberte správný účet nebo kanál.

**Q: Po přihlášení v prohlížeči se nic nestane**
Během přihlašování nechte Stream Toolkit otevřený – prohlížeč mu pošle výsledek. Pokud se nic nezmění, klikněte znovu na Připojit účet.
