# Pintasan

**⌨️ Pintasan** di bagian bawah menu kiri menampilkan semua pintasan yang telah Anda atur, dalam satu tempat.

## Ringkasan Pintasan

Setiap baris menampilkan kombinasi tombol dan apa yang dipicunya, misalnya `Timer › (nama timer) › Mulai / Jeda`. Klik sebuah baris untuk membuka halaman pengaturan fitur tersebut dan mengubahnya di sana. Pintasan tidak diedit di halaman ini.

Jika belum ada yang diatur, akan ditampilkan "Belum ada pintasan yang diatur."

## Fitur dengan Pintasan

| Fitur | Fungsi pintasan |
|------|------|
| [Penanda Sorotan Stream](./highlight) | Menambahkan penanda |
| [Media Board](./multimedia) | Memutar suara / menampilkan gambar / memutar video (satu pintasan per item) |
| [Terjemahan suara](./voice-translate) | Pintasan terjemahan suara |
| [Kontrol Scene OBS](./obs-scene) | **Ganti scene** / **Alihkan sumber** |
| [Timer](./timer) | **Mulai / Jeda**, **Putaran**, **Atur ulang** (per timer) |

## Mengatur Pintasan

[Penanda Sorotan Stream](./highlight), [Kontrol Scene OBS](./obs-scene), dan [Timer](./timer) menggunakan kolom pintasan yang sama. Untuk Media Board dan Terjemahan suara, lihat halamannya masing-masing.

1. Klik tombol pintasan
2. Tekan kombinasi tombol, misalnya `Ctrl+Shift+F1`
3. Lepaskan semua tombol untuk menyimpannya

- Tekan **Esc** saat merekam untuk membatalkan
- Jika kombinasi tersebut sudah digunakan oleh pintasan lain, pesan konflik akan muncul dan pintasan tidak disimpan. Pilih kombinasi lain
- Klik **✕** (atau tombol hapus) di sampingnya untuk menghapus pintasan
- Tombol numpad terpisah dari tombol angka di baris utama: `Num1` dan `1` adalah pintasan yang berbeda

Pintasan tetap berfungsi meskipun Stream Toolkit berjalan di latar belakang, misalnya saat Anda sedang bermain game.
