# Sneltoetsen

**⌨️ Sneltoetsen** onderaan het linkermenu toont op één plek alle sneltoetsen die je hebt ingesteld.

## Overzicht van sneltoetsen

Elke rij toont de toetscombinatie en wat die activeert, bijv. `Timer › (naam van timer) › Start / Pauze`. Klik op een rij om de instellingenpagina van die functie te openen en de sneltoets daar te wijzigen. Sneltoetsen worden niet op deze pagina bewerkt.

Is er nog niets ingesteld, dan staat er "Nog geen sneltoetsen ingesteld."

## Functies met sneltoetsen

| Functie | Wat de sneltoets doet |
|------|------|
| [Stream-hoogtepuntmarkering](./highlight) | Voegt een markering toe |
| [Media Board](./multimedia) | Speelt een geluid af / toont een afbeelding / speelt een video af (één sneltoets per item) |
| [Spraakvertaling](./voice-translate) | De sneltoets voor spraakvertaling |
| [OBS-scènebediening](./obs-scene) | **Scène wisselen** / **Bronnen schakelen** |
| [Timer](./timer) | **Starten/pauzeren**, **Ronde**, **Resetten** (per timer) |

## Een sneltoets instellen

[Stream-hoogtepuntmarkering](./highlight), [OBS-scènebediening](./obs-scene) en [Timer](./timer) gebruiken hetzelfde sneltoetsveld. Zie voor Media Board en Spraakvertaling hun eigen pagina's.

1. Klik op de sneltoetsknop
2. Druk op de toetscombinatie, bijv. `Ctrl+Shift+F1`
3. Laat alle toetsen los om op te slaan

- Druk tijdens het opnemen op **Esc** om te annuleren
- Wordt de combinatie al door een andere sneltoets gebruikt, dan verschijnt er een conflictmelding en wordt deze niet opgeslagen. Kies een andere combinatie
- Klik op **✕** (of de wisknop) ernaast om de sneltoets te verwijderen
- Toetsen op het numerieke toetsenblok zijn iets anders dan de cijfertoetsen in de bovenste rij: `Num1` en `1` zijn verschillende sneltoetsen

Sneltoetsen werken ook als Stream Toolkit op de achtergrond draait, bijv. terwijl je een game speelt.
