Заказ музыки

Зрители заказывают песни с YouTube командой в чате, и песни воспроизводятся в OBS одна за другой. Вы также можете добавлять песни сами и задать плейлист по умолчанию, который играет, когда заказов нет.

URL источника для OBS​

http://127.0.0.1:7272/song-request

Нажмите Копировать рядом с URL источника для OBS вверху страницы и добавьте его в OBS как источник «Браузер». См. Как добавить источники в OBS.

warning

Заказ музыки воспроизводит звук. В свойствах источника «Браузер» включите «Управлять аудио с помощью OBS», иначе музыка не попадёт в трансляцию.

подсказка

Также включите переключатель рядом с Заказ музыки в левом меню. Команды чата обрабатываются только пока переключатель включён.

На странице две вкладки: Настройки и Плейлист.

Вкладка «Настройки»​

Платформа​

У каждой платформы своя карточка:

  • Разрешить заказ песен с этой платформы: позволяет зрителям в этом чате заказывать песни
  • Включить ответы чат-бота (только Twitch, включено по умолчанию): отвечает в чате Twitch результатом каждой команды от имени подключённого аккаунта Twitch. Отображается, только когда Twitch включён и подключён

Неподключённая платформа показывает (не подключено) (Twitch) или URL чата не подключён (YouTube). Сначала подключите её:

  • Настройки Twitch
  • Настройки YouTube

Команды чата​

ПолеПо умолчанию
Префикс команды! (на выбор ! @ # $ % & ~)
Команда заказа песниsr
Удалить заказremove
Посмотреть список заказовqueue
Узнать текущую песнюsong
Задержка между заказами3000 ms

Задержка считается для каждого зрителя отдельно: после успешного заказа тот же зритель должен подождать указанное время, прежде чем заказать снова.

Настройки​

  • Показывать видео на экране (включено по умолчанию): если выключено, видео скрыто в OBS, но звук продолжает воспроизводиться
  • Лимит списка (1–100, по умолчанию 20): максимальное число заказанных песен в списке. Песни из плейлиста по умолчанию не учитываются
  • Показывать уведомление о заказе (включено по умолчанию): показывает в OBS карточку уведомления, когда зритель заказывает, удаляет песню или заказ не удаётся. Если включено, можно задать:
    • X / Y: позиция уведомления от левого верхнего угла (px, по умолчанию 16 / 16)
    • Масштаб уведомления: множитель размера (по умолчанию 1.0)
    • Тест оформления уведомления: отправляет тестовое уведомление в OBS

Каждое уведомление показывается 5 секунд; одновременно отображается не более 3.

Как этим пользуются зрители​

С настройками по умолчанию:

КомандаЧто делает
!sr <YouTube link>Заказывает это видео
!sr <search words>Ищет на YouTube и заказывает первый результат
!removeУдаляет последний заказ зрителя (но не песню, которая сейчас играет)
!queueОтвечает следующими 3 заказанными песнями
!songОтвечает названием песни, которая сейчас играет
  • Принимаются ссылки: youtube.com/watch?v=…, youtu.be/…, youtube.com/live/…, youtube.com/shorts/… или 11-символьный ID видео
  • Ссылки на плейлисты не принимаются
  • Заказ не удаётся, если список достиг значения Лимит списка
  • Новые заказы ставятся в очередь после заказов других зрителей, но перед песнями из плейлиста по умолчанию
  • !queue и !song работают только в чате Twitch при включённом Включить ответы чат-бота

Вкладка «Плейлист»​

Управление воспроизведением​

В верхней строке показано, кто заказал текущую песню, и её название. Кнопки:

  • Играть / Пауза: если ничего не играет, воспроизведение начинается с первой песни в списке
  • Остановить: останавливает воспроизведение
  • Следующая: переходит к следующей песне

Во время воспроизведения появляется полоса прогресса; перетащите её, чтобы перейти к нужному месту. Когда песня заканчивается, автоматически начинается следующая.

примечание

При запуске приложения ничего не воспроизводится автоматически. Нажмите Играть, чтобы начать.

Плейлист по умолчанию​

Вставьте URL плейлиста YouTube и выберите Циклическое воспроизведение или Случайное воспроизведение. Когда список заканчивается, песня из этого плейлиста автоматически добавляется и воспроизводится. Такие песни отмечены в списке как Список по умолчанию.

Плейлист по умолчанию читается через ваш аккаунт YouTube, поэтому сначала нужно войти через Google в Настройках YouTube.

Заказать вручную​

Вставьте URL видео YouTube и нажмите Добавить в список (или нажмите Enter). Ручной заказ не поддерживает поиск по словам.

Список​

Список (n) показывает все песни: платформа, заказчик, название и ID видео (нажмите, чтобы открыть на YouTube). Нажмите Удалить, чтобы убрать песню; удаление играющей песни переключает на следующую. Очистить очищает весь список.

Часто задаваемые вопросы​

Q: Зрители вводят команду, но ничего не происходит? Проверьте, что:

  • Переключатель Заказ музыки в левом меню включён
  • Для этой платформы отмечено Разрешить заказ песен с этой платформы
  • Для Twitch: чат Twitch читается функцией Чат. Если вы отключили Twitch на странице Чат (и Чат-бот не использует Twitch), команды из Twitch не принимаются

Q: Плейлист по умолчанию не воспроизводится? Убедитесь, что вы вошли через Google в Настройках и что URL — это ссылка на плейлист (содержит list=).

:::info Ограничения пробной версии

  • Заказ песен зрителями из чата доступен только в полной версии. В пробной версии заказ из чата отклоняется с сообщением «В пробной версии заказ песен недоступен». Заказать вручную и плейлист по умолчанию по-прежнему работают
  • В оверлее OBS отображается водяной знак

См. Сравнение пробной и полной версий. :::
