Колесо удачи

Создавайте собственные призовые колёса и крутите их в трансляции. Можно задать вес каждого варианта, цвета колеса и то, удаляется ли выпавший вариант после выбора.

На странице три вкладки: Настройки, Создать колесо и История. Сначала создайте колесо, затем запускайте его на вкладке Настройки.

Шаг 1: Создайте колесо​

  1. Откройте Колесо удачи в левом меню и перейдите на вкладку Создать колесо
  2. В разделе Мои колёса нажмите Добавить. Появится новое колесо с названием «Колесо 1» (затем «Колесо 2» и т. д.)
  3. Нажмите на карточку колеса, чтобы изменить его. Нажмите ✕ на карточке, чтобы удалить это колесо

Заголовок колеса​

Введите название колеса. Оно используется в списке колёс, выпадающих списках и истории.

Содержимое колеса​

  1. Нажмите Изменить содержимое
  2. Введите варианты, по одному в строке
  3. Нажмите Подтвердить

Вес​

Когда в колесе есть варианты, у каждого появляется поле Вес (минимум 1, по умолчанию 1). Размер сектора варианта и шанс его выпадения пропорциональны весу. Например, вариант с весом 2 выпадает вдвое чаще, чем вариант с весом 1.

Цветовая тема колеса​

  • Минимализм: встроенная бело-серая схема
  • Свой: создайте собственную цветовую схему. Введите Имя, выберите Цвета (3–5 цветов) — ＋ добавляет цвет, ✕ удаляет его, — затем нажмите Добавить

Чтобы изменить свою тему, нажмите её кнопку ✎. Чтобы удалить её, нажмите ✕. Свои темы также предлагаются как цветовые схемы для анимации колеса в Розыгрышах.

Удалять вариант после выбора​

Если включено, выпавший вариант убирается с колеса перед следующим вращением. Нажмите Сбросить, чтобы вернуть все варианты.

Шаг 2: Выберите режим отображения и добавьте источник OBS​

Перейдите на вкладку Настройки и выберите Режим отображения:

РежимОписаниеURL источника для OBS
Одно колесоOBS показывает только выбранное колесо. Переключайте колёса в выпадающем списке Текущее колесоhttp://127.0.0.1:7272/turntable
Несколько колёсOBS может показывать несколько колёс одновременно. У каждого колеса свой URLhttp://127.0.0.1:7272/turntable/<wheel ID>

В режиме Несколько колёс выберите колёса в Добавить на отображение колеса. Каждое добавленное колесо получает свою карточку со своим URL источника для OBS. Нажмите Копировать, чтобы скопировать его. Нажмите ✕ на карточке, чтобы убрать это колесо с отображения.

Добавьте скопированный URL в OBS как источник «Браузер». См. Как добавить источники в OBS. Колесо удачи не воспроизводит звук, поэтому включать «Управлять аудио с помощью OBS» не нужно.

подсказка

Также включите переключатель рядом с Колесо удачи в левом меню (Включить вывод в OBS). Пока он выключен, оверлей скрыт.

Шаг 3: Вращение​

На каждой карточке колеса на вкладке Настройки:

  • Запустить: запускает вращение. Когда анимация заканчивается, оверлей показывает результат. Кнопку нельзя нажать, пока в колесе нет вариантов или оно ещё вращается
  • Сбросить: возвращает удалённые варианты, сбрасывает колесо и очищает текущий Список победителей

Список победителей на карточке собирает все результаты с последнего Сбросить.

Запустить и Сбросить также доступны в окне Быстрые инструменты.

История​

Вкладка История хранит одну запись на каждый раунд — от первого вращения до следующего Сбросить. В ней указаны время, заголовок колеса и победители. Хранится история колёс только за последние 30 дней. Чтобы удалить запись, нажмите 🗑, а затем Подтвердить удаление.

:::info Ограничения пробной версии

  • Можно создать только 1 колесо
  • В оверлее OBS отображается водяной знак

Подробнее см. Сравнение пробной и полной версий. :::
