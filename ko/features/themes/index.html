테마 스타일

Steam Workshop을 통해 오버레이 외관을 공유하고 다운로드합니다. 테마에는 다음 기능의 외관을 포함할 수 있습니다:

  • 채팅방
  • 후원 바
  • 후원 알림
  • 새 팔로워 알림
  • 시청자 생일 알림
  • 후원 기록판
  • 실시간 투표
  • 시계
  • Twitch 목표 바: 팔로우 목표, 구독 목표, Bits 목표

왼쪽 메뉴 하단의 🎨 테마 스타일에서 엽니다. 페이지에는 내 테마와 다운로드한 테마 두 개의 탭이 있습니다. Steam이 실행 중이어야 합니다.

기능 페이지에서 테마 찾기 및 적용​

위에 나열된 각 기능에서 사용자 정의 CSS 섹션을 열고 Steam Workshop 테마 둘러보기를 클릭합니다:

  1. 테마 탐색에 이 기능의 Workshop 테마가 나열됩니다. 테마 이름 검색에 입력하고 검색을 클릭하거나, 이전 페이지 / 다음 페이지로 페이지를 넘깁니다
  2. 썸네일을 클릭하면 미리보기 이미지를 볼 수 있습니다
  3. 적용을 클릭합니다. 테마가 구독, 다운로드되어 이 기능에 적용됩니다
  4. 구독함에는 이 기능에 대해 이미 구독한 테마가 나열됩니다

테마가 적용된 동안에는 페이지에 **사용 중인 테마: (이름)**과 복원 버튼이 표시되며, 사용자 정의 CSS는 읽기 전용입니다. 복원을 클릭하면 원래 내 설정으로 돌아갑니다.

다운로드한 테마​

Steam에서 구독한 모든 테마가 나열됩니다. 구독한 테마는 자동으로 적용되지 않으므로 카드의 버튼을 사용하세요. OBS는 즉시 업데이트됩니다.

각 카드에는 미리보기, 이름, 사용하는 기능이 있으면 사용 중, 그리고 테마에 포함된 기능을 나타내는 **포함:**이 표시됩니다(✓는 현재 이 테마를 사용 중인 기능).

버튼동작
모두 적용테마에 포함된 모든 기능에 테마를 적용합니다. 다른 테마를 사용 중인 기능이 있으면 교체할지 확인합니다
선택 적용…적용할 기능을 선택합니다
모두 복원이 테마를 사용 중인 모든 기능을 테마 적용 전의 내 설정으로 되돌립니다
선택 복원…복원할 기능을 선택합니다
구독 취소구독을 취소합니다. 테마가 사용 중이면 해당 기능을 먼저 복원합니다

적용 후 하단에 변경 내용을 알리는 메시지가 30초 동안 표시되며, 복원 버튼으로 되돌릴 수 있습니다.

노트
  • 복원하면 교체된 테마가 아니라 원래 내 설정으로 돌아갑니다
  • 테마가 적용된 동안 변경한 외관은 복원 후 유지되지 않습니다
  • 다운로드 중…: Steam을 켜 두세요. 다운로드가 끝나면 적용할 수 있습니다
  • 삭제된 테마 (#id): Steam 구독에는 더 이상 없지만 일부 기능이 아직 사용 중인 테마입니다. 이미지가 표시되지 않을 수 있으므로 복원을 권장합니다
  • Steam이 실행 중이 아니면 Steam을 실행한 후 새로고침을 클릭하세요

내 테마: 테마 업로드​

  1. 공유할 기능의 외관을 각 기능 페이지에서 설정합니다
  2. 내 테마에서 새 테마 업로드를 클릭합니다
  3. 다음을 입력합니다:
    • 테마 이름(필수)
    • 테마 설명
    • 포함된 기능(하나 이상)
    • 미리보기 이미지(필수, 최대 1MB): 미리보기 이미지 선택을 클릭합니다
  4. 테마에 포함된 모든 이미지, 글꼴, 사운드를 배포할 권리가 있음을 확인하는 체크박스를 체크합니다. 개인 또는 비상업적 용도로만 라이선스된 소재는 업로드할 수 없습니다
  5. 테마 업로드를 클릭합니다

"브라우저에서 Steam Workshop 약관에 먼저 동의해야 테마가 공개됩니다"가 표시되면 약관에 동의해야 테마가 공개됩니다.

업로드한 테마 관리​

업로드한 각 테마에는 다음이 있습니다:

  • 다운로드 후 적용: 게시된 테마를 내 기능에 적용합니다. 현재 외관 설정을 덮어씁니다
  • 편집: 현재 외관 설정을 같은 테마에 다시 업로드합니다. 테마를 다운로드하지 않았다면 기존 미리보기 이미지가 이어지지 않으므로 새로 선택해야 합니다
  • Steam에서 관리: Steam에서 테마를 엽니다

:::info 체험판 제한 테마 스타일(Steam Workshop)은 정식판에서만 사용할 수 있습니다. 체험판에서는 🎨 테마 스타일을 열 수 없으며 테마를 적용할 수 없습니다.

체험판 / 정식판 비교를 참고하세요. :::
