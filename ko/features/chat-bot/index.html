채팅 봇

채팅에 메시지를 자동으로 보냅니다. 설정한 간격마다 보내는 정기 메시지와, 시청자가 명령어를 입력하면 답하는 키워드 응답을 지원합니다. 봇은 본인 계정으로 메시지를 보냅니다.

채팅 봇에는 OBS 오버레이가 없으므로 추가할 URL이 없습니다.

팁

왼쪽 메뉴에서 채팅 봇 옆의 스위치를 켭니다. 스위치가 꺼져 있으면 봇이 아무것도 보내지 않습니다.

페이지에는 설정, 정기 메시지, 키워드 응답 세 개의 탭이 있습니다.

설정 탭​

플랫폼에서 Twitch를 클릭하면 켜집니다(다시 클릭하면 꺼집니다). Twitch가 연결되어 있으면 옆의 점에 불이 들어오고, 그렇지 않으면 **(연결 안 됨)**이 표시됩니다. 먼저 Twitch를 연결하세요: Twitch 설정.

YouTube는 곧 출시로 표시되며 아직 켤 수 없습니다.

연결된 플랫폼이 없으면 나머지 두 탭에 "연결된 플랫폼이 없어 봇이 메시지를 보내지 않습니다."와 설정으로 이동 버튼이 표시됩니다.

정기 메시지​

방송 중에 일정한 간격으로 메시지를 보냅니다.

  1. + 추가를 클릭합니다
  2. 다음을 입력합니다:
    • 내용: 보낼 텍스트(Twitch는 최대 500자). 항상 한 줄입니다. Enter는 동작하지 않으며, 붙여넣은 줄바꿈은 공백으로 바뀝니다
    • 간격: 메시지 사이의 시간(분, 5–240, 기본값 15)
    • 최소 채팅 수: 마지막 메시지 이후 새 채팅이 몇 개 있어야 다시 보낼지(0–100, 기본값 2). 아무도 채팅하지 않는데 계속 메시지를 보내는 것을 방지합니다
    • 플랫폼: 메시지를 보낼 곳
  3. 저장을 클릭합니다

보내는 방식:

  • 방송 중일 때만 보냅니다. 첫 메시지는 방송 시작 즉시가 아니라 방송 시작 후 간격 한 번이 지난 뒤에 보냅니다
  • 여러 정기 메시지의 시간이 동시에 되면 한꺼번에 보내지 않고 나누어 보냅니다

키워드 응답​

시청자의 메시지가 명령어로 시작하면 응답합니다.

  1. + 추가를 클릭합니다
  2. 다음을 입력합니다:
    • 명령어: 접두사(! @ # $ % & ~)를 선택한 후 공백 없는 한 단어를 입력합니다(예: !dc). 채팅 메시지의 첫 단어와 비교하며, 대소문자는 구분하지 않습니다
    • 응답: 보낼 텍스트. {user}는 명령어를 사용한 시청자 이름으로 바뀝니다
    • 쿨다운: 같은 명령어가 다시 응답하기까지의 시간(초, 0–3600, 기본값 5)
    • 플랫폼: 응답할 곳
  3. 저장을 클릭합니다

키워드 응답은 방송 여부와 관계없이 언제든 동작합니다.

명령어는 다른 키워드 응답이나, 노래 신청 또는 추첨 키워드에서 이미 사용 중인 명령어와 같을 수 없습니다.

목록 관리​

두 탭 모두 각 항목에 다음이 있습니다:

  • 왼쪽 체크박스: 삭제하지 않고 항목을 켜거나 끕니다
  • 플랫폼 태그: 흐리게 표시된 태그는 설정 탭에서 해당 플랫폼이 꺼져 있다는 뜻입니다
  • 편집과 삭제

:::info 체험판 제한

  • 정기 메시지 1개, 키워드 응답 1개
  • 모든 메시지 끝에 (by StreamToolkit)가 붙으므로, 최대 메시지 길이가 그만큼 짧아집니다

체험판 / 정식판 비교를 참고하세요. :::
