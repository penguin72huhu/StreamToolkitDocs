음성 번역

단축키를 누른 채로 말하세요. Stream Toolkit이 음성을 텍스트로 변환하고 번역한 뒤, 두 줄을 OBS에 자막으로 표시합니다.

음성 인식은 Whisper 모델을 사용해 본인의 컴퓨터에서 실행됩니다. 그런 다음 MyMemory로 텍스트를 번역합니다.

페이지에는 설정과 외관 두 개의 탭이 있습니다.

1단계: OBS 소스 추가​

OBS 소스 URL은 페이지 상단에 표시됩니다:

http://127.0.0.1:7272/voice-translate

복사를 클릭하고 OBS에 브라우저 소스로 추가합니다. OBS에서 소스 추가하는 방법을 참고하세요. 음성 번역은 소리가 없으므로 "OBS를 통해 오디오 제어"를 켤 필요가 없습니다.

자막은 소스 하단에 표시됩니다. 위쪽에 원문, 아래쪽에 번역문이 표시되며, 자막 표시 시간이 지나면 서서히 사라집니다.

팁

왼쪽 사이드바에서 음성 번역 옆의 스위치(OBS 표시 켜기)를 켜세요. 스위치가 켜져 있을 때만 단축키가 동작합니다.

2단계: 단축키 설정​

**단축키 (누르는 동안 녹음, 놓으면 인식)**에서:

  1. 클릭하여 단축키 설정을 클릭합니다
  2. 원하는 키 조합을 누른 후 손을 뗍니다. Esc를 누르면 취소됩니다
  3. 단축키를 제거하려면 지우기를 클릭합니다

키 조합이 이미 다른 기능에서 사용 중이면 버튼에 단축키 충돌이 표시되고 단축키가 저장되지 않습니다.

단축키는 Stream Toolkit이 활성 창이 아닐 때도 동작합니다. 말하는 동안 누르고 있다가, 손을 떼면 인식과 번역이 진행됩니다. 녹음은 15초가 지나면 자동으로 멈춥니다.

단축키 아래의 REC 버튼을 마우스로 누르고 있어도 됩니다. 동작은 같습니다. 누르면 녹음하고, 놓으면 번역합니다. 빠른 도구 창에도 같은 REC 버튼이 있습니다.

3단계: 인식 설정​

항목설명
모델 상태로드 중 xx%, 준비 완료, 모델 로드 실패 중 하나가 표시됩니다. 준비 완료가 표시되면 녹음할 수 있습니다
Whisper 모델Tiny (가장 빠름, 약 40MB), Base (권장, 약 75MB)(기본값), Small (가장 정확, 약 245MB). 모델은 처음 사용할 때 다운로드됩니다. 모델을 바꾸면 다시 로드됩니다
음성 언어말하는 언어입니다. 기본값은 번체 중국어입니다
마이크녹음에 사용할 마이크입니다. 시스템 기본값은 Windows의 기본 입력 장치를 사용합니다

4단계: 번역 설정​

항목설명
자막 표시 시간자막이 화면에 표시되는 시간, 1–30초. 기본값은 5입니다
목표 언어번역할 언어입니다. 기본값은 영어입니다
번역 목표가 English일 때 Whisper 번역 사용목표 언어가 영어이면 MyMemory 대신 Whisper가 번역합니다(무료이며 할당량이 없지만 지연이 더 큽니다). 다른 목표 언어에는 영향이 없습니다
번역 서비스MyMemory

Email (선택)​

MyMemory는 무료입니다. 일일 할당량은 이메일 입력 여부에 따라 다릅니다:

  • 이메일 미입력: 일일 5,000자
  • 이메일 입력: 일일 50,000자(무료, MyMemory 가입 불필요)

이메일을 입력하고 저장을 클릭합니다. 이 이메일은 채팅방 번역과 공유됩니다.

아래 바에 **오늘 사용량 (대략, 매일 UTC 08:00 초기화)**이 표시됩니다. 할당량을 모두 사용하면 사용 한도 도달이 표시됩니다.

5단계: 외관​

외관 탭에서 자막의 모양을 바꿀 수 있습니다. 변경 사항은 바로 저장됩니다.

  • 미리보기: 샘플 자막을 표시합니다. 옆의 색상 상자는 미리보기 배경만 바꿉니다
  • 정렬: 왼쪽 정렬(기본값), 가운데 정렬, 오른쪽 정렬
  • 글꼴: 원본 언어(원문) 한 줄과 목표 언어(번역문) 한 줄이 있습니다. 각 줄에서 글꼴, 색상, 크기(8–120 px)를 설정합니다. 기본값은 원문 14 px, 번역문 22 px입니다
  • 그림자: 텍스트 그림자 색상
  • 기본값 복원: 기본 외관으로 되돌립니다

:::info 체험판 제한 목표 언어는 영어로 고정됩니다. 페이지에 "Demo판은 영어 번역만 지원합니다"가 표시됩니다.

자세한 내용은 체험판 / 정식판 비교를 참고하세요. :::

자주 묻는 질문​

Q: 단축키를 누르고 있어도 아무 반응이 없나요? 왼쪽 사이드바에서 음성 번역 옆의 스위치가 켜져 있는지, 모델 상태가 준비 완료로 표시되는지 확인하세요.

Q: 녹음은 되는데 OBS에 자막이 표시되지 않나요? MyMemory가 번역하지 못하면(예: 일일 할당량을 모두 사용한 경우) 자막이 표시되지 않습니다. 오늘 사용량 바를 확인하세요. 이메일을 입력하면 할당량이 늘어납니다. 목표 언어가 영어라면 할당량이 없는 번역 목표가 English일 때 Whisper 번역 사용을 켤 수도 있습니다.
