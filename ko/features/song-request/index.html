노래 신청

시청자가 채팅 명령어로 YouTube 노래를 신청하면 OBS에서 차례대로 재생됩니다. 직접 노래를 추가하거나, 신청곡이 없을 때 재생할 기본 재생 목록을 설정할 수도 있습니다.

OBS 소스 URL​

http://127.0.0.1:7272/song-request

페이지 상단의 OBS 소스 주소 옆에 있는 복사를 클릭한 후 OBS에 브라우저 소스로 추가합니다. OBS에서 소스 추가하는 방법을 참고하세요.

경고

노래 신청은 소리를 재생합니다. 브라우저 소스 속성에서 OBS를 통해 오디오 제어를 체크하지 않으면 음악이 방송에 나가지 않습니다.

팁

왼쪽 메뉴에서 노래 신청 옆의 스위치도 켜세요. 스위치가 켜져 있을 때만 채팅 명령어가 처리됩니다.

페이지에는 설정과 재생 목록 두 개의 탭이 있습니다.

설정 탭​

플랫폼​

플랫폼마다 카드가 있습니다:

  • 이 플랫폼 신청곡 허용: 해당 채팅의 시청자가 노래를 신청할 수 있습니다
  • 채팅 봇 응답 사용(Twitch 전용, 기본적으로 켜짐): 연결된 Twitch 계정으로 각 명령어의 결과를 Twitch 채팅에 답합니다. Twitch가 사용 중이고 연결되어 있을 때만 표시됩니다

연결되지 않은 플랫폼에는 (연결 안 됨)(Twitch) 또는 채팅방 주소가 연결되지 않음(YouTube)이 표시됩니다. 먼저 연결하세요:

  • Twitch 설정
  • YouTube 설정

채팅방 명령어​

항목기본값
명령어 접두사! (! @ # $ % & ~ 중에서 선택)
신청곡 명령어sr
신청곡 삭제remove
신청곡 목록 보기queue
현재 곡 조회song
신청곡 쿨다운 시간3000 ms

쿨다운은 시청자별로 계산됩니다. 신청에 성공하면 같은 시청자는 이 시간이 지나야 다시 신청할 수 있습니다.

설정​

  • 화면에 영상 표시(기본적으로 켜짐): 끄면 OBS에서 영상은 숨겨지지만 소리는 계속 재생됩니다
  • 목록 상한(1–100, 기본값 20): 목록에 들어갈 수 있는 신청곡의 최대 개수입니다. 기본 재생 목록의 곡은 포함되지 않습니다
  • 신청곡 알림 표시(기본적으로 켜짐): 시청자가 노래를 신청하거나 삭제하거나 신청에 실패하면 OBS에 알림 카드를 표시합니다. 켜면 다음을 설정할 수 있습니다:
    • X / Y: 왼쪽 위 모서리 기준 알림 위치(px, 기본값 16 / 16)
    • 알림 크기 조절: 크기 배율(기본값 1.0)
    • 알림 외관 테스트: OBS에 테스트 알림을 보냅니다

각 알림은 5초 동안 표시되며, 최대 3개까지 동시에 표시됩니다.

시청자 사용 방법​

기본 설정 기준:

명령어동작
!sr <YouTube 링크>해당 영상을 신청합니다
!sr <검색어>YouTube에서 검색해 첫 번째 결과를 신청합니다
!remove시청자의 가장 최근 신청곡을 삭제합니다(재생 중인 곡 제외)
!queue다음 신청곡 3개로 답합니다
!song재생 중인 곡으로 답합니다
  • 사용 가능한 링크: youtube.com/watch?v=…, youtu.be/…, youtube.com/live/…, youtube.com/shorts/…, 또는 11자리 영상 ID
  • 재생 목록 링크는 사용할 수 없습니다
  • 목록이 목록 상한에 도달하면 신청이 실패합니다
  • 새 신청곡은 다른 시청자의 신청곡 뒤, 기본 재생 목록 곡 앞에 들어갑니다
  • !queue와 !song은 채팅 봇 응답 사용이 켜진 Twitch 채팅에서만 동작합니다

재생 목록 탭​

재생 조작​

맨 위 줄에 현재 곡을 신청한 사람과 곡 제목이 표시됩니다. 버튼:

  • 재생 / 일시정지: 재생 중인 곡이 없으면 목록의 첫 번째 곡부터 시작합니다
  • 정지: 재생을 멈춥니다
  • 다음 곡: 다음 곡으로 건너뜁니다

곡이 재생되는 동안 진행 바가 표시되며, 드래그하면 원하는 위치로 이동합니다. 곡이 끝나면 다음 곡이 자동으로 시작됩니다.

노트

App을 시작할 때 자동으로 재생되지 않습니다. 재생을 눌러 시작하세요.

기본 재생 목록​

YouTube 재생 목록 URL을 붙여넣고 순차 재생 또는 무작위 재생을 선택합니다. 목록이 비면 이 재생 목록의 곡이 자동으로 추가되어 재생됩니다. 이 곡들은 목록에 기본 목록으로 표시됩니다.

기본 재생 목록은 YouTube 계정을 통해 읽어 오므로, 먼저 YouTube 설정에서 Google로 로그인해야 합니다.

수동 신청곡​

YouTube 영상 URL을 붙여넣고 목록에 추가를 클릭합니다(또는 Enter). 수동 신청곡은 검색어를 지원하지 않습니다.

목록​

**목록 (n)**에는 모든 곡이 플랫폼, 신청자, 제목, 영상 ID(클릭하면 YouTube에서 열림)와 함께 표시됩니다. 삭제를 클릭하면 곡이 제거되며, 재생 중인 곡을 삭제하면 다음 곡으로 건너뜁니다. 비우기를 누르면 목록 전체를 비웁니다.

자주 묻는 질문​

Q: 시청자가 명령어를 입력해도 아무 반응이 없나요? 다음을 확인하세요:

  • 왼쪽 메뉴의 노래 신청 스위치가 켜져 있는지
  • 해당 플랫폼의 이 플랫폼 신청곡 허용이 체크되어 있는지
  • Twitch의 경우: Twitch 채팅은 채팅방 기능을 통해 읽습니다. 채팅방 페이지에서 Twitch를 껐다면(채팅 봇도 Twitch를 사용하지 않는 경우) Twitch 명령어를 받을 수 없습니다

Q: 기본 재생 목록이 재생되지 않나요? 설정에서 Google로 로그인되어 있는지, URL이 재생 목록 링크(list= 포함)인지 확인하세요.

:::info 체험판 제한

  • 시청자 채팅 신청곡은 정식판에서만 사용할 수 있습니다. 체험판에서는 채팅으로 신청하면 "체험판에서는 시청자 신청곡을 지원하지 않아요" 메시지와 함께 실패합니다. 수동 신청곡과 기본 재생 목록은 사용할 수 있습니다
  • OBS 오버레이에 워터마크가 표시됩니다

체험판 / 정식판 비교를 참고하세요. :::
