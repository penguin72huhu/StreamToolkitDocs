시청자 생일 알림

시청자의 생일을 목록에 추가해 두세요. 목록에 있는 시청자가 생일 당일 또는 생일 직후에 방송 중 채팅을 하면 방송 화면에 생일 알림이 표시됩니다. 시청자마다 생일 한 번에 알림은 한 번만 표시됩니다.

OBS 소스 URL​

http://127.0.0.1:7272/birthday-alert

시청자 생일 알림 설정 페이지 상단에서 URL을 복사하여 OBS에 브라우저 소스로 추가합니다. OBS에서 소스 추가하는 방법을 참고하세요.

경고

알림에는 소리가 재생됩니다. 브라우저 소스 속성에서 OBS를 통해 오디오 제어를 체크하지 않으면 방송에서 소리가 들리지 않습니다.

왼쪽 사이드바에서 시청자 생일 알림 옆의 스위치를 켭니다. 스위치가 켜져 있을 때만 App이 채팅에 연결하고 생일을 확인합니다. 테스트 알림과 다시 보기 버튼은 스위치가 꺼져 있어도 동작합니다.

페이지에는 설정, 시청자 목록, 외관 세 개의 탭이 있습니다.

동작 방식​

  • 목록에 있는 시청자가 생일부터 설정한 일수까지의 기간에 채팅하면 알림이 표시됩니다. 생일 전에는 표시되지 않습니다.
  • 시청자마다 생일 한 번에 알림은 한 번만 표시됩니다. 12/28 생일을 1/2에 알린 경우에도 전년도 생일로 계산됩니다.
  • 알림은 시청자가 채팅한 플랫폼이 방송 중일 때만 표시됩니다. 방송 중이 아니거나 App이 아직 방송 여부를 판단하지 못한 상태에서는 채팅해도 알림이 표시되거나 기록되지 않으며, 다음에 방송 중에 채팅할 때 표시됩니다.
  • YouTube 채팅 연결 시 불러오는 이전 채팅 기록은 계산되지 않으므로, App을 재시작해도 App이 꺼져 있던 동안 채팅한 사람에게 알림이 표시되지 않습니다.
  • 2/29 생일은 윤년이 아닌 해에는 2/28로 처리됩니다.

설정 탭​

채팅 연결​

기능이 켜져 있을 때 표시됩니다. 각 플랫폼의 채팅 연결 상태가 표시됩니다:

  • Twitch: 채널이 설정되어 있지 않으면 Twitch 채널이 설정되지 않았어요. 먼저 Twitch를 연결하세요와 설정으로 이동이 표시됩니다. 먼저 Twitch를 연결하세요: Twitch 설정.
  • YouTube: 채팅이 연결되어 있지 않으면 자동 연결과 직접 입력(설정의 채팅 URL 필드로 이동)이 표시됩니다. 자동 연결을 사용하고 Google로 로그인한 경우 방송 시작 후에도 연결되지 않으면 채팅 페이지에서 연결을 누르세요가 표시됩니다. YouTube 설정과 채팅방을 참고하세요.

플랫폼이 연결되면 방송 중, 방송 안 함, 방송 여부를 알 수 없음 중 하나도 표시됩니다. 알림은 방송 중일 때만 표시됩니다.

설정​

항목설명
생일 후 며칠까지 알릴지0–30. 기본값: 7. 0 = 생일 당일만.
표시 시간각 알림이 화면에 표시되는 시간(초, 1–60). 기본값: 6.

알림 테스트​

테스트 알림을 클릭하면 테스트 시청자와 오늘 날짜로 샘플 알림을 OBS에 보냅니다. OBS에만 표시되고 기록되지 않으며, 왼쪽 사이드바의 스위치가 꺼져 있어도 동작합니다. 버튼이 잠시 보냄으로 바뀝니다.

시청자 목록 탭​

시청자 추가​

시청자를 추가하는 방법은 두 가지입니다:

  • + 최근 채팅한 사람에서 추가: 최근 채팅한 사람 중에서 선택합니다. 메모 이름에 해당 시청자의 이름이, 계정은 이미 연결된 상태로, 생일에는 오늘 날짜가 입력된 양식이 열립니다.
  • + 이름으로 추가: 계정 이름을 직접 입력합니다.

최근 채팅한 사람에는 채팅이 연결되어 있는 동안 채팅한 시청자가 표시됩니다(최대 200명, 30일간 보관). 새로고침을 클릭하면 목록이 업데이트됩니다. 이미 목록에 있는 시청자는 등록됨으로 표시되며 다시 선택할 수 없습니다. 목록이 길면 검색창이 나타납니다.

양식을 작성합니다:

  1. 메모 이름: 알고 있는 이름(예: 민수). 선택 사항입니다.
  2. 생일: 월과 일(연도 없음).
  3. 계정: 최소 하나의 계정. 한 시청자가 Twitch와 YouTube처럼 여러 계정을 가질 수 있습니다.
    • ＋ 계정 직접 입력: Twitch 또는 YouTube를 선택하고 이름을 입력합니다. Twitch는 아이디 또는 표시 이름, YouTube는 @핸들 또는 채널 이름을 입력합니다.
    • ＋ 최근 채팅한 사람에서: 이미 연결된 계정을 추가합니다.
    • **✕**를 누르면 계정이 삭제됩니다.
  4. 저장을 클릭합니다(또는 Enter). 취소(또는 Esc)를 누르면 양식이 닫힙니다.

직접 입력한 이름과 연결​

직접 입력한 이름은 그 시청자가 처음 채팅할 때 계정과 연결됩니다. 대소문자와 맨 앞의 @는 구분하지 않습니다. 이름이 겹칠 수 있으므로 최근 채팅한 사람에서 고르는 것이 더 정확합니다.

YouTube는 @핸들을 입력하세요. 채팅방 페이지에서 @핸들 대신 시청자 이름 표시가 켜져 있지 않으면 채널 이름으로는 연결되지 않을 수 있습니다.

목록의 각 계정에는 다음이 표시됩니다:

  • 연결됨: [이름]: 계정이 연결되었습니다.
  • 「[이름]」 채팅 대기 중: 아직 연결되지 않은 직접 입력한 이름입니다.
  • 새로 연결됨: 시청자가 채팅할 때 App이 이 계정을 자동으로 연결했습니다. 본인이 맞는지 확인한 후 ✓ 맞아요를 클릭하고, 아니면 연결 해제를 클릭하세요.
  • 이 계정은 이미 「[이름]」에 등록돼 있어요: 직접 입력한 이름이 목록의 다른 시청자의 계정과 일치했습니다. 한 계정은 한 시청자에게만 등록할 수 있으므로, 여기 이름을 바꾸거나 둘 중 하나를 삭제하세요.

연결 해제를 누르면 계정 아래에 입력란이 열립니다. 해제 후에는 입력란의 이름(변경 가능)으로 다시 찾고, 그 시청자가 다음에 채팅할 때 계정이 다시 연결됩니다.

목록​

생일 알림 기간에 해당하는 시청자가 먼저 표시되고, 그다음 다가오는 생일 순으로 표시됩니다. 시청자가 5명보다 많으면 검색창이 나타납니다. 각 시청자에는 다음이 표시됩니다:

  • 채팅 대기: 지금이 이 시청자의 생일 기간입니다. 채팅하면 바로 알림이 표시됩니다.
  • 🎂 [날짜] 알림 완료: 이번 생일 알림이 이미 표시되었습니다.
  • ▶ 다시 보기: 이 시청자의 알림을 OBS에 다시 표시합니다. 언제든 사용할 수 있으며 기록되지 않습니다.
  • 편집: 메모 이름, 생일, 계정을 변경합니다. 생일을 변경하면 새 날짜에 알림이 다시 표시될 수 있습니다.
  • 삭제: 삭제를 클릭한 후 삭제 확인을 클릭합니다.

외관 탭​

미리보기​

미리보기는 OBS 소스와 같은 페이지를 사용합니다. 미리보기 옆의 색상 선택기로 미리보기 배경을 바꿀 수 있으며, ▶ 애니메이션 다시 재생을 클릭하면 알림 애니메이션을 다시 재생합니다.

통일 스타일 / 플랫폼별 개별​

  • 통일 스타일: Twitch와 YouTube가 같은 알림 스타일을 사용합니다.
  • 플랫폼별 개별: 플랫폼마다 각자의 스타일을 사용합니다. 아래 버튼으로 Twitch 또는 YouTube를 선택하고 설정을 편집합니다. 처음 전환하면 아직 사용자 정의하지 않은 플랫폼은 현재 통일 스타일을 복사하며, 카운트다운 바 색상은 플랫폼마다 따로 갖습니다.

기본값 복원을 누르면 편집 중인 스타일이 기본 스타일로 돌아갑니다.

이미지​

  • 이미지 선택: 소재 관리에서 이미지를 선택합니다. 이미지가 없으면 케이크 이모지가 표시됩니다. 지우기를 누르면 이미지가 제거됩니다.
  • 이미지 크기: 1–400 px.
  • 이미지 위치: 왼쪽, 오른쪽, 위쪽, 아래쪽.

사운드​

기본 제공 사운드를 선택합니다: 없음, 차임벨(기본값), 코인, 종소리, 팝, 팡파르. **▶**를 클릭하면 들어볼 수 있습니다. 사운드 선택을 클릭하면 소재 관리에서 직접 준비한 사운드 파일을 사용할 수 있습니다.

사용자 정의 텍스트​

알림에 표시할 문구를 작성합니다. 비워 두면 기본 문구 {name}님, 생일 축하해요!를 사용합니다. 다음을 사용할 수 있습니다:

변수바뀌는 내용
{name}채팅에서의 시청자 이름
{label}메모 이름(메모가 비어 있으면 채팅 이름)
{birthday}생일(예: 10/20)
{MM} {DD}두 자리 월과 일. 원하는 형식을 직접 조합할 수 있습니다(예: {DD}/{MM})
{date}오버레이 언어로 표시한 생일
{platform}플랫폼 이름

텍스트와 색상​

  • 텍스트: 사용자 정의 텍스트와 시청자 이름의 글꼴, 크기, 색상을 설정합니다.
  • 색상: 배경, 그림자, 카운트다운 바.

사용자 정의 CSS​

사용자 정의 CSS를 펼치면 편집 중인 스타일(통일 스타일 또는 선택한 플랫폼)의 CSS를 편집할 수 있습니다. 기본값 복원을 누르면 템플릿 CSS로 돌아가고, 소재 관리를 누르면 소재 관리가 열립니다. 여기서 Steam Workshop 테마도 적용할 수 있습니다. 테마가 적용된 동안에는 CSS가 읽기 전용입니다. 테마 스타일을 참고하세요.

:::info 체험판

  • 목록에는 최대 3명까지 등록할 수 있습니다. 목록에 그보다 많은 시청자가 있으면(예: 정식판 저장 데이터) 초과한 시청자는 잠김 🔒으로 표시되며, 알림이 표시되지 않고 편집하거나 다시 보기할 수 없습니다.
  • 사용자 정의 CSS는 정식판에서만 사용할 수 있습니다.
  • OBS의 알림에 워터마크가 표시됩니다.

체험판 / 정식판 비교를 참고하세요. :::

자주 묻는 질문​

Q: 방송에서 소리가 나지 않나요? 브라우저 소스 속성에서 OBS를 통해 오디오 제어가 체크되어 있는지, OBS 믹서에서 해당 소스가 음소거되어 있지 않은지 확인하세요. 또한 사운드가 없음으로 설정되어 있지 않은지 확인하세요.

Q: 시청자가 생일에 채팅했는데 알림이 표시되지 않았나요? 왼쪽 사이드바의 스위치가 켜져 있는지, 설정 탭의 채팅 연결에서 해당 플랫폼이 방송 중으로 표시되는지, 목록의 계정이 연결됨으로 표시되거나 직접 입력한 이름이 채팅 이름과 일치하는지 확인하세요. OBS가 열려 있지 않을 때 표시되었다면 ▶ 다시 보기를 사용하세요.

Q: OBS 소스를 늦게 추가했는데, 이전 알림이 다시 재생되나요? 아니요. 새로 열린 소스는 연결된 이후에 도착한 알림만 표시합니다. 시청자 목록 탭에서 ▶ 다시 보기를 사용하면 다시 표시할 수 있습니다.
