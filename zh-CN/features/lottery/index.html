抽奖

观众在 Twitch 或 YouTube 聊天室输入关键词即可参加。报名结束后随机抽出中奖者，抽奖动画会在 OBS Overlay 上播放。

OBS 来源网址​

http://127.0.0.1:7272/lottery

点击页面上方 OBS 源网址 旁的 复制，再在 OBS 中添加为浏览器源。请参考 如何在 OBS 加入来源。抽奖不会播放声音，因此不需要勾选“通过 OBS 控制音频”。

提示

同时也要打开左侧菜单 抽奖 旁的开关（开启 OBS 显示）。开关关闭时，Overlay 会保持隐藏。

页面有两个标签页：设置 与 历史记录。

设置​

投票平台​

点击 Twitch 或 YouTube 选择哪个平台的聊天室可以参加。可以两个都选。未连接的平台会显示 （未连接）（Twitch）或 未连接聊天室网址（YouTube）。连接方式请参考 Twitch 设置 与 YouTube 设置。

抽奖关键词​

包含此关键词的聊天消息即可让该观众参加。每位观众每次抽奖只能参加一次。关键词为空时无法点击 开始收集。

抽奖时间​

报名开放的时间（秒）。默认为 300，范围为 10–3600。

人数上限​

参加人数达到此数量时会提前结束报名。输入 0 表示不限人数。

抽取后删除选项​

开启后，中奖者会在下一次抽取前从参加者中移除，因此在同一次抽奖中不会再被抽中。

提示文字​

报名期间显示在 Overlay 上的提示，告诉观众关键词与参加人数。可设置字体、颜色与大小（px）。

抽奖动画​

  • ID 快速轮换（默认）：报名期间参加者的名字会在画面上飘动，抽奖时快速轮换
    • 收集画面字体：字体、字号，以及名字标签的颜色（最多 5 种）
    • 抽奖动画字体：抽奖时轮换名字的字体与字号
    • 恢复默认：恢复这些设置
  • 转盘动画：参加者会被放到转盘上，转盘旋转后选出中奖者。选择配色：极简 或你在 转盘 中制作的自定义主题

报名期间无法更改平台、关键词、时间、人数上限、抽取后删除选项或动画类型。

进行抽奖​

  1. 点击 开始收集。面板会显示 收集中…、剩余时间与参加人数
  2. 报名期间，可以在 手动输入参加者名称 输入名字后点击 新增（或按 Enter）。若名字已在名单中，会显示“此 ID 已在名单中”
  3. 若要在时间到之前结束报名，点击 结束收集。时间到或达到 人数上限 时也会结束报名。面板随后显示 时间到！
  4. 点击 开始抽奖。Overlay 会播放动画，结束后中奖者会显示在 中奖者 下方
  5. 若要再抽一位中奖者，点击 再次抽取

在任何阶段点击 取消抽奖，都会清除所有参加者与中奖者，Overlay 会回到等待状态。

历史记录​

历史记录 标签页为每次抽奖保留一笔记录，包含时间、关键词与参加人数。展开记录可查看中奖者与完整的参加者名单。只保留最近 30 天的抽奖记录。若要删除记录，点击 🗑 再点击 确认删除。

:::info 试用版限制 OBS Overlay 会显示水印。详情请参考 试用版 / 正式版比较。 :::
