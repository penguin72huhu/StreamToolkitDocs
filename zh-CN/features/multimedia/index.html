实况效果板

点击按钮或按下快捷键，即可在直播画面上显示图片、播放视频与音效。

页面有三个标签页：图片、视频 和 音效。每个标签页都有自己的 OBS 来源网址。

标签页OBS 来源网址通过 OBS 控制音频
图片http://127.0.0.1:7272/imageboard不需要
视频http://127.0.0.1:7272/videoboard必须
音效http://127.0.0.1:7272/soundboard必须

点击各网址旁的 复制，在 OBS 中添加为浏览器源。请参考 如何在 OBS 加入来源。视频与音效是在 OBS 来源中播放，而不是在 Stream Toolkit 中播放，因此这两个来源必须勾选 通过 OBS 控制音频，否则观众听不到声音。

提示

打开左侧菜单 实况效果板 旁的开关（开启 OBS 显示）。开关关闭时，无论使用按钮还是快捷键，都无法显示图片，视频与音效也不会播放。

共通操作​

图片、视频与音效都以卡片形式列出：

  • 点击卡片可展开或收起其设置
  • 卡片右侧的勾选框：勾选后，该项目会出现在 快速工具 的启动工具中。新项目默认为勾选
  • ✕ 删除该项目
  • 若本地文件已被移动或删除，卡片会显示 找不到文件

快捷键​

每个项目都可以设置自己的快捷键：

  1. 展开卡片并点击快捷键按钮
  2. 按下想要的按键组合后放开。按 Esc 取消
  3. 若要移除快捷键，点击 清除

若该组合已被其他功能使用，就不会保存，按钮会显示冲突提示。即使 Stream Toolkit 不是当前窗口，快捷键也有效。所有快捷键也会列在 快捷键总览 页面。

图片​

新增图片​

  1. 点击 新增图片
  2. 选择文件（jpg、jpeg、png 或 gif）。文件名会作为图片名称

展开卡片会显示缩略图与以下设置：

  • 名称：图片名称
  • 文件路径：点击 重选 选择其他文件
  • 快捷键：按一次显示图片，再按一次隐藏
  • 设置位置大小：请见下方
  • 删除图片：删除图片

显示与隐藏​

点击卡片上的 ○ 按钮即可在 OBS 中显示图片，按钮会变成 ◉。再点一次即可隐藏图片。

显示设置​

允许同时显示多张图片 默认关闭。关闭时，显示一张图片会隐藏当前显示中的图片。开启后可以同时显示多张图片。

设置位置大小​

  • X 位置 / Y 位置：单位为 px。0/0 为来源的正中央。正值往右／下移动，负值往左／上移动
  • 宽 / 高：原始大小的百分比。100 = 原始大小。🔗 按钮会锁定长宽比（默认开启）。点击后可自由缩放
  • 图片显示中时，修改会即时在 OBS 中预览
  • 保存 保留修改，重置 恢复为打开窗口时的数值，取消 不保存并关闭

视频​

点击 新增视频 新增一张卡片，再展开它：

  • 视频名称：显示在卡片上的名称
  • 来源：YouTube 或 本地
    • YouTube：将视频链接粘贴到 YouTube 网址。点击 测试解析 进行检查。成功时会显示“已解析，播放时自动应用”
    • 本地：点击 选择文件 选择 mp4、webm 或 ogg 文件。大小上限为 200MB，文件越大延迟越高。若需要透明背景，请使用 WebM（VP9 Alpha）视频
  • 循环播放：重复播放视频
  • 播放时间：设置 从 与 到（时、分、秒、毫秒）。到 保持 00:00 即播放到结尾
  • 音量：0–100%
  • 快捷键：按下即播放视频。视频播放中再按一次即停止
  • 设置位置大小：与图片相同的位置与大小栏位。点击 预览循环 可在调整时让视频在 OBS 中循环播放，点击 停止预览 停止。完成后点击 保存 或 取消

点击卡片上的 ▶ 即可在 OBS 中播放视频，点击 ■ 停止。

音效​

点击 新增音效 新增一张卡片，再展开它：

  • 音效名称：显示在卡片上的名称
  • 来源：YouTube 网址 或 本地文件
    • YouTube 网址：粘贴链接后点击 测试解析 进行检查
    • 本地文件：点击 选择文件 选择 mp3、wav、ogg、flac、m4a、aac 或 opus 文件
  • 播放时间：设置 从 与 到。到 保持 00:00 即播放到结尾
  • 音量：0–100%
  • 快捷键：按下即播放音效

点击卡片上的 ▶ 即可在 OBS 中播放音效，点击 ■ 停止。同一时间只会播放一个音效，播放另一个音效会停止当前的音效。

:::info 试用版限制

  • 只能新增 1 张图片、1 个视频与 1 个音效
  • 图片与视频 Overlay 会显示水印

详情请参考 试用版 / 正式版比较。 :::

常见问题​

Q：视频或音效有播放，但直播中没有声音。 请确认 /videoboard 与 /soundboard 来源已勾选 通过 OBS 控制音频，且这些来源在 OBS 混音器中没有静音。

Q：无法选择我的视频文件。 只能选择 mp4、webm 与 ogg 文件，最大 200MB。若文件更大，会显示大小上限的提示，且不会新增该文件。
