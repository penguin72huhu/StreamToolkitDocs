实况精彩标记

直播中按下快捷键，记录精彩片段发生在“开播后多久”。之后剪辑时，可以用这份时间列表在录像中找到精彩片段。

标记会保存在 Stream Toolkit 中。此功能没有 OBS Overlay，因此不需要添加 OBS 来源。

页面有两个标签页：设置 与 精华记录。

提示

打开左侧菜单 实况精彩标记 旁的开关。开关关闭时，快捷键与 MARK 按钮都不会新增标记。

步骤一：选择来源​

来源 决定直播时间的计算方式：

来源时间的计算方式需求
Twitch从当前 Twitch 直播开始算起的时间已连接 Twitch。请参考 Twitch 设置
YouTube从当前 YouTube 直播开始算起的时间已登录 Google。请参考 YouTube 设置
手动对齐（默认）本页手动计时器的数值无

Twitch 与 YouTube 旁的圆点显示是否已连接。未连接时，选项会显示 （未连接） 或 （尚未登录 Google）。

若在未开播时标记（或在 手动对齐 下计时器已停止时标记），时间会记录为 尚未开播。使用 Twitch 来源时，这个结果可能需要约 20 秒才会出现，因为 Stream Toolkit 会重试几次，以防 Twitch 还没登记刚开始的直播。

手动计时器​

选择 手动对齐 时，会出现 手动计时器：

  1. 以 HH:MM:SS 输入当前的直播时间（例如开播当下输入 00:00:00）
  2. 点击 开始同步计时。计时器会从该数值开始往上计时
  3. 每个标记都使用计时器的当前数值
  4. 点击 停止 停止计时器

标记时创建 Twitch 剪辑​

只有来源为 Twitch 时才会出现此选项。开启后，每次标记也会同时创建一个 Twitch 剪辑。

  • 必须正在直播。剪辑长度约 30 秒
  • 剪辑保存在 创作者仪表板 → 内容 → 剪辑
  • 标记后页面会显示 已创建 Twitch 剪辑，或失败原因：未在直播，无法创建、权限不足，请重新连接 Twitch、尚未连接 Twitch 或 创建失败，请稍后再试

步骤二：设置快捷键​

默认快捷键为 Ctrl+Shift+M。若要更改：

  1. 点击快捷键按钮
  2. 按下想要的按键组合后放开。按 Esc 取消
  3. 若要移除，点击 清除

若该组合已被其他功能使用，按钮会显示 此快捷键已用过，快捷键不会保存。即使 Stream Toolkit 不是当前窗口，快捷键也有效。

也可以点击快捷键下方的 MARK 按钮，效果与快捷键相同。快速工具 窗口中也有 MARK 按钮。

步骤三：直播中标记​

  1. （选填）标记前先在 标记名称 输入名称。留空会自动编号（精華標記_1、精華標記_2…）
  2. 按下快捷键或点击 MARK

输入的名称只会用于下一个标记，之后栏位会清空。

精华记录​

精华记录 标签页列出所有标记，最新的在最前面。每一行显示直播时间、名称、来源，以及标记的日期与时间。

  • 复制：将标记复制为文字，格式为 [date] name 🎬 stream time (source)
  • 🗑️：点击后再点击 确认删除 即可删除标记
  • 打开 Twitch 剪辑：该标记有创建 Twitch 剪辑时才会出现。在 Twitch 上打开剪辑

:::info 试用版限制 无法使用 标记时创建 Twitch 剪辑，会显示为“正式版启用”。

详情请参考 试用版 / 正式版比较。 :::
