表情墙

观众在聊天室使用表情符号时，表情符号会在直播画面上飘过。

:::note 开始之前 表情墙会读取聊天室中的表情符号，请先连接你使用的平台。请参考 Twitch 设置 与 YouTube 设置。 :::

步骤一：添加 OBS 来源​

复制页面上方的 OBS 源网址：

http://127.0.0.1:7272/emote-wall

在 OBS 中将它添加为浏览器源。请参考 如何在 OBS 加入来源。表情墙不会播放声音，因此不需要勾选“通过 OBS 控制音频”。

提示

同时也要打开左侧菜单 表情墙 旁的开关（开启 OBS 显示）。开关关闭时，聊天室的表情符号不会送到 Overlay。

步骤二：选择来源​

来源 下有 Twitch 与 YouTube 两张卡片。每张卡片都会显示连接状态：

  • Twitch 账号未连接时，Twitch 显示 （未连接）
  • YouTube 聊天室未连接时，YouTube 显示 未连接聊天室网址

勾选卡片上的 启用表情符号墙，即可显示该平台聊天室的表情符号。取消勾选则忽略该平台。

步骤三：动画设置​

设置说明
贴图大小每个表情符号的大小，16–256 px
每条消息最多 emote 数每条聊天消息最多取用的表情符号数量（1–20）
飘动持续时间每个表情符号飘动的时间，1–30 秒
飘动速度50–500 px/s

点击区块标题旁的 恢复默认，可将四个数值全部恢复。

步骤四：测试​

点击 测试（在 OBS 显示），会以当前设置将示范的 Twitch 表情符号送到 Overlay。测试表情符号的数量依照 每条消息最多 emote 数。

:::info 试用版限制 画面上有表情符号时，OBS Overlay 会显示水印。详情请参考 试用版 / 正式版比较。 :::
