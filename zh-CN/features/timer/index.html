计时器

在直播画面上显示倒计时或秒表。倒计时可以通过你点击的按钮增减时间，也可以由 Twitch 追随、订阅、Bits 与赞助自动增减。

页面有两个标签页：设置 与 创建计时器。请先创建计时器，再从 设置 控制它。

步骤一：创建计时器​

  1. 打开左侧菜单的 计时器，切换到 创建计时器 标签页
  2. 在 我的计时器 下点击 新增。会创建一个初始时间 10 分钟、带有三个时间选项（+30 秒、+1 分、+5 分）的倒计时计时器
  3. 点击计时器卡片即可编辑。点击卡片上的 ✕ 可删除该计时器

预览 显示所选计时器的样子。用旁边的颜色框可更改预览背景。

在预览下方切换 计时器设置 与 外观。

步骤二：计时器设置​

计时模式​

  • 倒计时：从初始时间往下倒数
  • 秒表：从 0 往上计时，可记录计圈。秒表模式没有初始时间、警示时间、结束音效与时间选项

名称​

显示在计时器列表、下拉菜单与快速工具中的名称。

初始时间​

倒计时的起始时间，以时、分、秒设置。旁边会显示换算后的总秒数。

警示时间​

剩余时间达到此数值时，计时器文字会切换为 外观 中设置的 警示 颜色。保持 0 表示不警示。

倒计时结束音效​

倒计时到 0 时播放的音效。选择 无 或内置音效之一（铃声、金币、钟声、弹出、号角）。点击 ▶ 试听。若要使用自己的文件，点击 选择音效 并从素材管理中选择。

音效由 OBS 浏览器源播放，因此计时器来源需勾选 通过 OBS 控制音频。请参考 如何在 OBS 加入来源。

时间选项​

时间选项是倒计时的加减时间按钮。每个计时器最多 20 个。

若要新增，填写 新增时间选项 表单：

  1. 触发来源：选择自动套用此选项的事件
    • 手动：只在你点击按钮时套用
    • 追随：每次有新的 Twitch 追随时套用
    • Twitch Bits：有 Bits Cheer 时套用
    • Twitch 新订阅：有 Twitch 订阅时套用
    • 赞助：有赞助时套用。用 赞助平台 选择 YouTube、O'Pay、ECPay 与 PayPal 中哪些要计入
  2. 选择 Twitch Bits 与 赞助 时，还需设置：
    • 触发门槛：一个单位所需的 Bits 或赞助金额
    • 换算方式：整数倍触发 或 按比例换算（见下方示例）
  3. 加时间：选择 ＋ 或 －，再设置时、分、秒
  4. 点击 新增

若要修改选项，点击其 编辑，修改表单后点击 保存（或 取消）。点击 ✕ 可删除。设有自动触发的选项会标上 🔗 与触发名称。

换算示例：触发门槛 100 bits，加时间 +1 分，观众 Cheer 了 250 bits：

  • 整数倍触发：只计算门槛的完整倍数 → 2 × 1 分 = +2 分
  • 按比例换算：250 ÷ 100 × 1 分 → +2 分 30 秒

赞助的金额会先换算成 App 设置中选择的货币，再与门槛比较。

备注
  • 自动触发只影响倒计时计时器
  • 设有自动触发的时间选项仍会以按钮形式出现在控制台中，因此你也可以手动点击
  • Twitch 新订阅 每个订阅事件只套用一次：一次赠送多个订阅也只套用一次。只有在 Twitch 目标条 中开启 计算重新订阅 时，重新订阅才会套用

控制快捷键​

为此计时器设置键盘快捷键：

  • 开始／暂停
  • 计圈快捷键（仅限秒表）
  • 重设快捷键

另请参考 快捷键总览。

步骤三：外观​

设置说明
字体时间文字的字体
字号12–300 px
字体颜色正常：纯色 或 渐变（两种颜色与 角度）。警示（仅限倒计时）：达到警示时间后使用的颜色
背景颜色时间后方的背景
边框外框颜色、透明度 与 粗细（0–20 px）
阴影阴影颜色、透明度、模糊 与 X / Y 偏移

步骤四：选择显示模式并添加 OBS 来源​

切换到 设置 标签页。在 控制台 下选择 显示模式：

模式说明OBS 来源网址
单一计时器OBS 只显示所选的计时器。用 当前计时器 下拉菜单切换计时器http://127.0.0.1:7272/timer
多计时器每个计时器有自己的网址，可分别加入 OBShttp://127.0.0.1:7272/timer/<timer ID>

在 多计时器 模式下，从 加入显示 选择计时器。每个加入的计时器都会有自己的卡片与 OBS 源网址。点击 复制 即可复制。点击卡片上的 ✕ 可将它从显示中移除。

将复制的网址在 OBS 中添加为浏览器源。请参考 如何在 OBS 加入来源。

提示

同时也要打开左侧菜单 计时器 旁的开关（开启 OBS 显示）。开关关闭时，计时器在 OBS 中会隐藏。

步骤五：控制计时器​

设置 标签页中的每张计时器卡片都有：

  • 开始 / 暂停：秒表的暂停按钮显示为 停止。倒计时到 0 后，必须先重设或加时间才能再开始
  • 计圈（仅限秒表）：计时中记录一圈。各圈会列在卡片下方，显示时间与前一圈的差距
  • 重设：停止计时器并回到初始时间（秒表为 0），同时清除计圈记录
  • 加时间（仅限倒计时）：每个时间选项各有一个按钮

计时中的时间只显示在 OBS Overlay 中，不会显示在设置页面上。你也可以从 快速工具 窗口控制计时器，该窗口也会显示当前时间。

:::info 试用版限制 只能创建 1 个计时器。详情请参考 试用版 / 正式版比较。 :::
