Twitch 目标条

在直播画面上显示 Twitch 追随、订阅与 Bits 目标的进度条。每种目标类型都有自己的进度条、自己的设置与自己的 OBS 网址。

:::note 开始之前 目标条计算的是 Twitch 事件，请先连接你的 Twitch 账号。请参考 Twitch 设置。 :::

步骤一：选择目标类型并添加 OBS 来源​

在页面上方选择目标类型：追随、订阅 或 Bits。按钮下方的 OBS 网址 会随之改变。点击 复制 即可复制。

目标类型OBS 来源网址
追随http://127.0.0.1:7272/goal/follow
订阅http://127.0.0.1:7272/goal/sub
Bitshttp://127.0.0.1:7272/goal/bits

将每个要显示的进度条分别添加为 OBS 的浏览器源。请参考 如何在 OBS 加入来源。目标条不会播放声音，因此不需要勾选“通过 OBS 控制音频”。

提示

同时也要打开左侧菜单 Twitch 目标条 旁的开关（开启 OBS 显示）。开关关闭时，进度条在 OBS 中会隐藏。

步骤二：设置目标​

以下所有设置都套用到你在上方选择的目标类型。

  • 标题：显示在进度条上的标题文字
  • 目标：目标数字（0 或以上的整数）
  • 进度：显示当前数量、目标与百分比

进度的计算方式​

目标类型计入进度的项目
追随每次新追随加 1。Twitch 连接期间，每 30 秒也会与 Twitch 上频道的追随者总数同步一次。点击 同步 可立即同步
订阅新订阅与赠送订阅（一次赠送多个订阅时，按赠送数量增加）。只有开启 计算重新订阅 时才计入重新订阅
Bits每次 Cheer 增加 Cheer 的 Bits 数量

订阅选项​

只在 订阅 显示：

  • 按 Tier 加权：开启后，较高等级的订阅会增加较多进度。关闭时每个订阅都加 1
  • 计算重新订阅：开启后，重新订阅的消息也会增加进度

重置进度​

订阅 与 Bits 有 重置进度 按钮。点击后再点击 确定重置，即可将当前数量归 0。目标数字会保留。

追随 没有重置按钮，因为它的数量跟随你在 Twitch 上的追随者总数。

步骤三：调整外观​

预览​

上方的 预览 显示所选目标类型的进度条。用旁边的颜色框可更改预览背景。勾选 预览达成 可查看达成目标后的样子。

外观设置​

设置说明
背景颜色进度条的背景
进度条颜色已填满部分的颜色
达标颜色达成目标后的填充颜色
标题字标题的字体、颜色与大小（8–72 px）
目标字数字的字体、颜色与大小（8–72 px）
百分比百分比的字体、颜色与大小（8–72 px）

点击 恢复默认 可恢复所选目标类型的外观。

自定义 CSS​

点击 自定义 CSS 展开编辑器。每种目标类型都有自己的 CSS。请用它来调整布局与结构。颜色、字体与大小请在上方的外观设置中设置。

  • 恢复默认：恢复默认 CSS
  • 管理素材：打开素材管理，管理 CSS 中使用的图片

若你的 CSS 用 !important 覆盖了某个属性，对应的外观控件会被锁定，因为 CSS 无论如何都会优先生效。

:::info 试用版限制

  • 自定义 CSS 仅限正式版
  • OBS Overlay 会显示水印

详情请参考 试用版 / 正式版比较。 :::
