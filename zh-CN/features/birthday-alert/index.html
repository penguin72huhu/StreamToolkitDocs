粉丝生日通知

把观众的生日登记到名单里。名单上的观众在生日当天或生日后几天内于直播中说话时，直播画面会弹出生日通知。每位观众每次生日只通知一次。

OBS 来源网址​

http://127.0.0.1:7272/birthday-alert

从 粉丝生日通知 设置 页面上方复制网址，在 OBS 中新增为浏览器源。请参考 如何在 OBS 加入来源。

注意

通知会播放音效。请在浏览器源的属性中勾选 通过 OBS 控制音频，否则直播中听不到声音。

打开左侧菜单 粉丝生日通知 旁的开关。只有开关开启时，App 才会连接聊天室并比对生日。测试通知 与 重播 按钮在开关关闭时也能使用。

页面有三个标签页：设置、观众名单、外观。

运作方式​

  • 名单上的观众从生日当天到你设置的天数内说话，就会弹出通知。生日前不会通知。
  • 每位观众每次生日只通知一次。12/28 的生日在 1/2 才通知，仍算是前一年的生日。
  • 只有在观众说话的平台正在直播时才会通知。未开播时，或 App 还无法判断是否开播时，观众说话不会触发也不会记录通知；等他下次在直播中说话时才会弹出。
  • YouTube 聊天室连接时载入的历史消息不算数，所以重启 App 不会通知 App 关闭期间说过话的人。
  • 2/29 的生日在非闰年会改在 2/28。

设置标签页​

聊天室连接​

功能开启时显示。每个平台都会显示聊天室是否已连接：

  • Twitch：若尚未设置频道，会显示 尚未设置 Twitch 频道，请先连接 Twitch 与 前往设置。请先连接 Twitch：Twitch 设置。
  • YouTube：聊天室未连接时，会显示 自动连接 与 手动填写（跳到设置页的聊天室网址栏位）。若使用自动连接且已登录 Google，会显示 开播后如果还没连上，请到聊天室页面点连接。请参考 YouTube 设置 与 聊天室。

平台连接后，还会显示 直播中、未开播 或 无法判断是否开播。只有 直播中 才会通知。

设置​

栏位说明
生日后几天内说话会通知0–30。默认：7。0 = 只有生日当天。
显示时间每则通知在画面上停留的秒数（1–60）。默认：6。

测试通知​

点击 测试通知，会用测试观众与今天的日期送一则示范通知到 OBS。它只显示在 OBS，不会写入记录，左侧菜单的开关关闭时也能使用。按钮会短暂变成 已发送。

观众名单标签页​

新增观众​

新增观众有两种方式：

  • + 从最近聊天的人新增：挑选最近说过话的人。表单打开时会以他的名字作为备注、账号已绑定好，生日则预填今天的日期。
  • + 手动新增：自己输入账号名称。

最近聊天的人 列出聊天室连接期间说过话的观众（最多 200 人，保留 30 天）。点击 刷新 更新列表。已在名单上的观众会显示 已登记，无法重复选择。列表较长时会出现搜索框。

填写表单：

  1. 备注名称：你对他的称呼，例如 小明。可不填。
  2. 生日：月与日（不含年份）。
  3. 账号：至少一个账号。一位观众可以有多个账号，例如同时有 Twitch 与 YouTube。
    • ＋ 手动输入账号：选择 Twitch 或 YouTube 并输入名称。Twitch 请填账号或显示名称；YouTube 请填 @代称或频道名称。
    • ＋ 从最近聊天的人加入：加入一个已绑定的账号。
    • ✕ 移除账号。
  4. 点击 保存（或按 Enter）。取消（或 Esc）关闭表单。

手动输入的名字与绑定​

手动输入的名字，会在这位观众第一次说话时绑定账号。比对时不分大小写，也会忽略开头的 @。名字可能重复，从最近聊天的人里挑选比较保险。

YouTube 请输入 @代称：除非在聊天室页面开启 显示观众名称而非 @代称，否则输入频道名称可能永远比对不到。

名单上每个账号会显示：

  • 已绑定：[名称]：账号已绑定。
  • 待绑定：[名称]：手动输入、尚未绑定的名字。
  • 新绑定：观众说话时 App 自动绑定了这个账号。确认是本人后点击 ✓ 确认无误，不是的话点击 解除绑定。
  • 此账号已登记在「[名称]」：手动输入的名字比对到了名单上另一位观众的账号。同一个账号只能登记在一位观众，请改掉这里的名字，或删掉其中一笔。

解除绑定 会在账号下方打开一个输入框。解除后改用框中的名字比对（可以修改），等这位观众下次说话时重新绑定。

名单​

生日通知待触发的观众排在最前面，接着是即将到来的生日。观众超过 5 位时会出现搜索框。每位观众会显示：

  • 等待说话：现在是他的生日期间，他一说话就会弹出通知。
  • 🎂 已通知 [日期]：这次生日的通知已经显示过。
  • ▶ 重播：在 OBS 再显示一次这位观众的通知。随时可用，不会写入记录。
  • 编辑：修改备注、生日或账号。修改生日后，新日期可以再次触发通知。
  • 删除：点击 删除，再点击 确认删除。

外观标签页​

预览​

预览使用与 OBS 来源相同的页面。用 预览 旁的取色器可以更改预览背景，点击 ▶ 重播动画 可再播放一次通知动画。

统一样式／各平台独立​

  • 统一样式：Twitch 与 YouTube 使用相同的通知样式。
  • 各平台独立：每个平台有自己的样式。用下方按钮选择 Twitch 或 YouTube 并编辑其设置。第一次切换时，尚未自定义的平台会复制目前的统一样式，各自带有自己的倒计时条颜色。

恢复默认 会把正在编辑的样式恢复为默认样式。

图片​

  • 选择图片：从素材管理选择图片。未选择时显示蛋糕表情符号。清除 移除图片。
  • 图片大小：1–400 px。
  • 图片位置：靠左、靠右、上方 或 下方。

音效​

选择内置音效：无、铃声（默认）、金币、钟声、弹出、号角。点击 ▶ 试听。点击 选择音效 可从素材管理使用自己的音效文件。

自定义文字​

填写通知上显示的文字。留空则使用默认文字：{name} 生日快乐！ 可使用：

占位符替换为
{name}观众在聊天室的名称
{label}你填的备注名称（备注为空时使用聊天室名称）
{birthday}生日，例如 10/20
{MM} {DD}两位数的月和日，可自组格式，例如 {DD}/{MM}
{date}按 Overlay 语言显示的生日
{platform}平台名称

文字与颜色​

  • 文字：设置 自定义文字 与 观众名称 的字体、大小与颜色。
  • 颜色：背景、阴影 与 倒计时条。

自定义 CSS​

展开 自定义 CSS 可编辑正在编辑的样式（统一样式或所选平台）的 CSS。恢复默认 会恢复模板 CSS，管理素材 打开素材管理。也可以在这里套用 Steam Workshop 主题。套用主题期间 CSS 为只读。请参考 主题样式。

:::info 试用版

  • 名单最多 3 位观众。若名单中有更多观众（例如来自正式版存档），多出的观众会显示为锁定 🔒：不会触发通知，也无法编辑或重播。
  • 自定义 CSS 仅限正式版。
  • 通知在 OBS 中会显示水印。

请参考 试用版 / 正式版比较。 :::

常见问题​

Q：直播中没有声音？ 确认浏览器源属性中已勾选 通过 OBS 控制音频，且 OBS 混音器中该来源没有静音。也请确认 音效 不是设为 无。

Q：观众在生日时说话了，但没有弹出通知。 确认左侧菜单的开关已开启、设置 标签页的 聊天室连接 中该平台显示 直播中，以及名单上的账号显示 已绑定，或手动输入的名字与他在聊天室的名称相符。若通知显示时 OBS 没有开启，请使用 ▶ 重播。

Q：我比较晚才加入 OBS 来源，会补播之前的通知吗？ 不会。新开启的来源只会显示连接之后才到达的通知。可在 观众名单 标签页使用 ▶ 重播 再显示一次。
