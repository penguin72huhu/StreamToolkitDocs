# Hotkeys

**⌨️ Hotkeys** at the bottom of the left menu lists every hotkey you have set up, in one place.

## Hotkeys Overview

Each row shows the key combination and what it triggers, e.g. `Timer › (timer name) › Start / Pause`. Click a row to open that feature's settings page and change it there. Hotkeys are not edited on this page.

If nothing is set up yet, it shows "No hotkeys set up yet."

## Features with Hotkeys

| Feature | What the hotkey does |
|------|------|
| [Stream Highlight Marker](./highlight.md) | Adds a marker |
| [Media Board](./multimedia.md) | Plays a sound / shows an image / plays a video (one hotkey per item) |
| [Voice Translation](./voice-translate.md) | The voice translation hotkey |
| [OBS Scene Control](./obs-scene.md) | **Switch scene** / **Toggle sources** |
| [Timer](./timer.md) | **Start / Pause**, **Lap**, **Reset** (per timer) |

## Setting a Hotkey

[Stream Highlight Marker](./highlight.md), [OBS Scene Control](./obs-scene.md), and [Timer](./timer.md) share the same hotkey field. For Media Board and Voice Translation, see their own pages.

1. Click the hotkey button
2. Press the key combination, e.g. `Ctrl+Shift+F1`
3. Release all keys to save it

- Press **Esc** while recording to cancel
- If the combination is already used by another hotkey, a conflict message appears and it is not saved. Choose a different combination
- Click **✕** (or the clear button) next to it to remove the hotkey
- Numpad keys are separate from the number keys on the main row: `Num1` and `1` are different hotkeys

Hotkeys work even while Stream Toolkit is in the background, e.g. while you are in a game.
