ตั้งค่า

คลิก ⚙️ ตั้งค่า ที่ด้านล่างของเมนูด้านซ้าย หน้านี้รวมตัวเลือกที่ใช้ทั้งโปรแกรม การเชื่อมต่อแพลตฟอร์ม และระบบชำระเงินสำหรับการสนับสนุน

ทั่วไป​

ตัวเลือกหน้าที่ค่าเริ่มต้น
ธีมโหมดการแสดงผลของอินเทอร์เฟซ: เทาสลัว หรือ สว่างเทาสลัว
ภาษาภาษาของอินเทอร์เฟซ เปลี่ยนทันที—
เมื่อกด X ให้ย่อลงทาสก์บาร์การปิดหน้าต่างจะย่อลงถาดระบบแทนการออกจากโปรแกรมเปิด
สกุลเงินสำหรับการสนับสนุนหน่วยสกุลเงินที่ใช้ทั้งโปรแกรม ใช้กับแถบสนับสนุน การแจ้งเตือน และการแสดงจำนวนเงินอื่น ๆ ทั้งหมดตั้งค่าตอนเปิดโปรแกรมครั้งแรกตามภาษาของระบบ (เช่น จีนตัวเต็ม (ไต้หวัน) → TWD, ญี่ปุ่น → JPY, อื่น ๆ → USD)

การเชื่อมต่อแพลตฟอร์ม​

Twitch​

คลิก เชื่อมต่อบัญชี แล้วอนุญาตในเบราว์เซอร์ เมื่อเชื่อมต่อแล้วจะแสดง เชื่อมต่อแล้ว @ชื่อของคุณ และปุ่ม ยกเลิกการเชื่อมต่อ ขั้นตอนทั้งหมด: การตั้งค่า Twitch

หลังเชื่อมต่อแล้ว ▸ ตั้งค่าการแปลงค่า ใช้กำหนดมูลค่าของ Bits และสมาชิกในสกุลเงินสำหรับการสนับสนุนของคุณ:

  • กลไกแบ่งรายได้: 50 / 50 หรือ 70 / 30
  • ทุก 100 Bits, สมาชิก Tier 1, สมาชิก Tier 2, สมาชิก Tier 3
  • บันทึก เก็บค่าสำหรับสกุลเงินปัจจุบัน คืนค่าเริ่มต้น จะกรอกค่าในตัวสำหรับสกุลเงินนั้น

YouTube​

  1. คลิก เชื่อมต่อบัญชี แล้วลงชื่อเข้าใช้ด้วย Google ขั้นตอนโดยละเอียด: การตั้งค่า YouTube
  2. เมื่อเชื่อมต่อแล้วจะแสดง เชื่อมต่อแล้ว: ชื่อช่อง ยกเลิกการเชื่อมต่อ จะยกเลิกการเชื่อมโยงบัญชี
  3. เลือกวิธีค้นหาแชทสด:
    • ตรวจหาไลฟ์ปัจจุบันอัตโนมัติ: ต้องลงชื่อเข้าใช้ Google คลิก เชื่อมต่อ เพื่อค้นหาไลฟ์ปัจจุบันหรือที่กำลังจะเริ่มในช่องของคุณ หากมีหลายรายการ ให้เลือกจากรายการ
    • ระบุ URL เอง: วาง URL ห้องแชท
  4. แจ้งให้กรอก URL ห้องแชททุกครั้งที่เปิดโปรแกรม: ไม่บังคับ

▸ ตั้งค่าการแปลงค่า ใต้ YouTube ใช้กำหนดมูลค่าของการเป็นสมาชิก (YouTube ไม่ส่งจำนวนเงินสำหรับการเป็นสมาชิก):

  • ตั้งค่าระดับการเป็นสมาชิก: เพิ่มชื่อแต่ละระดับและมูลค่า ชื่อระดับต้องตรงกับช่อง YouTube ของคุณทุกตัวอักษร
  • ระดับที่ไม่ได้ระบุไว้: มูลค่าที่ใช้กับระดับที่ไม่อยู่ในตาราง
  • ระดับของสมาชิกที่มอบให้: ระดับที่จะใช้นับสมาชิกที่มอบให้
  • ระดับที่พบในเหตุการณ์แต่ไม่มีในตารางจะแสดงพร้อมปุ่ม เพิ่มในตาราง / ละเว้น

การเชื่อมต่อแพลตฟอร์มสนับสนุน​

คลิกระบบชำระเงินเพื่อขยาย แต่ละระบบมีลิงก์ คลิกดูวิธีใช้ ไปยังคู่มือการตั้งค่า:

  • PayPal
  • Stripe
  • O'Pay
  • ECPay

ทดสอบการแจ้งเตือน​

ปุ่ม ทดสอบการแจ้งเตือน ข้างหัวข้อจะเปิดหน้าต่างทดสอบ:

  • กรอก ชื่อทดสอบ, ข้อความทดสอบ, จำนวนเงินทดสอบ เลือก แพลตฟอร์มทดสอบ แล้วคลิก ส่งการแจ้งเตือนทดสอบ
  • ทดสอบ YouTube Super Chat: ใส่ สตริงจำนวนเงิน เช่น $5.00 หรือ NT$150 แล้วคลิก ส่งทดสอบ Super Chat เพื่อทดสอบการอ่านจำนวนเงินและการแปลงสกุลเงิน
