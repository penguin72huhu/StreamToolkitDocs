แจ้งเตือนวันเกิดผู้ชม

เพิ่มวันเกิดของผู้ชมไว้ในรายชื่อ เมื่อผู้ชมในรายชื่อแชทระหว่างไลฟ์ในวันเกิดหรือไม่นานหลังวันเกิด การแจ้งเตือนวันเกิดจะเด้งขึ้นบนหน้าจอสตรีม ผู้ชมแต่ละคนจะได้รับการแจ้งเตือนหนึ่งครั้งต่อวันเกิด

URL ซอร์ส OBS​

http://127.0.0.1:7272/birthday-alert

คัดลอก URL จากด้านบนของหน้า ตั้งค่าแจ้งเตือนวันเกิดผู้ชม แล้วเพิ่มลงใน OBS เป็นซอร์สเบราว์เซอร์ ดู วิธีเพิ่มซอร์สใน OBS

warning

การแจ้งเตือนจะมีเสียง ต้องติ๊กเลือก ควบคุมเสียงผ่าน OBS ในคุณสมบัติของซอร์สเบราว์เซอร์ มิฉะนั้นจะไม่ได้ยินเสียงในสตรีม

เปิดสวิตช์ข้าง แจ้งเตือนวันเกิดผู้ชม ในแถบด้านซ้าย โปรแกรมจะเชื่อมต่อแชทและตรวจวันเกิดเฉพาะตอนที่สวิตช์เปิดอยู่เท่านั้น ส่วนปุ่ม ทดสอบการแจ้งเตือน และ เล่นซ้ำ ใช้ได้แม้สวิตช์ปิดอยู่

หน้านี้มีสามแท็บ: ตั้งค่า, รายชื่อผู้ชม และ รูปลักษณ์

วิธีการทำงาน​

  • ผู้ชมในรายชื่อที่แชทตั้งแต่วันเกิดไปจนถึงจำนวนวันหลังวันเกิดที่คุณตั้งไว้ จะได้รับการแจ้งเตือน ก่อนวันเกิดจะไม่มีอะไรแสดง
  • ผู้ชมแต่ละคนได้รับการแจ้งเตือนหนึ่งครั้งต่อวันเกิด วันเกิด 12/28 ที่แจ้งเตือนในวันที่ 1/2 ยังนับเป็นวันเกิดของปีก่อนหน้า
  • การแจ้งเตือนจะขึ้นเฉพาะตอนที่แพลตฟอร์มที่ผู้ชมแชทอยู่กำลังไลฟ์เท่านั้น ระหว่างที่คุณไม่ได้ไลฟ์ หรือขณะที่โปรแกรมยังไม่ทราบว่าคุณกำลังไลฟ์หรือไม่ การแชทจะไม่ทำให้แจ้งเตือนขึ้นหรือถูกบันทึก และจะแสดงในครั้งถัดไปที่ผู้ชมแชทระหว่างไลฟ์
  • ประวัติแชทที่โหลดมาตอนแชท YouTube เชื่อมต่อจะไม่ถูกนับ ดังนั้นการรีสตาร์ทโปรแกรมจะไม่แจ้งเตือนคนที่แชทระหว่างที่โปรแกรมปิดอยู่
  • วันเกิด 2/29 จะถือเป็น 2/28 ในปีที่ไม่ใช่ปีอธิกสุรทิน

แท็บตั้งค่า​

การเชื่อมต่อแชท​

แสดงเมื่อเปิดใช้งานฟีเจอร์นี้ แต่ละแพลตฟอร์มจะแสดงว่าแชทเชื่อมต่ออยู่หรือไม่:

  • Twitch: หากยังไม่ได้ตั้งช่อง แถวนี้จะแสดง ยังไม่ได้ตั้งช่อง Twitch โปรดเชื่อมต่อ Twitch ก่อน พร้อมปุ่ม ไปที่การตั้งค่า ให้เชื่อมต่อ Twitch ก่อน: การตั้งค่า Twitch
  • YouTube: หากแชทยังไม่เชื่อมต่อ แถวนี้จะแสดง เชื่อมต่ออัตโนมัติ และ กรอกเอง (พาไปที่ช่อง URL แชทในหน้าตั้งค่า) หากคุณใช้การเชื่อมต่ออัตโนมัติและลงชื่อเข้าใช้ด้วย Google แล้ว จะแสดง หากเริ่มไลฟ์แล้วยังไม่เชื่อมต่อ ให้กดเชื่อมต่อที่หน้าแชท ดู การตั้งค่า YouTube และ ห้องแชท

เมื่อแพลตฟอร์มเชื่อมต่อแล้ว จะแสดง กำลังไลฟ์, ไม่ได้ไลฟ์ หรือ ไม่ทราบว่ากำลังไลฟ์หรือไม่ ด้วย การแจ้งเตือนจะขึ้นเฉพาะเมื่อเป็น กำลังไลฟ์ เท่านั้น

ตั้งค่า​

ฟิลด์คำอธิบาย
นับหลังวันเกิดกี่วัน0–30 ค่าเริ่มต้น: 7 โดย 0 = เฉพาะวันเกิดเท่านั้น
ระยะเวลาแสดงระยะเวลาที่การแจ้งเตือนแต่ละครั้งแสดงบนหน้าจอ หน่วยเป็นวินาที (1–60) ค่าเริ่มต้น: 6

ทดสอบการแจ้งเตือน​

คลิก ทดสอบการแจ้งเตือน เพื่อส่งการแจ้งเตือนตัวอย่างไปยัง OBS โดยใช้ผู้ชมทดสอบและวันที่ของวันนี้ การแจ้งเตือนนี้แสดงใน OBS เท่านั้นและจะไม่ถูกบันทึก ใช้ได้แม้สวิตช์ในแถบด้านซ้ายปิดอยู่ ปุ่มจะเปลี่ยนเป็น ส่งแล้ว ชั่วครู่

แท็บรายชื่อผู้ชม​

การเพิ่มผู้ชม​

เพิ่มผู้ชมได้สองวิธี:

  • + เพิ่มจากคนที่แชทล่าสุด: เลือกคนที่เพิ่งแชท ฟอร์มจะเปิดขึ้นโดยใส่ชื่อของเขาเป็นชื่อที่บันทึกไว้ ผูกบัญชีให้แล้ว และใช้วันที่ของวันนี้เป็นวันเกิด
  • + เพิ่มด้วยชื่อ: พิมพ์ชื่อบัญชีเอง

คนที่แชทล่าสุด แสดงรายชื่อผู้ชมที่แชทระหว่างที่แชทเชื่อมต่ออยู่ (สูงสุด 200 คน เก็บไว้ 30 วัน) คลิก รีเฟรช เพื่ออัปเดต ผู้ชมที่อยู่ในรายชื่อแล้วจะแสดง เพิ่มแล้ว และเลือกซ้ำไม่ได้ เมื่อรายชื่อยาวจะมีช่องค้นหาปรากฏขึ้น

กรอกฟอร์ม:

  1. ชื่อที่บันทึกไว้: ชื่อที่คุณใช้เรียกเขา เช่น Alex ไม่บังคับ
  2. วันเกิด: เดือนและวัน (ไม่ต้องใส่ปี)
  3. บัญชี: อย่างน้อยหนึ่งบัญชี ผู้ชมหนึ่งคนมีได้หลายบัญชี เช่น ทั้ง Twitch และ YouTube
    • ＋ พิมพ์บัญชีเอง: เลือก Twitch หรือ YouTube แล้วพิมพ์ชื่อ สำหรับ Twitch ใช้ชื่อล็อกอินหรือชื่อที่แสดง สำหรับ YouTube ใช้ @แฮนเดิลหรือชื่อช่อง
    • ＋ จากคนที่แชทล่าสุด: เพิ่มบัญชีที่ผูกไว้แล้ว
    • ✕ นำบัญชีออก
  4. คลิก บันทึก (หรือกด Enter) ยกเลิก (หรือ Esc) จะปิดฟอร์ม

ชื่อที่พิมพ์เองและการผูกบัญชี​

ชื่อที่พิมพ์เองจะผูกกับบัญชีเมื่อผู้ชมคนนั้นแชทครั้งแรก การจับคู่ไม่สนตัวพิมพ์เล็ก/ใหญ่และ @ นำหน้า ชื่ออาจซ้ำกันได้ ดังนั้นเลือกจากคนที่แชทล่าสุดจะปลอดภัยกว่า

สำหรับ YouTube ให้พิมพ์ @แฮนเดิล: หากไม่ได้เปิด แสดงชื่อผู้ชมแทน @แฮนเดิล ในหน้าแชท ชื่อช่องอาจจับคู่ไม่ได้เลย

แต่ละบัญชีในรายชื่อจะแสดง:

  • ผูกแล้ว: [ชื่อ]: บัญชีนี้ผูกแล้ว
  • รอ “[ชื่อ]” แชท: ชื่อที่พิมพ์เองซึ่งยังไม่ได้ผูก
  • เพิ่งผูก: โปรแกรมผูกบัญชีนี้อัตโนมัติเมื่อผู้ชมแชท ตรวจสอบว่าเป็นคนเดียวกันจริง แล้วคลิก ✓ ถูกต้อง หรือคลิก ยกเลิกการผูก หากไม่ใช่
  • บัญชีนี้อยู่ใน “[ชื่อ]” แล้ว: ชื่อที่พิมพ์ไปตรงกับบัญชีที่เป็นของผู้ชมคนอื่นในรายชื่อ หนึ่งบัญชีผูกได้กับผู้ชมคนเดียว จึงต้องเปลี่ยนชื่อตรงนี้หรือลบรายการใดรายการหนึ่ง

ยกเลิกการผูก จะเปิดกล่องใต้บัญชี หลังยกเลิกการผูก จะใช้ชื่อในกล่องจับคู่แทน (แก้ไขได้) และบัญชีจะผูกใหม่เมื่อผู้ชมคนนั้นแชทครั้งถัดไป

รายชื่อ​

ผู้ชมที่ถึงกำหนดแจ้งเตือนวันเกิดจะอยู่ด้านบนสุด ตามด้วยวันเกิดที่กำลังจะมาถึง เมื่อมีผู้ชมมากกว่า 5 คนจะมีช่องค้นหาปรากฏขึ้น ผู้ชมแต่ละคนจะแสดง:

  • รอแชท: อยู่ในช่วงวันเกิดแล้ว การแจ้งเตือนจะขึ้นทันทีที่เขาแชท
  • 🎂 แจ้งแล้ว [วันที่]: การแจ้งเตือนสำหรับวันเกิดนี้แสดงไปแล้ว
  • ▶ เล่นซ้ำ: แสดงการแจ้งเตือนของผู้ชมคนนี้ใน OBS อีกครั้ง ใช้ได้ทุกเมื่อและจะไม่ถูกบันทึก
  • แก้ไข: เปลี่ยนชื่อที่บันทึกไว้ วันเกิด หรือบัญชี การเปลี่ยนวันเกิดจะทำให้การแจ้งเตือนขึ้นได้อีกครั้งสำหรับวันที่ใหม่
  • ลบ: คลิก ลบ แล้วคลิก ยืนยันการลบ

แท็บรูปลักษณ์​

ตัวอย่าง​

ตัวอย่างใช้หน้าเดียวกับซอร์ส OBS ใช้ตัวเลือกสีข้าง ตัวอย่าง เพื่อเปลี่ยนพื้นหลังของตัวอย่าง และคลิก ▶ เล่นแอนิเมชันซ้ำ เพื่อเล่นแอนิเมชันการแจ้งเตือนอีกครั้ง

รูปแบบเดียวกัน / แยกตามแต่ละแพลตฟอร์ม​

  • รูปแบบเดียวกัน: Twitch และ YouTube ใช้รูปแบบการแจ้งเตือนเดียวกัน
  • แยกตามแต่ละแพลตฟอร์ม: แต่ละแพลตฟอร์มมีรูปแบบของตัวเอง เลือก Twitch หรือ YouTube ด้วยปุ่มด้านล่างแล้วแก้ไขการตั้งค่า เมื่อสลับครั้งแรก แพลตฟอร์มที่คุณยังไม่ได้ปรับแต่งจะคัดลอกรูปแบบเดียวกันปัจจุบัน โดยแต่ละแพลตฟอร์มมีสีแถบนับถอยหลังของตัวเอง

คืนค่าเริ่มต้น จะคืนรูปแบบเริ่มต้นให้กับรูปแบบที่คุณกำลังแก้ไข

รูปภาพ​

  • เลือกรูปภาพ: เลือกรูปภาพจากตัวจัดการวัสดุ หากไม่เลือก จะแสดงอีโมจิเค้ก ล้าง จะนำรูปภาพออก
  • ขนาดรูปภาพ: 1–400 px
  • ตำแหน่งรูปภาพ: ชิดซ้าย, ชิดขวา, ด้านบน หรือ ด้านล่าง

เสียง​

เลือกเสียงในตัว: ไม่มี, เสียงกระดิ่ง (ค่าเริ่มต้น), เหรียญ, เสียงระฆัง, ป๊อป, แตรวง คลิก ▶ เพื่อฟัง คลิก เลือกเสียง เพื่อใช้ไฟล์เสียงของคุณเองจากตัวจัดการวัสดุ

ข้อความกำหนดเอง​

เขียนข้อความที่จะแสดงบนการแจ้งเตือน เว้นว่างไว้เพื่อใช้ข้อความเริ่มต้น: สุขสันต์วันเกิด {name}! คุณสามารถใช้:

ตัวแทนแทนที่ด้วย
{name}ชื่อของผู้ชมในแชท
{label}ชื่อที่บันทึกไว้ของคุณ (ใช้ชื่อในแชทหากชื่อที่บันทึกไว้ว่าง)
{birthday}วันเกิด เช่น 10/20
{MM} {DD}เดือนและวันแบบสองหลัก สำหรับจัดรูปแบบเอง เช่น {DD}/{MM}
{date}วันเกิดตามภาษาของโอเวอร์เลย์
{platform}ชื่อแพลตฟอร์ม

ข้อความและสี​

  • ข้อความ: ตั้งค่าฟอนต์ ขนาด และสีสำหรับ ข้อความกำหนดเอง และ ชื่อผู้ชม
  • สี: พื้นหลัง, เงา และ แถบนับถอยหลัง

CSS กำหนดเอง​

ขยาย CSS กำหนดเอง เพื่อแก้ไข CSS ของรูปแบบที่คุณกำลังแก้ไข (รูปแบบเดียวกันหรือแพลตฟอร์มที่เลือก) คืนค่าเริ่มต้น จะคืน CSS ของเทมเพลต และ จัดการวัสดุ จะเปิดตัวจัดการวัสดุ ยังสามารถใช้ธีมจาก Steam Workshop ได้ที่นี่ ระหว่างที่ใช้ธีมอยู่ CSS จะเป็นแบบอ่านอย่างเดียว ดู ธีม

:::info เวอร์ชันทดลองใช้งาน

  • รายชื่อมีได้สูงสุด 3 คน หากรายชื่อมีมากกว่านั้น (เช่น จากไฟล์บันทึกของเวอร์ชันเต็ม) ผู้ชมส่วนที่เกินจะแสดงเป็นล็อก 🔒: จะไม่ทำให้เกิดการแจ้งเตือน และแก้ไขหรือเล่นซ้ำไม่ได้
  • CSS กำหนดเองใช้ได้เฉพาะในเวอร์ชันเต็มเท่านั้น
  • การแจ้งเตือนจะมีลายน้ำใน OBS

ดู การเปรียบเทียบเวอร์ชันทดลอง / เวอร์ชันเต็ม :::

คำถามที่พบบ่อย​

Q: ไม่มีเสียงในสตรีม? ตรวจสอบว่าได้ติ๊กเลือก ควบคุมเสียงผ่าน OBS ในคุณสมบัติของซอร์สเบราว์เซอร์ และซอร์สไม่ได้ถูกปิดเสียงในมิกเซอร์ของ OBS รวมทั้งตรวจสอบว่า เสียง ไม่ได้ตั้งเป็น ไม่มี

Q: ผู้ชมแชทในวันเกิดแต่ไม่มีการแจ้งเตือนขึ้น ตรวจสอบว่าสวิตช์ในแถบด้านซ้ายเปิดอยู่ การเชื่อมต่อแชท ในแท็บ ตั้งค่า แสดง กำลังไลฟ์ สำหรับแพลตฟอร์มนั้น และบัญชีในรายชื่อแสดง ผูกแล้ว หรือชื่อที่พิมพ์ไว้ตรงกับชื่อในแชทของเขา หากการแจ้งเตือนแสดงไปแล้วตอนที่ OBS ไม่ได้เปิดอยู่ ให้ใช้ ▶ เล่นซ้ำ

Q: ฉันเพิ่มซอร์ส OBS ทีหลัง จะเล่นการแจ้งเตือนก่อนหน้าซ้ำไหม? ไม่ ซอร์สที่เพิ่งเปิดจะแสดงเฉพาะการแจ้งเตือนที่มาหลังจากเชื่อมต่อแล้วเท่านั้น ใช้ ▶ เล่นซ้ำ ในแท็บ รายชื่อผู้ชม เพื่อแสดงอีกครั้ง
