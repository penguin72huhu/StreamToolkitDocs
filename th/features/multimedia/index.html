Media Board

แสดงรูปภาพ เล่นวิดีโอ และเล่นเอฟเฟกต์เสียงบนสตรีมได้ด้วยการคลิกหรือปุ่มลัด

หน้านี้มีสามแท็บ: รูปภาพ, วิดีโอ และ เสียง แต่ละแท็บมี URL ซอร์ส OBS ของตัวเอง

แท็บURL ซอร์ส OBSควบคุมเสียงผ่าน OBS
รูปภาพhttp://127.0.0.1:7272/imageboardไม่จำเป็น
วิดีโอhttp://127.0.0.1:7272/videoboardจำเป็น
เสียงhttp://127.0.0.1:7272/soundboardจำเป็น

คลิก คัดลอก ข้าง URL แต่ละรายการ แล้วเพิ่มลงใน OBS เป็นซอร์สเบราว์เซอร์ ดู วิธีเพิ่มซอร์สใน OBS วิดีโอและเสียงจะเล่นในซอร์ส OBS ไม่ใช่ภายใน Stream Toolkit ดังนั้นคุณต้องเปิด ควบคุมเสียงผ่าน OBS สำหรับสองซอร์สนี้ มิฉะนั้นผู้ชมจะไม่ได้ยินเสียง

tip

เปิดสวิตช์ข้าง Media Board ในแถบด้านซ้าย (เปิดการแสดงใน OBS) ระหว่างที่ปิดอยู่ จะแสดงรูปภาพไม่ได้ และวิดีโอกับเสียงจะไม่เล่น ไม่ว่าคุณจะใช้ปุ่มหรือปุ่มลัด

การควบคุมทั่วไป​

รูปภาพ วิดีโอ และเสียงทั้งหมดจะแสดงเป็นการ์ด:

  • คลิกการ์ดเพื่อขยายหรือยุบการตั้งค่า
  • ช่องติ๊กทางขวาของการ์ด: เมื่อติ๊กเลือก รายการนั้นจะปรากฏในเครื่องมือเรียกใช้ของ เครื่องมือด่วน รายการใหม่จะถูกติ๊กเลือกเป็นค่าเริ่มต้น
  • ✕ ลบรายการ
  • หากไฟล์ในเครื่องถูกย้ายหรือลบไปแล้ว การ์ดจะแสดง ไม่พบไฟล์

ปุ่มลัด​

แต่ละรายการมีปุ่มลัดของตัวเองได้:

  1. ขยายการ์ดแล้วคลิกปุ่มปุ่มลัด
  2. กดชุดปุ่มที่ต้องการ แล้วปล่อย กด Esc เพื่อยกเลิก
  3. หากต้องการลบปุ่มลัด ให้คลิก ล้าง

หากชุดปุ่มนั้นถูกใช้โดยฟีเจอร์อื่นอยู่แล้ว จะไม่ถูกบันทึกและปุ่มจะแสดงข้อความแจ้งว่าขัดแย้งกัน ปุ่มลัดทำงานได้แม้ Stream Toolkit จะไม่ใช่หน้าต่างที่ใช้งานอยู่ ปุ่มลัดทั้งหมดยังแสดงรวมอยู่ในหน้า ปุ่มลัด ด้วย

รูปภาพ​

เพิ่มรูปภาพ​

  1. คลิก เพิ่มรูปภาพ
  2. เลือกไฟล์ (jpg, jpeg, png หรือ gif) ชื่อไฟล์จะกลายเป็นชื่อรูปภาพ

เมื่อขยายการ์ดจะแสดงภาพขนาดย่อและการตั้งค่าต่อไปนี้:

  • ชื่อ: ชื่อรูปภาพ
  • เส้นทางไฟล์: คลิก เลือกใหม่ เพื่อเลือกไฟล์อื่น
  • ปุ่มลัด: กดหนึ่งครั้งเพื่อแสดงรูปภาพ กดอีกครั้งเพื่อซ่อน
  • ตั้งค่าตำแหน่งและขนาด: ดูด้านล่าง
  • ลบรูปภาพ: ลบรูปภาพ

แสดงและซ่อน​

คลิกปุ่ม ○ บนการ์ดเพื่อแสดงรูปภาพใน OBS ปุ่มจะเปลี่ยนเป็น ◉ คลิกอีกครั้งเพื่อซ่อนรูปภาพ

การตั้งค่าการแสดงผล​

อนุญาตให้แสดงหลายรูปพร้อมกัน ปิดเป็นค่าเริ่มต้น ระหว่างที่ปิดอยู่ การแสดงรูปภาพจะซ่อนรูปภาพที่กำลังแสดงอยู่ เปิดตัวเลือกนี้เพื่อแสดงหลายรูปภาพพร้อมกัน

ตั้งค่าตำแหน่งและขนาด​

  • ตำแหน่ง X / ตำแหน่ง Y: หน่วยเป็น px โดย 0/0 คือจุดกึ่งกลางของซอร์ส ค่าบวกจะเลื่อนไปทางขวา/ลง ค่าลบจะเลื่อนไปทางซ้าย/ขึ้น
  • กว้าง / สูง: เป็น % ของขนาดต้นฉบับ 100 = ขนาดต้นฉบับ ปุ่ม 🔗 ล็อกอัตราส่วนภาพ (เปิดเป็นค่าเริ่มต้น) คลิกเพื่อปรับขนาดได้อิสระ
  • ระหว่างที่รูปภาพแสดงอยู่ การเปลี่ยนแปลงจะแสดงตัวอย่างแบบสดใน OBS
  • บันทึก เก็บการเปลี่ยนแปลง รีเซ็ต กลับไปยังค่าตอนที่เปิดหน้าต่าง ยกเลิก ปิดโดยไม่บันทึก

วิดีโอ​

คลิก เพิ่มวิดีโอ เพื่อเพิ่มการ์ด แล้วขยายการ์ด:

  • ชื่อวิดีโอ: ชื่อที่แสดงบนการ์ด
  • แหล่งที่มา: YouTube หรือ ในเครื่อง
    • YouTube: วางลิงก์วิดีโอลงใน URL ของ YouTube คลิก ทดสอบการแยกวิเคราะห์ เพื่อตรวจสอบ หากสำเร็จจะแสดง "แยกวิเคราะห์แล้ว จะใช้อัตโนมัติเมื่อเล่น"
    • ในเครื่อง: คลิก เลือกไฟล์ เพื่อเลือกไฟล์ mp4, webm หรือ ogg จำกัดขนาด 200MB และไฟล์ที่ใหญ่ขึ้นจะมีความหน่วงมากขึ้น หากต้องการพื้นหลังโปร่งใส ให้ใช้วิดีโอ WebM (VP9 Alpha)
  • เล่นวนซ้ำ: เล่นวิดีโอซ้ำ
  • เวลาเล่น: ตั้งค่า จาก และ ถึง (ชั่วโมง นาที วินาที ms) ปล่อย ถึง ไว้ที่ 00:00 เพื่อเล่นจนจบ
  • ระดับเสียง: 0–100%
  • ปุ่มลัด: กดเพื่อเล่นวิดีโอ กดอีกครั้งระหว่างที่วิดีโอกำลังเล่นเพื่อหยุด
  • ตั้งค่าตำแหน่งและขนาด: ช่องตำแหน่งและขนาดเหมือนกับของรูปภาพ คลิก วนซ้ำตัวอย่าง เพื่อเล่นวิดีโอวนซ้ำใน OBS ระหว่างที่คุณปรับ และ หยุดตัวอย่าง เพื่อหยุด คลิก บันทึก หรือ ยกเลิก เมื่อเสร็จ

คลิก ▶ บนการ์ดเพื่อเล่นวิดีโอใน OBS คลิก ■ เพื่อหยุด

เสียง​

คลิก เพิ่มเสียง เพื่อเพิ่มการ์ด แล้วขยายการ์ด:

  • ชื่อเสียง: ชื่อที่แสดงบนการ์ด
  • แหล่งที่มา: URL ของ YouTube หรือ ไฟล์ในเครื่อง
    • URL ของ YouTube: วางลิงก์แล้วคลิก ทดสอบการแยกวิเคราะห์ เพื่อตรวจสอบ
    • ไฟล์ในเครื่อง: คลิก เลือกไฟล์ เพื่อเลือกไฟล์ mp3, wav, ogg, flac, m4a, aac หรือ opus
  • เวลาเล่น: ตั้งค่า จาก และ ถึง ปล่อย ถึง ไว้ที่ 00:00 เพื่อเล่นจนจบ
  • ระดับเสียง: 0–100%
  • ปุ่มลัด: กดเพื่อเล่นเสียง

คลิก ▶ บนการ์ดเพื่อเล่นเสียงใน OBS คลิก ■ เพื่อหยุด เล่นได้ทีละหนึ่งเสียงเท่านั้น การเริ่มเสียงอื่นจะหยุดเสียงที่กำลังเล่นอยู่

:::info ข้อจำกัดของเวอร์ชันทดลองใช้งาน

  • เพิ่มได้เพียงรูปภาพ 1 รายการ วิดีโอ 1 รายการ และเสียง 1 รายการ
  • โอเวอร์เลย์รูปภาพและวิดีโอจะแสดงลายน้ำ

ดูรายละเอียดที่ การเปรียบเทียบเวอร์ชันทดลอง / เวอร์ชันเต็ม :::

คำถามที่พบบ่อย​

Q: วิดีโอหรือเสียงเล่นอยู่ แต่ไม่มีเสียงในสตรีม ตรวจสอบว่าได้ติ๊กเลือก ควบคุมเสียงผ่าน OBS สำหรับซอร์ส /videoboard และ /soundboard และซอร์สไม่ได้ถูกปิดเสียงในมิกเซอร์ของ OBS

Q: เลือกไฟล์วิดีโอของฉันไม่ได้ เลือกได้เฉพาะไฟล์ mp4, webm และ ogg ขนาดไม่เกิน 200MB หากไฟล์ใหญ่กว่านั้น จะมีข้อความแจ้งขีดจำกัดและไฟล์จะไม่ถูกเพิ่ม
