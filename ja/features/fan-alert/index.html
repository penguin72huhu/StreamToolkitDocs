新規フォロワー通知

Twitch で誰かがフォローしたとき、または YouTube チャンネルが登録されたときに、配信画面に通知をポップアップ表示します。

OBS ソース URL​

http://127.0.0.1:7272/fan-alert

新規フォロワー通知 の設定 ページ上部の URL をコピーし、OBS にブラウザソースとして追加します。OBS でソースを追加する方法 を参照してください。

警告

通知ではサウンドが再生されます。ブラウザソースのプロパティで OBS を介して音声を制御する にチェックを入れないと、配信で音が聞こえません。

左サイドバーの 新規フォロワー通知 の横にあるスイッチで通知のオン/オフを切り替えます。オフの間は新規フォロワーは表示も記録もされず、テストボタンも動作しません。

複数のフォロワーが続けて届いた場合、通知は順番待ちになり、1 つずつ表示されます。このオーバーレイには専用の待ち行列があるため、支援通知 の後ろで待たされることはありません。

設定タブ​

連携プラットフォーム​

通知を表示するプラットフォームにチェックを入れます：Twitch と YouTube（初期設定で両方にチェック）。緑のドットは接続済みを意味します。接続されていない場合は 未認証 と表示されます。

  • Twitch：新規フォローごとにすぐ通知が表示されます。先に Twitch を接続してください：Twitch 設定。
  • YouTube：新規チャンネル登録者。先に Google でログインしてください：YouTube 設定。

YouTube の登録者の検出方法：

  • YouTube にはリアルタイムの「新規登録者」イベントがないため、アプリは 1.5 分ごとに YouTube へ最近の登録者を問い合わせます。
  • 確認は、配信中で、YouTube ライブチャットがそのライブ配信に接続されている間だけ行われます。待機所や配信終了後には確認しません。
  • 配信開始前に登録した人（確認開始より約 5 分以上前）は通知されません。
  • ページのヒントにあるとおり、YouTube は登録を公開している視聴者のみ通知し、数分〜数時間遅れることがあります。

設定​

項目説明
表示時間各通知が画面に表示される秒数（1–60）。初期値：5。
同じ視聴者は 24 時間に 1 回だけ通知初期設定でオフ。オンにすると、同じ視聴者が 24 時間以内に再びフォローした場合（例：フォロー解除して再フォロー）は表示も記録もされません。

通知のテスト​

テスト通知 (Twitch) または テスト通知 (YouTube) をクリックすると、サンプルの通知を OBS に送信します。テスト通知は履歴に追加されません。

新規フォロワー通知がオフの場合、テストは再生されず、ページに 先にクイック切替で新規フォロワー通知をオンにしてください と表示されます。

外観タブ​

プレビュー​

プレビューには OBS ソースと同じページが使われます。プレビュー の横のカラーピッカーでプレビューの背景を変更し、▶ アニメーションを再生 をクリックすると通知アニメーションをもう一度再生します。

共通スタイル / プラットフォームごとに個別​

  • 共通スタイル：Twitch と YouTube で同じ通知スタイルを使います。
  • プラットフォームごとに個別：プラットフォームごとに専用のスタイルを使います。下のボタンで Twitch または YouTube を選び、その設定を編集します。初めて切り替えたとき、まだカスタマイズしていないプラットフォームには現在の共通スタイルがコピーされ、それぞれ専用のカウントダウンバーの色が付きます。

初期設定に戻す で、編集中のスタイルを初期スタイルに戻します。

画像​

  • 画像を選択：素材管理から画像を選びます。画像がない場合はハートの絵文字が表示されます。クリア で画像を削除します。
  • 画像サイズ：1–400 px。
  • 画像位置：左寄せ、右寄せ、上、下。

サウンド​

内蔵サウンドを選びます：なし、チャイム（初期設定）、コイン、ベル、ポップ、ファンファーレ。▶ をクリックすると試聴できます。サウンドを選択 をクリックすると、素材管理から自分のサウンドファイルを使えます。

カスタムテキスト​

通知に表示する文を書きます。{name} でフォロワー名、{platform} でプラットフォーム名を表示します。空欄にすると既定の文{name} さん、フォローありがとう！が使われます。

テキストと色​

  • テキスト：カスタムテキスト と フォロワー名 のフォント、サイズ、色を設定します。
  • 色：背景、影、カウントダウンバー。

カスタム CSS​

カスタム CSS を展開すると、編集中のスタイル（共通スタイルまたは選択中のプラットフォーム）の CSS を編集できます。初期設定に戻す でテンプレート CSS に戻し、素材を管理 で素材管理を開きます。ここでは Steam Workshop のテーマも適用できます。テーマを適用している間、CSS は読み取り専用です。テーマ を参照してください。

履歴タブ​

両方のプラットフォームの最近の新規フォロワーを、新しい順にプラットフォーム・名前・時刻とともに一覧表示します。履歴はアプリ内にのみ表示され、オーバーレイには表示されません。

  • 最大 100 人まで保存され、30 日より古い項目は自動的に削除されます。
  • クリア をクリックすると一覧を空にします。

:::info 試用版 カスタム CSS は製品版でのみ使用でき、OBS の通知に透かしが表示されます。試用版 / 製品版の比較 を参照してください。 :::

よくある質問​

Q：配信で音が出ません。 ブラウザソースのプロパティで OBS を介して音声を制御する にチェックが入っているか、OBS の音声ミキサーでソースがミュートになっていないかを確認してください。また、サウンド が なし になっていないかも確認してください。

Q：YouTube の登録者の通知が出ませんでした。 通知されるのは公開されている登録のみで、YouTube が反映するまで数分〜数時間かかることがあります。また、アプリが確認するのは、配信中で YouTube ライブチャットが接続されている間だけです。

Q：OBS ソースを後から追加しました。それ以前の通知は再生されますか？ いいえ。新しく開いたソースには、接続後に届いた通知だけが表示されます。それ以前のフォロワーは 履歴 タブで確認できます。
