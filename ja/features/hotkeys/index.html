ショートカット

左メニューの一番下にある ⌨️ ショートカット では、設定済みのすべてのショートカットを一か所で確認できます。

ショートカット一覧​

各行にはキーの組み合わせと、それで実行される操作が表示されます（例：タイマー › （タイマー名） › 開始/一時停止）。行をクリックすると該当機能の設定ページが開き、そこで変更できます。このページではショートカットを編集できません。

まだ何も設定していない場合は「まだショートカットが設定されていません。」と表示されます。

ショートカットに対応している機能​

機能ショートカットの動作
配信ハイライトマーカーマーカーを追加
メディアボード効果音の再生 / 画像の表示 / 動画の再生（項目ごとに 1 つのショートカット）
音声翻訳音声翻訳のショートカット
OBS シーン制御シーン切り替え / ソースの表示切替
タイマー開始／一時停止、ラップ、リセット（タイマーごと）

ショートカットの設定​

配信ハイライトマーカー、OBS シーン制御、タイマー は同じショートカット入力欄を使います。メディアボードと音声翻訳については、それぞれのページを参照してください。

  1. ショートカットのボタンをクリックします
  2. キーの組み合わせを押します（例：Ctrl+Shift+F1）
  3. すべてのキーを離すと保存されます
  • 記録中に Esc を押すとキャンセルできます
  • その組み合わせが別のショートカットですでに使われている場合は、競合メッセージが表示され保存されません。別の組み合わせを選んでください
  • 横にある ✕（またはクリアボタン）をクリックするとショートカットを削除できます
  • テンキーのキーはメインキーボードの数字キーとは別扱いです：Num1 と 1 は異なるショートカットです

ショートカットは Stream Toolkit がバックグラウンドにある間（ゲーム中など）も動作します。
