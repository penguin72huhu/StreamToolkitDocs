抽選

視聴者は Twitch または YouTube のチャットにキーワードを入力して参加します。受付終了後にランダムで当選者を抽選し、抽選アニメーションが OBS オーバーレイで再生されます。

OBS ソース URL​

http://127.0.0.1:7272/lottery

ページ上部の OBS ソース URL の横にある コピー をクリックし、OBS にブラウザソースとして追加します。OBS でソースを追加する方法 を参照してください。抽選は音を再生しないため、「OBS を介して音声を制御する」をオンにする必要はありません。

ヒント

左サイドバーの 抽選 の横にあるスイッチ（OBS 表示をオンにする）もオンにしてください。オフの間、オーバーレイは非表示のままです。

ページには 設定 と 履歴 の 2 つのタブがあります。

設定​

投票プラットフォーム​

Twitch または YouTube をクリックして、どのプラットフォームのチャットから参加できるかを選びます。両方選ぶこともできます。接続されていないプラットフォームには、Twitch は （未接続）、YouTube は チャット URL が未接続です と表示されます。接続方法は Twitch 設定 と YouTube 設定 を参照してください。

抽選キーワード​

このキーワードを含むチャットメッセージを送った視聴者が参加者になります。各視聴者は 1 回の抽選につき 1 回だけ参加できます。キーワードが空の間は 収集を開始 をクリックできません。

抽選時間​

参加を受け付ける時間（秒）。初期値は 300、範囲は 10–3600 です。

参加人数の上限​

この人数に達すると、受付が早めに終了します。0 を入力すると無制限になります。

抽選後に選択肢を削除​

オンにすると、当選者は次の抽選の前に参加者から外され、その抽選で再び当選することはありません。

案内テキスト​

受付中にオーバーレイに表示される案内で、視聴者にキーワードと参加者数を伝えます。フォント、色、サイズ（px）を設定できます。

抽選アニメーション​

  • ID 高速切り替え（初期設定）：受付中は参加者の名前が画面上を漂い、抽選時に高速で切り替わります
    • 収集画面のフォント：フォント、文字サイズ、名前チップの色（最大 5 色）
    • 抽選アニメーションのフォント：抽選中に切り替わる名前のフォントと文字サイズ
    • 初期設定に戻す：これらの設定を元に戻します
  • ルーレットアニメーション：参加者をルーレットに並べ、回して当選者を決めます。配色を選びます：ミニマル または ルーレット で作成したカスタムテーマ

受付中は、プラットフォーム、キーワード、抽選時間、参加人数の上限、抽選後に選択肢を削除、アニメーションの種類を変更できません。

抽選を行う​

  1. 収集を開始 をクリックします。パネルに 収集中…、残り時間、参加者数が表示されます
  2. 受付中は、参加者名を手動入力 に名前を入力して 追加 をクリック（または Enter）できます。すでにリストにある名前の場合は「この ID はすでに名簿にあります」と表示されます
  3. 時間切れの前に受付を終了するには 収集を終了 をクリックします。時間切れや 参加人数の上限 に達したときも受付は終了します。パネルには 時間切れ！ と表示されます
  4. 抽選を開始 をクリックします。オーバーレイでアニメーションが再生され、終わると 当選者 の下に当選者が表示されます
  5. さらに当選者を選ぶには もう一度抽選 をクリックします

どの段階でも 抽選をキャンセル をクリックすると、すべての参加者と当選者がクリアされ、オーバーレイは待機状態に戻ります。

履歴​

履歴 タブには、抽選ごとに時刻、キーワード、参加者数が記録されます。記録を展開すると、当選者と参加者の全リストを確認できます。抽選の履歴は直近 30 日分のみ保存されます。記録を削除するには 🗑 をクリックしてから 削除の確認 をクリックします。

:::info 試用版の制限 OBS オーバーレイに透かしが表示されます。詳しくは 試用版 / 製品版の比較 を参照してください。 :::
