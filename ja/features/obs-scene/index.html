OBS シーン制御

OBS シーン制御 を使うと、グローバルショートカットや クイックツール から、配信ソフトのシーン切り替えやソースの表示/非表示ができます。OBS Studio、Streamlabs、Meld Studio に対応しています。

この機能にはオーバーレイがないため、OBS にブラウザソースとして追加するものはありません。

備考

ショートカットは、サイドバーの OBS シーン制御 スイッチがオンのときだけ動作します。Stream Toolkit のウィンドウがタスクトレイに最小化されていても動作します。

設定ページには 接続設定 と ショートカット設定 の 2 つのタブがあります。

接続設定タブ​

ステップ 1：配信ソフトを選ぶ​

配信ソフト で OBS Studio、Streamlabs、Meld Studio のいずれかを選びます。切断中のみ変更できます。

配信ソフトごとにショートカットとシーン一覧が別々に保存されるため、配信ソフトを切り替えるとそのソフト用の設定が表示されます。

ステップ 2：配信ソフトを準備する​

OBS Studio​

  1. OBS で ツール → WebSocket サーバー設定 を開きます
  2. WebSocket サーバーを有効にする にチェックを入れます
  3. 接続情報を表示 をクリックしてパスワードを確認します
  4. Stream Toolkit で ホスト（初期値 localhost）、ポート（初期値 4455）、パスワード を入力します

Streamlabs / Meld Studio​

設定は不要です。プログラムを起動しておくだけで使えます。

ステップ 3：接続する​

接続 をクリックします。状態 が 接続済み に変わります（OBS と Meld ではバージョン番号も表示されます）。切断 をクリックすると接続を切ります。

起動時に自動接続（初期設定でオン）：Stream Toolkit の起動時と、機能のスイッチをオンにしたときに自動で接続します。機能のスイッチをオフにすると切断します。

シーン​

シーン セクションには、シーンとそれぞれのソース数が一覧表示され、現在のシーンはハイライト表示されます。配信ソフトでシーンを変更した後は、更新 をクリックして最新の一覧を取得してください。

切断中も、最後に取得した一覧が表示されます。

ショートカット設定タブ​

ショートカットを設定するには、クリックしてショートカットを設定 をクリックしてからキーの組み合わせを押します。Esc でキャンセルします。その組み合わせが別の機能ですでに使われている場合は ショートカットの競合 と表示され、保存されません。ショートカットの横の ✕ をクリックするとクリアします。

シーン切り替え​

  1. 追加 をクリックします
  2. ショートカットを設定します
  3. 切り替え先のシーンを選びます

行の末尾の ✕ をクリックすると削除します。

ソースの表示切替​

1 つのショートカットで、同じシーン内の複数のソースをまとめて制御できます。

  1. 追加 をクリックします
  2. ショートカットを設定します
  3. 名前 を入力します（任意。クイックツールのボタン名に使われます。空欄の場合はシーン名が使われます）
  4. ソースが属するシーンを選びます
  5. ソースを追加 をクリックし、ソースを選んで 表示、非表示、切替 のいずれかを選びます（初期値は 切替）
  6. ソースを追加する場合は手順 5 を繰り返します

項目のシーンを変更すると、ソース一覧はクリアされます。

ヒント

配信ソフトに存在しなくなったシーンやソースは赤で表示されます。ドロップダウンから選び直してください。

クイックツールから使う​

機能がオンで、ショートカット項目が 1 つ以上ある場合、クイックツール に OBS シーン制御 カードが表示され、項目ごとにボタンが並びます。ボタンをクリックすると、そのショートカットを押したのと同じ動作をします。

エラーメッセージ​

ショートカットやボタンを使ったときに、次のメッセージが表示されることがあります：

メッセージ意味
OBS に接続されていません未接続です。接続設定 タブで 接続 をクリックしてください
シーン「…」が見つかりません配信ソフトでシーンの名前が変更されたか、削除されています
ソースが見つかりません：…それらのソースはシーンに存在しなくなっています

試用版の制限​

備考

試用版で設定できるショートカット項目は合計 1 つです（シーン切り替えとソースの表示切替の合計）。試用版 / 製品版の比較 を参照してください。

よくある質問​

Q：OBS に接続できないと表示され、OBS を開いた後も再試行されません。 最初の接続に失敗した場合（例えば OBS がまだ起動していなかった場合）、Stream Toolkit は再試行を続けません。配信ソフトを起動してから 接続 をクリックしてください。一度接続に成功すれば、接続が切れても自動で再接続します。
