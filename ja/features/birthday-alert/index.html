視聴者誕生日通知

視聴者の誕生日をリストに登録しておくと、登録した視聴者が誕生日当日またはその少し後に配信中にチャットしたとき、配信画面に誕生日の通知がポップアップ表示されます。各視聴者への通知は 1 回の誕生日につき 1 回です。

OBS ソース URL​

http://127.0.0.1:7272/birthday-alert

視聴者誕生日通知 の設定 ページ上部の URL をコピーし、OBS にブラウザソースとして追加します。OBS でソースを追加する方法 を参照してください。

警告

通知ではサウンドが再生されます。ブラウザソースのプロパティで OBS を介して音声を制御する にチェックを入れないと、配信で音が聞こえません。

左サイドバーの 視聴者誕生日通知 の横にあるスイッチをオンにしてください。オンの間だけ、アプリはチャットに接続して誕生日を照合します。テスト通知 と 再表示 ボタンはオフの間も動作します。

ページには 設定、視聴者リスト、外観 の 3 つのタブがあります。

しくみ​

  • リストに登録された視聴者が、誕生日から設定した日数後までの間にチャットすると通知が表示されます。誕生日より前には何も表示されません。
  • 各視聴者への通知は 1 回の誕生日につき 1 回です。12/28 の誕生日が 1/2 に通知された場合も、前の年の誕生日として数えます。
  • 通知が表示されるのは、視聴者がチャットしたプラットフォームが配信中のときだけです。配信していない間や、配信中かどうかをアプリがまだ判断できない間は、チャットしても通知も記録もされず、次に配信中にチャットしたときに表示されます。
  • YouTube チャットの接続時に読み込まれる過去のチャットは数えないため、アプリを再起動しても、閉じている間にチャットした人は通知されません。
  • 2/29 の誕生日は、うるう年以外では 2/28 になります。

設定タブ​

チャット接続​

機能をオンにすると表示されます。各プラットフォームのチャットが接続されているかを表示します：

  • Twitch：チャンネルが設定されていない場合、Twitch チャンネル未設定です。先に Twitch を連携してください と 設定へ が表示されます。先に Twitch を接続してください：Twitch 設定。
  • YouTube：チャットが接続されていない場合、自動接続 と 手動で入力（設定のチャット URL 欄に移動）が表示されます。自動接続を使っていて Google にログインしている場合は、配信開始後も接続されない場合は、チャットページで「接続」を押してください と表示されます。YouTube 設定 と チャット を参照してください。

プラットフォームが接続されると、配信中、配信していません、配信中か判断できません のいずれかも表示されます。通知は 配信中 のときだけ表示されます。

設定​

項目説明
誕生日から何日後まで通知するか0–30。初期値：7。0 = 誕生日当日のみ。
表示時間各通知が画面に表示される秒数（1–60）。初期値：6。

通知のテスト​

テスト通知 をクリックすると、テスト用の視聴者と今日の日付でサンプルの通知を OBS に送信します。OBS にだけ表示されて記録されず、左サイドバーのスイッチがオフでも動作します。ボタンは一時的に 送信しました に変わります。

視聴者リストタブ​

視聴者を追加する​

視聴者を追加する方法は 2 つあります：

  • + 最近チャットした人から追加：最近チャットした人から選びます。その人の名前がメモ名に、アカウントが紐付け済みの状態で、今日の日付が誕生日に入った状態でフォームが開きます。
  • + 名前で追加：アカウント名を自分で入力します。

最近チャットした人 には、チャット接続中にチャットした視聴者が表示されます（最大 200 人、30 日間保存）。更新 をクリックすると更新します。すでにリストにいる視聴者には 登録済み と表示され、再度選ぶことはできません。リストが長い場合は検索欄が表示されます。

フォームに入力します：

  1. メモ名：あなたが呼んでいる名前（例：Alex）。任意。
  2. 誕生日：月と日（年なし）。
  3. アカウント：1 つ以上のアカウント。1 人の視聴者に複数のアカウント（例：Twitch と YouTube の両方）を登録できます。
    • ＋ アカウントを入力：Twitch または YouTube を選び、名前を入力します。Twitch はログイン名か表示名、YouTube は @ハンドルかチャンネル名を入力します。
    • ＋ 最近チャットした人から：すでに紐付け済みのアカウントを追加します。
    • ✕ でアカウントを外します。
  4. 保存 をクリック（または Enter）します。キャンセル（または Esc）でフォームを閉じます。

入力した名前と紐付け​

入力した名前は、その視聴者が初めて発言したときにアカウントと紐付けられます。照合では大文字・小文字と先頭の @ は区別しません。名前は重複することがあるので、最近チャットした人から選ぶ方が確実です。

YouTube は @ハンドルを入力してください：チャットページで 視聴者名を @ハンドルの代わりに表示 がオンになっていないと、チャンネル名では一致しないことがあります。

リストの各アカウントには次のいずれかが表示されます：

  • 紐付け済み：[名前]：アカウントが紐付けられています。
  • 「[名前]」の発言待ち：入力した名前がまだ紐付けられていません。
  • 新規紐付け：視聴者の発言でアプリがこのアカウントを自動的に紐付けました。本人か確認して ✓ 本人で OK をクリックするか、違う場合は 紐付け解除 をクリックします。
  • このアカウントは「[名前]」に登録済みです：入力した名前が、リスト内の別の視聴者のアカウントと一致しました。1 つのアカウントは 1 人の視聴者にしか登録できないため、ここの名前を変えるか、どちらかを削除してください。

紐付け解除 をクリックすると、アカウントの下に入力欄が開きます。解除後はその欄の名前（変更可能）で照合し、その視聴者が次に発言したときに改めて紐付けます。

リスト​

誕生日の通知期間中の視聴者が先頭に、その後に次に誕生日を迎える視聴者が並びます。視聴者が 5 人を超えると検索欄が表示されます。各視聴者には次のものが表示されます：

  • 発言待ち：誕生日期間中です。チャットで発言するとすぐに通知が表示されます。
  • 🎂 [日付] 通知済み：この誕生日の通知はすでに表示されています。
  • ▶ 再表示：この視聴者の通知を OBS にもう一度表示します。いつでも使え、記録されません。
  • 編集：メモ名、誕生日、アカウントを変更します。誕生日を変更すると、新しい日付で再び通知されるようになります。
  • 削除：削除 をクリックしてから 削除の確認 をクリックします。

外観タブ​

プレビュー​

プレビューには OBS ソースと同じページが使われます。プレビュー の横のカラーピッカーでプレビューの背景を変更し、▶ アニメーションを再生 をクリックすると通知アニメーションをもう一度再生します。

共通スタイル / プラットフォームごとに個別​

  • 共通スタイル：Twitch と YouTube で同じ通知スタイルを使います。
  • プラットフォームごとに個別：プラットフォームごとに専用のスタイルを使います。下のボタンで Twitch または YouTube を選び、その設定を編集します。初めて切り替えたとき、まだカスタマイズしていないプラットフォームには現在の共通スタイルがコピーされ、それぞれ専用のカウントダウンバーの色が付きます。

初期設定に戻す で、編集中のスタイルを初期スタイルに戻します。

画像​

  • 画像を選択：素材管理から画像を選びます。画像がない場合はケーキの絵文字が表示されます。クリア で画像を削除します。
  • 画像サイズ：1–400 px。
  • 画像位置：左寄せ、右寄せ、上、下。

サウンド​

内蔵サウンドを選びます：なし、チャイム（初期設定）、コイン、ベル、ポップ、ファンファーレ。▶ をクリックすると試聴できます。サウンドを選択 をクリックすると、素材管理から自分のサウンドファイルを使えます。

カスタムテキスト​

通知に表示する文を書きます。空欄にすると既定の文{name} さん、お誕生日おめでとう！が使われます。次のプレースホルダーを使えます：

プレースホルダー置き換わる内容
{name}チャットでの視聴者の名前
{label}メモ名（メモ名が空欄の場合はチャットでの名前）
{birthday}誕生日（例：10/20）
{MM} {DD}2 桁の月と日。独自の形式を作れます（例：{DD}/{MM}）
{date}オーバーレイの言語で表した誕生日
{platform}プラットフォーム名

テキストと色​

  • テキスト：カスタムテキスト と 視聴者名 のフォント、サイズ、色を設定します。
  • 色：背景、影、カウントダウンバー。

カスタム CSS​

カスタム CSS を展開すると、編集中のスタイル（共通スタイルまたは選択中のプラットフォーム）の CSS を編集できます。初期設定に戻す でテンプレート CSS に戻し、素材を管理 で素材管理を開きます。ここでは Steam Workshop のテーマも適用できます。テーマを適用している間、CSS は読み取り専用です。テーマ を参照してください。

:::info 試用版

  • リストに登録できるのは最大 3 人です。それより多く登録されている場合（例：製品版のセーブデータ）、超えた分の視聴者は 🔒 でロック表示され、通知は表示されず、編集や再表示もできません。
  • カスタム CSS は製品版でのみ使用できます。
  • OBS の通知に透かしが表示されます。

試用版 / 製品版の比較 を参照してください。 :::

よくある質問​

Q：配信で音が出ません。 ブラウザソースのプロパティで OBS を介して音声を制御する にチェックが入っているか、OBS の音声ミキサーでソースがミュートになっていないかを確認してください。また、サウンド が なし になっていないかも確認してください。

Q：視聴者が誕生日にチャットしたのに通知が表示されませんでした。 左サイドバーのスイッチがオンになっているか、設定 タブの チャット接続 でそのプラットフォームが 配信中 になっているか、リストのアカウントが 紐付け済み になっているか、または入力した名前がチャットでの名前と一致しているかを確認してください。OBS を開いていない間に表示された場合は ▶ 再表示 を使ってください。

Q：OBS ソースを後から追加しました。それ以前の通知は再生されますか？ いいえ。新しく開いたソースには、接続後に届いた通知だけが表示されます。もう一度表示するには 視聴者リスト タブの ▶ 再表示 を使ってください。
