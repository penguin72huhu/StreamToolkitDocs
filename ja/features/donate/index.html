支援目標バー

支援目標に向けたプログレスバーを配信画面に表示します。選んだプラットフォームからの支援は自動的に合計に加算されます。

OBS ソース URL​

http://127.0.0.1:7272/donate

支援目標バー の設定 ページ上部の URL をコピーし、OBS にブラウザソースとして追加します。OBS でソースを追加する方法 を参照してください。

左サイドバーの 支援目標バー の横にあるスイッチで、OBS でのバーの表示/非表示を切り替えます。オフの間、バーは非表示になります。

通貨​

バーには 設定 ページで設定した サポート通貨 が使われます。他の通貨の支援は、この通貨に換算してから加算されます。換算できない通貨の支援はバーに加算されません（支援通知と支援履歴ボードには元の通貨のまま表示されます）。

設定タブ​

連携プラットフォーム​

バーに加算する支援のプラットフォームにチェックを入れます：

  • Twitch — Bits とサブスク
  • YouTube
  • PayPal
  • Stripe
  • O'Pay
  • ECPay

緑のドットは接続済みを意味します。接続されていない場合は （未接続） と表示されます。これらのチェックボックスはバーで数える対象だけを決めるもので、支援通知や支援履歴ボード（それぞれ独自のプラットフォーム一覧があります）には影響しません。

  • YouTube：ライブチャットが連携されていない場合、チャット URL が未接続です と 2 つのボタンが表示されます：自動接続（Google ログインが必要）と 手動で入力（設定のチャット URL 欄に移動）。YouTube 設定 を参照してください。
  • YouTube ⚙️：バーに加算する カウント対象 を選びます：スーパーチャット、スーパーステッカー、メンバー加入、メンバー継続、ギフト メンバーシップ、ジュエル。ジュエル には Google ログインが必要です。
  • メンバーシップのイベントにチェックを入れているのにメンバー価格が設定されていない場合、⚠ メンバー価格が未設定 が表示されます。クリックすると設定に移動し、YouTube の 換算設定 で等級の価格を入力できます。
  • Twitch の Bits とサブスクの金額は、設定 → Twitch → 換算設定 で設定します。Twitch 設定 を参照してください。
  • PayPal、Stripe、O'Pay、ECPay の接続方法は PayPal、Stripe、O'Pay、ECPay を参照してください。

現在の進捗​

現在の合計、目標、パーセントを表示します。

項目説明
タイトル任意。バーの上に表示されます。
目標金額目標金額（サポート通貨）。
手動追加金額を入力して 追加 をクリック（または Enter）すると合計に加算されます。
リセット現在の合計をゼロに戻します。先に確認が表示されます。元に戻せません。

外観タブ​

プレビュー​

プレビューにはサンプル金額でバーが表示されます。プレビュー の横のカラーピッカーでプレビューの背景を変更できます。達成プレビュー にチェックを入れると、達成状態のバーを確認できます。

フォントと色​

初期設定に戻す をクリックすると、初期の外観に戻ります。

  • フォント：タイトル、金額、%表示 のフォント、色、サイズ（8–72 px）を設定します。
  • 色：背景、目標バー（進捗部分の色）、目標バー達成（目標達成後の進捗部分の色）を設定します。

カスタム CSS​

カスタム CSS を展開すると、バーの CSS を編集できます。初期設定に戻す で初期 CSS に戻し、素材を管理 で CSS に使う画像の素材管理を開きます。ここでは Steam Workshop のテーマも適用できます。テーマを適用している間は、元に戻すまで CSS は読み取り専用です。テーマ を参照してください。

:::info 試用版 カスタム CSS は製品版でのみ使用できます。実際の決済サービス（PayPal / Stripe / O'Pay / ECPay）と YouTube のメンバーシップイベント・ジュエルは試用版では使用できず、オーバーレイに透かしが表示されます。試用版 / 製品版の比較 を参照してください。 :::

よくある質問​

Q：テスト通知を送ったら合計が増えました。 設定ページの テスト通知 は実際の支援として扱われるため、（そのプラットフォームにチェックが入っていれば）バーに加算されます。テスト後は リセット をクリックして合計をゼロに戻してください。
