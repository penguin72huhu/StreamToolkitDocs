クイックツール

クイックツール は、ゲームや OBS の横に開いておける小さな操作ウィンドウです。メインウィンドウに切り替えなくても、機能のオン/オフやよく使う操作ができます。

クイックツールを開く​

次のどちらかの方法で開きます：

  • メインウィンドウの左サイドバー上部にある ⚡ クイックツール をクリックします
  • Stream Toolkit のタスクトレイアイコンを右クリックし、クイックツールを開く を選びます

ウィンドウがすでに開いている場合は、2 つ目を開かずに既存のウィンドウが前面に表示されます。

ウィンドウ​

  • 移動：タイトルバーをドラッグします
  • 📌 ピン留め / ピン留めを解除：ウィンドウを他のウィンドウより手前に表示し続けます。ウィンドウを開いたときはピン留めがオンです
  • ✕：ウィンドウを閉じます

ウィンドウはアプリのテーマと表示言語に従います。

クイックスイッチパネル​

左端の › 矢印をクリックすると クイックスイッチ パネルがスライドして開きます。すべての機能が一覧表示されます：

  • スイッチで機能をオン/オフします（メインサイドバーの各機能の横にあるスイッチと同じ）
  • ⚙（設定を開く）でメインウィンドウを表示し、その機能の設定ページを開きます

パネルの外側をクリックするか、もう一度矢印をクリックすると閉じます。

機能はメインサイドバーと同じ順番で並びます。順番を変更するには、メインウィンドウのサイドバーで機能の横にある ⠿ ハンドルをドラッグします。

機能カード​

操作項目がある機能は、有効にするとカードとして表示されます。カードは最初は折りたたまれており、カードのタイトルをクリックすると展開/折りたたみできます。これらの機能がどれもオンになっていない場合は 有効な機能がまだありません と表示されます。

機能カードでできること
OBS シーン制御接続状態と、設定したシーン切り替え・ソースの表示切替ごとのボタン（現在のシーンはハイライト表示）。未接続の間はボタンを押せません。ショートカット項目が 1 つ以上あるときだけカードが表示されます
音声翻訳REC ボタン — 押している間録音し、離すと翻訳します
配信ハイライトマーカーMARK ボタン。マーク後、プラットフォームアイコンとタイムスタンプが 5 秒間表示されます
支援目標バー現在額 / 目標額とプログレスバー、金額を手動追加 欄と 追加、リセット
タイマー表示中の各タイマー：名前、時間、開始 / 一時停止、リセット、設定した時間追加ボタン。ストップウォッチでは代わりに 停止 と ラップ が表示されます
ルーレット表示中の各ルーレット：スタート と リセット
メディアボードピン留めした画像（表示 / 非表示）、ピン留めした動画（再生）、ピン留めした効果音（再生）のボタン
リクエスト曲再生 / 一時停止、停止、次の曲

操作にショートカットが割り当てられている場合は、そのボタンにショートカットが表示されます。

ここで操作するものがない機能（チャット、Twitch 目標バー、支援通知、支援履歴ボード、時計、エモートウォール、リアルタイム投票、抽選、チャットボット）は、クイックスイッチパネルのオン/オフスイッチのみです。

ヒント

支援目標バーのカードの リセット は 2 回クリックが必要です：1 回目でボタンが リセットを実行 に変わり、10 秒以内にもう一度クリックすると金額がゼロになります。

備考

タイマーとルーレットは各機能の 表示モード に従います：単一タイマー / 単一ルーレット では現在選択中のものだけが表示され、複数タイマー / 複数ルーレット では追加したものだけが表示されます。1 つもない場合、カードには タイマーがありません / ルーレットがありません と表示されます。
