聊天室

聊天室 把 Twitch 與 YouTube 的聊天訊息合併顯示在同一個 overlay，並可自動翻譯。也能把聊天室顯示在只有你自己看得到的透明桌面視窗。

OBS 來源網址​

http://127.0.0.1:7272/chat

以瀏覽器來源加入 OBS：如何在 OBS 加入來源。這個 overlay 沒有聲音。

資訊

左側選單的 聊天室 開關開啟時，訊息才會送到 overlay。關閉時仍會接收聊天訊息，所以投票、抽獎、點歌等讀取聊天室的功能照常運作。

開始之前​

先連接要顯示的平台：

  • Twitch 設定
  • YouTube 設定

設定頁分成 設定 與 外觀 兩個分頁。

設定分頁​

平台​

  • 顯示平台 icon（Twitch / YouTube）：在每則訊息前顯示 ／ 圖示

每個平台各有一張卡片。平台名稱旁的圓點在已連接且已啟用時會亮綠燈；Twitch 未連接時顯示 （未連接），YouTube 未連結聊天室時顯示 未連結聊天室網址。

選項說明
啟用聊天室顯示這個平台的訊息
顯示頭像顯示觀眾頭像
顯示徽章（Twitch）／顯示徽章（會員圖示）（YouTube）顯示徽章
顯示觀眾名稱而非 @代稱僅 YouTube。登入 Google 後才能勾選

YouTube 已啟用但尚未連結聊天室時，卡片上會出現兩個按鈕：

  • 自動連結：自動找到你目前的直播（需先登入 Google）
  • 手動填寫：跳到設定頁貼上聊天室網址

最多訊息數：畫面上保留的訊息則數（5–200，預設 50）。

自動翻譯​

  1. 勾選 啟用翻譯
  2. 目標語言：訊息要翻譯成的語言。預設 跟隨介面語言，使用 App 的介面語言
  3. 不翻譯的語言（選填）：勾選的語言不會被翻譯。葡萄牙文 PT-BR／PT-PT 無法區分，勾選其一等於兩者都略過

翻譯服務 為 MyMemory，不需要 API Key。

  • Email（選填）：不填每日額度為 5,000 字元；填入 email 並按 儲存 可提升至每日 50,000 字元（免費，不需在 MyMemory 註冊）
  • 下方進度條顯示今日的粗估用量，每日 UTC 08:00 重置

測試​

  • 發送測試訊息：送出一則隨機範例訊息到 overlay
  • 清除：清空 overlay 上的所有訊息

若出現 連線失敗，伺服器可能未啟動，表示 Stream Toolkit 的本機伺服器沒有回應。

桌面聊天室視窗​

將聊天室以透明、置頂的小視窗疊在遊戲畫面上，只有你自己看得到，適合單螢幕直播。

  1. 點 開啟視窗（或在系統匣圖示按右鍵，選 開啟桌面聊天室）
  2. 未鎖定時，拖曳上方橫條移動視窗、拉邊框調整大小
  3. 擺好後點 🔒 鎖定，滑鼠會穿透視窗直接操作遊戲。要解鎖時，把滑鼠移到視窗上，點右上角出現的 🔓；或在設定頁點 🔓 解鎖

重設位置 會把視窗移回預設位置。

設定說明
外觀樣式僅名字＋內容（預設）或 與 OBS 聊天室相同
字級12–32 px，預設 16。僅 僅名字＋內容 樣式可設定
文字不透明度10–100%，預設 100%
背景不透明度0–100%，預設 40%
訊息淡出0–120 秒，預設 0。每則訊息顯示設定秒數後淡出，淡出的訊息無法再捲回查看。設為 0 則不淡出，解鎖時可往上捲動查看先前的訊息（最多保留「最多訊息數」則）
在直播畫面中隱藏預設開啟。OBS「顯示器擷取」拍不到這個視窗，觀眾不會看到兩份聊天室。截圖與 Discord 分享畫面也會看不到它
提示

若在遊戲全螢幕時看不到這個視窗，請把遊戲改成「無邊框視窗」或「視窗化」模式。可按 發送測試訊息 確認視窗的位置與大小。

外觀分頁​

預覽​

分頁上方是即時預覽。預覽 旁的顏色選擇器只改變預覽的背景色；頭像、徽章、平台 icon 勾選框只影響預覽顯示的內容。

外觀設定​

恢復預設 會還原為預設外觀（若有套用主題，則還原為主題的外觀）。

  • 出現方向：上到下、下到上（預設）、左到右、右到左
  • 文字：暱稱 與 訊息 分別設定
    • 字型、字級（px）、顏色。暱稱可選 原始顏色（觀眾在平台上的顏色）或 自訂顏色
    • 外框：顏色、透明度、粗度
    • 陰影：顏色、透明度、模糊、X／Y 位移
  • 圖示大小：平台icon、頭像、徽章 的縮放倍率（0.1–5x）
  • 顏色：每則訊息的 背景顏色

自訂 CSS​

展開 自訂 CSS 可直接編輯 overlay 的 CSS。管理素材 可上傳圖片供 CSS 引用。恢復預設 會還原預設 CSS。另請參考 主題樣式。

提示

若自訂 CSS 用 !important 設定了外觀設定中的某個欄位，該欄位會變成灰色無法調整（「此設定由自訂 CSS 操控」）。已套用主題時 CSS 為唯讀，請先還原再編輯。

試用版限制​

資訊
  • 開啟自動翻譯時，聊天室 overlay 會加上浮水印
  • 自訂 CSS 僅限正式版
  • 桌面聊天室視窗 僅限正式版

詳見 試用版 / 正式版比較。
